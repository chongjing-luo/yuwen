# 规范参考原件库

本目录只保存具有来源记录、可核验版本和明确使用边界的参考材料。教材、课标等规范输入进入 `work/knowledge/_meta/`；高考候选批次因来源等级和缺口不同，先进入 `Data/reference/gaokao/registry/` 独立登记，不能直接支撑官方命题结论。

| 子目录 | 当前状态 | 用途 |
|---|---|---|
| `curriculum/` | 已有现行课标官方PDF及解析包 | 课程定位、任务群、核心素养与学业质量表现 |
| `junior/` | 待收集 | 初高中纵向关联的规范依据 |
| `policy/` | 待收集 | 四川用卷和考试政策 |
| `gaokao/` | 已建立批次 | 2011—2025四川卷/四川适用卷；2012—2025可得试卷已渲染、校验并完成 MinerU 解析；2011原页失效需补源 |
| `teacher_books/` | 部分取得 | 必修下册教师用书已在 `Data/textbook/` 并完成解析；其他册待补，检索入口与排除理由见该目录 README |

不得把搜索结果链接、AI输出或第三方题库直接当作规范Artifact。
