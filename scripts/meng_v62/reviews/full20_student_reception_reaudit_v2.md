# 《氓》V6.2现有20页学生接收独立复审 V2

## 结论先行

本轮把旧审查结论全部视为历史，只按普通高中学生真实上课顺序，重新阅读现行三套PPT及备注、教学母版、完整逐字稿和学生材料；没有读取视觉审查者的结论。

总体判定：**REWRITE**。20页中没有P0，但有1页P1、3页P2：

| 处置 | 页数 | 页面 |
|---|---:|---|
| PASS | 16 | O01、O03—O09、C101—C105、C202、C204、C206 |
| REWRITE | 2 | O02、C201 |
| MERGE | 2 | C203→C202、C205→C204 |
| DELETE | 0 | 无 |

| 严重度 | 页数 | 含义 |
|---|---:|---|
| P0 | 0 | 无安全或根本性失效 |
| P1 | 1 | O02的全班串行参与结构会显著损害接收质量与时间 |
| P2 | 3 | C201材料—动作错位；C203、C205程序比例及相邻页冗余 |
| P3 | 16 | 可保留，但有真实课堂待观察项 |

最重要的判断：

1. O01确实支持从初高中课文、小说和整本书广泛回忆爱情/婚姻作品，也没有向学生索要无框架深析；但“它写了什么”更容易得到情节梗概而非主题，属于P3观察。
2. O02形式上让全员开口，实质上却让每人只说约十秒、其余时间串行等待。后半程很可能出现重复、低质量补充、轮次焦虑和听觉疲劳；“全员公开发言”不等于“多数人高质量参与”。这是本轮唯一P1。
3. O03把抽象和分类责任放在教师，不要求学生在没有框架时深析；其诚实分支允许现场材料不足时承认不足，设计边界成立。
4. 第一章整体接收链清楚，五页均可保留；C103、C104时长是否与单句/两句增益相称，需要试教。
5. 第二章C202和C203连续用11分钟处理同两句，C203的闭眼听辨有价值，但无需独立六分钟页面；C204和C205连续用9分钟处理婚事由占问到迁嫁，C205的对称拆句可压入C204后半。C201另有“先在教材写三个动作，发03A后卡上同一栏却未被明确填写”的作品落点错位。

## 逐页学生接收审查

### O01｜我们还记得哪些爱情与婚姻故事？——PASS / P3

- **进页前我知道什么**：我只知道要开始新课，还没有《氓》题名、标准篇目或主题分类。
- **第一眼看到什么**：一个宽泛但清楚的回忆问题，以及“篇名—它写了什么”的开放行线；没有教师预列答案。
- **我实际做什么、是否多数人参与**：我独立回忆初高中课文、小说或整本书，写篇名和一句朴素说明。两分钟静默保证每个人都有动作；想不起可翻目录或诚实留空，多数人可以真实参与。
- **我会怎么想、有什么情绪**：入口低压，但记忆较弱者仍可能因别人未知的进度而焦虑；目录恢复路径能缓解。题干“写了什么”通常先唤起情节，不必强装深刻主题。
- **可见作品**：O01回忆单上的个人篇目与自然话。
- **教师如何据实收束**：只确认每人有一项或有恢复路径，不讲主题、不列范文。
- **下页是否真的调用**：O02直接要求读取这张清单，并允许听到新作品后补写，调用真实。
- **删/并损失**：删除会使O02退回少数快反应学生主导；不宜并入公开发言页，因为个人安静检索必须先发生。
- **P3观察**：记录空白率、翻目录比例，以及学生写的是情节还是可辨主题；不要把“朴素说明”升级为尚无框架的深析。

### O02｜把故事说给全班听——REWRITE / P1

- **进页前我知道什么**：我有一张可能只有一项、也可能仍空白的个人清单。
- **第一眼看到什么**：一句容易开口的句式“《____》写了____”，没有复杂规则。
- **我实际做什么、是否多数人参与**：全班按固定座位依次每人说约8—10秒；我在未轮到时听别人并补一项。形式上人人得到一次公开发言，但40—50人会形成约10分钟串行队列：每个人的主动认知仅十秒，其余大多是等待。
- **我会怎么想、有什么情绪**：前段可能新鲜，后段很容易疲劳；重复篇目越来越多，学生会为了“另一层意思”临时加工低质量差异。轮次临近时会预演自己的句子而少听别人；空白者即便可说“先听”，仍承受全班暴露压力。
- **可见作品**：教师黑板上的篇名—原话长卷，以及个人新增项。教师同时听、判断、压缩、书写几十条内容，记录准确度难保证。
- **教师如何据实收束**：脚本要求不分类，只记原话，这是正确边界；但在串行高流量中很难忠实保存每人的措辞。
- **下页是否真的调用**：O03会引用黑板条目，调用合同存在；若O02记录失真或后半质量下降，O03的输入也会变弱。
- **删/并损失**：完全删除会失去公共文学池，但保留现结构的成本过高。
- **改写方向**：改为“个人检索→两人互说→四人汇总2—3篇及各自主题→全班只收集不重复作品与代表性不同说法”。每个人仍真实开口，但开口发生在同桌/小组并行阶段；全班公共阶段控制6—8条，教师能准确记录。不要坚持“全员逐一对全班说”作为参与证明。

### O03｜从相遇，走进共同生活——PASS / P3

- **进页前我知道什么**：我刚听到班级中的多个作品和朴素说法，但这些内容仍是散点。
- **第一眼看到什么**：实际流程先看黑板长卷，教师归纳后才出现“从相遇，走进共同生活”的转场句。
- **我实际做什么、是否多数人参与**：我听教师逐项指回真实篇名与原话，核对归纳是否贴切；可补充一处。不是每个人必须再次发言，但人人有可核对对象，参与方式合理。
- **我会怎么想、有什么情绪**：如果教师真的引用同学原话，我会感觉前页不是走程序；若直接念预设结论，则会感觉我的作品只是装饰。
- **可见作品**：被教师现场改写过的班级主题谱及照片。
- **教师如何据实收束**：分类责任由教师承担，并允许学生指出说窄之处；现场主题单一时承认“多数停在相遇”，不伪造婚姻主题，边界正确。
- **下页是否真的调用**：O04用“一位更早的女子回望婚姻”接入新文本；以后全文讨论计划再读主题谱，近端调用成立。
- **删/并损失**：删除会让O02成为篇目堆积；不宜并入O02边说边分，否则教师分类会反向控制后续发言。
- **P3观察**：O02改写后同步调整本页输入；记录教师能否在4分钟内逐条指回而非套用预制主题。

### O04｜氓——PASS / P3

- **进页前我知道什么**：我已从旧作品走到“婚姻和共同生活”这一新阅读方向，但尚不知道新课题名。
- **第一眼看到什么**：极简题名、读音和《诗经·卫风》，形成真实揭题停顿。
- **我实际做什么、是否多数人参与**：我注音、翻书、定位“氓之蚩蚩”；这是全员低门槛动作。
- **我会怎么想、有什么情绪**：长时间公共交流后终于进入新文本，会有聚拢和松一口气的感觉；题义被暂缓，不会马上被知识压住。
- **可见作品**：教材题名旁注音与第一句定位。
- **教师如何据实收束**：只正音、报出处并说是一位女子回头讲婚姻，不预讲结局。
- **下页是否真的调用**：O05立即从第一句连续听读，调用直接。
- **删/并损失**：删除会使旧作品讨论与原诗听读直接碰撞；并入O05会削弱揭题停顿。
- **P3观察**：若O02仍超时，本页最容易被仓促压缩；应保护这一分钟。

### O05｜第一次完整听读·第一至第三章——PASS / P3

- **进页前我知道什么**：知道题名、读音、最低出处和女子回望婚姻，尚未收到三问或悲剧原因框架。
- **第一眼看到什么**：前三章原诗和“眼随声走”，原诗是主对象。
- **我实际做什么、是否多数人参与**：跟随教师声音连续阅读，在教材某句旁点点或留问号。人人有动作，走神者可从行首重新进入。
- **我会怎么想、有什么情绪**：文言密度高，可能掉队；不被当场追问分析降低防御感，但“边听边标停顿”仍会分散少数学生。
- **可见作品**：前三章个人停顿记号或问号。
- **教师如何据实收束**：不解释、不总结，第三章末无声切页。
- **下页是否真的调用**：O06连续完成全诗；O07把六章停顿转成自然话，调用成立。
- **删/并损失**：不能删除；与O06是同一次完整听读的物理分页，逻辑上已合并，不应再插入问题。
- **P3观察**：记录文言跟读掉队率和行首提示的恢复效果。

### O06｜第一次完整听读·第四至第六章——PASS / P3

- **进页前我知道什么**：故事已从初见走到迁嫁与劝诫，但还没听到婚后事实和结尾。
- **第一眼看到什么**：后三章原诗，版式延续前页。
- **我实际做什么、是否多数人参与**：继续随声读到末句，十五秒静默后确认停顿处；允许无记号。
- **我会怎么想、有什么情绪**：后半事实与“亦已焉哉”可能带来压抑、惊讶或困惑；静默给真实反应留空间，不强迫表态。
- **可见作品**：全诗范围的个人停顿句或问号。
- **教师如何据实收束**：不立即解释情感，只提示看回自己的记号。
- **下页是否真的调用**：O07立刻要求选择停顿句并写自然反应。
- **删/并损失**：不能删除；与O05共同构成完整接收。
- **P3观察**：记录后半段跟读持续度，以及静默是否被课堂噪声或教师急于讲话破坏。

### O07｜把第一次听见的《氓》留在纸上——PASS / P3

- **进页前我知道什么**：已完整听过六章并有个人停顿，但还没有三问。
- **第一眼看到什么**：引句空白和“我看见/我听见/我想问”，没有情绪词清单或标准主题。
- **我实际做什么、是否多数人参与**：听读后才拿到初听卡；个人抄一句、写一句自然话，再与同桌各说一次。书面和双人通道覆盖多数人，尚未找到者可诚实保留。
- **我会怎么想、有什么情绪**：比全班公开更安全；允许“尚未找到”避免假感受，但55秒抄诗加写话对慢写者偏紧。
- **可见作品**：初听卡、同伴不同注意点和黑板右侧两三个真实关键词。
- **教师如何据实收束**：只读真实文字，不公布主题。
- **下页是否真的调用**：O08开始仍停留本页，先逐项引用黑板真实文字后才切页发三问，调用很近且具体。
- **删/并损失**：删除会让三问覆盖个人第一反应；不宜并入O08。
- **P3观察**：记录55秒完成率、真实空白率和教师引用是否可追溯到具体学生文本。

### O08｜读懂六章，我们要回答什么？——PASS / P3

- **进页前我知道什么**：我有自己的初听句，也听过同桌；还未被要求解释全诗原因。
- **第一眼看到什么**：实际先听教师引用O07，再看到经历、婚后生活、婚姻原因三问。
- **我实际做什么、是否多数人参与**：核对引用来源并保存三问；此刻不回答。人人能保存书签，认知负担可控。
- **我会怎么想、有什么情绪**：问题大，但因已完整听读，不是毫无文本经验的空降深析；“先不回答”降低压力。
- **可见作品**：后发的三问书签和可能标注的初步判断。
- **教师如何据实收束**：只说明三问分别跟事实、具体日子和累积证据走，不提供答案框架。
- **下页是否真的调用**：第一、二章材料多次标明全文后取回；当前20页内第一问通过故事轨道逐步积累，后用部分成立。
- **删/并损失**：删除会使逐章活动缺少全文方向；不宜提前并入O01—O04。
- **P3观察**：后续章节必须真实回到原措辞，否则书签会成为一次性仪式。

### O09｜只带三块路标，走进第一章——PASS / P3

- **进页前我知道什么**：已听完整诗、保存个人反应和三问，但作品从属与叙述者身份尚不稳。
- **第一眼看到什么**：《诗经》—风—《卫风》—《氓》的从属链，以及独立的“女子第一人称回望”。
- **我实际做什么、是否多数人参与**：听最低知识说明，在教材写两行；两名学生复述，全班只补遗漏。人人书写，公共发言不冒充全员参与。
- **我会怎么想、有什么情绪**：信息量可控，知识与刚听到的“我”相连，不像突然插入文学史测验。
- **可见作品**：教材题名旁的出处链与“女子回望”。
- **教师如何据实收束**：只校准总集、305篇、风雅颂归属和讲述者，不扩展。
- **下页是否真的调用**：C101立即以女子称男子为“子”和行动主体为基础读第一章。
- **删/并损失**：删除会造成身份误认；拆分会打断故事，现有合页合理。
- **P3观察**：“三块路标”与台词“两类路标”表述略有差异，但不影响接收；可统一措辞。

### C101｜第一章完整初读与行动主体——PASS / P3

- **进页前我知道什么**：知道讲述者是女子，且已听过全诗；第一章词义与人物判断仍未校准。
- **第一眼看到什么**：完整五行原诗以及圈他、划她、留问号的简单任务。
- **我实际做什么、是否多数人参与**：听教师读、自己整章读并圈划；同桌只核主体。每人都有纸面证据，生词可留问号，多数人能参与。
- **我会怎么想、有什么情绪**：任务明确、低评价；但未释义文言中辨“动作”会让部分学生不确定。
- **可见作品**：03A和教材中的行动圈划、问号与一处修订。
- **教师如何据实收束**：引用两条真实动作，只给“有人来、有人送、谈婚事”的粗轮廓。
- **下页是否真的调用**：C102—C104逐句处理初稿，C105重建全章。
- **删/并损失**：删除或并入C102会失去整章先行与未知状态。
- **P3观察**：统计主体误判与问号，不把困难误读成“不认真”。

### C102｜贸丝到谋婚——PASS / P3

- **进页前我知道什么**：知道男子来、女子叙述，但六个古词和来意转折尚不准确。
- **第一眼看到什么**：两句原诗和三个开放问题，没有译文与人格标签。
- **我实际做什么、是否多数人参与**：先独立自然口译70秒并圈转折字，再分读、听同桌、听教师校词、修订。人人有可写入口。
- **我会怎么想、有什么情绪**：先写后校准可能有不确定感，但允许“谁做什么”和保留准确原话，风险可控。
- **可见作品**：03B自然口译、转折字、修订和教材词旁批注。
- **教师如何据实收束**：引用学生表达后才解释词义，限定“蚩蚩”只是出场印象，不倒灌终局。
- **下页是否真的调用**：C105旁白明确取回“他怎样来”。
- **删/并损失**：旧碎页已合理合并；并入C103会混淆叙事转折与空间动作。
- **P3观察**：六分钟动作较多，需记录公开示例前真实完成率。

### C103｜送—涉—至的空间行迹——PASS / P3

- **进页前我知道什么**：知道来意已到谋婚，尚未具体感受女子送行的空间长度。
- **第一眼看到什么**：原句和三个相隔的原词，无路线答案、地图和情绪标签。
- **我实际做什么、是否多数人参与**：手指预走、用笔连接、补主体、说自然话；同桌只查三个动作。动作具体，绝大多数可参与，不愿画者可指读。
- **我会怎么想、有什么情绪**：身体动作有助于看见距离，也可能让熟练学生感觉为一句诗投入过多程序。
- **可见作品**：学生自己的送行线与空间叙述。
- **教师如何据实收束**：只校准涉、淇、顿丘并引用不同自然话，不统一情绪。
- **下页是否真的调用**：C105取回“她怎样送”；全文后计划用原词讨论投入。
- **删/并损失**：删除会压平送、涉、至；感官通道与相邻页不同，现阶段不建议合并。
- **P3观察**：五分钟用于一句诗是否带来可见复述增益；若无增益，再考虑压缩而非先删页。

### C104｜四小句怎样把婚事继续说下去——PASS / P3

- **进页前我知道什么**：只知道送到顿丘、婚事未当场定下；前页中性转场没有预告解释/安抚/约期。
- **第一眼看到什么**：完整两句、开放问题和四个空格，没有三层分类、译文或后来暴力。
- **我实际做什么、是否多数人参与**：90秒用自己的词处理四小句并合并意思；读听交换后分享，教师再校词与归纳。人人有书写和双人角色，暂不愿读者可先听。
- **我会怎么想、有什么情绪**：古词未校前先分句较难，但可逐句写“在说什么”；“无怒”会引发警觉，脚本及时限制证据边界。
- **可见作品**：四句功能、合并理由、声音标记、听者反馈与“无怒”问号。
- **教师如何据实收束**：学生表达之后才归纳解释、安抚、约期；保留学生措辞，不强迫二稿变化。
- **下页是否真的调用**：C105要求讲婚事怎样暂缓又约定；问号留给全文后。
- **删/并损失**：两句应保持同一话轮；并入C105会混淆有支架生成和撤答检索。
- **P3观察**：七分钟是否过长，以及学生在校词前的四句概括是否真有内容而非空填。

### C105｜第一章撤答重建——PASS / P3

- **进页前我知道什么**：第一章局部已经处理，但不知道离开纸面能否连续讲成故事。
- **第一眼看到什么**：完整原诗供最后重读，右侧只有来、送、暂缓又约定三个检索范围。
- **我实际做什么、是否多数人参与**：重读后合教材、03A/03B同时翻背、同桌互查、B键熄屏，再两人各讲30秒；查漏后只开教材定位、合书补说，最后只恢复03B写轨道。人人必须说和写，参与真实。
- **我会怎么想、有什么情绪**：黑屏会提高检索压力，但三条口头范围与“可先讲最确定一段”提供可接受支撑。
- **可见作品**：遗漏、定位、补说、第一章轨道格、自然章意和回看词。
- **教师如何据实收束**：引用两条现场章意，只修事实断点，公共整理发生在学生写作后。
- **下页是否真的调用**：C201开头明确先看第一格，调用直接。
- **删/并损失**：删除会让前三个局部活动不整合；不能并入C104。
- **P3观察**：记录材料互查与熄屏执行、30秒连贯度及“没有遗漏”的真实比例。

### C201｜第二章整读与视线——REWRITE / P2

- **进页前我知道什么**：第一章轨道第一格已形成，故事停在秋期约定；第二章细节尚未处理。
- **第一眼看到什么**：第二章五句全文和“哪一句让等待有了位置”，没有先突出哭笑、卜筮或迁嫁。
- **我实际做什么、是否多数人参与**：先听读、整读，并在教材边写三个动作；之后才收到03A，再口译首句、画视线、同桌核站位方向。人人有动作，但五分钟内经历“轨道回看—听读—教材动作—发卡—口译—画线—互查—四词校准”，切换偏多。
- **我会怎么想、有什么情绪**：视线任务能把等待放进空间；但发下的03A顶部又要求“我最确定的三个动作”，教师没有明确让我把刚写在教材的动作转入该栏，我会不知道这一栏现在填不填。
- **可见作品**：脚本实际留下教材三个动作、03A自然话和视线；母版却把“三个动作初稿”也声明在03A，作品位置不一致。
- **教师如何据实收束**：引用动作原词、校准四词，再以垝垣→复关收束，内容据实。
- **下页是否真的调用**：C202真实取回同一视线；C206声称取回“三个动作和视线自然话”，但动作究竟在教材还是03A不清。
- **删/并损失**：整章先行与视线都不可删，且合理合在一页；问题在动作与材料流程，不应删除或再合并。
- **改写方向**：二选一并写死：要么完整读后立即发03A，在03A写三个动作再做视线；要么动作只留教材并删除03A重复栏。同步统一“证据位置”和C206取回口令，减少一次无效转写。

### C202｜不见与既见的文本对照——PASS / P3

- **进页前我知道什么**：女子站在垝垣望向复关；见与不见的词义和动作转折尚未校准。
- **第一眼看到什么**：上下两句完整对照和三个自然问题，没有伤心/高兴标签或完成表格。
- **我实际做什么、是否多数人参与**：个人口译、圈相照应原词、上下对读、听教师后补回原词。书面与双人任务覆盖多数人。
- **我会怎么想、有什么情绪**：不见—既见、泣涕—笑言很容易发现，涟涟和载的语势需要教师点拨；难度有梯度。
- **可见作品**：两句自然话和原词对照。
- **教师如何据实收束**：学生分享后才释义，要求情绪标签回到触发条件和动作。
- **下页是否真的调用**：C203直接用圈出的词做朗读，C206取回变化；调用真实。
- **删/并损失**：不能删；但可在本页后半直接加入一次简短盲听，从而吸收C203。
- **P3观察**：圈词是否变成“把所有词都圈上”，以及学生能否说清触发关系。

### C203｜闭眼听见转折——MERGE into C202 / P2

- **进页前我知道什么**：刚用5分钟处理同两句，已完成口译、圈词、对读和回读。
- **第一眼看到什么**：仍是同两句，新增“只标一处—闭眼听—报原词”的三步程序。
- **我实际做什么、是否多数人参与**：个人设计一处声音变化、轻声试读；两人轮流闭眼听、反馈、改一处、再读，再听全班两组。双人结构确实让多数人开口和倾听。
- **我会怎么想、有什么情绪**：闭眼同桌比全班表演安全，真实听感有价值；但连续两页、共11分钟停在同两句，会产生“已经懂了还在做流程”的拖沓感。第二遍、交换、全班样例和章末再调用形成重复。
- **可见作品**：一处朗读标记、原词理由、听者定位和改读记录。
- **教师如何据实收束**：不评最佳读法，只承认有原词且能被听见的方案，边界正确。
- **下页是否真的调用**：C206允许自然使用标记，但不检验听者记录本身；完整独立页的证据没有被充分后用。
- **删/并损失**：纯删除会失去“纸面理解能否进入声音”的检验；并入C202不会失去核心功能。
- **合并方向**：C202完成圈词后，每对只做“一读一听一反馈”，交换可在章末重读自然发生；保留听者“在____附近听见/未听见”一项即可。将两页总时长压至7—8分钟。

### C204｜无咎言的最小文化支架——PASS / P3

- **进页前我知道什么**：已理解等待的骤变，但不具备卜筮名物知识，也不能用后来结局解释本句。
- **第一眼看到什么**：原句、卜/筮/体/咎言四项支架和“这次结果”一个问题。
- **我实际做什么、是否多数人参与**：利用已给名物独立组织自然话，同桌只查错位，听教师后删越界词或补“这次”。人人可以完成基础口译。
- **我会怎么想、有什么情绪**：知识支架降低陌生感；问题答案较直接，但真正学习点是限制“一定幸福”的时间越界。
- **可见作品**：自然口译、当次结果和限定修订。
- **教师如何据实收束**：后置说明它只推进当时婚事，不保证后来生活。
- **下页是否真的调用**：C206要求把占问作为婚事推进节点；第四、第五章计划再比较，近端调用成立。
- **删/并损失**：文化支架不能删；可与C205合成“占问以后怎样走到迁嫁”的一页，不必牺牲边界。
- **P3观察**：学生是否真的写出过越界词；若极少，统一“圈删越界词”环节可缩短。

### C205｜以尔/以我双方迁移动作——MERGE into C204 / P2

- **进页前我知道什么**：当次占问无不祥、婚事继续向前；贿与迁尚未校准。
- **第一眼看到什么**：一个对称句式、以尔/以我两栏和四个主体/物件问题。
- **我实际做什么、是否多数人参与**：个人拆句、听两个词义、两人指读两侧、交换、合读、说自然话、修订。多数人能参与，但为一句结构透明的诗设置了较完整的程序链。
- **我会怎么想、有什么情绪**：分清车、嫁妆、来、迁有必要；若刚用5分钟处理占问，再用4分钟反复拆合一句，容易感觉课堂在延缓故事前进。
- **可见作品**：03B对称表与一句自然话。
- **教师如何据实收束**：准确指出男子来迎、女子携嫁妆迁往男子家，不提前讲婚后。
- **下页是否真的调用**：C206会取回迁嫁事实，但不会再使用两人指读与交换证据。
- **删/并损失**：不能把事实吞成“他们结婚了”；但无需独立一页。
- **合并方向**：放在C204后半，用“这次占问→车来/贿迁”的因序把两句连读；个人填两栏后只做一次同桌核对和合句，不再交换表演。C204+C205总时长压至7分钟左右。

### C206｜第二章撤答重建——PASS / P3

- **进页前我知道什么**：等待位置、见与不见、占问边界和迁嫁事实已处理，但尚未证明能离开局部任务讲成故事。
- **第一眼看到什么**：完整第二章和等待—骤变—占问到迁嫁三条旁白范围，没有完成章意。
- **我实际做什么、是否多数人参与**：完整重读，合教材、两卡翻背、同桌互查、B键熄屏；两人轮流30秒旁白，查漏后只开教材定位再合书，最后只恢复03B写第二格。人人有口头和书面产出。
- **我会怎么想、有什么情绪**：流程与C105相似，熟悉会降低负担；也可能形成每章固定“黑屏考试”的预期，需要避免机械化。
- **可见作品**：第二章轨道格、自然章意、后文回看词、查漏与补说记录。
- **教师如何据实收束**：引用两条真实章意，只修事实断点，不覆盖个人措辞。
- **下页是否真的调用**：脚本明确C301打开第二格并追问迁嫁后为何转向桑叶；虽然C301不在现有20页内，调用指令具体可执行。
- **删/并损失**：删除会使第二章四块局部活动不整合；不能并入C205，因为证据状态从有支架变为撤答。
- **P3观察**：记录第二次使用同构黑屏流程后是否仍有检索价值，还是学生只在复述口头三项；同时核验C201动作初稿修订后能否真实进入旁白。

## 跨20页的学生体验判断

### 参与不等于轮流被点到

真正覆盖多数人的页面，主要依靠个人书写和双人同步：O01、O07、C101—C105、C202—C206。O02则把参与误等同为“每人依次对全班说一次”；总开口人数高，但单位时间内只有一个人认知活跃，其他人容易等待、预演或走神。应把全员参与移到并行的同桌/四人组，将全班舞台用于少量可比较、可追踪的输入。

### 是否向学生索要无框架深析

O01没有要求深析，只要篇名和一句“写了什么”；O02也只要求朴素主题。O03明确由教师承担抽象分类，学生只核对与补充，这一点合理。风险不在“问题太深”，而在O02持续时间和公共表达质量，以及O03能否真的从现场原话归纳。O08的三个大问题出现在完整听读和个人初听之后，且明确暂不回答，也不属于无框架索答。

### 程序负担

第一章五页虽有多次生成—同伴反馈—修订，但感官通道有变化，仍可保留。第二章在C202/C203连续处理同两句、C204/C205连续处理最后两句，程序密度明显高于故事推进速度；合并两组页面能保留文本证据、听觉检验、文化边界和主体关系，同时减少重复交换与重复收束。

### 作品与后用

大部分作品都有近距离后用：O01→O02→O03，O05/O06→O07→O08，第一章局部→C105→C201，第二章局部→C206。最明确的作品合同缺口是C201：三个动作先写在教材，03A又有同名栏目却无明确转写口令，后续又声称取回03A动作初稿。该处必须在进入课堂前统一。

## 建议的最小改动顺序

1. 先重写O02：把全班串行一圈改为并行互说、小组汇总、全班精选共享；同步微调O03读取的新公共作品池。
2. 修正C201的03A发放时点、三个动作填写位置和C206取回口令，使作品只落在一个明确位置。
3. 将C203的单次盲听核心并入C202，将C205的对称拆句核心并入C204；保留关键学生证据，删除重复交换、重复全班展示和重复转场。
4. 试教时重点记录O01空白率、O02真实听取率、C103/C104时间收益、C206第二次黑屏流程的新鲜度与检索质量。

## 声明边界

本报告是对现行PPT、母版、逐字稿与学生材料的桌面学生接收复审。它判断设计是否可能支持真实参与、理解路径和作品后用，不声称真实学生已经理解、参与、保持或迁移学习；P3项目必须通过课堂观察验证。
