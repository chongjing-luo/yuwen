# 《氓》V6.4逐页重新取证实施计划

1. 冻结V6.4规格和四十八页功能总账：逐页登记唯一功能、主动作、产物、第一次后用、删除损失、正常反例和当前裁决。
2. 先关闭结构性阻断：C304并入C303；C105删除虚假个人回看承诺；C504学习单移除舞台指令；C601解除末句泄答；C602/C603修复视觉歧义和提前结论；C606建立六章母轨道。
3. 将全文综合从七页重构为八页：S01—S04去除强制断点、强制修改、强制争议和过度程序；S04真实回用O03主题谱；S05—S06产物进入新增S07个人知识清单；S08完成三问、诗写/未写边界、婚姻讨论收纳、可选追问和完整朗读。
4. 逐模块重读O01—C606全部页面，不以“未被旧审查点名”为通过证据；执行相邻合并、标题泄答、前后台、正常反例、程序成本和故事回接测试，发现问题即局部改写。
5. 同步更新教案、学习单、逐字稿、PPT构建器、验证器、测试和总账；保证所有渠道的信息顺序与产物落点一致。
6. 全量构建八个模块和四十八页完整课件，运行模块测试、合并测试、Office结构验证、Markitdown、PDF、逐页PNG、联系表、前台禁用语扫描和产物后用审计。
7. 主动完成至少一轮找错—修复—全量复验，保存问题记录、旧/新差异、SHA-256和不可覆盖的QA目录。
8. 锁定同一候选，交原视觉功能审查者与原学生接收审查者复验所有修改页、相邻页及全课后用；任一P0/P1/P2存在则继续返工。
9. 页面功能双审清零后，冻结女子、男子和家人的统一角色设定板，按逐图用途生成重要场景插图；加入PPT后再次执行视觉、接收和内容边界复验。
10. 只有页面与插图两个阶段均完成P0/P1/P2清零，才冻结唯一V6.4母版并更新最终教案、学生材料、课件、QA证据和交付清单。
