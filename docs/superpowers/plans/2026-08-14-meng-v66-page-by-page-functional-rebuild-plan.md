# 《氓》V6.6逐页功能重构实施计划

**目标：** 将V4的45页待审素材重构为一个页数服从理解、每页唯一功能可验证、前台有语文味、逐页有真实课堂剧本、活动具有真实参与、视觉与插图服从教学意义的无图正式候选；通过全量渲染、修复复验及独立视觉/学生接收双审后，才进入插图A/B。

**设计依据：** `docs/superpowers/specs/2026-08-14-meng-v66-page-by-page-functional-rebuild-design.md`

**逐页裁决：** `work/备课/选择性必修下册/氓/_v62_stage/19_氓_V66_V4逐页功能重构裁决.md`

## 阶段1：冻结合同和页面映射

1. 建立V6.6统一页面数据源，重新编号所有物理页；旧页号仅保留溯源。
2. 每页提交前页输入、唯一困难、唯一功能、文学对象、首答信息状态、学生动作、参与路径、产物、教师作用、等待、反馈、修订、后用、正常反例、主视觉、插图资格、第一人称接收、故事回接、删除损失、相邻反证和失败信号。
3. 新增《诗经》文化入口；合并旧03、旧22；将旧20拆为首答态与恢复态。
4. 写失败测试：后台语言不得进入前台；排序、分类、答案结构不得在首答态泄露；页面产物和第一次后用必须同名同位置。

## 阶段2：重写导入和全文初见

1. 导入从“篇名—故事—朴素主题”的广泛检索开始，不预列作品，不追问幸福本质。
2. 设计个人、同桌、四人、公共增量、教师后置归纳五段真实流程；PPT只显示自然表达入口，不画管理流程。
3. 把旧作主题谱的现场归纳并入揭题事件。
4. 增加《诗经》最低文化坐标，控制在初听所需范围内。
5. 保留完整听读、个人停点和三问后置出现。

## 阶段3：逐章重写

1. 第一章重写“贸丝/谋”的信息状态、“四句一番话”的声音活动和章末自然重建。
2. 第二章删除完成态因序图，改为先分主体和动作、再由板书生成因序。
3. 第三章把比兴体验拆成两个物理状态；删除重复章末解释。
4. 第四章撤除“双时间”的现成结论，保留学生首答后教师命名；责任链守住主体和伦理边界。
5. 第五章删除屏幕“三秒沉默”，用真实声场；把婚前警讯与后文核验写得准确、不归责。
6. 第六章保留同词反折、有界多解、双真相和末句止息边界，避免确定出走图像。

## 阶段4：重做三问综合和婚姻讨论

1. 人生长卷：个人纸带先封存，组内轮说，六章公共长卷后置形成。
2. 不幸表现：“生活事实卡”先用现实语言说明，再交换猜回原诗并撤回越界表述。
3. 不幸原因：“事实—作用—边界”卡沿人生长卷放置，再由他组质询原因类型和证据强度。
4. 婚姻讨论：每人返诗提出关系条件，四人全部轮说后每组只留一张“给未来的卡”，教师据真实卡片归纳良好共同生活的支点。
5. 回投导入主题谱，只讨论《氓》为原有文学版图增加了什么，不重新深析旧作。

## 阶段5：知识收纳与终读

1. 《诗经》文化身份采用合书首答—封存—开书修复—再合书串说。
2. 字词自选两项完成音—义—原句三联，教师只修真实共错。
3. 艺术手法从“叙事、比兴与对照、复现反折、四言叠词与声音”四类检索原句并说明作用。
4. 终课允许留下理解、语言发现或问题；完整终读不少于180秒，末句后不加价值口号。

## 阶段6：构建、验证与视觉复验

1. 由统一数据源生成教学母版、逐页真实剧本和PPT备注。
2. 运行页面合同、时间、跨页产物、首答状态、前台禁词、逐字稿完整性和PPT物理页数测试。
3. 将PPT全量转PDF和逐页图片，生成缩略图总览。
4. 内容QA检查错字、篇章次序、占位符、原诗准确性和备注完整性。
5. 视觉QA检查后排可读、焦点、空白功能、溢出、对齐、低对比和流程骨架泄漏。
6. 修复第一轮发现的问题，重新构建和重渲染受影响页；至少完成一次修复—复验。

## 阶段7：独立双审与插图A/B

1. 冻结PPT、教学母版、真实剧本、学习材料及渲染图SHA。
2. 独立视觉审查和学生接收审查逐页裁决；P0/P1/P2任一存在即回到相应阶段返工。
3. 无图候选双审清零后，才制作少量已获资格页面的插图A/B物理状态。
4. 每张人物图绑定冻结角色板，完成彩色、灰度、低亮和实际入页尺寸身份盲认。
5. 插图合入产生新PPT和新SHA，重新全量双审；无可测理解增益则保留无图版。

## 完成证据

- 页面合同验证通过；
- PPT Office打开与解包验证通过；
- 全量渲染无P0/P1/P2视觉缺陷；
- 每页讲者备注含真实可演出的逐字稿；
- 教学母版、逐页剧本、PPT及学习材料映射一致；
- 独立视觉和学生接收复审在同一组SHA上P0=P1=P2=0；
- 插图若合入，必须在新SHA上重新满足同一门槛；
- 未试教前只称“受控试教候选”，不声称学生已经学会。
