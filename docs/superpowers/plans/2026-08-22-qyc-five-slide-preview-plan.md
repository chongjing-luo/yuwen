# 《沁园春·长沙》五页视觉样张实施计划

## 目标

按已批准规格，在`Tmp/work/qyc_5slide_preview/`生成QYC-S3-001—005五页PPTX及渲染预览；不进入正式S4目录，不创建任何锁。

## 任务

1. 提取五页当前前台状态和逐字稿，确认本机字体、PptxGenJS与渲染工具可用。
2. 编写隔离构建脚本，建立统一色彩、字体、页码母题和五种功能版式，并把完整真实剧本写入讲者备注。
3. 生成PPTX，做文本提取与结构检查，确保顺序、前台纯度和答案时序正确。
4. 渲染五页与缩略总览，进行独立视觉审查，记录至少一轮真实问题。
5. 修复问题并复验，交付PPTX、逐页渲染图、总览图和简短QA记录。

## 验收

- 5页、16:9、Q001—Q005顺序正确；Q002不提前显示答案。
- 每页备注包含页面ID、承接、教师实讲、学生过程、可能回应、反馈、时序和切页。
- 无溢出、遮挡、低对比、边距不足或后台语言上屏。
- 输出仅位于`Tmp/`，无design/materials/audit锁。
