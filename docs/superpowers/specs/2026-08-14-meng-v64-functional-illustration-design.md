# 《氓》V6.4功能性插图与人物连续性设计

## 一、设计结论

采用“**统一人物圣经＋九幅功能性场景小图＋逐图准入＋入页后全量复审**”方案。

插图不是把《氓》画成连环画，也不承担教师已经完成的主题解释。它只在图像比文字更快、更准确地帮助学生辨认动作、空间、时间、物象或叙事层次时进入PPT。原诗、学生作品和问题已经足够有力的页面继续无图。

### 备选方案与取舍

1. **每个重要情节都配图**：叙事连续，但容易把诗歌变成现成故事板，抢走原诗并替学生想象；否决。
2. **只画氛围装饰**：容易统一美感，但学生不观察、不比较、不引用，删除也无学习损失；否决。
3. **稀疏功能图**：只画空间、物象、时间和声音层次中确有认知收益的节点；采用。

## 二、不可突破的边界

1. 不把“蚩蚩”直接画成伪善或阴险，只呈现女子当时看见的忠厚外观与他抱布而来的动作。
2. 不把后文倒灌为男子婚前已经明确预谋欺骗；画面不出现诡笑、藏刀、黑影或反派色码。
3. 不虚构诗中没有写明的具体殴打场面；“至于暴矣”只可用距离、姿态、空间失衡或人物回避表现关系变化。
4. 不把兄弟的不知与嘲笑画成全家围攻；只呈现诗中明确的“不知”“咥其笑矣”和女子独自思量。
5. 不把“亦已焉哉”画成女子已经离开家门、登车远走或获得确定的新生活。原文只足以支持停止判断。
6. 不把生成图当作先秦服饰和地理的精确史料。设定采用有根据的概括性先秦中原视觉，并在教师后台保留“艺术化示意”边界。
7. 不在图内生成文字、箭头、标签或答案。需要的字词和问题仍由PPT原生文字承担。

## 三、共同画风与PPT适用性

- 风格描述：温润手绘、东方动画电影感、简洁形体、清楚轮廓、平涂与轻水彩纹理；不得复制任何在世艺术家的可识别笔触或具体作品构图。
- 时代气质：概括性的先秦中原乡野，交领右衽、布麻质感、克制发饰；不混入汉唐高髻、宋明建筑和华丽宫廷服饰。
- 色板：暖纸 `#E9DEC9`、炭墨 `#28231E`、桑叶青 `#627765`、淇水青 `#7B9898`、朱砂 `#A24D43`、旧金 `#A58355`。
- 光线：柔和侧光；婚前明度略高，婚后只降低明度和饱和度，不更换视觉世界。
- 构图：单一动作、人物少、低细节背景；16:9或4:3横向小景，主体偏一侧，另一侧留出PPT文字空间。
- 禁止：电影海报式大场面、复杂群像、强烈特效、夸张哭泣、现代妆容、文字、水印、边框、假古籍印章。
- 入页面积：原则上不超过单页视觉面积的25%；不得使核心原文低于28pt或任务入口失去第一层级。

## 四、人物圣经

### W01｜女子

- 身份连续：同一位女子跨“初见—迁嫁—婚后—回望”四阶段；不设未经文本证明的具体年龄数字。
- 身形与面部：中等身高、纤细但不脆弱；柔和椭圆脸、平直眉、深棕杏眼、鼻口比例固定。
- 基础发式：中分后束的低髻或低束发；迁嫁阶段可以增加极简发带，婚后只允许轻微松散，不换成另一种脸或高髻。
- 基础服装：交领右衽、窄袖布衣、及踝长裙；主色桑叶灰青，内层暖米色，朱砂只作极小系带。
- 阶段变化：初见衣料完整、姿态开放；迁嫁带简洁包袱；婚后衣色略旧、袖口轻微磨损；回望姿态挺直而克制，不用“胜利者海报”表达醒悟。

### M01｜男子

- 身份连续：婚前和婚后使用同一脸型、身材、发束和服装体系，不能用换脸证明表里不一。
- 身形与面部：略高于W01、普通青年体格；较方的椭圆脸、直眉、深棕眼、鼻梁与下颌比例固定。
- 基础发式与服装：顶部束发、无华丽冠饰；褐灰交领短袍、深炭腰带、布履。
- 状态变化：婚前身体朝向W01、距离较近；婚后以背离、占据空间、拒绝回应等克制姿态表现关系失衡，不采用反派化表情。

### B01/B02｜兄弟

- 只在“兄弟不知，咥其笑矣”场景出现；保持次要、低细节、非主角化。
- 使用与M01明显不同的脸型和衣色，不与男子混淆；不增加父母、邻居或围观群体。

### 固定道具

- 布匹：天然麻布色，卷法在I01、I02保持一致。
- 淇水：灰青水色、缓弯河道；不同季节允许水量变化，但河岸视觉体系一致。
- 垝垣：低矮残损夯土墙，不画成城楼。
- 车与帷裳：木轮小车、素色布帷；不采用汉唐华丽婚车。
- 桑叶：同一枝形和叶脉体系，用明度、含水感和下垂程度表现“沃若—黄陨”。

## 五、角色设定板验收

第一张生成物不是课堂插图，而是身份锚板，必须同时包含：

- W01正面头像、四分之三侧面、全身比例和四阶段小像；
- M01正面头像、四分之三侧面、全身比例和婚前/婚后姿态；
- B01/B02简化头像；
- W01/M01基础服装色块；
- 布匹、车帷、桑叶三件固定道具；
- 不出现文字和编号，编号由后期原生排版添加。

角色板通过以下四项才冻结：

1. W01、M01跨姿态仍一眼可认作同一人；
2. 服饰没有明显汉唐宋明特征或现代影楼感；
3. 固定道具形制清楚、可被后续场景复用；
4. 画面简洁，可裁成单个身份参考，不是复杂剧情海报。

九幅图全部是候选，不是配额。单图审查或入页A/B比较不通过，可少于九幅；不得为了“已经生成”而保留。

## 七、生成与验收流程

1. 生成角色设定板草案，只审身份、服饰、道具和PPT可裁切性。
2. 若角色板不通过，只针对一个变量迭代；通过后保存为冻结身份锚，不再凭文字重新想象角色。
3. 每幅场景生成时都引用冻结角色板；物象场景引用相应固定道具锚。
4. 单图先审：文本事实、身份一致性、画面简洁、无文字水印、无不必要叙事。
5. 对每个候选页制作无图版和入图版；若图像没有提高动作辨认、空间定位、状态比较或审美秩序，保留无图版。
6. 只修改通过A/B比较的局部页面；原文和任务字号不得下降到放行线以下。
7. 重建完整PPT，产生新哈希；旧哈希的双审结论不得沿用。
8. 重跑37项合同、Office验证、禁用语扫描、48页渲染、独立视觉审查和独立学生接收审查。
9. 任一P0/P1/P2存在即返工；只有新候选再次清零，才冻结为最终插图版。

## 九、完成标准

- 角色设定板通过四项验收并冻结；
- 每幅入页图都有不可替代的学习功能、文本边界和明确学生动作；
- 人物、服饰、道具、色板、光线与画风没有明显漂移；
- 原诗和任务仍为页面第一视觉层级；
- 新PPT完成全量自动、Office、视觉与学生接收复验，P0=P1=P2=0；
- 报告明确P3仍须真实试教，不宣称插图已经提高学习成效。
