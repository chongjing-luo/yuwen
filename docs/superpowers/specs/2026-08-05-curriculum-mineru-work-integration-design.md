# 课程标准 MinerU 处理与 `work/` 吸纳设计

## 目标

对教育部官方《普通高中语文课程标准（2017年版2020年修订）》执行一次可复核的 MinerU 解析，并把课标思想转化为 `work/` 中可执行、可评价、可回溯的备课规则。

## 输入与输出

- 规范输入：`Data/reference/curriculum/普通高中语文课程标准（2017年版2020年修订）_教育部官方版.pdf`
- 解析根目录：`Data/textbook_extract/普通高中语文课程标准（2017年版2020年修订）/`
- MinerU 原始产物目录：上述目录下的 `mineru_result/`
- 解析说明：上述目录下的 `README.md`，记录输入哈希、处理时间、API参数、产物清单、核验结果和使用边界
- 规范来源仍是教育部官方 PDF；MinerU Markdown、JSON、图片和 `_origin.pdf` 均为定位与分析用衍生产物

## MinerU 流程

1. 使用项目现有 `scripts/mineru_client.py` 提交单个 PDF，参数保持中文、公式识别和表格识别开启。
2. 轮询任务至完成，下载结果 ZIP，并完整解压到 `mineru_result/`。
3. 保留 MinerU 原始目录结构，不重命名内部文件；只在外层建立稳定的课程标准目录。
4. 若任务失败，保留批次号和错误信息，不生成“已完成”记录；重试不得覆盖已验证结果。

## 解析验收

- `full.md` 存在且非空；标题、目录、正文六大部分和两个附录可检索。
- `content_list.json` 等 JSON 均可解析。
- `_origin.pdf` 与规范输入的页数和标题一致；记录两者哈希及派生关系。
- 抽查封面、课程性质、核心素养、课程结构、学习任务群、学业质量、实施建议和附录页面；直接引文必须回看规范 PDF。
- 检查18个学习任务群名称、7/9/9课程安排、四项核心素养和五级学业质量等关键口径。

## `work/` 吸纳范围

采用结构化吸纳，不逐段复制课标：

1. `课程与教学理论方法论（语文版）.md`：校准课程性质、基本理念、核心素养关系、任务群、课程结构、学业质量和实施原则。
2. `备课方法论（语文版）.md`：把“课标—教材—学情—目标—任务—评价”变成备课步骤，落实真实语文实践、学习任务群、情境和三类语文活动整合。
3. `教学环节技术与技巧（语文版）.md`：补充自主合作探究、专题学习、整本书阅读、跨媒介活动和过程性评价的执行边界。
4. `PPT设计与演示方法论（语文版）.md`：只吸纳跨媒介素养、信息来源判断和“技术服务语文实践”的原则。
5. `语文备课系统_知识点提取研究计划.md`：把课标基线落实到来源登记、字段约束、受控词表、学业质量映射、评分与门禁。
6. `work/README.md`：更新导航摘要；通用版只改必要的术语和交叉引用。

## 吸纳原则

- 区分课标明示、教材事实、研究解释和教学建议，禁止把后两者冒充课标原文。
- 核心素养四方面按整体关系处理，不机械地给每篇课文贴单一素养标签。
- 学习任务群是课程内容组织方式，不等同于固定课型或单一教学法。
- 阅读与鉴赏、表达与交流、梳理与探究应在真实语言运用情境中整合。
- 学业质量用于描述表现水平和设计评价证据，不直接等同于题目难度标签。
- 所有课标直接引文保存 PDF 页码定位；MinerU 文本只作检索入口。

## 最终检查

- 扫描 `work/` 中旧版本名、错误任务群数量、错误术语和错误学分口径。
- 检查新增主张是否有课标定位或明确标注为项目解释。
- 运行 Markdown 差异检查、链接检查、JSON解析和 PDF 完整性检查。
- 保留现有用户修改和无关删除状态，不做重置或覆盖。
