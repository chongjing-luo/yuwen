# 《氓》V6.6逐页功能重构设计

## 一、为什么现有方案仍让人觉得“没有诚意”

问题不在于页面没有标题、活动或备注，而在于这些字段经常只是设计者对自己的陈述：写着“让学生理解”“形成长卷”“删除会损失”，却没有证明课堂中哪一种学生行为发生了、留下什么证据、后面怎样真正使用。完整的格式因此可能掩盖不完整的学习。

生成式方案还容易受到三种局部最优诱惑：

1. 用“讲到了很多”替代“学生形成了连续理解”；
2. 用“安排了讨论”替代“多数学生真实表达并修订”；
3. 用“页面看起来丰富”替代“视觉帮助学生面对原诗”。

V6.6不再从“现有45页怎样润色”出发，而从“学生此刻必须发生什么变化”反推页面。现有45页只是待审材料，允许保留、重写、合并、拆分或删除；页数和课时不是质量目标。

## 二、三种可能路径及裁决

### 路径A：在现有45页上逐页润色

优点是改动较小，已有构建器和备注可以复用。缺点是旧页面划分会继续主导思考，容易把标题换得更自然，却保留重复活动、孤立产物和无意义图形。

### 路径B：功能先行的逐页重构（采用）

先冻结全课理解轨迹和逐页合同，再审判旧页。每一页只保留一个主要文学对象和一个可观察的学生变化；相邻页能无损承担时合并，学习困难过多时拆分。页面、逐字稿、学习单、板书与试教证据使用同一数据源。

此路径成本较高，但最符合“局部尽善尽美必须服务全课最优”的要求。

### 路径C：先以重要场景和插图重建视觉叙事

优点是观感容易明显提升。缺点是图片会反过来替学生规定想象、提前交付空间或意象答案，并掩盖尚未解决的教学问题。只有在页面功能冻结后，才允许将它作为局部视觉实施手段。

## 三、最终目标

学生不是收到45个知识片段，而是经历一条连续的理解：

1. 从自己读过的爱情与婚姻文学出发，看见这一主题在文学中的广阔面貌；
2. 完整听见一位女子从相识、等待、迁嫁、婚后失衡到清醒止息的自述；
3. 沿六章逐句读懂字词、动作、声音、意象、叙事和人物处境；
4. 用原诗回答三问：她经历了什么，她婚后的不幸在生活中是什么样子，这场婚姻为什么走到这一步；
5. 在有证据、不归责受伤者的前提下，讨论良好共同生活需要怎样的结构；
6. 最后收纳《诗经》常识、核心字词、叙事结构、比兴、复现反折、语言与声音，并让全诗重新完整响起。

学习过程应有投入、发现、惊讶、同情、辨析、表达、安静和回味，不以持续接收信息或连续填表作为课堂常态。

## 四、全课理解结构

### 1. 文学回忆：求广，不求早深

学生从小学到高中自由检索爱情或婚姻作品，写篇名、一句话故事和一个朴素主题。导入不预列三篇标准作品，也不提前追问“幸福的本质”。

课堂依次完成：个人检索、同桌互说、四人组保留差异、各组向全班贡献一个增量、教师引用学生原话后置归纳。教师归纳爱情与婚姻文学已经出现的广泛方向，再引入《氓》将展开的“爱情进入共同生活以后”这一新主题。

设计资格：多数学生有低门槛材料并真实开口；公共材料有篇目广度和主题差异；教师总结来自现场而非预填答案。

### 2. 整体初见：让诗先作为声音发生

揭题、正音、出处后完整听读六章。学生只留下真实停点、看到的画面、听见的声音或一个问题。三问必须在完整听读和个人初见之后出现，避免分析框架覆盖第一次接收。

### 3. 六章细读：知识沿故事生长

每章遵循“整章进入—必要局部停驻—人物或故事回接”。字词、文化、句法和手法由教师准确讲解；学生能够观察、口译、比较、朗读或解释的部分先保留首答。每章只保留一次整体重建，不复制六套相同章末程序。

- 第一章：来、送、约——两个人怎样走近婚事；后来回看时，早期细节只能构成需要观察的信息，不能倒推已经证实的预谋。
- 第二章：等、见、迁——约定怎样成为等待，情绪怎样随“不见／既见”转折，婚事怎样走向迁移。
- 第三章：桑、鸠、女——叙事为何停驻，劝告怎样由物来到人，比兴如何从体验中被命名，男女脱身处境怎样不对等。
- 第四章：桑叶落下、三岁食贫、渡水、行为反复——生活事实与责任判断怎样分开并连接。
- 第五章：日复一日、既遂至暴、兄弟笑、独自悲——不幸怎样成为具体日常，理解和托举怎样缺席。
- 第六章：旧愿、边界、旧日欢乐、后来失信、亦已焉哉——她怎样重新评价过去并作出止息判断；不虚构诗未叙述的出走细节。

### 4. 三问综合与婚姻讨论

综合不从零再造材料，而直接调用细读阶段已经形成的人生轨迹、生活片段和原因证据。

1. 经历：全班共同完成一条六章人生长卷，个人能自然讲述转折与因果。
2. 不幸表现：学生用现实生活语言解释贫困、持续劳作、背叛或反复、粗暴、嘲笑、不被理解和孤立，再逐项猜回原诗依据。
3. 原因：学生先独立判断，小组对因果箭头质询证据和强度，明确男子失信与粗暴的直接责任、关系失衡与支持缺失的持续条件，以及女子投入不是伤害原因。
4. 共同生活：每个人用一处原诗提出一个关系条件，四人全员轮说后每组只形成一张支点卡。教师归纳审慎了解、长期一致、边界与尊重、劳动和权力的公平、支持网络以及发现失衡后的求助与止损。

### 5. 知识收纳与完整终读

先合书检索，后开书修复，再回原句终读。文化常识、字词、艺术手法分别按不同检索对象组织，不塞进一页。终课只留下一个改变最大的理解、一个语言发现或一个仍愿追问的问题，随后让全诗完整响起。

## 五、逐页放行合同

每一个物理页面或明确的动画状态必须提交以下字段；缺关键字段直接失败：

1. **前页输入：** 学生进入本页前已经知道、仍不知道什么；
2. **唯一困难：** 本页只解决哪个具体理解障碍；
3. **唯一功能：** 页面结束后学生比此前多形成什么；
4. **文学对象：** 对应哪一句、哪组词、哪种声音、哪一段人物处境或哪份学生作品；
5. **信息状态：** 首答前哪些内容必须隐藏，何时揭示；
6. **学生主动作：** 学生实际读、听、说、写、画、排、辩、演或观察什么；
7. **参与路径：** 个人、同桌、小组和全班阶段各由谁真正行动；
8. **可见产物：** 产物的确切载体、位置和最小合格样态；
9. **教师作用：** 必要精讲、示范、追问、归纳或边界校准是什么；
10. **真实等待：** 首答、倾听、反馈和修订各有多少秒；
11. **反馈与亲自修订：** 学生依据什么改变自己的理解；
12. **第一次后用：** 后面哪一页、哪句话真实读取该产物；
13. **正常反例：** 想不起、无新增、不同意、已经准确、沉默或超时时怎样诚实完成；
14. **主视觉职责：** 原诗、关系、学生操作、现场作品、声音、空间、时间、物象或必要留白中的哪一种；
15. **插图资格：** 禁止、可研究或条件A/B，及其理由；
16. **第一人称接收：** 学生可如何说“我刚才做了什么，现在多明白什么，依据是什么”；
17. **故事回接：** 局部知识怎样回到人物行动、处境和全诗进程；
18. **删除损失：** 删除后哪条已验证的学习链会断；
19. **相邻反证：** 为什么不能由前后页无损承担；
20. **失败信号：** 出现哪些可观察现象必须返工。

“此页有内容”“此页比较好看”“教师能讲完”均不构成保留证据。

## 六、页面裁决类型

- **保留：** 唯一功能、产物与后用均成立，仅需文字或视觉微调；
- **重写：** 页面位置和文学对象合理，但动作、语言、产物、反馈或视觉不能实现功能；
- **合并：** 相邻页可无损承担该功能，独立成页只增加切换和重复；
- **拆分：** 同页同时承担两个以上无法闭环的主要困难；
- **删除：** 产物没有消费者、活动只是装饰、内容已经被别页覆盖，或删后学习链无损；
- **待试教：** 桌面设计成立，但只有真实课堂才能判断的P3风险。

旧页编号只用于溯源。新版本页数由裁决自然产生，不强行保持45页。

## 七、参与和活动的硬标准

### 桌面放行

- 每个核心活动先有全员个人准备或等价的全员接收痕迹；
- 公共表达不能冒充全员参与，必须另有并行表达证据；
- 听者拥有具体任务，如补一条新篇目、定位原词、指出证据强度或记录观点变化；
- 活动前台原则上只有一个主动作、一个必要反馈和一次本人修订；
- 连续三页若认知动作、感官通道、社会结构、作品形态和反馈方式中有三项基本相同，必须返工；
- 不能依靠组长代写、代表发言或公共答案出现后的补抄证明参与。

### 受控试教门槛

- 导入个人有效回忆痕迹率不低于90%；
- 固定分层随机样本中的同桌或小组有效开口率不低于85%，沉默和无效回答进入分母；
- 公共文学长卷至少出现8部不同作品、5个自然主题方向，且不由单一学生或教师提供主要材料；
- 关键首答必须在公共答案出现前封存，不能事后补抄；
- 细读抽样中，学生能用自然话把局部知识接回人物故事的比例不低于80%；
- 三问综合作品须能回到原诗，诗外推断和受害者归责为零容忍问题；
- 真实时间超支超过标称页面簇的10%，或连续两页学生只能复述活动手续而不能复述诗意，至少判P2。

这些门槛用于否决设计，不用于宣称未经试教的学生已经学会。

## 八、教学手法库及选择规则

手法由困难选择，不按页面平均分配。V6.6至少从以下库中按需选择，并记录“为什么这一手法优于更轻的手法”：

| 困难 | 可选手法 | 必要证据 |
|---|---|---|
| 声音和情绪转折 | 完整听读、接读、删句听辨、教师朗读示范、声场退去 | 停顿或声线变化及其原词依据 |
| 字词和文化 | 必要微讲、语境口译、词卡归句、正误辨析 | 准确音义回到原句 |
| 动作和空间 | 指尖路径、身体朝向、简图定位、动作小景后置校准 | 动作顺序或空间关系图 |
| 时间 | 嵌套时间、长时与片刻并置、前后回访 | 学生能同时说出不同时间尺度 |
| 意象 | 凝视、感官词、同物回访、后文改前文、有界多解 | 带新证据的保留、改写或撤回 |
| 叙事 | 事件链、章间接力、合书复述、教师叙事性精讲 | 连贯人物—动作—结果 |
| 证据边界 | 明写／可推／不可断言、双真相、因果箭头质询 | 有依据修订，推断强度降低或更准确 |
| 日常体验 | 匿名生活片段、声音退场、第三人称微叙事 | 能猜回具体原句且不虚构 |
| 广泛表达 | 个人检索、同桌并行、四人保留差异、公共增量、教师后置归纳 | 个体开口与公共广度分别成立 |
| 价值讨论 | 全员轮说、一组一卡、冲突卡质询、关系支点图 | 原诗依据＋关系条件＋修订 |
| 知识收纳 | 合书检索、开书修复、再合书表达、终读提醒 | 真实错项被本人修复 |
| 文学回味 | 静默、留白、完整朗读、开放终课一句 | 学生有安静出口，不被表单挤压 |

手法升级遵循最低有效强度：一句设问停顿 → 个人原词标记 → 同桌限定互证 → 四人轮说 → 全班讨论 → 走动或立场活动。活动更热闹不代表理解更深。

## 九、学生前台语言标准

学生可见文字只保留原文、自然问题、此刻必要的行动邀请和活动后形成的共同发现。以下内容禁止进入前台：教学目标、学生角色、设计理由、流程管理、评价术语、机器合同、研发语言以及“今天不……而要……”式方法宣言。

每段前台文字必须通过四项测试：

1. 教师在真实课堂中读出来不生硬；
2. 学生第一次听就知道面对哪句诗、哪个人物和要做什么；
3. 语言贴近动作、场景、声音和人物，不由“结构、维度、回收、建模、生成”等抽象词串联；
4. 删除后不会失去必要信息的句子一律删除。

文学味不是堆砌华丽辞藻，而是让问题从原诗的动作、声音和处境中自然长出来。

## 十、视觉与插图设计

### 1. 一页一个主视觉职责

主视觉只能首先承担一种职责：放大原诗、显示关系、承载操作、保存学生作品、制造声音／空间／时间体验或提供必要物象。卡片、圆点、箭头和空框不是天然视觉；如果学生不观察、不操作、后续不引用，就是无意义图形。

### 2. 插图五项准入

插图必须同时通过：

1. 明确帮助辨认一个动作、空间、时间、物象或叙事节点；
2. 学生会观察、比较、定位或引用它；
3. 无图确有可测的理解损失；
4. 不把推断画成事实，不在首答前交付答案；
5. 不压缩原诗字号、不抢走页面焦点。

若图中正是学生要从原词形成的答案，只能采用“无图首答B0—短暂揭图B1—撤图回词B2”。B0、B1、B2均须可渲染、可哈希、可独立审查。

## 十一、评估与否决机制

### 严重度

- **P0：** 事实、文本、伦理或安全灾难；
- **P1：** 核心学习链断裂、首答泄答、原诗失真、主要人物或场景严重误画；
- **P2：** 页面功能未充分实现、参与证据不成立、产物孤立、语言或视觉明显妨碍理解、关键流程不可执行；
- **P3：** 桌面条件基本成立，仅真实试教或投影环境能判断的风险。

任一P0、P1或P2存在即不放行。总分、制作成本、审美或其他页面优点不能抵消。

### 独立双审

1. 学生接收审查者逐页报告：学生原先知道什么、接收什么、具体行动、谁参与、形成什么、如何修订、是否能接回故事；
2. 页面功能与视觉审查者逐页报告：唯一意义、删并反证、前台语言、主视觉、后排可读性、插图功能和人物连续性；
3. 审查输入绑定PPT、逐字稿、学习单和审计文件的路径与SHA；
4. 审查者不参与同一轮页面写作；
5. 修复后只认新哈希复验，不沿用旧报告。

## 十二、实施顺序与交付物

1. 冻结本设计及逐页放行量表；
2. 对V4的45页逐页裁决，输出“留／写／并／拆／删”及证据；
3. 先重构导入，再按六章、综合、知识收纳和终读依次实施；
4. 更新教学母版、逐页真实剧本、学习材料、板书和PPT备注；
5. 由统一数据源构建新版PPT，运行内容、时间、信息状态和跨文件一致性合同；
6. 全量渲染，完成第一次视觉和内容审查；
7. 至少完成一次真实的修复—重新渲染—复验；
8. 进行独立视觉和学生接收双审，清零全部P0/P1/P2；
9. 仅为通过资格的页面制作少量插图A/B样张；
10. 插图合入后生成新哈希，再做全量双审；
11. 最终只冻结一个当前版本，旧候选不与正式文件并列。

必须交付：逐页放行总账、教学母版、逐页真实课堂剧本、学生材料清单、课堂手法地图、无图PPT、渲染图、构建和验证报告、独立双审报告、试教观察表、插图资格表及获准图片登记。

## 十三、设计自检

- 无TBD、TODO或以“后续再定”回避的关键要求；
- 页数明确不冻结，避免与逐页最优冲突；
- “广泛导入—全文细读—三问综合—婚姻讨论—知识收纳—完整终读”前后连贯；
- 桌面放行和真实试教效果明确分开；
- 插图不能先于页面功能，不把图片偏好当学习增益；
- 自动合同不能替代独立审查，独立审查也不能替代真实试教；
- 用户要求的文学语言、真正参与、每页意义、统一人物和独立否决均已成为硬门槛。

## 十四、V3独立审查后的强制增补

V2的71张物理画面虽然字段齐全，独立视觉审查仍发现39张P1，学生接收审查发现8张P2。这证明“逐页合同完整”不能自动证明课堂成立。V3增加以下不可绕过的否决：

1. **删除方先发言。** 每页默认删除，设计者必须证明理解链、个人证据或必要体验会在哪一处断裂；文档中补写一段“删除损失”不等于证明。
2. **物理画面独立演出。** 首答、现场作品、校准、撤答和本人修订分别拥有状态级逐字稿、舞台动作、时间盒、证据位置和切页触发；不再把逻辑节点的整段剧本复制到多个状态备注。
3. **后台ID零暴露。** B0/B1、逻辑页ID、P级和机器标签只能存在于备注、数据源和审查文件，学生画面不得出现。
4. **公共完成不等于个人掌握。** 全文第一、二、三问在公共长卷或教师归纳以后都设置撤答个人末答；学生只深做本组一部分材料不能冒充完整答案。
5. **真实取回旧作。** S02必须物理取回C505《一间屋子里的许多年》，从旧稿抽取和补证；不再重新写一份相似材料冒充后用。
6. **版式也是答案。** C604和S06首答态使用等大、同色、随机散卡；左右分栏、颜色和空间聚团只能在校准态出现。
7. **实验声明必须诚实。** 第三章在完整初读以后进行的是“删句再听”，不再声称获得未见桑叶、斑鸠时的真实基线。
8. **学生前台回到文学语言。** “长期行动核验、求助通道、失衡持续”等后台术语改成由诺言、日子、家务、倾听、停止和离开构成的自然话；术语只在确有知识价值时后置命名。
9. **知识总结分离首答、校准和再检索。** 《诗经》文化五项、六章六词和四类诗法均具有可审查的无答案首答、完整校准与撤架个人检索。
10. **模块重建阈值。** 一个模块超过四分之一物理画面被判P0/P1/P2，或同一根因贯穿三页以上，整段从目标和原文顺序重新划页，不继续局部润色。

V3因此不冻结71页或268分钟。当前实现候选为46个逻辑节点、79个物理画面、280分钟；增加的页面只用于把原来同屏或藏在备注里的学习闭环变成真实可演、可审查的物理状态，并不构成新的知识负担。
