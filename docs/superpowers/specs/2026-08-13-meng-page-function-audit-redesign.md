# 《氓》V6：逐页功能审计驱动的整体重构规格

## 1. 决策摘要

V6不以“把V5.3再润色一遍”为目标，也不以保住127页、274分钟为约束。它先重新证明每个学习事件和每一页的存在资格，再同源重写教案、学习单、逐页无生试讲稿和PPT；页面结构冻结以后，才制作统一角色的正式插图。

新的评价单位不是“这页看起来完整”，而是：

> 前页学生产出 → 本页唯一动作 → 本页可见变化 → 后页实际调用

一页只有在这条因果链闭合、且不能由邻页无损承担时，才能保留。审计结果只允许“保留、合并、移动、重写、删除”，没有“基本可用，以后再改”。

V5.3在V6通过全量审查以前只作为基线保留，不被覆盖；它的页数和时长不构成新版目标。V6放行后，旧版才移入版本历史或系统回收站，不与正式交付并列。

## 2. 为什么此前会出现“看似完整，实际浅薄”

问题不是AI完全没有框架，而是常见生成方式有四个结构性偏差：

1. **以教师发送代替学生接收。** 页面写了问题、教师说了解释，就被误判为学生已经理解。
2. **以局部合理代替全程因果。** 单页语言通顺、活动像活动，却不检查学生此刻是否已有完成它的文本经验和分析工具。
3. **以成分齐全代替页面必要。** 有导入、有三问、有讨论、有总结，并不能证明相邻四页没有重复，也不能证明听众有任务。
4. **缺少真正的否决机制。** 评分容易让优点抵消关键缺陷，“大体不错”最终成为放行理由。

因此，增加提示词或再列一批原则仍不够。V6同时引入三种约束：

- **前置约束：** 学生现在能不能做；
- **因果约束：** 做前与做后发生了什么可观察变化；
- **否决约束：** 任一硬门失败就返工，平均分不能补偿。

## 3. 项目目标与非目标

### 3.1 目标

1. 学生沿六章原文持续看见人物、动作、时间、声音和认识怎样变化，得到一个完整故事，而非零散字词和术语。
2. 每个问题都匹配学生当时已经拥有的原文、知识、方法和表达框架。
3. 意义生成尽可能覆盖全体学生；公开发言之外，听众也必须倾听、记录、追问或修订。
4. 逐句释义、语言知识、文学体验和生活讨论互相支撑，不彼此割裂。
5. PPT前台只保留学生此刻必须看见的内容；目标、学情、方法论和评估语言全部进入后台。
6. 每页均有可实际演出的无生试讲稿，以真实课堂节奏检验页面，而不是用提纲冒充逐字稿。
7. 插图必须帮助学生进入具体动作、意象或时空关系，同时保持文本边界、审美质量和人物一致性。
8. 形成可重复使用的逐页审计、教学手法选择、插图资产和独立复核机制。

### 3.2 非目标

- 不为维持2课时、127页或274分钟而倒推内容；
- 不要求每一页都放人物插画；原文批注、关系变化、现场板书和留白本身也可以承担视觉功能；
- 不用活动数量、课堂热闹或教师话语的文学腔代替学生学习；
- 不把现代婚恋术语直接当作《氓》的原意；
- 不预先编造学生答案，再把它包装成“课堂共创”；
- 未经真实试教，不宣称学生已经喜欢、享受、学会或完成迁移。

## 4. 审计对象、标识与版本策略

### 4.1 审计对象

首轮审计覆盖V5.3全部127页：S001为隐藏教师导航，S002—S127为126张学生路径页。隐藏页也要说明其管理功能，但不套用学生发言覆盖指标。

审计先保留旧ID，以便定位旧版问题；新版结构冻结后再分配V6页码，并生成“旧ID—处理决定—新ID”映射。被合并或删除的旧ID仍保留审计记录，避免问题随重编号消失。

### 4.2 页面处理决定

| 决定 | 含义 |
|---|---|
| 保留 | 六道硬门全部通过，仅允许校字、间距等非功能性修正 |
| 合并 | 功能可由相邻页同一学习事件无损承担，合并后重新审计 |
| 移动 | 页面功能有效，但前置条件、认识边界或调用位置错误 |
| 重写 | 功能值得保留，但问题、动作、覆盖、证据或视觉不合格 |
| 删除 | 没有不可替代的学习收益，或只是重复、装饰、预制答案 |

不允许用“加一句说明”掩盖前置条件错误，也不允许把“移动”当作规避重写的手段。

### 4.3 版本

- 基线：`5.3-literary-participation`；
- 新版内部标识：`6.0-page-function-audit`；
- V6全量放行前，V5.3不覆盖、不永久删除；
- V6放行后，正式目录只保留V6交付物，V5.3进入版本历史或系统回收站；
- 插图试验目录`assets/illustrations_v1_samples`和`assets/illustrations_v2_vignettes`不自动成为V6资产。

## 5. 逐页功能审计模型

### 5.1 唯一功能句

每页先写一条后台功能句：

> 在【可定位的前置条件】下，【哪些学生】通过【具体动作】，把【页前作品/认识】变成【页后作品/认识】，生成【保存证据】，并在【后续页面】被调用。

一句话不能清楚写完，说明页面承担了过多核心任务；与相邻页写出相同变化，说明页面重复。

审计首先标明`audit_scope`：

- `learning_page`：独立承担一次学生认识或作品变化的学习页；
- `event_carrier`：因远距可读、完整听读、活动持续显示等原因承载同一学习事件的一种屏幕状态。

`event_carrier`不是逃避逐页审计的例外。它仍须证明唯一载体职责、视觉必要、不能无损合并和所属事件；只是“作品变化、保存、后续调用”在完整学习事件层面判定。例如首次听读跨两张原文页，两页的唯一职责分别是让前三章、后三章在不中断听读时保持可读，整体事件才生成个人停顿句。若一张载体页没有可读性或课堂操作上的独立损失，仍须合并或删除。

### 5.2 必填数据字段

| 字段 | 必填内容 | 直接否决情形 |
|---|---|---|
| `legacy_id` / `new_id` | 旧版稳定ID和冻结后的新版ID | 页码变化后无法追踪处理决定 |
| `audit_scope` | `learning_page`或`event_carrier`；后者必须引用所属事件 | 用载体页身份掩盖重复内容 |
| `learning_unit` | 页面所属的完整学习事件 | 页面孤立，找不到输入与闭合位置 |
| `unit_role` | 输入、体验、澄清、生成、交流、质询、修订、收束、转场中的一个主角色 | 主角色不唯一 |
| `supporting_move` | 可选的朗读、书写、倾听、板书等辅助动作 | 用辅助动作冒充第二核心功能 |
| `prerequisite` | 已有原文经历、知识、方法、作品及证据页 | 所需框架尚未建立，或只是假定学生会 |
| `epistemic_status` | 文本明写、教材解释、合理推断、现代延伸、课堂生成 | 把推断或现代框架当作原诗事实 |
| `unique_function` | 学生将什么变成什么 | 不能说清，或与前后页相同 |
| `student_input` | 实际调用的前页产出或既有经验 | 只在语言上说“承接”，却不使用产出 |
| `student_action` | 主体、动作、对象、时长、产物 | 只有“理解、感受、思考、讨论”等空泛动词 |
| `voice_coverage` | 独立准备、同伴表达、小组贡献、公开发言的覆盖和抽取方式 | 意义生成没有全员准备，小组可由一人包办 |
| `listener_task` | 非发言者听什么、记什么、怎样反馈 | 有展示而听众无事可做，或记录从未使用 |
| `observable_change` | 页前状态、页后状态及判据 | 证据只是“完成任务”，看不出认识变化 |
| `artifact_location` | 教材旁批、学习单、板书、口头采集或屏幕现场记录 | 声称有证据却无保存位置 |
| `previous_relation` | 前页怎样成为本页输入 | 只有主题连续，没有学习连续 |
| `next_relation` | 后页怎样比较、质询或修订本页产出 | 一次性书写，后续再未出现 |
| `deletion_loss` | 删除将失去的不可替代能力、证据或转折 | 只能回答“少一个过渡”“不够完整” |
| `merge_test` | 与前后页合并的结果和不能合并的理由 | 可以无损合并却仍独占一页和时间 |
| `channel_split` | 屏幕、教师口头、学习单分别承担什么 | 三者问题口径、任务或答案状态不一致 |
| `framework_cost` | 新增概念、分类维度和操作步骤 | 支架比原诗更难，或一次引入过多维度 |
| `primary_visual_duty` | 题名、全文/章内整读、原文批注、文本比较/关系图、动作小景、意象点景、活动界面、现场共创中的唯一主视觉机制 | 没有主机制，或多个机制争抢解释权 |
| `secondary_visual` | 可选，只能用于定位、强调或维持连续性，不得承载新的解释 | 辅助元素删去后任务含义改变，说明它实际是第二主机制 |
| `time_value` | 分钟成本与不可替代收益 | 时间增加却没有覆盖、作品或理解增量 |
| `decision` | 保留、合并、移动、重写、删除 | 用模糊结论回避处理 |
| `review_status` | 自审、学生接收审查、视觉审查的缺陷与关闭证据 | 缺陷无责任页、无修复、无复验 |

六道门分别保存结构化结果：`gate_id`、`gate_status`（`pass/fail/na`）、`evidence_refs`、`failure_code`、`reviewer`和`reviewed_at`。证据引用采用`页ID#字段`、`事件ID#产出`或`资产ID#任务卡字段`格式。`na`只允许`event_carrier`在第4、5门使用，且必须引用一个已经通过这两门的所属学习事件；其他位置出现`na`即失败。

统一失败码至少包括：

- `G1_PREREQ_MISSING`：前置不存在；
- `G1_BOUNDARY_OVERREACH`：认识边界越界；
- `G2_FUNCTION_DUPLICATE`：功能重复；
- `G2_ROLE_MULTIPLE`：核心角色不唯一；
- `G3_ACTION_VAGUE`：学生动作不可执行；
- `G3_COVERAGE_FALSE`：覆盖无法实现；
- `G3_LISTENER_IDLE`：听众无任务；
- `G4_CHANGE_UNOBSERVABLE`：变化不可观察；
- `G5_OUTPUT_ORPHAN`：产出没有后续调用；
- `G6_MERGEABLE`：可以无损合并；
- `G6_DELETION_LOSS_EMPTY`：删除损失不存在。

两名审查者结果不一致时默认不放行。双方先只围绕证据引用复核一次；仍不一致，则由未参加写作、未看双方结论的第三名审查者独立裁决。裁决结果及理由写入`review_status`，不得由设计者自行取较宽结论。

### 5.3 六道硬门

`learning_page`必须同时通过：

1. **学生现在能做：** 前置理解和方法已有可定位证据；
2. **本页只做一件不可替代的事：** 唯一功能明确且不与邻页重复；
3. **学生真的在行动：** 动作具体，意义生成有全员入口；
4. **行动后发生可观察变化：** 页前与页后作品或认识可以比较；
5. **产出后来真的使用：** 它进入后续解释、追问、修订或总结；
6. **删除或合并确有损失：** 损失不能由相邻页以相同时长承担。

任一硬门失败，`decision`不得为“保留”。版式漂亮、教师台词流畅、总分较高均不能抵消。

`event_carrier`必须通过第1、2、3、6门；第4、5门在所属学习事件级通过并以`na + 事件证据引用`回填。这样既逐页说明它为何存在，也不伪造一张封面或半幅原文独自造成了学习变化。

### 5.4 特殊页面

- **封面：** 标为`event_carrier`，只承担命名作品、聚拢注意和建立审美基调；不得提前规定结尾情绪或中心思想。
- **转场页：** 必须改变学生的时间、对象或行动；纯口号和重复标题删除。
- **整读页：** 以一次完整听读事件审计，允许原文因可读性跨两页，但两页不能分别虚构学习功能。
- **回收页：** 必须实际调用此前学生作品；只公布教师答案不算回收。
- **留白页：** 若为现场共创，必须说明谁写、写在哪里、怎样保存和后用；不能预填答案再称共创。

## 6. 新的整课学习链

V6按以下因果链重组，不受旧模块页数限制：

1. 广泛回忆初高中爱情、婚姻文学；
2. 完整听读《氓》，保存个人停顿处；
3. 补充进入原文所需的最小《诗经》与朗读支架；
4. 六章按意义句群讲读，持续看见前后叙事；
5. 每章穿插一个与本章困难匹配、形态不同的短活动；
6. 六章接力，重构女主人公的一生；
7. 把诗中压缩的婚后生活还原成可感的日常；
8. 通过证据听证区分伤害责任、关系延续条件和时代阻力；
9. 婚姻圆桌，让学生形成并修订自己的判断；
10. 收纳字词、叙事、语言形式、意象、人物认识和阅读方法；
11. 最后完整朗读，以声音检验理解是否重新进入全文。

这一链条遵循“全文—局部—全文”“体验—解释—表达—修订”。三问开头只导航，不要求学生在缺少原文时写高阶归因；完整读懂后再集中回答。

## 7. 导入示范批次：从广泛回忆到新的婚姻叙事

旧S003—S005限定三篇作品，并过早追问“幸福或困境取决于什么”。学生既缺分析框架，也没有充分开口；固定显示“真实了解、尊重与行动、平衡支持与边界”，还把教师结论伪装成课堂共创。V6按下列事件重做。

| 暂定页 | 唯一功能 | 学生动作与覆盖 | 可见变化与后续调用 | 视觉职责 |
|---|---|---|---|---|
| N01 | 命名《氓》并让全班进入作品 | 看题、翻到原文；教师不从结尾定调 | 全班知道今天共同阅读的文本 | 纯题名、出处和纸本肌理；首次听读前不突出桑叶、淇水、枯黄、湍急或人物情绪 |
| N02 | 从个人记忆中检索爱情或婚姻文学 | 每人写1—3篇初高中语文课上读过的课文或整本书，并用一句自然话说“它写了什么”；45秒仍空白者翻教材目录或使用教师按本班进度准备的作品提示条，也可先听同伴后补写 | 从“等教师列篇目”变为“每人带着一份旧经验”；允许经恢复支架后形成 | 大留白；提示条开始时隐藏，确有需要才出现，不预设主题框架 |
| N03 | 让每名学生的旧经验进入小组公共记忆 | 四人依次发言，每人15—20秒；记录者只记篇名和主题短语；重复作品可以补不同主题 | 个人清单变成小组作品谱，不由一人包办 | 清楚显示轮流规则、计时和记录位置 |
| N04 | 扩大班级看到的爱情、婚姻主题范围 | 每组20秒：优先贡献尚未出现的作品或不同主题；若均重复，就指出两个已有作品之间一项有根据的联系。按8组设计，总公开时间不超过3分钟；超过8组时先同主题并组再抽取 | 形成真实班级作品库，人人同时勾记一项自己未想到的内容 | 现场板书/批注界面；不预填学生答案 |
| N05 | 教师把广泛回忆整理成文学主题谱，而不替学生深析 | 教师只用现场已经出现的学生词语和作品归类；“相遇、爱慕、思念、等待、选择、阻力、共同生活、失去、离别”等只放在讲者备注作为可能词库，不要求全部出现；学生可补充或纠正 | 零散作品成为由本班实际材料形成的宽广主题场，后续可定位《氓》新增了哪一种叙事 | 每个上屏主题都保留至少一篇学生作品出处；明确标为教师现场整理，不冒充学生原话 |
| N06 | 从已有主题场引入《氓》的新阅读对象 | 学生听教师转场：“今天再读一个更早的故事。它不只写相遇，还由一位女子回望婚后的日子。” | 从熟悉作品转向新的第一人称婚姻叙事 | 只呈现必要原文身份，不给婚姻处方 |
| N07 | 建立全文导航，不预制答案 | 只读三问，不写三份猜想 | 学生知道读完全诗后要回答什么 | 三问简洁、远距可读，无装饰性长句 |

三问保持朴素：

1. 她经历了什么？
2. 她婚后的不幸，在生活中是什么样子？
3. 这场婚姻为什么走到这一步？

导入的价值在广度、发言和共同记忆，不在立刻形成深刻婚姻理论。教材课文和语文课整本书阅读优先；学生说到影视改编时，教师自然追问其文学来源，能定位原作则收入，不能定位则暂记在“相邻故事”而不批评。学生主动说到其他课外文学作品可以进入，教师不主动铺开课外清单。教师总结明确标为教师对现场材料的整理，不伪称学生原话。

## 8. 全文听读与最小必要支架

### 8.1 第一次完整听读

导入后完整听读六章，中途不停顿、不释义、不答三问。因后排可读性可分两张原文页，但它们是一个不可拆的学习事件。

学生只完成一项个人动作：在使自己停顿的一句旁留下点、问号或短语“我听见/我看见/我想问”。听后先同桌各说一次，再匿名收集或自愿分享2—3个真实停顿处，使个人初读进入公共课堂。没有明显感受也可报告“尚未找到”，不强迫预设情绪。

### 8.2 最小支架

只补充后续逐句阅读立即需要的内容：

- 《诗经》是我国最早的诗歌总集，收诗305篇；
- 风、雅、颂，《氓》属于《卫风》；
- 女子第一人称回望婚姻经历；
- 四言节奏和本课确实会造成朗读阻滞的字音。

赋、比、兴、反复、叠词、时间压缩、对照等，在学生先听见或看见语言现象以后再命名。字音不采用一页集中倾倒；能随章解决的放回相应句群。

## 9. 六章讲读：让原文持续成为理解主线

### 9.1 基本节奏

每章按以下闭环推进：

> 完整读本章 → 连读一个意义句群 → 定点释义和人物行动 → 观察语言怎样改变处境 → 完成匹配困难的短活动 → 接回整章 → 学生用自然话讲出这一章

30组诗句全部覆盖基本释义、说话者/行动者和叙事推进，但不机械制造30张“孤句＋译文＋术语”页面。全诗主要按12个意义句群组织，页数由可读性和学生行动决定。

### 9.2 讲读页的持续坐标

每张句群讲读页至少让学生能够定位：

- 六章位置；
- 当前章完整原文轨道；
- 当前句群高亮；
- 前一个状态、当前发生的变化、后续走向三者中与本页唯一功能直接相关的关系。

这不是要求六层信息同时争夺注意。正式批量制作前，先冻结三张16:9真实版式原型：短句群、最长句群、含比较或活动的句群。原型遵守：

- 当前原句是第一视觉焦点，原则上不小于38pt；确因长句换行时不得小于34pt；
- 当前章原文轨道保留本章全部可读原句，原则上不小于22pt，当前句群以色块或字重高亮，不另做不可读缩略全文；
- 六章坐标只显示“第几章”和当前进度，不承担原文阅读，不小于18pt；
- 前态、当前变化、后向合计最多三个一行短项；若本页只需要其中一项，就不补齐三项；
- 一页最多四个主要信息块：当前原句、章内轨道、六章坐标、关系/活动区；
- 空间不足时按“装饰 → 后向提示 → 前态说明”的顺序删减；当前原句、当前章可读语境和紧凑的六章位置码始终保留，不得缩成装饰；
- 以100英寸16:9投影、约7米后排作为目标场景完成实际尺寸渲染；若现场条件暂不可得，必须明确记录为桌面模拟风险，不能声称后排实测通过。

三张原型须先通过学生接收和视觉审查，再用于全课。坐标不做成细小页脚，也不允许以缩字完成“信息齐全”。

### 9.3 12个意义句群

| 章 | 句群A | 句群B |
|---|---|---|
| 一 | 外在印象与真实来意 | 远送、媒妁条件、安抚与婚期 |
| 二 | 登垣、未见、哭泣、见到后的骤变 | 卜筮、车来与迁嫁 |
| 三 | 桑叶、斑鸠与劝诫的起点 | 从物到人、从自身到性别处境 |
| 四 | 桑叶变化与多年食贫 | 淇水场景与明确责任判断 |
| 五 | 多年劳动如何重复成生活 | 粗暴、家人不解与独自反思 |
| 六 | 偕老愿望与“有岸/有泮” | 少年记忆、违誓核验与停止判断 |

### 9.4 认识边界

- “蚩蚩”先按教材解释为忠厚的样子，它是出场印象，不自动证明真实长期品格；
- “匪来贸丝，来即我谋”可支持表面来意与真实来意不同，不能证明男子有计划地伪装完整人格；
- “将子无怒”可以在全文后重看，但不能倒推婚前暴力事实，也不能断言女子已经识别危险而故意忽视；
- 日常所说“恋爱脑”只能作为学生可能提出的现代口语，教师须转写为情感投入下的浪漫化解释或确认偏向；它不是心理诊断，也不是男子失信和粗暴的原因；
- 女主人公的信任、迁嫁、投入、长期劳作和支持缺失，可以解释关系为什么难以及时停止，不承担对方伤害的责任；
- “淇则有岸”是边界语言，不固定为第三次明确渡水；
- “亦已焉哉”表现停止判断。诗没有写明她是否已经实际离家、怎样离开或后来怎样生活。

## 10. 章内异质活动与教学手法库

### 10.1 选择原则

教学手段不按“每页换一种花样”选择，而按学习困难反推。每个活动必须回答：它解决哪一个阅读困难；不用它，学生会缺少哪项经验或证据；活动后怎样接回原诗。

连续学习事件若重复相同动作，却没有改变阅读对象、任务难度、反馈方式或产出形态，就合并或重写。朗读、回诗、倾听等核心语文动作可以多次出现，但每次必须在完整学习链中承担不同的可定位作用。活动不以表演能力、私人情感披露或少数外向学生为门槛。

### 10.2 手法库

| 学习困难 | 可选手法 | 合格产出 |
|---|---|---|
| 字词或背景造成进入障碍 | 定点释义、微型背景、教师示范、分歧整理 | 能把字义放回原句，继续朗读 |
| 听不见声音变化 | 完整听读、句群连读、变速读、重音迁移、双声部、静默读 | 有证据的停顿、重音或速度方案 |
| 看不清动作和时空 | 动作接龙、人物站位、路线图、时间展开、接力讲述 | 连续行动链或时空变化图 |
| 只会报术语 | 去术语观察、替换、删除、关键词回声、多解释竞争、镜像对照 | “原词—语言变化—处境变化”解释 |
| 诗句过度压缩，生活不可感 | 生活镜头、声音场景、定格、物件视角、情绪温度 | 有原诗依据且标明想象边界的日常画面 |
| 小组由少数人包办 | 人人先说、同桌复述、小组拼图、随机代表、观点续写 | 每人有准备或表达痕迹 |
| 展示时听众失去任务 | 听众证据单、找空缺、记录分歧、补充、反例、可见修订 | 发言者作品因听众反馈而改变 |
| 观点像标签 | 证据听证、事实/推断界线、反例检验、责任与解释分庭 | 判断—证据—限度三者齐全 |
| 读完无法收束 | 一句话章意、三十秒旁白、双层句、修改前后、给后来人的一句话 | 可从原诗重建的个人表达 |

### 10.3 六章优先活动形态

- 第一章：不知道结局时的初见印象；全文后再回来看哪些细节需重新判断；
- 第二章：按“望—不见—泣—见—笑—迁”组织动作并设计两种速度；
- 第三章：先描述“沃若”的质地，再让两种解释竞争，到“黄而陨”后修订；
- 第四章：把经历事实与叙述者的责任判断分开；
- 第五章：把“夙兴夜寐”的多年压缩展开为一天，标出原诗依据和合理想象；
- 第六章：用疲惫克制与清醒决绝两种声音读“亦已焉哉”，允许复杂情绪并存。

## 11. 全文后的三问活动

三项活动都必须包含：全员个人准备、小组共作、公开表达、听众任务、同伴追问、返回原诗、可见修订。教师总结只能在学生作品之后出现。

### 11.1 她经历了什么：六章人生接力

六组各认领一章。组内每人先写一条本章行动或心境变化句并依次轮读，小组再从全员材料中合成三句不超过三十秒的自然叙述，并指出一句托住叙述的原诗。台下是“故事守门人”，记录一处讲清的转折和一处断裂；每两章开放追问，台上据此补充或改写。这样公开代表只负责呈现共同作品，不能取代组员的意义生成。

最终每人修订：

> 我认为最重要的转折是____，因为诗中写道____；从这里以后____。

活动的核心不是六组依次汇报，而是把局部章意重新接成一个人的完整经历。

### 11.2 她婚后的不幸在生活中是什么样子：让诗句长成日子

每名学生先独立选择清晨劳作、日复一日的贫困、丈夫态度改变、面对粗暴、家人讥笑、独自回想等一个生活时刻，写下一个动作和一处原诗依据；组内轮读后合成一个四十秒以内的日常镜头，可用旁白、声音场景、定格或双人讲述。呈现时不用原诗原句做台词，也不虚构具体伤害方式。

听众必须回答两件事：哪句诗使这个生活镜头站得住；哪一部分只是合理想象。每次呈现后指定一名听众提出证据质疑，呈现组必须回到原诗，当场改写、删去或保留并说明镜头中的一句。每名学生再依据这次反馈完成并修订：

> 她的不幸，不只是____，更是____。

教师从学生表达中整理长期劳作、贫困、言行不一、背叛或反复、粗暴伤害、得不到理解、孤立无援等现实处境。分类由现场材料生长出来，不提前放在任务页上。

### 11.3 为什么走到这一步：证据听证与因果分层

个人准备前先同时看见三种不同问题；每名学生选择其中一个，形成“我的判断＋原诗证据＋不能说满之处”。小组再把判断卡放入对应问题并检查是否错位：

- 谁直接造成了伤害；
- 什么使这段关系长期延续并越来越失衡；
- 她形成停止判断后，现实中还可能面对什么阻力。

公开听证时，一组陈述，另一组必须用“这是诗中明写、合理推断，还是现代延伸”追问；其余听众同时在学习单的原因听证栏标注“明写/推断/延伸”，并记一处支持证据或疑问。每轮除指定质询组外，再抽取一项听众补充。原组依据质询当场移动、改写或撤回原因卡。

全部听证结束后，每名学生都必须对自己的判断卡执行“保留、移动、改写、撤回”之一，在学习单原因听证栏并列保存修改前和修改后；教师收束时从这些真实修订中选择代表性变化，而不是只展示台上卡片。最终明确：

- 男子的失信、反复、背叛和粗暴由男子负责；
- 女主人公的情感投入、已经付出的成本、长期劳作、支持缺失与时代处境可以解释停止为何艰难，不减轻对方责任；
- 第一章中有限信息、表面来意与真实来意的不同、婚前印象和“无怒”值得全文后重看，但不能把她写成明知危险仍自找后果。

### 11.4 婚姻圆桌

在三问形成充分文本依据以后，才讨论作品给后来人的提醒。先在第三人称和文学作品范围内发言，不要求学生暴露家庭或亲密关系经历。

圆桌可从以下五个相互关联的生活问题中选择，不要求一课全部覆盖：

1. 婚前怎样保持审慎，并让长期行动而非一时形象接受时间检验；
2. 怎样识别承诺与行动、婚前与婚后的持续反差；
3. 已经付出很多时，为什么继续付出不一定能修复失衡；
4. 好的关系为什么需要支持网络，而孤立和讥笑怎样加重困境；
5. 彻底失望、形成边界和决定停止之间有什么区别。

每人选择一问，写一句判断和一处原诗依据。四人依次发言，听者轮流承担“找依据”“查归责”“问限度”三种任务；小组保留一项没有消失的真实分歧。全班公开分享时，发言组先呈现判断与分歧，听众从原诗依据、是否过度归责受伤者、是否说得太满三个方向追问；原作者当场改写或说明保留。最后每人写一句给后来人的提醒，与开场的旧故事主题谱建立一处联系。

教师最后只收束现场真正出现的学生原话、原诗和必要边界。若现场材料支持，可以归纳“好的婚姻需要长期可信、相互尊重、责任对等、支持可及和边界有效”；没有出现的维度不伪装成学生共同结论，可由教师明确以补充意见提出，不能冒充唯一标准答案。

## 12. 知识收纳

收纳不是把课堂重新压成知识清单。先遮答检索，再核对并回到原诗，至少包含：

1. **故事与六章结构：** 相识议婚、等待迁嫁、回望劝诫、婚变控诉、劳作孤立、违誓与停止判断；
2. **字音字义和特殊用法：** 本课实际影响理解与朗读的字词；
3. **语言形式：** 四言节奏、叠词、反复、对照、时间压缩、第一人称回望；
4. **赋比兴与核心意象：** 桑叶前后变化、淇水和边界语言，多解必须保留证据与限度；
5. **人物与关系认识：** 女主人公的投入、劳作、孤立、反思和停止判断；男子的失信、反复和粗暴；
6. **阅读方法：** 从人物行动进入叙事，用词语和形式解释处境，区分文本事实、合理推断和现代延伸；
7. **个人修订：** 初读停顿句、最重要转折、生活处境句、原因判断和婚姻提醒的前后变化。

最后一次完整朗读不再承担“第一次感受”，而用于检验学生能否把局部知识重新放回一个完整声音和故事。

## 13. 学生前台与逐页无生试讲稿

### 13.1 学生前台

允许显示：

- 此刻需要朗读、凝视、比较或标记的原诗；
- 帮助看见动作、时空、声音、词语变化的必要视觉；
- 学生此刻真正要回应的问题；
- 完成活动不可缺少的时长、步骤和产出要求；
- 活动发生以后才形成的共同发现。

禁止显示：

- 学生角色、教学目标、设计意图、认知诊断和评估标准；
- “理解链、知识碎片、硬门、接收审计、页面功能”等研发语言；
- “不填表、不概括、不分析、不抢答”等否定式管理口号；
- 活动发生前的标准答案；
- 教师已有结论冒充的学生共创；
- 删除后不影响当下学习的装饰性说明。

每个可见文本框执行删除测试：删去后学生仍能完成当下任务，就移入讲者备注或删除。

### 13.2 真实剧本

每一实际页面都要有连续无生试讲稿，并至少包含：

- 教师可以自然说出的完整台词；
- 何时切屏、走位、指向、板书、分发、朗读、静默和等待；
- 学生先做什么、做多久、怎样结束；
- 至少两类可能回应，以及教师怎样接住、追问或暂存；
- 沉默、误读、过度推断和时间超限时的处理；
- 发言者与听众的同步任务；
- 本页证据保存处；
- 这一页怎样自然接向下一页。

剧本不能写成“教师讲解—学生思考—教师总结”的干瘪提纲，也不能虚构学生一定感动、愤怒或说出预定答案。页面标称时间必须覆盖真实等待、表达、追问和修订，不只计算教师说话。

## 14. 视觉与插图系统

### 14.1 视觉优先级

> 原诗第一，学生当下任务第二，必要解释第三，插图第四。

插图不是每页配图指标。逐句和句群页优先使用原文批注；关系变化优先用清楚的动作或关系图；书写、讨论、检索页优先保留空间。只有当人物动作、意象、时空或生活场景难以仅靠文字迅速进入时，才考虑插图。

### 14.2 页面视觉类型

每页只能选择一个`primary_visual_duty`。`secondary_visual`只能定位或强调已有内容，例如同一底图上的局部高亮；它不得带来新的解释、人物动作或象征。若辅助元素承担新的理解任务，就必须拆页或重新确定主视觉。

| 页面主功能 / `unit_role` | 允许的唯一主要视觉类型 | 禁止做法 |
|---|---|---|
| 封面、题名 | 题名 | 用核心意象或人物替全文定调 |
| 全文听读、章首/章末整读 | 全文/章内整读 | 用人物插图挤占完整原诗；把跨页原文误记成两个学习功能 |
| 定点释义、语言观察、节奏、前后照应 | 原文批注 | 同页再放叙事情节图和复杂关系图 |

### 14.5 插图任务卡与一票否决

每张人物图在生成前必须填写：服务页面、原诗依据、唯一视觉功能、允许事实、禁止推断、角色ID、`character_variant`、`costume_id`、`hair_id`、`prop_id`、`timeline_position`、`relative_scale`、`reference_sheet`、`continuity_neighbors`、动作、构图、镜头尺度、画面复杂度、缩小后核心、固定配色、放置区域和无图替代方案。缺少任一人物连续性字段，不得生成人物场景。无人物资产将人物字段明确记为`na`，并说明视觉连续性依据。

出现下列任一情况，图片不得进入正式PPT：

- 看图比读诗更快得到标准答案；
- 把合理推断画成文本事实；
- 抢走原诗的第一视觉层级；
- 为容纳图片而缩小正文或活动空间；
- 人物跨页漂移、服饰失据或年龄跳变；
- 缩小到实际入页尺寸后三秒内看不出核心动作；
- 相邻页无新增教学功能地重复同一画面；若复用，必须有可定位的高亮、批注、视角或理解变化；
- 只能解释为“好看”，说不出具体理解收益。

每张候选图按同一程序验收：

1. 提交无图页和有图页的同尺寸对照；
2. 按实际PPT放置尺寸渲染整页，不用原始大图代替入页效果；
3. 至少两名未参与生成、未看提示词的观察者分别进行三秒辨识；
4. 观察者记录第一眼对象、辨认到的动作/意象/关系、它带来的理解和新增误读；
5. 两名观察者都必须先将原诗或学生任务识别为页面主对象，并准确辨认任务卡规定的核心视觉；
6. 任一观察者把合理推断说成文本事实，或第一眼只看图而忽略原诗/任务，该图立即否决；
7. 通过后再核对角色参考图、相邻场景和实际课件色彩；修复过的图重新进行完整三秒测试。

现有第二张“亦已焉哉”样片所用布带没有文本依据，不进入正式V18方案；V18默认不再生成人物图。

## 15. 评估、缺陷和返工闭环

### 15.1 四层评估

1. **页面级：** 六道硬门、前台纯净、剧本可演、视觉职责；
2. **学习事件级：** 输入—行动—交流—修订—调用是否闭合，覆盖是否真实；
3. **整课级：** 全文连续性、问题时机、活动多样性、三问回收、知识收纳；
4. **插图资产级：** 文本边界、角色一致、时代可信、三秒辨识、美感和入页收益。

### 15.2 缺陷等级

| 等级 | 定义 | 处理 |
|---|---|---|
| P0 | 事实错误、文本越界、文件损坏、严重前台泄漏、关键学习链断裂 | 禁止交付，立即返工 |
| P1 | 任一页面硬门失败、活动覆盖虚假、前置框架错误、听众无任务、产出无后用、插图误导 | 不得放行 |
| P2 | 语言AI化、课堂话语不自然、互动不足、视觉层级或节奏明显削弱学习 | 本轮必须关闭 |
| P3 | 只有真实试教才能判定的负担、回应或时间风险 | 记录试教观察点，不伪装为已验证 |

P0、P1、P2不能用总分抵消，也不能降级成“建议”。

### 15.3 独立审查

至少设置两名不参与本轮写作的审查者：

- **学生接收审查者：** 只依据实际页面、讲者备注和学习单，逐页记录学生看见、听见、做过、可能理解、可能误解和留下的作品；重点检查前置条件、发言覆盖、听众任务和后续调用。
- **视觉审查者：** 依据全量联系表、关键页原分辨率图、角色设定和插图任务卡，检查原诗是否为视觉主线、远距可读、留白、层级、动作辨识、人物一致和文本越界。

审查者不能以设计者“本来想表达什么”为放行依据。审查结论必须定位到页、字段或资产；修复后由原审查者复验修复页，并扩大到所属模块，防止局部修复制造新断点。

### 15.4 百分制量表

| 维度 | 分值 |
|---|---:|
| 文本、教材和认识边界 | 20 |
| 学生接收连续性与问题时机 | 20 |
| 页面必要性与因果闭合 | 20 |
| 参与覆盖、倾听、追问和修订 | 15 |
| 语文质地、体验和课堂剧本 | 15 |
| 视觉、插图与跨文件实施质量 | 10 |

评分只在硬门全部通过、P0—P2清零以后进行，不能参与缺陷豁免。每一分必须绑定`页ID/事件ID/资产ID + 证据字段`。各维度使用下列可复算锚点：

| 维度 | 90%锚点 | 95%锚点 | 100%锚点 |
|---|---|---|---|
| 文本、教材和认识边界 | 所有事实与解释正确，事实/推断/延伸明确 | 多义处主动呈现竞争解释及限度，跨文件完全一致 | 在95%基础上，所有高风险判断均有教材或原诗双重定位且无冗余解释 |
| 学生接收连续性与问题时机 | 无前置倒置，全文—局部—全文链闭合 | 各事件输入与后用可逐项追踪，认知负担有恢复支架 | 在95%基础上，每个关键转折均能由学生作品重建而非教师代述 |
| 页面必要性与因果闭合 | 六门全通过，旧新映射完整 | 所有合并/删除均有反事实证据，载体页无伪功能 | 在95%基础上，全课无可进一步无损合并的页面或事件 |
| 参与覆盖、倾听、追问和修订 | 关键意义页全员有入口，展示均有听众任务 | 个人—小组—公开—修订链均有保存证据，无一人包办路径 | 在95%基础上，不同表达偏好的学生均有等价参与通道且证据被后用 |
| 语文质地、体验和课堂剧本 | 前台无研发语言，台词自然，剧本可演 | 朗读、动作、意象、讨论随文本生长，分支和等待真实 | 在95%基础上，删去任何教师套话仍不损害课堂，体验与语言发现高度统一 |
| 视觉、插图与实施质量 | 远距可读、无技术缺陷、图文不越界、文件一致 | 原诗持续为主线，角色和资产全量一致，修复回归完成 | 在95%基础上，每项视觉都能证明三秒理解收益且无可删装饰 |

处在两档之间时，只能按已经满足的较低锚点评分；不凭印象给中间高分。两位审查者对某维度分档不一致时，默认采用较低档；若较低档导致不放行，则按前述第三方流程裁决。

放行必须同时满足：

- 全部页面硬门通过；
- P0、P1、P2清零；
- 总分不低于95；
- 每一维度得分率不低于90%；
- 学生接收与视觉两名独立审查者明确通过；
- 至少完成一次“发现问题—修复—修复页复验—模块回归—整课回归”；
- 教案、学习单、讲稿、PPT、课程数据和页码映射一致。

### 15.5 返工流程

> 审计 → 处理决定 → 重写共享课程数据 → 同源生成材料 → 自审 → 双独立审查 → 修复 → 修复页复验 → 模块全量复验 → 跨模块整课复验

若页面再次失败，不以措辞微调妥协；回到其唯一功能、前置条件或所属学习事件重新设计。

## 18. 真实课堂边界

V6的机器检查、桌面模拟和独立代理审查只能证明：设计内部一致、页面功能可解释、文件可用、明显风险已关闭。它们不能证明真实学生已经产生预期情绪、享受课堂、掌握知识或改变婚姻观。

真实试教后另行记录：不同学生的发言覆盖、朗读变化、作品修订、认知断点、情绪安全、活动负担、实际时长和意外回应。只有这些证据可以决定压缩课时、调整问题或声明课堂效果。

## 19. 本规格的放行判定

本规格要求后续实施始终回答三个问题：

1. 这一页为什么必须在这里？
2. 学生在这一页实际做了什么，作品或理解怎样改变？
3. 没有这一页，哪项后续学习会真实受损？

任何页面、活动或插图若不能给出可核验答案，就不进入V6正式交付。
