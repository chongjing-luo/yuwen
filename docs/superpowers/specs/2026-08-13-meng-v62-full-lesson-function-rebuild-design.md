# 《氓》V6.2全课功能重构设计

## 1. 决策

采用“先重建全课功能骨架，再逐模块构建、渲染、独立双审和冻结”的路线。V5完整母版与旧V6前三章只作为证据基线，不在原页上继续打补丁。已经通过同哈希双审的V6.2导入保留，但仍须在完整课中验证它的学生作品是否被后文真实调用。

本轮评价单位不是“页面是否有内容”，而是：

> 前页真实输入 → 本页唯一困难 → 学生不可替代的动作 → 可见作品或声音变化 → 原词证据 → 回到人物故事 → 后页真实调用

任何P0、P1或P2缺陷均有否决权，不以美观、平均分或其他页面优点抵消。

## 2. 全课学习脊柱

1. 广泛回忆初高中爱情、婚姻文学，人人用朴素话公开说一篇；教师引用现场原话后置归纳，再进入《氓》。
2. 第一次完整听读六章，保存个人初听文字；三问在完整听读和个人生成之后出现。
3. 沿六章原文逐句推进。每个意义句群解决必要字词、句法、声音、空间、意象或文化障碍，结束时必须说明人物故事新增了什么。
4. 每章只做一次正式整体重建，并把学生自然章意接入持续增长的六章故事轨道。
5. 全文后三问依次通过人生接力、生活镜头、责任质询与现实阻力讨论回收。
6. 回看第一章，区分诗中明写、合理推断和不能断言，再讨论早期警告、判断审慎与关系结构。
7. 婚姻圆桌先让学生生成有原诗依据的认识，再由教师引用学生原话收束；不预填“婚姻避坑指南”。
8. 学生自选不稳知识回诗补证，最后完整朗读，以一条解释和一个保留问题结束。

## 3. 每页五联合同

每一物理页及其备注、学习材料必须共同证明：

- 教学功能：解决一个可定位困难，删除或并入相邻页会产生明确损失；
- 学生接收：学生能用第一人称说清读了什么、做了什么、比前页多明白什么、依据和修订在哪里；
- 课堂活动：活动程序不超过一个主动作、一个必要反馈和一次亲自修订，除非能逐项证明额外理解收益；
- 真实剧本：备注含连续教师台词、静默、走位、学生普通回应、误读或沉默分支、收束和切页句；
- 视觉功能：原诗、关系、声音、空间或学生作品只有一个主焦点，插图不能泄答、越界或抢走证据。

相邻页另做合并测试；每章另做体验节奏测试。单页有用但可无损合并，仍判P2。

## 4. 第一章冻结设计：5个学习事件

### C101 第一章完整进入

完整朗读第一章，在教材或初读卡上只追踪“谁做了什么”。四言节奏随原句处理，不另设知识流程页。产物是两个人物的行动初稿。

### C102 从“贸丝”读到“谋婚”

合并旧N014、N015。覆盖氓、蚩蚩、贸、匪、即、谋；学生先比较诗句先让人看见的动作与女子随后说明的来意，再接受定点释义。只读出叙事转折，不把蚩蚩当终身人格证明，也不把来意转折直接扩写为系统欺骗。

### C103 她把他送了多远

处理“送子涉淇，至于顿丘”。学生用手指或笔让送、涉、至连续发生，形成一条低虚构路线，再说成自然话。空间体验结束必须回到女子主动远送这一人物行动。

### C104 她怎样把婚事继续说下去

合并旧N017、N018，把“匪我愆期，子无良媒。将子无怒，秋以为期”作为一轮完整对话。覆盖愆期、良媒、将、无同毋、以……为期；学生先自然口译，再听辨解释条件、安抚和约期三层言语行动。给“无怒”留下问号，但不能把它说成诗已写明婚前暴力。

### C105 再读第一章，把相遇讲完整

合并旧N019、N021，并把旧N020的必要证据边界降为章末一个真实后用动作。学生完整重读，合书讲清“他怎样来—她怎样送—婚事怎样暂缓又约定”，听者只补一处遗漏；讲述者回诗补说。产出第一章自然章意、故事轨道第一格，并留一个全文后必须重新打开的原词或问号。

自然时长预计27分钟；实际时间不得通过压缩等待伪造，真实试教后再调整。

## 5. 材料分发

- C101才发第一章初读卡，卡面只有第一章原诗与行动追踪，不显示后续分析框架；
- C101结束后再发第一章细读单，包含C102—C105的开放问题和留痕位置，不预填词义、译文、人物评价或后文事实；
- C105留下的原词或问号必须在全文回看模块物理出现并由学生修订；在消费者建成以前，第一章只称“候选”，不虚构完整闭环。

## 6. 教学手法与视觉

第一章的体验节奏为“完整读与主体追踪—对照读叙事转折—画空间行迹—听一轮完整对话—合书自然讲述”，不得重新退化为连续五页“个人填写—同桌核对—教师公布—换笔”。

正文构建阶段不加入人物插图。C102、C103未来可分别测试后置动作小景与空间小景，但必须先有无图版；图片只有提高定位、解释准确率或复述质量时才准入。W01、M01角色圣经在全文功能冻结后建立。

## 7. 验证与放行

每个模块按以下顺序执行：

1. 原文、注释、解释边界、时间盒、前台禁语和信息时序自动验证；
2. 同源生成教学母版、按时分发的学生材料、逐页真实剧本、PPT与完整备注；
3. Office结构、ZIP、MarkItDown、PDF和逐页PNG全量验证；
4. 第一次渲染必须主动发现问题并完成至少一轮修复—复验；
5. 固定全部审查输入路径和SHA-256；
6. 独立视觉审查与独立学生接收审查只读同一组输入；
7. P0/P1/P2清零后才能冻结，P3必须登记真实试教观察方法；
8. 插图入页后再次执行同样的全套验证和双审。

桌面放行只证明课堂设计具备可执行通道，不声称学生已经理解、喜欢或完成迁移。
