# 《氓》V6.5逐页功能与全课节奏重构

## 1. 本轮为何必须重新审计

V6.4已经解决了早期课件中缺少全文主线、学生前台泄露设计语言、导入预列三篇作品、讨论没有个人准备、讲者备注不是课堂剧本等问题，但旧放行标准仍有一个根本缺口：它能够证明单页字段齐全，却不能充分证明四十八页连在一起以后，学生仍在连续地阅读一首诗。

当前课件的大量页面都有原诗、有活动、有产物，也能声明后用；然而六章反复采用“整章初读—局部微任务—章末撤答旁白”，多数活动又共享“个人生成—同伴核查—本人修订—少量公开”的底层协议。局部看都合理，整体却可能让学生把《氓》接收成持续的任务审核，而不是一个女子逐渐展开、转折并醒悟的完整声音。

V6.5因此增加两种旧标准没有充分执行的否决：

1. **连续理解否决：** 一页完成后，学生若只多了一个词义、标签或活动经验，却说不清它怎样改变人物故事与前后文，本页不通过。
2. **全课节奏否决：** 一页独立有用，但与相邻页或同类远距页面形成机械重复、程序疲劳或产物消费循环，仍须合并、重写或删除。

## 2. 目标与非目标

### 2.1 目标

- 每页只有一个可证实的课堂功能，且该功能落实到学生实际可见、可听、可做的前台。
- 学生沿六章原诗形成“字面意思—事件—人物处境—前后变化—证据判断—自己的表达”的连续理解。
- 教师在必要处承担准确释义、朗读示范、关系建模、文学归纳和节奏调节，不只组织学生互评。
- 活动方式根据阅读困难选择；连续页面在认知动作、感官通道、社会结构和作品形态上保持有意义的变化。
- 综合讨论真正回答经历、不幸表现和悲剧原因，并回到开课时的爱情与婚姻文学版图；不重复消费前页产物。
- 图片只在页面功能冻结后进入，以统一人物和美学系统帮助动作、空间、时间、物象或叙事层次的理解。

### 2.2 非目标

- 不追求保住48页，也不以减少页数本身作为优秀证明。
- 不把“更多学生动作”当成“更多学习”；安静听读、教师精讲和完整朗读可以是最佳手段。
- 不让学生每页都写、互查、修订，也不取消所有必要的个人生成和同伴反馈。
- 不为视觉丰富而每页加图；原诗、板书、留白、声音和现场学生作品都可承担主视觉。
- 未经真实试教，不声称学习效果已经得到证明。

## 3. 每页功能合同

每页必须用下式写出唯一功能：

> 在学生已经拥有【可定位前置理解】的情况下，通过【一个主要课堂动作】，把【页前理解或作品】转成【页后连续理解或作品】，留下【证据】，并在【具名后页】第一次被真实读取。

同时回答十问：

1. 学生进入本页时真实知道什么？来源在哪里？
2. 当前只有哪个困难值得独占这一页？
3. 学生第一眼能否知道对象、动作和结束条件？
4. 任务所需的字词、方法和分析框架是否已经具备？
5. 学生实际留下什么可检查作品？
6. 对原文、人物或叙事的连续理解增加了什么？
7. 教师或同伴只反馈什么，作者拥有什么修订权？
8. 产物在哪一页首次真实调用？
9. 删除或并入相邻页会失去什么不可替代的学习？
10. 标题、前台文字、版式和插图是否全部服从唯一功能？

下列说法不能作为功能：“导入新课”“活跃气氛”“帮助理解”“让学生感受”“进行总结”“承上启下”。

## 4. 学生接收链

每个理解性页面或学习事件必须至少闭合：

> 原句定位 → 必要字面疏通 → 事件或声音还原 → 人物处境 → 前后变化 → 有边界的证据判断 → 学生自然表达

一页不必独自完成七环，但必须准确说明自己承担哪一环、读取了哪一环、把什么交给下一环。活动完成而人物故事没有增加，至少为P2。

独立学生接收审查采用第一人称记录：

- 我进页时已经知道什么；
- 我实际看见、听见和做了什么；
- 我最低会产出什么、认真时会产出什么、迎合老师时可能写什么；
- 我是否知道为什么做；
- 我对原文和人物多理解了什么；
- 后面是否真的再次使用。

## 5. 单页与全局双重裁决

每页只能得到以下六种裁决：

| 裁决 | 条件 |
|---|---|
| 保留 | 功能、接收链、全课节奏和呈现均成立，只需文字校对 |
| 轻改 | 功能成立，需缩短前台、减轻程序或优化剧本与视觉 |
| 重写 | 功能值得保留，但学生动作、支架、接收链或教师作用不成立 |
| 合并 | 相邻页可无损承担，或两个页面实为同一理解事件 |
| 移动 | 功能成立，但当前出现时机造成泄答、支架不足或后用过远 |
| 删除 | 没有不可替代收益、产物无消费者、只是装饰或重复消费 |

### 5.1 单页硬门

- P0：事实、伦理或安全问题；
- P1：曲解原文、提前泄答或使核心学习无法完成；
- P2：功能不成立、支架不足、活动有产物但没有连续理解、可以无损合并、程序明显压过原文；
- P3：真实试教中需要观察的负荷、节奏、物流和呈现风险。

任一P0、P1或P2存在即不放行，平均分和其他优点不能抵消。

### 5.2 全局节奏硬门

整套课件另审查：

- 连续三页若认知动作、感官通道、社会结构、作品形态中有三项相同，原则上P2；
- 同一底层协议连续或高频重复，即使表面活动名称不同，也必须削减；
- 六个章末页不自动拥有六次同构活动资格；只在能力要求真实升级时保留完整撤答互证；
- 综合页不得再次制造前文已有的同类产物，只能进行更高层次的选择、组织、讨论或迁移；
- 教师连续缺席于释义、示范和归纳，学生长期自写互审时，判为教学建模不足；
- 总时长不设预定课时上限，但每一分钟都必须换来新的文本经验、能力或必要停留。

## 6. 教师教学手段的恢复

教师不是答案机器，也不是流程管理员。以下手段在符合文本困难时可直接准入：

- **叙事性精讲：** 用自然语言把短促诗句还原为人物动作与事件，不把成熟主题提前交给学生。
- **思维示范：** 选择一处原句示范“我先看见什么事实—怎样连接前后—哪些话还不能说”，其余由学生迁移。
- **朗读示范：** 教师先读出一次可辨差异，再让学生说明自己听见什么和依据什么，不要求人人设计复杂朗读谱。
- **板书建模：** 教师依据学生真实发言生成简洁人物轨道、关系变化或意象前后照应，而非让学生承担行政分类。
- **必要知识微讲：** 对卜筮、通假、古今义等无法由猜测可靠获得的知识，用最短准确讲解扫清阻断。
- **文学停留：** 对桑叶荣枯、淇水有岸、末句收束等值得凝视之处，允许安静观看、听读和短暂停顿，不强迫立即填表。
- **后置归纳：** 在学生已有材料后，用准确、富有语文质地的语言整理共同发现，并明确分歧和文本边界。

教师讲解必须产生学生可检验的理解，不以讲述时长本身证明有效；学生活动也必须产生理解，不以参与人数本身证明有效。

## 7. 导入四页的冻结方向

导入采用“广泛唤醒—人人小范围表达—公共扩展—教师归拢—揭题”路线：

- O01面向小学至高中、课文、小说和整本书，学生尽量回忆篇名、故事和朴素主题；不预列三篇，不追问爱情幸福的本质。
- O02保证每个人在同桌或四人组完整说出一次；全班阶段只扩展新篇目或同篇不同主题，不追求人人公开。
- O03教师引用本班真实作品和原话，归拢爱情与婚姻文学常见处境，再提出《氓》尚待回答的新问题。
- O04用简洁而有仪式感的揭题和正音进入先秦女子的完整讲述。

优化重点是降低O01“它让我想到什么”的抽象性、压缩O02管理语言、让O03的归纳既有广度又不预判《氓》；不是把导入改回高阶分析。

## 8. 本轮优先重构对象

根据两路独立预审，先处理以下全局簇：

1. 六个章末页C105、C206、C306、C406、C505、C606：取消机械同构，设计由“教师带领复述—双人重建—个人撤答—全诗统整”逐步升级的能力曲线。
2. C303、C503等程序过载页：每页只保留一个主要理解动作，必要解释由教师承担。
3. C606与S01：避免连续两次重建六章人生；全诗母轨道一旦形成，下一页必须转向三问而非重写六句。
4. S01—S04：从45分钟连续写审改，改为口头讲述、板书共建、证据选择、第三人称讨论等不同节奏。
5. S05—S08：删除重复汇编，保留“检索—校准—文学发现—安静带走”的清晰收束。

其余页面按同一标准逐页取证，不因风险较低自动保留。

## 9. 插图准入

人物圣经继续冻结；场景图在页面功能审计完成前不得入页。每幅候选图必须提交：

- 对应页面和精确原句；
- 帮助学生看清的动作、空间、时间、物象或叙事层次；
- 看图以后学生必须返回的原词；
- 可能造成的时代、情节、动机和结局误读；
- W01、M01及次要人物与冻结设定的一致性；
- 统一色板、线条、光源、构图、留白和页面占比；
- 无图A版与有图B版的真实学习收益。

图片只增加气氛、替学生解释象征、暗示诗中未写事实或破坏人物连续性，直接删除。插图加入后，旧PPT哈希及旧视觉、接收审查全部失效，必须全量重审。

9. 真实试教后依据学生作品、理解断点、课堂负荷和朗读变化继续迭代。

桌面通过只说明“没有已知的设计硬伤”，不能替代真实课堂效果。
