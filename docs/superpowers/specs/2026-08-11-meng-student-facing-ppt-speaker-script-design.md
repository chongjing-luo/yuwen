# 《氓》学生前台课件与逐页逐字稿重构设计

## 1. 问题与目标

当前课件虽已建立连续阅读链，但部分学生可见页面泄漏了教师后台设计语言，例如“今天不收集知识碎片，而是建立一条理解链”和学生角色“林晓”的能力画像。这些内容属于备课目标、学习者建模和质量控制，不是学生此刻需要学习的《氓》文本内容。

本轮重构目标是：

1. 学生投影只呈现原文、问题、任务材料、必要知识和活动后生成的结论；
2. 教学目标、学生画像、误区预测、分流算法、证据门槛和设计解释全部退入讲者备注、教案或审计文件；
3. 新版课件每页讲者备注都有可直接授课的逐字稿；
4. 以逐字稿为依据，重新审计学生在每页实际看见、听见、做过、想过和形成了什么；
5. 不把桌面脚本模拟写成真实课堂数据。

本轮不把“教学”理解为教师将整理好的知识搬运给学生。学生应在诵读、发现、核验、讨论、安静思考和表达中主动形成理解，并感到过程有节奏、有选择、有完成感。所谓“享受”不是额外添加游戏或热闹包装，而是降低无效负担，让诗歌语言、问题悬念、同伴回应和理解生成本身构成积极体验。

## 2. 采用方案

采用“单一PPTX、前后台严格分层”方案。

- 前台：学生可见的幻灯片画面；
- 后台：PowerPoint讲者备注、教案、学生角色审计和质量评估文件；
- 同一页的前台材料与后台逐字稿必须一一对应，不建立容易失同步的教师版/学生版双课件。

现有33页只作为待审材料，不作为新版页数指标。新版页数完全由90分钟核心课和可选比较课中的学习目的决定：需要完整呈现原文、留出观察或保护答案时序时可以拆页；若两页只重复管理语言或设计说明则合并或删除。校验器检查“所有实际页面”，不再要求固定33页。

## 2.1 学习体验原则

1. 每页只有一个主要目的：进入情境、阅读原文、发现语言、形成解释、表达判断或完成反馈；
2. 不把每页都做成信息讲授页，也不把每页都做成高压任务页；
3. 课堂在“听/读—看见—动手—互说—安静想—获得反馈”之间有节奏变化；
4. 连续接受教师信息不得超过一个短环节，核心理解尽量由学生先观察、再命名、后整合；
5. 保留诵读、停顿、回味和自主选择，不以填满页面、填满时间为完整；
6. 活动必须服务文本理解，拒绝与诗歌无关的游戏化、表演性热闹和强迫性私人分享；
7. “享受学习”是设计目标而非预设结果，只能检查是否提供了审美进入、适度挑战、学生自主和完成感的条件，不能在试教前声称学生已经享受课堂。

## 3. 学生可见内容合同

### 3.1 允许出现

- 《氓》原文、教材注释范围内的必要释义；
- 指向原文的核心问题和当前任务；
- 学生完成任务所需的步骤、时间和作品格式；
- 活动后才显示的参考整合、文本知识和解释边界；
- 学生可以直接使用的写作框架、评价量表和修改要求；
- 课时名称、当前章次和必要页码。

### 3.2 禁止出现

- 学生角色姓名、能力画像、预测缺陷和审计结论；
- “建立理解链、避免知识碎片、认知断点、前提闭合、硬门、验证合同”等教学设计或研发术语；
- “支持轨、低恢复、0—2章/3—4章分流”等教师分层算法和身份暗示；
- 机器校验、设计版本、核心页/可选页等交付管理语言；
- 在学生作答前泄漏参考答案、预设误区或教师期望结论；
- 只服务于向观察者解释“这堂课如何设计”的文字。

### 3.3 判断规则

每一条可见文字必须至少满足一项：

1. 帮助学生读懂具体诗句；
2. 帮助学生完成当前操作；
3. 帮助学生核对已经完成的回答；
4. 帮助学生形成或修订有证据的表达。

若一条文字只让学生知道教师怎样设计、怎样评价或怎样分类学生，则退入后台。

页面信息量不设机械字数上限，而由本页目的决定。完整诗章可以占据一页的主要空间；任务页只呈现完成任务必需的信息；反馈页只整合学生刚刚处理过的关键知识。无论文字多少，后排可读性、视觉主次和可用留白必须通过渲染检查。

### 3.4 第二页改造方向

第二页不再展示方法论和学生画像，改为文本问题页：

> 读完《氓》，我们要回答三个问题：她经历了怎样的变化？她怎样重新认识这段经历？诗歌用哪些语言让这种变化可以被看见？

页面只保留三个文本问题及对应的关键原词入口，不出现“理解链”“学生角色”或学习者缺陷描述。

## 4. 讲者备注逐字稿合同

新版课件每页备注按固定字段组织：

1. `【本页时间】`：本页总时长；
2. `【逐字稿】`：教师可以直接说出口的完整话语；
3. `【学生动作】`：学生此时具体读、圈、写、说、核对或修改什么；
4. `【等待与观察】`：教师何时停顿，观察哪些真实迹象；
5. `【回答范围】`：可以接受的答案范围，不伪造学生必然答出；
6. `【条件追问】`：分别处理无回答、只有标签、证据不足和理解越界；
7. `【本页证据】`：本页结束时应留下的可观察作品或口头证据；
8. `【转场逐字稿】`：连接下一页的完整教师话语。

逐字稿要求：

- 写出学生实际会听见的教师语言，不能只写“引导学生思考”“组织讨论”等操作摘要；
- 教师不朗读学生画像、设计意图、误区名称和分流规则；
- 任务页先给问题、留出等待和学生操作，再在反馈页说参考整合；
- 不预写虚假的学生回答、人数、正确率或课堂效果；
- 可写“如果学生只说……，教师接着问……”，不得写成“学生已经理解……”；
- 逐字稿和等待时间共同受本页时间预算约束。
- 逐字稿须标明本页体验节奏：何处朗读、何处安静、何处允许学生选择、何处由同伴说而不是教师说；不得用连续讲述填满本页时长。

## 5. 逐字稿驱动的评估合同

### 5.1 前台纯净度

- 全部学生可见页面逐页扫描禁止词和语义泄漏；
- 学生画像、后台方法论和分流身份在可见页出现一次即失败；
- 有教学价值的评价量表可以保留，但教师内部达成门槛不得公开显示为学生分类。

### 5.2 逐字稿完整度

- 全部实际页面包含八个固定字段；
- `【逐字稿】`与`【转场逐字稿】`必须是完整可说句，不得仅为动作标签；
- 任务页必须有等待与观察，反馈页必须说明答案出现的前提；
- 任一核心页缺少逐字稿、学生动作、回答范围或条件追问即失败。

### 5.3 内容一致性

- 学生所听到的关键结论必须能在原文、教材注释或已核验研究档案中定位；
- 逐字稿不得说出学生页没有材料支持的新结论；
- 页面、逐字稿、学习单和教案的任务、时间、产出、答案顺序一致。

### 5.4 接收链评估

学生角色只作为后台审计工具。每页按以下顺序记录：

```text
学生看见什么 → 教师在作答前说了什么 → 学生做什么 →
学生可能给出哪些范围的回答 → 教师如何追问 →
本页结束后新增什么理解 → 怎样进入下一页
```

普通“林晓”和低恢复镜像都必须通过这条逐页链；角色名称和画像不得出现在学生可见页或教师说出口的逐字稿中。

### 5.5 时间与话语比例

- 以每分钟约200个汉字估算教师实际讲述时长；舞台指令、等待和学生动作不计入教师话语字数；
- 核心90分钟内教师逐字话语估算不超过24分钟，保留至少55%的学生语言实践；
- 活动页的教师话语只负责设问、规则和必要支架，不用讲述替代学生阅读；
- 若脚本字数与本页时长冲突，优先删教师解释，不能压缩学生操作和等待。

### 5.6 学习体验与节奏

- 每个核心课时至少包含一次完整或分章诵读、一次安静独立观察、一次同伴交换、一次公开但非强迫的文本表达和一次个人完成感明确的作品收束；
- 不出现连续三页以教师解释和结论接收为主要活动的页面；
- 每8—12分钟至少改变一次学习方式，但不为了变化而打断正在形成的深度阅读；
- 学生在重要任务中至少有一处真实选择，例如选择证据、选择解释入口或选择待修改句；
- 逐页评估除“看见/听见/做出/学到”外，增加“本页体验负担”和“学生自主性”检查；
- 体验设计只能证明课堂提供了享受学习的条件，真实感受仍须通过试教观察和学生反馈获取。

## 6. 文件更新范围

必须同步更新：

- `scripts/build_meng_pptx.js`：按学习目的重新规划页序，清除前台泄漏，生成八字段逐字稿；
- `04_氓_课堂教学课件.pptx`：按新版页序重建课件，页数不预先固定；
- `00_设计与评估标准.md`：加入前后台分离和逐字稿硬门；
- `00_实施计划.md`：加入逐页脚本编写、前台审计与复验步骤；
- `02_氓_2+1课时教案.md/.docx`：说明逐字稿用途及课堂实施边界；
- `05_质量评估与迭代记录.md`：记录本轮发现、返修和验收证据；
- `07_学生视角课堂信息流重构设计.md`：从页面意图审计升级为“可见内容＋实际话语”审计；
- `08_学生角色全程模拟与接收审计.md`：以逐字稿重跑普通/低恢复两条路径；
- `scripts/validate_meng_lesson_package.py`与测试：取消固定33页合同，加入前台禁止项、逐字稿字段、答案时序、话语时长和体验节奏检查；
- `09_交付清单与SHA256.md`：最后更新全部变化文件哈希。

学习单只在课件任务发生变化时同步修改；不为迁就脚本而额外增加学生负担。

## 7. 验证与放行

放行需要同时满足：

1. 全部学生可见页面完成逐页人工审计和禁止项扫描；
2. 全部页面讲者备注八字段齐全，逐字稿可以直接授课；
3. 核心课教师话语估算不超过24分钟，学生实践比例不低于55%；
4. 普通学生角色与低恢复镜像逐页复验无认知断点；
5. 任务页不提前泄漏反馈页答案；
6. PPTX通过Office结构、文本抽取和全量逐页视觉检查；
7. 任何视觉或内容修复后，至少再完成一次受影响页复验；
8. 质量记录明确本结论是桌面设计验收，不是真实课堂成效。
9. 两个核心课时均通过学习方式节奏、自主选择、审美进入、认知负担与完成感条件审计。

## 8. 非目标

- 不把逐字稿写成教师必须机械朗读的表演稿；它是可直接使用的基准脚本，教师可根据真实回答做有限调整；
- 不在学生页增加“设计说明”来解释为何删改；
- 不虚构学生发言、达成率或试教数据；
- 不重做与本轮前台/后台分离无关的教材研究和视觉主题。
