# ADR-002：三目标降为备课方法工作框架

## 状态

Accepted

## 日期

2026-08-21

## 背景

“让学生学到更多有价值的知识、真正学懂、享受学习”由项目所有者早期随手提出。系统随后把它扩写成20个K/U/J机制节点，并进一步升格为项目“北极星”和所有文件的普遍准入法庭。这使资料、目录、脚本、schema和工程治理也被要求绑定教学目标节点，超出了原始表述的证据与权力范围。

2026-08-21，项目所有者明确纠正：三个目标属于备课方法论，不应居于项目顶层。

## 决策

1. 将三目标文档移至 `work/methodology/lesson-preparation/备课三目标与实现机制.md`，标记为可修订的备课工作框架。
2. K/U/J节点继续用于组织备课原则、教学活动、课堂观察和教学效果解释；它们不再是资料、目录、脚本、schema或工程治理的普遍准入条件。
3. `work/principles/`继续保存教学原则的机器投影；节点字段表示教学作用坐标，不表示项目级合法性。
4. `work/evaluation/`只保留评估程序、标准收敛和报告，不再定义教学目标。
5. “桌面验证不冒充课堂效果”作为证据纪律继续有效，其依据是认识与数据边界，不依赖三目标具有项目北极星地位。

## 对ADR-001的影响

本决策补充ADR-001的职责边界：`methodology`容纳备课目标框架，`evaluation`只容纳评估治理。ADR-001关于统一存放、高考资料分层及不保留旧路径的其余决策继续有效。

## 后果

- 项目不再因一个文件没有K/U/J标签就拒绝资料或工程产物。
- 教学方法内部仍可使用既有20节点，避免立即破坏原则注册、课程合同和课堂观察结构。
- 三目标及节点本身成为可被课程标准、教学理论和真实课堂证据修订的候选方法，而不是不可质疑的上位前提。
