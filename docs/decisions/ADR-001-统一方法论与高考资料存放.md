# ADR-001：统一方法论与高考资料存放

## 状态

Accepted

## 日期

2026-08-20

## 机制节点

K1（知识可找、可追溯）、J7（系统可信与诚实边界）。

## 背景

人读方法论曾平铺在 `work/` 根目录，并分散于手册、备课规则、机器原则和评估目录；高考研究、题型视图、候选答案和批处理状态也曾混放。使用者无法仅凭路径判断文件的权威级别，生成器还可能把派生题型页重新写进试卷实体目录。

## 决策

采用以下规范结构：

```text
work/methodology/                 人读方法论唯一入口
├── foundations/                  四层八份理论参考
├── lesson-preparation/           法条、唯一备课规程与设计工具
└── manuals/                      S0—S9专项操作规则

work/knowledge/exams/             高考资料唯一入口
├── papers/                       唯一试卷实体
├── views/by_type/                可重建题型视图
├── research/                     带状态边界的研究报告
├── workbench/                    草稿、切片、候选与队列
└── _meta/                        协议、映射、冻结与状态
```

`work/principles/`继续作为机器原则真相源，`work/evaluation/`继续作为评估治理与报告区；两者不并入人读方法论目录。`work/knowledge/assessment/`继续保存命题组卷资产，不并入来源试卷库。

规范根与重要路径由 `docs/architecture/storage-layout.json` 机器登记，根目录 `AGENTS.md` 提供人读导航。旧目录不保留兼容副本或软链接。

## 备选方案

### 只改导航，不移动文件

成本低，但同类内容仍有多个物理入口，脚本可继续生成到旧位置，无法根治。

### 保留旧路径软链接

短期兼容外部脚本，但会让旧入口长期存活，目录检查无法判断使用者是否真正迁移，因此拒绝。

### 把原则、评估全部并入methodology

表面集中，却混淆人读操作、机器强制和评估证据三种职责，因此拒绝。

## 后果

- 方法与高考资料各有一个入口，文件性质可由父目录判断。
- 所有内部硬编码路径必须同步迁移；外部未纳管脚本需要按本ADR更新。
- 题型视图可以安全重建，不会产生第二套题库。
- 今后更改规范根必须更新存放契约、ID解析表、AGENTS导航并通过 `validate_storage_layout.py`。
