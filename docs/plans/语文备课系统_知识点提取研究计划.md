## 一、目标、边界与完成定义

### 1.1 项目目标

从教材、单元任务、教师用书、课程标准和高考真题中，建立一套能够：

1. 回答“教什么、为什么教、如何迁移”的高中语文知识体系；
2. 同时呈现人文维度与语言维度；
3. 将每个知识点映射到高考评价体系，但不夸大“教材直接命题”；
4. 从原子知识点向上汇总为单元、册级和全局地图；
5. 让所有重要结论都能在两分钟内回到已核实的规范来源载体复核。

### 1.2 本阶段不做什么

- 不直接生成完整教案、课堂活动方案或 PPT。
- 不把网络题库、AI 输出或 MinerU OCR 当作最终权威来源。
- 不为前言、后记、单元任务和教师用书分别生成知识点卡。
- 不在模板和受控词表冻结前启动全量批写。
- 不把“可能考”“主题相近”写成“高考直接衔接”。

### 1.3 完成定义（Definition of Done）

项目只有同时满足以下条件才算完成：

- 81 张知识点卡、28 份单元图谱、5 份册级总表全部达到各自评分门槛；
- 教材 114 项均完成 `DG0—DG4`，通过 `SG-UNIT / SG-REC / SG-BOOK`，且 A 层硬门、B 层质量分和双审一致性全部合格；
- 封存评估集与教学查询达到 C 层方法有效性门槛，限制与污染边界已公开，并生成 `SG-METHOD` 记录；
- 教材来源链、变更传播和全库一致性通过审计，生成 `TEXTBOOK-LOCK-2.0-textbook` 并闭合 `SG-TB`；
- `SG-TB` 之后先完成 `SG-EXAM-CAL`，再使 17 年高考配对卷的清洗、题组切分、题型汇编和真题 EKP 研究通过单独的高考规格验收；
- 教材核心产物、真题产物、映射表和全局地图均有稳定 ID、依赖记录、版本和评审记录；
- 所有硬性否决项为 0，引用、ID 和跨文件关系为 0 断链；
- 所有直接引文已经回看规范来源载体，核心结论证据覆盖率为 100%；
- 上游变更已经触发并完成所有受影响下游成果的复核。

## 三、知识体系与数据契约

### 3.1 双维度仍是组织主轴

```text
人文维度：单元主题 → 文本母题 → 文化议题 → 育人指向
语言维度：任务群 → 文体知识 → 语言现象 → 读写方法 → 迁移任务
```

母题不是“标准答案”。它属于研究解释，必须满足：

- 基于文本，而非脱离文本贴价值标签；
- 面向学生能够理解和讨论的真实问题；
- 至少有两处相互独立的文本证据；
- 明确标注为“有依据的解释”，不得冒充教材明示结论。

### 3.2 原子知识点

知识卡不是散文式概述。卡内每个可复用知识结论都拆为原子知识点，至少包括：

| 字段 | 要求 |
|---|---|
| `kp_id` | 全库唯一且稳定 |
| `statement` | 一句话表述一个可教、可学、可迁移的结论 |
| `dimension` | 人文或语言为主维度，可加次标签 |
| `knowledge_type` | 事实、概念、程序、策略、解释或价值辨析 |
| `primary_layer` | 必备知识、关键能力、学科素养、核心价值之一 |
| `mapping_reason` | 解释为什么归入该主层级 |
| `evidence_ids` | 至少一条有效证据；核心解释至少两条文本证据 |
| `confidence` | 已核实、有依据的解释、暂定、冲突或未核实 |

四层主归属按知识点自身的操作定义判断，不再使用“能归更高层就一律取最高层”的规则。一个事实知识不会因为具有育人意义就被改标为核心价值；跨层影响通过关系表表达。

### 3.3 稳定 ID

册码固定如下：

| 册码 | 册次 |
|---|---|
| `B1` | 必修上册 |
| `B2` | 必修下册 |
| `X1` | 选择性必修上册 |
| `X2` | 选择性必修中册 |
| `X3` | 选择性必修下册 |
| `TB2` | 必修下册教师教学用书，仅用于来源 ID |

推荐格式：

```text
知识卡：CARD-B1-U01-01
知识点：KP-CARD-B1-U01-01-001
证据：EV-CARD-B1-U01-01-001
单元图谱：UNIT-B1-U01
册级总表：BOOK-B1
真题：EXAM-2025-NC2-Q014
```

活动、整本书阅读、语言专题和诵读卡使用独立类型码，但仍遵守“一份有效学生教材切分包对应一张复合卡”。中文标题可改，稳定 ID 不随标题或切分序号变化。选择性必修下册两个以 `13_` 开头的源文件必须由清单分配不同永久 ID。

### 3.4 状态机

```text
planned → drafted → linted → primary_reviewed ─────────────→ accepted → published
             ↑                    │       └→ secondary_reviewed ─┘
             └──── rework ←───────┤                    │
                                  └→ adjudication ─────┘

accepted / published --上游变化→ review_required → linted
```

- `accepted` 之前不得进入下游汇总。
- 同一成果必须先达到 `linted`，再进入内容评审；需要第二复审时，主审通过也不能直接验收。
- 任一评审要求返工时进入 `rework`，修改后从 `drafted` 重新运行检查。
- 评审结论冲突时进入 `adjudication`；仲裁结果只能转入 `accepted` 或 `rework`。
- 上游内容变化后，下游进入 `review_required`，更新后重新运行检查与受影响维度评审。
- `published` 仅表示已进入阶段性交付，不表示以后不可修订。

## 四、来源治理与证据协议

### 4.1 来源等级与载体状态

“书或文件所代表的来源”与“本地实际文件载体”必须分开建模：一个 `source_id` 可以对应原始 PDF、切分 PDF、MinerU `_origin.pdf`、JSON、网页快照等多个 `artifact_id`。来源等级描述来源权威性；载体真实性描述当前文件能否承担终审。

| 等级 | 来源 | 可承担的证明责任 |
|---|---|---|
| `S1` | 正式教材、配套教师用书、课程标准、考试院文件、正式试卷及官方答案 | 教材事实、课程定位、命题事实 |
| `S2` | 国家级辞书、权威版本、学术专著、同行评审论文 | 文学史、作者背景、术语和研究解释 |
| `S3` | 正规教育媒体、教研机构解析 | 辅助解释和交叉核对 |
| `S4` | 聚合题库、个人网页、AI 输出 | 仅用于发现线索，不得单独支撑正式结论 |

载体另标为：`正式电子版`、`纸本扫描件`、`切分衍生`、`OCR衍生`、`网页快照`、`图像`、`计算结果`。本地扫描件只有在版本、来源链和真实性完成核验后，才可作为该 S1 来源的规范载体；不能因为内容看似教材就自动称为“S1原件”。

每个来源必须指定唯一 `canonical_artifact_id` 作为终审载体，并为每个 artifact 独立记录哈希、取得方式、`derived_from`、转换过程和 `authenticity_status`。真实性状态受控为 `unverified / verified / conflict / rejected`；只有 `verified` artifact 可被指定为 canonical。现有 `full.md`、JSON 和 MinerU `_origin.pdf` 均默认为衍生载体，只帮助定位；不得自动成为终审规范载体。

### 4.2 来源登记表

来源登记与文件登记分别记录：

```text
Source：source_id、题名、编著者/发布机构、出版社或发布渠道、版次、
ISBN/文号、发布日期、适用范围、source_level、版权备注、canonical_artifact_id

Artifact：artifact_id、source_id、carrier_type、本地路径、原始URL、获取日期、
页数/大小、SHA-256、derived_from、转换过程、authenticity_status、是否canonical

SourceRelation：relation_id、relation_type、source_id_from、source_id_to、
relation_status、evidence_ids、verifier、verified_at
```

教师用书—学生教材配套关系使用 `relation_type=edition_match`，`relation_status` 受控为 `verified / incompatible / unknown`。不得把该状态只写在知识卡自由文本中。

执行前应建立以下参考原件库：

```text
Data/reference/
├── curriculum/       # 课程标准、高考评价体系及正式说明
├── junior/           # 初中关联所需的正式教材、目录或可核验版本信息
├── policy/           # 四川用卷等考试院正式公告
└── gaokao/           # 2023—2026试卷、答案、评分资料及来源元数据
```

第三方题库可以作为检索入口，但不得替代正式试卷；非官方答案必须明确标注权威等级。

### 4.3 最小证据记录

每条证据至少包含：

```text
evidence_id
claim_id + target_id + field_path
claim_type
source_id + artifact_id + source_level + carrier_type
locator_type + locator
exact_quote（引文型证据必填）
support_relation = supports / context / contradicts
verification_status + verifier + verified_at
```

`locator` 按载体分支：

- PDF：规范 artifact、物理页码（1 起）、印刷页码（可 N/A）、必要时 bbox；
- HTML：网页快照 artifact、快照时间、标题层级/锚点和文本片段；
- 图像：artifact、页/帧和 bbox；
- 派生计算：输入 claim/evidence/artifact ID、公式或算法、口径、工具及版本、输出结果。

PDF 引文必须目视核对 `canonical_artifact_id` 指向的规范主文件页面；读取 PDF 文本层、MinerU `_origin.pdf` 或 OCR 文本都不算终审核对。`full.md` 行号会随重新解析变化，不得作为唯一定位符。

基础阶段必须建立 `split_manifest`。其中 `split_page` 与 `original_page_start` 都按 1 起计数，映射公式固定为：

```text
original_page = original_page_start + split_page - 1
```

每条映射记录规范主文件 artifact ID、切分 artifact ID、起止页、双方页数、页数恒等检查和 `mapping_verification_status`。144 个切分包全部执行首页/末页边界或渲染指纹核验；不得用抽样结果支撑 100% 定位有效率。

### 4.4 主张类型

| 类型 | 含义 | 最低证据要求 |
|---|---|---|
| `Q` | 教材或原文直接引语 | 在 S1 的规范 artifact 上逐字目视核对 |
| `F` | 作者、册次、体裁、年代等事实 | S1；教材未载时补 S2 |
| `I` | 母题、意象作用、文化意义等研究解释 | 至少两处文本依据并写推理 |
| `M` | 四层、任务群、纵向贯通等框架映射 | 框架映射须有官方定义+本课证据；纵向关系须有两端证据+递进理由 |
| `R` | 教学建议 | 教师用书证据，或明确标为“本项目建议” |
| `E` | 高考衔接判断 | 已登记真题小问和具体 KP；潜在题型不得冒充实证 |
| `D` | 字数、频次、跨年统计等派生结论 | 输入 ID、口径、公式/算法、工具版本和可复算结果 |

所有进入正式成果的非空需证字段必须有证据编号或明确的 `N/A + 原因`。所有 `I` 类解释均须至少两处相互独立的文本依据。来源等级高不等于延伸解释自动成立。

### 4.5 教师用书覆盖不足的处理

原“教学提示”拆为：

1. 教材学习提示；
2. 配套教师用书意见；
3. 本项目教学建议。

`TB2` 只有在版次、ISBN、出版信息和适用教材完成配套核验后，才能作为必修下册的配套教师用书证据。若 `edition_match` 关系的 `relation_status=unknown`，只能表述“该教师用书提出”，不得上升为当前学生教材的确定编者意图。其他四册统一写“未取得同册教师用书，待补证”。不得留空猜测、套用必修下册意见或把学生教材学习提示冒充教师用书意见。

教师用书指标分开报告：

- 来源可得率 = 有确认配套教师用书的知识卡数 ÷ 81；
- 实际引用率 = 引用有效教师用书证据的卡数 ÷ 有确认配套且存在相关条目的卡数。

客观缺源不扣单卡内容分，但分子、分母和配套状态必须公开。

### 4.6 高考衔接等级

| 等级 | 定义 | 表述边界 |
|---|---|---|
| `M1 直接调用` | 真题明确出现篇名、原句、注释，或可唯一识别的教材任务 | 可称“直接衔接” |
| `M2 方法迁移` | 陌生材料回链到具体已验收 KP，并要求相同能力动作 | 称“迁移衔接”；泛称“都考阅读能力”不成立 |
| `M3 一般关联` | 仅主题、文体或潜在题型相近 | 只能称“教学相关” |
| `M0 无可靠关联` | 当前没有足够证据 | 不强行建立映射 |

真题 ID 必须细化到小问，例如 `EXAM-2025-NC2-Q014-A`。试卷、答案和评分资料按 `document_role=paper / answer / scoring` 分别建立 Source，各自具有独立的发布机构、来源等级和 canonical artifact，再用 SourceRelation 建立对应关系。非官方答案不得继承正式试卷的 S1 等级，也不得支撑“官方答案”或“官方评分标准”结论。

任何具体年份、卷别、题号、分值和答案都必须回链到已登记 artifact 和小问 ID。题数以原卷为准，不预设固定题量或跨年总题数。

### 5.2 特殊内容包

- 活动单元：按活动步骤建立 `subtask_id`，提取完成活动所需的语文能力、活动证据和社会文化议题。
- 整本书阅读：按导读、推进、研讨、分享等教材实际阶段建立 `subtask_id`；不得凭空补齐教材未设阶段。
- 语言专题：按知识专题建立子项，必须包含正例、反例或应用任务。
- 古诗词诵读：每册一张复合卡，篇目使用 `subtext_id`；简化教学建议，但不降低引文与事实核验标准。

### 5.3 单元知识图谱

单元图谱只能汇总本单元所有 `accepted` 卡和对应单元任务，必须包含：

- 卡片和 KP 覆盖清单；
- 人文维度与语言维度矩阵；
- 共性、差异、前提、深化、比较、迁移等关系；
- 单元学习/研习任务原文定位及能力拆解；
- 高考衔接等级与真题回链；
- 前后单元递进；
- 冲突、缺源和待核实项。

单元图谱不能只是复制知识卡摘要，也不能新增无法回链到卡片或单元任务的确定性结论。

### 5.4 册级总表

册级总表汇总该册全部已验收单元图谱、古诗词诵读卡和前言信息，负责：

- 统一术语、合并同义知识点、保留不同语境下的差异；
- 描述跨单元的前置、深化和迁移关系；
- 给出人文主线、语言主线和任务群分布；
- 标明本册教师用书证据覆盖情况；
- 输出可检索的知识点索引和未解决问题清单。

### 5.5 真题解构与映射表

每道题及其小问建立稳定 ID，记录卷别、题号、规范 artifact 定位、题干、分值、答案来源等级、四层/四翼/情境编码、能力动作和原子考点。真题基础解构不写 KP 链接或 M 等级。

真题基础解构不得与教材知识卡生产并行。必须先通过教材锁定门：81 张知识卡、28 份单元图谱和 5 份册级总表全部 `accepted`，课程标准和教材来源链通过最终检查；之后才能启动真题清洗、题组切分和题型汇编。正式“真题—KP”映射仍作为独立关系表，必须等待真题 ID、EKP ID 和教材知识点 ID 均稳定。

### 5.6 全局知识地图

全局地图的**直接上游**只有 5 份册级总表和 1 份考点映射总表；81 张卡、28 份图谱和 17 年真题产物属于通过直接上游传递而来的**血缘上游**。验收分别计算直接依赖完整率与传递血缘完整率，不能把两者混称为“全部直接上游”。全局地图至少包含：

- 人文维度树；
- 语言维度树；
- 任务群、文体、方法和素养的交叉关系；
- 初中关联、必修到选必的纵向递进；
- 高考 M1/M2 映射；
- 冲突、空白和低证据覆盖区域。

## 六、评估标准

### 6.1 A/B/C 三层评价与硬性否决

评估分为三层，不能相互补偿：

| 层 | 回答的问题 | 判定用途 |
|---|---|---|
| A. 合格性硬门 | 当前版本是否有资格被评分 | Schema/语义 lint、来源、Claim—Evidence、Q 引文、I 双证、ID/链接、上游、SHA、R/P；任一失败即返工 |
| B. 产物质量分 | 合格版本的内容质量是否达标 | 使用 `2.0-textbook` 冻结权重、单项最低分和总分门槛，由观察项唯一复算 |
| C. 方法与过程有效性 | 提取方法是否能稳定扩批并服务备课查询 | 双审一致性、缺陷逃逸、封存评估集、教学查询和批次稳定性 |

A 层失败时正式总分记 `N/A`；可保留诊断性观察结果帮助返工，但不得写 `pass`。C 层失败不自动改写已合格单件，却会暂停扩批和 `SG-TB`，直到方法重新校准。

以下 R01—R10 任一项为“是”即 A 层失败，并冻结已消费该内容 SHA 的下游：

出现任一项即不计分、退回返工，并冻结受影响的下游成果：

1. `R01`：伪造、错引、张冠李戴，或作者、篇名、册次、年代、题号、分值等关键事实错误；
2. `R02`：直接引文无法定位，正式主张无适配来源，或任一 `I` 类研究解释不足两处独立文本证据；
3. `R03`：合编课文中有文本未覆盖，整个必填模块缺失，或特殊内容包使用错误模板；
4. `R04`：把研究解释写成教材明示，把学习提示冒充教师用书意见，把网络解析或 OCR 冒充原始证据；
5. `R05`：原子知识点没有主层级、映射理由或有效证据；
6. `R06`：将任何非 M1 记录写成高考“直接衔接”，或引用未登记真题作为实证；
7. `R07`：使用未验收或 hash 不匹配的上游生成单元、册级或全局成果；
8. `R08`：数量、ID、版本或跨文件链接不一致，导致来源链无法回溯；
9. `R09`：使用非现行课标、自由改写任务群名称，或把学习任务群误作固定课型/固定教学法；
10. `R10`：机械铺满四项核心素养却无语言实践依据，或把学业质量水平直接当作课文、知识点、题目难度标签。

分数不能抵消否决项。

### 6.2 Claim、证据、N/A 与通用硬指标

DG2 前先冻结 `claim_register`。每个正式主张以 `claim_id + target_id + field_path` 唯一标识，不能用 Markdown 行号代替语义路径。正文正式结果区中所有非 N/A 的 `Q/F/I/M/R/E/D` 最小命题进入分母；问题清单、模板说明、自检和版本记录不进入。

- 一条 EV 可以支持多个 Claim，但必须逐 Claim 记录绑定；复合单元格必须拆成可独立判断真伪的最小命题。
- Q 类按 quote span 计数并逐字目视核对 canonical PDF；一行含三段引文时分母为三。
- I 类每条 Claim 至少有两个承担不同推理前提的独立文本依据；同一段拆成两个 EV、同一内容的 OCR/PDF/截图均只算一份依据。
- 允许的 `na_kind` 只有 `not_applicable / permitted_unavailable / future_locked / no_reliable_relation`；`missing_required` 不是 N/A，直接判 DG2 失败。
- `0/0` 只能报告 `N/A + reason`，不得报告 100%；合法无关系时使用量表内等值治理观察项，不能删除整个维度。

适用指标全部要求 100%，并保存分子、分母和异常 ID：

```text
正式主张覆盖率       = 完整合格证据链的 asserted Claim / asserted Claim 总数
I 类独立双证率       = 至少两个独立文本依据的 I Claim / I Claim 总数
Q 引文片段准确率     = canonical PDF 逐字匹配的 quote span / quote span 总数
Locator 有效率       = 可在锁定 Artifact 上复核的 locator / locator 总数
目标绑定率           = 唯一解析 target_id + field_path 的绑定 / 绑定总数
来源适配率           = 满足对应 Claim 类型来源规则的 Claim / asserted Claim 总数
合法 N/A 率          = 允许类型、理由和边界均通过的 N/A / N/A 总数
ID/路径引用解析率    = 可解析引用 / 引用总数
上游合规率           = 仅消费 accepted 且 hash 匹配上游的下游 / 本批下游总数
```

严重事实错误、低置信正式结论和未解释占位符均必须为 0。暂时缺证的线索只能进入问题清单，不得进入正式知识点、关系或评分分母。

### 6.3 统一评分计算规则

6.10 与 `rubrics.json` 已固定各维度和检查点权重。`2.0-textbook-eval-1` 只把粗检查点展开为可复算观察项，不改变权重、单项最低分或总分门槛。

```text
覆盖型检查点得分 = checkpoint_weight × pass_count / applicable_count
判断型检查点得分 = checkpoint_weight × 通过子项权重 / 适用子项权重
维度得分         = ROUND_HALF_UP(检查点得分之和, 0.5)
总分             = 各维度得分之和，不二次取整
```

- 计分器必须使用十进制定点运算；不得用二进制浮点近似或整体印象直接给半分。
- 子观察项默认等权；非等权必须在评审前写入带 SHA 的 observation manifest。
- 每项保存 `scope_query / applicable_count / pass_count / failed_ids / evidence_refs / defect_ids`。
- 合法 N/A 只从事实观察分母剔除，并切换到等值治理观察项；原维度权重和单项门槛不变。
- 评审中发现漏列 Claim 或观察项，只能扩充分母后重算；不得删除 Claim、失败 ID 或观察项来缩小分母。
- 生产者、主审、第二复审三角色分离；两审在各自记录封存前不得读取、协商或转述对方结论。
- 两审绑定同一 artifact version、内容 SHA、Claim SHA、rubric SHA、observation SHA、upstream snapshot SHA 和 validator run。
- 两位评审各自达到总分与全部单项，结论一致，总分差≤5、任一单维差≤2，R01—R10全否，最终P0/P1/P2=`0/0/0`。
- 任一阈值、Claim/N/A 分母或否决判断冲突均进入独立仲裁，不得用平均分通过。若修改正文，生成新 SHA 并由两审完整重审。
- 最终展示分可取两审算术平均值并保留 0.25；是否 accepted 始终由双方各自过门和 DG4 决定。
- 校准样板修改后仍须由原两审对同一最终版本重评并各自达到 92；仲裁分不能替代双评。

各模板的检查点和观察项属于版本化评价解释层；改变权重或门槛等同于契约变更，必须升级版本并重新评估既有分数。

### 6.11 评审覆盖与独立性

1. 生产者对所有成果做 100% 自检；自动检查只承担已实现的机械规则，语义项进入版本化 semantic lint。
2. 教材 81 张卡、28 份单元图谱和 5 份册表全部执行 100% 独立主审和 100% 独立第二复审。
3. 生产者、主审、第二复审三角色分离；两审在各自原始记录封存前互不可见。
4. 两审必须锁定同一 version、content/file SHA、Claim SHA、rubric SHA、observation SHA、上游 snapshot 和 validator run。
5. 讨论只在两份原始评审封存后进行；内容修订产生新 SHA 后，两审完整重走，旧评审只作历史审计。
6. 高考研究产物、映射总表和全局地图的双审覆盖由 `SG-EXAM-CAL` 冻结，默认不得低于全量第二复审。
7. 每个 review package 保存评分表、问题单、首次缺陷、修改记录、绑定 manifest 和最终裁决，使第三人可复算。

### 6.12 缺陷等级与返工

| 等级 | 定义 | 处理 |
|---|---|---|
| `P0` | 否决项、来源造假、严重事实错误、依赖断裂 | 冻结下游；本项返工；所有派生成果失效重审 |
| `P1` | 不触发 6.1 否决项，但足以导致总分或单项低于门槛的重大质量缺陷 | 整项返工，复查相关维度与链接 |
| `P2` | 措辞、格式或非核心遗漏 | 修正后复核，冻结版本前清零 |

- 定义 `总分缺口 = max(0, 总分门槛 - 实得总分)`，`最大单项缺口 = max(0, 各单项最低分 - 对应实得分)`。无 P0，且总分缺口不超过 5、最大单项缺口不超过 2 时可以定向返修；任一条件超出即整份重做。
- 同一批次第二次未通过，扩大到 100% 复审；第三次未通过，更换执行者并重新校准样板。
- 任何成果进入 `accepted` 前，开放的 P0、P1、P2 必须全部清零；未核实线索移入问题清单，不作为开放缺陷留在正式成果中。
- 通过后记录版本和内容哈希；上游改变时按依赖关系触发差异复核。
- 修订后的 P0/P1/P2=0 不得覆盖首次检出记录。批次观察项一致率目标≥90%；P0 逃逸率必须为0，P1逃逸率≤10%，P2逃逸率目标≤20%。
- 任一 P0 逃逸立即暂停相关生产者/同源链扩批；P1 超阈值时批次转黄、全批复核并完成根因复盘；P2 超阈值时下一批前重校准边界和措辞样例。

### 6.13 项目级进度与质量指标

单卡分数不能代表项目完成度。每个批次结束时，协调者必须同时记录以下指标的分子、分母、计算时间、validator `run_id` 和批次哈希：

```text
卡片验收率       = accepted 知识卡数 ÷ 81
图谱验收率       = accepted 单元图谱数 ÷ 28
册表验收率       = accepted 册级总表数 ÷ 5
证据覆盖率       = 完整合格证据链的 asserted Claim ÷ asserted Claim 总数
I 类独立双证率   = 至少两个独立文本依据的 I Claim ÷ I Claim 总数
Q 引文准确率     = canonical PDF 逐字匹配 quote span ÷ quote span 总数
引用定位有效率   = 规范 artifact 上可复核 locator 数 ÷ locator 总数
引用解析率       = 可解析 ID/路径引用数 ÷ 引用总数
上游合规率       = 只消费 accepted 上游的下游成果数 ÷ 下游成果总数
观察项一致率     = 两审相同判断的适用观察项数 ÷ 共同适用观察项总数
P0/P1/P2逃逸率  = 二审首次发现且主审未发现对应缺陷的成果数 ÷ 二审成果数
```

项目级“绿灯”必须同时满足：结构检查通过，适用证据硬指标、引用解析率和上游合规率均为 100%，观察项一致率≥90%，最终 P0/P1/P2=0，P0逃逸率=0、P1逃逸率≤10%。`0/0` 报 N/A 并写理由，不得作为 100% 绿灯证据。首次逃逸记录不能被修订关闭后的 0 覆盖。任一指标未达标时，批次结论保持 `rework` 或 gate `blocked`，不得用平均分或完成数量掩盖缺口。

> 基础 validator 当前仍有工具化边界：正文 Markdown 列数、切分 Artifact 页码范围、review 目标 hash、Claim/量表 hash、batch manifest、QD 注册和 M0 结构化 N/A 尚未全部自动强制。`validator passed` 只能证明已实现检查通过，不能单独闭合 DG1/DG2；未自动化项必须进入版本化 semantic lint。

每次批次报告至少附：账本快照、检查点明细（通过数/应检数）、问题单、评分表、文件 SHA-256、校验器报告和上下游影响清单；这样可以在人员更换或上游改版后重现同一判定。

### 6.16 批次绿灯、返工和阻塞判定

- **绿灯 `green`：** 本批目标 DG0—DG4 全部闭合；validator 无 error；适用证据硬指标、引用解析率和上游合规率均为100%；观察项一致率≥90%；最终P0/P1/P2=0；P0逃逸率=0、P1逃逸率≤10%；账本/front matter/transition/review binding/DG4 receipt一致。
- **返工 `rework`：** 有 A 层失败、分数或单项未达标、P2 未清零、引用/任务/KP 缺口或评审绑定漂移。内容返工后必须回到 DG1，不得只改分数表。
- **阻塞 `blocked`：** 只作为 batch/gate disposition；必需上游未 accepted、规范来源缺失或依赖边界无法形成合法 N/A 时暂停。受阻 deliverable 仍使用 `drafted` 或 `review_required` 并附 blocker，不把 `blocked` 写入当前 deliverable 状态枚举。
- validator 的 warning 不自动等于失败，但每条 warning 必须在批次报告中给出责任人、影响范围、N/A/补证动作和关闭条件；未登记处置的 warning 不能判绿灯。

batch manifest 至少锁定 `batch_id`、时间、ledger SHA、validator run、contract/rubric/observation SHA、目标、上游版本与hash、producer、primary reviewer、secondary reviewer和coordinator。默认WIP=2个单元；只有连续两个batch green且逃逸/一致性达标，才允许临时提高到3。

### 6.17 C 层方法有效性

逐件双审只能证明当前成品合格，不能单独证明提取方法具有稳定召回率和可迁移性。`SG-METHOD` 使用生产任务发出前封存的评估集：按“册码 × material_type”分层选择 12 张卡、4 份单元图和 1 份未生成册表；记录现有 generic 草稿造成的污染风险，本阶段称“封存评估集”，不宣称完全前瞻盲测。

| 指标 | 通过值 |
|---|---:|
| 关键事实/强制任务义务召回率 | 100% |
| KP 语义精确率、召回率、F1 | 各 ≥90% |
| 主维度/知识类型/四层标签 macro-F1 | ≥85% |
| Claim—Evidence 支持准确率 | 100% |
| Q quote span 与 locator 准确率 | 100% |
| 关系边精确率 | ≥90% |
| 未支持正式主张率 | 0% |

KP 和标签指标同时报告分子、分母及 95% bootstrap 区间。任何 R01/R02/R03、关键事实/任务召回率不足100%、证据硬指标不足100%或KP F1<90%，均暂停扩批并回到模板/提示/样板校准。

方法指标的计量协议同时冻结，避免在看到结果后改匹配规则或重采样口径：

- Gold 由两名未查看生产输出的标注者独立生成，第三人只在双方封存后仲裁；仲裁前分类标签一致性须达 `Krippendorff's alpha ≥0.80`，KP 集合配对 F1 须达 0.85，否则先修订标注手册并重标，不得直接仲裁掉低一致性。
- KP 匹配以单卡为边界做一对一最优配对；核心命题、对象/动作、范围和证据边界均等价才计命中。过宽、过窄、无证扩展不计匹配；重复输出计假阳性；一条输出不得同时抵消多条 Gold，除非 Gold 先验登记为合并关系。同时报告 micro P/R/F1 和单卡 macro-F1，正式过门以表中 P/R/F1 各≥90%为准。
- 95% 区间使用事先登记的随机种子，按“册码 × material_type”分层，以交付物为聚类单位做 10,000 次 bootstrap，不把同卡内 KP 伪当独立样本。单件册表不伪造置信区间，只做完整个案过门；小分母的区间只用于显示不确定性，不代替表中点估计门槛。
- 关系边精确率是硬门；另行报告召回率和 F1 作诊断，本阶段不将“边数量”或关系召回率设为硬绩效，以免驱动强造关系。

另设12个固定教学查询，覆盖单课事实、文本解释、语言方法、单元任务、跨课比较、册级递进和证据回查：任务完成率≥90%，核心事实与证据准确率100%。计时从独立评估者看到冻结查询开始，到其打开 canonical Artifact 目标页并完成核心结论核对为止；12问中至少11问须在120秒内完成，同时报告中位数和 P90。最终 `SG-METHOD` 至少需要3名未参与生产/评审的语文教师或等价专家，可用性中位数≥4/5，且无“可能导致教学事实错误”的严重意见；只有2名评估者时只能记为 pilot，不得闭合 `SG-METHOD`。

## 八、并行边界与协作规则

### 8.1 可并行

- `SG-EVAL` 切换后、不同 batch manifest 锁定的不同单元；
- 单元简报完成后的不同知识卡；
- `SG-EXAM-CAL` 通过后，真题阶段内部不同文档的结构化解构；
- 各册全部单元通过后的五份册级总表；
- 不同成果之间的自动检查、主审和第二复审。

同一成果内部不得并行跳步，必须先完成自动检查并进入 `linted`，再进行内容评审。

### 8.2 必须串行

- 来源字段 → Schema 和引证规范；
- 候选Schema/词表/量表版本化 → `SG-CAL` → 评价解释件试运行 → `SG-EVAL` → 新批次生产；
- 全部教材卡/图谱/册表accepted + `SG-METHOD` → `SG-TB` → `SG-EXAM-CAL` → `SG-EXAM`；
- 单元简报 → 单元卡；
- 单元全部卡DG4 → 单元图谱DG0—DG4；
- 全册单元和诵读通过 → 册级总表DG0—DG4；
- 真题与 KP 双方 ID 稳定 → 正式映射；
- 全部上游通过 → 全局地图。

### 8.3 共享状态管理

- `sources.jsonl`、`artifacts.jsonl`、`source_relations.jsonl`、`deliverables.jsonl`、`taxonomy.yaml`、batch manifest、transition和主ID清单只由一个协调者串行合并；

## 九、主要风险与控制

| 风险 | 影响 | 控制措施 |
|---|---|---|
| OCR 粘连、漏字、注释移位 | 引文和语言分析失真 | OCR 只定位；所有引文回看规范 artifact；高风险项双审 |
| 教师用书只覆盖必修下册 | 教学提示口径不一 | 三类教学字段分开；缺源显式 N/A；单独统计覆盖率 |
| 母题和文化标签主观化 | 把价值判断冒充教材结论 | 标记主张类型；两处文本依据；独立评审 |
| 任务群等术语数量不一致 | 全库分类漂移 | 以课标原文建立受控词表，禁止自由造词 |
| 现有样板错误被批量继承 | 规模化返工 | 样板降级；10卡5图校准；达到92分后冻结模板 |
| 真题来源或卷别不可靠 | 高考映射失真 | 原件、政策、答案分开登记；题数按原卷生成 |
| 多执行者并发导致 ID 冲突 | 关系断链 | 单一协调者维护主清单；一文件一所有者；自动校验 |
| 上游修订未传导 | 汇总内容过期 | 记录依赖和哈希；变化触发下游 `review_required` |
| 为追求覆盖强行建立关系 | 知识地图虚假繁密 | 允许 M0 和“未核实”；不以关系数量作为绩效 |
| 评分凭印象、分母漂移 | 同件换评审无法复算 | Claim/observation manifest锁SHA；十进制定点计分；第三人复算 |
| 新旧评价规则局部混用 | 同批结论不可比较 | `SG-EVAL`整包cutover；记录唯一cutover batch和在制件边界 |
| 逐件高分被误当方法有效 | 扩批后仍系统性漏项 | 封存评估集、教学查询、召回率/F1/逃逸率独立过门 |
