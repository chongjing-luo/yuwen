# 试卷库组织约定

## 一、核心原则：卷是实体，省是视图

同一份全国卷被多省使用——按省建库必然复制。**主实体 = 试卷（卷代码×年份）**，省 = 使用映射（派生索引）。三种视图全部由映射生成、零复制：按省历年 / 按卷种历年 / 按题型。

## 二、卷代码表（初稿，v1.0 冻结此项；新增先登记再产生数据）

| 代码 | 卷名（文件名可能出现的写法） | 年代 |
|---|---|---|
| DG1 / DG2 | 全国大纲卷 Ⅰ/Ⅱ（"全国Ⅰ卷""大纲版Ⅱ"） | 2008-2015 |
| XK1 / XK2 / XK3 | 新课标 Ⅰ/Ⅱ/Ⅲ | 2016-2020 |
| JIA / YI | 全国甲卷 / 乙卷 | 2021-2023（甲由课标Ⅲ演化） |
| XG1 / XG2 | 新高考 Ⅰ/Ⅱ | 2021- |
| BJ / SH / TJ / JS / ZJ | 北京 / 上海 / 天津 / 江苏 / 浙江（自主命题期） | 各省不同 |

## 三、文件 → 试卷身份的判定规则（证据分级）

1. **文件名含卷名**（如云南文件夹内的"2016 年…（新课标Ⅲ卷）"）→ paper_code 直接归一，evidence=filename（**第一证据**，采集者已按真实身份命名，实测覆盖 647/1014）；
2. **文件名为自主命题省名且该省当年自主** → paper_code=省代码，evidence=autonomous_province（102 件）；
3. **文件名为省名但该省当年用全国卷**（四川等，265 件）→ 待**省使用映射表**（province_usage.jsonl：省份×年份→卷代码）解析——映射表本身是需核验的知识，逐省逐年登记 evidence 来源；
4. **异常队列**：自主省文件夹内出现全国卷命名文件（channel_mismatch，14 件已标记）→ 内容核验后归位，不信任单一证据。

映射落地：`work/knowledge/高考真题整理/EXMAP-V2_版本2文件试卷映射.jsonl`（979 行，含 SHA/权威/状态）。

## 四、去重铁律

- 同一 paper_code×年份 的多渠道件：**空白卷选一份主件**（优先页数完整/无水印/与既有库同源），其余标 duplicate_channel 保留原件但不重复解析；
- 解析卷同理独立选主件（不同教辅的解析可以并存为多证据，但主件唯一）；
- SHA 逐字节相同直接弃收（已执行：36 件）。

## 五、目录与命名

- L0 原件：`Data/高考语料/按省采集-版本2/`（按采集渠道原样保全；**不入 git**，README 除外——L0 治理专项前的地方性规则）；
- L1 整理件（后续 MinerU+切分后）：`work/knowledge/高考真题整理/PAPER-{代码}-{年份}_{卷名}/`（ID+后缀命名，§3.8 裁决 1）；
- 题节点 ID：`PAPER-{代码}-{年份}-Q{n}`（与既有 `GK-*` 族并行；`GK-NC3-2016` 保留为 `PAPER-XK3-2016` 的历史别名，ID 解析表加映射规则）。

## 六、权威与答案纪律

| 内容 | 权威 |
|---|---|
| 空白卷（试卷本体） | S1 待核验（核验=与官方发布渠道交叉或双源一致） |
| 官方答案/评分标准 | S2 |
| 解析卷内第三方答案 | S3 答案候选（answer_candidate），**不因入册升级权威** |

题-KP 映射在对应年份答案闭合（official 或双源）前维持 M0——多省解析卷正是答案候选的新供给，逐卷登记 answer_source_status。

## 七、分叉分支交付契约（每份试卷四件）

1. 原件 PDF（+SHA，若为该卷主件）；
2. MinerU 整理件（确定性管线，可重建）；
3. `questions.jsonl`（沿用 exam_extract schema：题节点/题型/页码定位）；
4. catalog 与映射表增量行（paper 级实体 `PAPER-*` 入 catalog；province_usage 增量）。

**验收门禁**（主分支执行）：`build_catalog --check` 零悬空 + 试卷校验器（由四川版泛化为卷代码参数化版）+ 答案状态登记完整 + 映射 evidence 可追溯。

## 八、处理优先级（需求驱动）

近 5 年全国卷系主件优先（XG1/XG2/JIA/YI，2020-2024，约 16 份空白卷主件——命题蓝图与题型分布立即可用），其次自主命题省（BJ/SH/TJ 近 5 年），2008-2015 大纲卷最后。
