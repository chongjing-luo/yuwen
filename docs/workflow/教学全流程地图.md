# 教学全流程地图

九环节构成一个循环：规划 → 备课（研究+设计）→ 制作 → 审计 → 上课 → 作业/测评 → 诊断 → 反思 → 回到规划。每个环节的条目含义：

- **机制节点**：本环节承载的三目标机制（K/U/J，定义见 `work/evaluation/三目标实现机制.md`）——准入规则：不服务任何节点的产物不做；
- **库**：本环节消费的知识/方法论资产；
- **skill**：本环节的 agent 工作流（`.agents/skills/`，见 Phase D）；
- **评估**：放行判据与两本账归属。

## 循环关系

```
S1 规划 ──→ S2 文本研究 ──→ S3 教学设计 ──→ S4 物料制作 ──→ S5 审计放行 ──→ S6 课堂实施
  ↑                                                              │
  │                                                              ↓
  └── S9 反思沉淀 ←── S8 命题诊断 ←── S7 作业批改 ←──────────────┘
```

知识（K）在 S2→S7→S8 形成四站闭环；学懂（U）的主循环在 S3→S5→S6、后循环在 S7；享受（J）主要在 S3 设计、S6 验证。S6 是桌面账与课堂账的分界——此前一切判据均为设计条件，此后才有效果证据。
