# 教学全流程地图

九环节构成一个循环：规划 → 备课（教案+设计）→ 制作 → 独立终审 → 宿主放行 → 上课 → 作业/测评 → 诊断 → 反思 → 回到规划。单篇备课的三个正式阶段是S2教案、S3教学设计、S4 PPT与物料；S5是独立终审，不是第四个内容制作阶段，也不在项目文件内代替宿主放行。每个环节的条目含义：

- **机制节点**：当前备课方法用来描述教学作用的K/U/J工作坐标（定义见 `work/methodology/lesson-preparation/备课三目标与实现机制.md`）。教学目标、活动和课堂证据按需绑定；资料与工程产物按自身契约验收；
- **库**：本环节消费的知识/方法论资产；
- **skill**：本环节的 agent 工作流（`.agents/skills/`，见 Phase D）；
- **评估**：放行判据与两本账归属。

## 循环关系

```
S1 规划 ──→ S2 教案（内含证据研究） ──→ S3 教学设计 ──→ S4 PPT与物料 ──→ S5 独立终审 ──→ S6 课堂实施
  ↑                                                              │
  │                                                              ↓
  └── S9 反思沉淀 ←── S8 命题诊断 ←── S7 作业批改 ←──────────────┘
```

知识（K）在S2定范围并经S7/S8复现测评；学懂（U）的主循环在S3→S5→宿主放行→S6、后循环在S7；享受（J）主要在S3设计、S6验证。S5是独立终审门并形成待宿主放行候选；`yuwen-selfcheck`在循环之外治理skill、原则、血缘和测试。S6是桌面账与课堂账的分界。
