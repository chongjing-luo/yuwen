# 单元与学期规划（S1）

服务机制节点：**K1 教什么界定、K3 复现排程、K4 网络化**。执行依据：`work/methodology/manuals/S1-规划手册.md`中的`MM-S1-01`—`MM-S1-05`；通用参考：`.agents/skills/_shared/references.md`。

## 输入

- 单元图谱 `work/knowledge/<册>/units/UNIT-*.md`（accepted 状态）与册级汇总 `work/knowledge/<册>/册级汇总/BOOK-*.md`
- 班级学情（若已有）：`work/teaching/<班级>/diagnostics/` 的掌握热图
- 课标定位：图谱内"课标对接"栏

## 步骤

1. 从图谱提取本单元全部"教"级 KP，按课文分组；每条 KP 落到课时或写明显 defer 与理由（K1，N-01）。
2. 制作**复现排程表**：每个核心 KP 至少两次提取式激活——课堂首答周、作业闭卷周、单元卷周、跨课回投周（K3，检索练习/间隔效应）。
3. 制作**跨课回投清单**：本单元 KP 与已学册次卡片的关系边（引用真实 CARD-ID，K4）。
4. 标注单元内课时的高峰负荷分布，避免连续两课时都是高强度综合课（K5，P-35）。
5. 写入 `work/teaching/<册>/<单元>/unit_plan.md`（含 KP-课时对照表、排程表、回投清单）。

## 放行条件

- 每个"教"级 KP：有课时落点或有 defer 理由；
- 核心 KP 复现排程 ≥ 2 次且间隔 ≥ 1 周；
- 回投清单的关系边全部解析到真实卡片 ID；
- 声明：本规划为桌面设计，课时可行性待真实排课检验（P-12）。

## 常见错误

- 只排进度不排 KP（丢掉 K1/K3，规划退化为日历）；
- 复现排程全是"重讲"没有"检索"——复现必须是学生提取，不是教师再讲一遍。
