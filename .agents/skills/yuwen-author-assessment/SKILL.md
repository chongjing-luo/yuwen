# 命题组卷（S8a）——真题库制卷版

服务机制节点：**K1（四站第三站）、K3（测评回收）、K4（跨课回投）、U6（解释分层给分）**。
规格基线：`work/knowledge/高考分析/四川卷题型规格研究_2026-08-17.md`（下称《规格研究》，制题必读）。
题库：`work/knowledge/高考真题整理/`（182 卷四层产物：题目/组视图/考点/答案）。

## 输入

- 目标卷型（默认 JIA 型 2021-2024 规格；可指定 SCZ 期风格做语用专题卷）
- 单元图谱与课程数据（kp_weights 的 basis；无图谱时用《规格研究》§2 考点分布作 basis）
- 题库四层：`questions/Q*.md`（题面）、`groups/G*.md`（材料组）、`answers.jsonl`（candidate 答案）、`kp_tags.jsonl`（考点）

## 制题三路径（《规格研究》§4.2，逐题型指定）

> v2 硬性步骤（SC-MOCK-001 实测教训）：凡从题库取材（直用或改造），材料入卷前必须与库内 `questions/Q*.md` 及 `mineru_result/*/full.md` **双源比对**——OCR 丢字（如"饘"）、源内删句会沿库沿袭入卷；比对发现的差异要么修复要么在教师卷登记，不留无痕差异。

1. **整题直用**（阅读组/文言组/诗歌组适用）：
   - 条件：2018-2024 组式条目 + 材料自足 + 答案非 missing；
   - **答案人工核验**：库内答案全部为 S3 candidate，入卷前逐题人工核对（客观题对照解析证据，主观题检查赋分点完整性）；
   - 登记溯源：原卷名+题号+答案核验结论。**溯源台账逐条须与库实况一致**——不虚构回改记录、不误述库答案状态（"截断/完整"以 answers.jsonl 实读为准）、能力表述不过强（"全部新制"这类断言先逐题核对）。
2. **拆组改造**（高稳定模板迁移）：
   - 三个模板：论述三问（3×3）、文学三问（3+6+6）、文言四件套（3+3+3+10）；
   - 迁移规则：保设问动作与分值结构，换材料（新选文言传记/散文/学术论述，避开《规格研究》A4/A5 已用清单）；改造材料须**整段重出**并登记（含删节理由），禁止无痕删句换词；
   - 语用拼组：语段新写（可植入川元素复刻 SCZ 风格，§3），成语/病句/衔接/补写等小题从多卷语段拆组重嵌，每小题答案随新语料重推并逐条核验。
3. **新材料原创**（不可回避项）：
   - 默写：按教材必背篇目 × 情境句生成（不从题库抽，出处必须现行教材内）；
   - 作文：材料必须原创（思辨短材料/主题材料/任务情境三型，参照 §2.8 题型谱系），要求句式沿用真题惯例；
   - 实用类图表：数据必须重制（时效性）；若以文字梳理题替代图示（2024 甲卷 Q05 先例），须正式决策销"待重制"待办，不留悬挂。

## 流程（六步，手动执行）

1. **定蓝图**：卷型规格表（分节/题量/分值，逐项引《规格研究》§1）+ 逐题型制题路径指定（直用/改造/原创）+ kp_weights（每条 basis）+ 总分/时长定死。蓝图先于任何题目存在（P-37）。
2. **逐题型制题**（手动，不用构建器）：按蓝图路径逐题制作；每题登记四项溯源（路径/原卷题号或"新写"/答案核验人=制题员/材料来源）；主观题 scoring_points 合计==题分。
3. **组装**：题号/分节/分值对齐规格表；合计=150；默写不超纲、作文要求句完整。
4. **独立评审**（强制分离）：
   - 评审者与制题者必须为不同实例/人；评审输入为学生卷成品+蓝图+溯源表；
   - 评审维度与否决级：**P0**（答案错误/材料事实错误/泄答案——材料或选项含原卷答案标记）；**P1**（规格不符/分值错/难度结构与目标失配/材料-设问不匹配/无痕删改）；**P2**（溯源不完整/**溯源失实**（v2：改动记录与库实况不符——虚构回改、误述库答案状态、计数错误、能力表述过强）/赋分点不足/表述瑕疵）；
   - 逐题给级+证据（页/题号/原文摘录）+可执行修复建议；**任一 P0/P1 存在即不放行**；评审未发现任何问题视为评审不充分，要求复评（证伪先行，参照备课审计 P-37）；
   - **溯源抽验**（v2 新增）：评审至少抽 2 处改动记录对库核实（题库源文件实读比对）。
5. **修订迭代**：按评审意见修订→复验原级问题清零→新问题按级处理；迭代记录（轮次/意见/处置）入评审报告。
6. **放行登记**：产物=学生卷+教师卷（含答案+评分量规+溯源表）+蓝图+评审报告；状态"桌面已验·待施测"（两本账纪律）；评审报告存档于产物目录。

## 产物目录

`work/knowledge/assessment/papers/{卷编号}/`：`学生卷.md`、`教师卷.md`（答案/量规/溯源）、`蓝图.md`、`评审报告.md`。

## 禁止

- 用构建器代替手动制题（校验脚本仅作门禁，不作生成）；
- 直用答案未核验的题（S3 candidate 必须人工核后才可入卷）；
- 直用真题作文材料与真题默写（出处进度冲突）；
- 拆组时破坏材料完整性（删句换词不留痕）——改造材料须整段重出并在教师卷标注；
- 学生卷零后台信息（v2 明确：溯源/核验/**状态标注**均不入卷头——状态行移考务文件或卷尾小字）；
- 无蓝图先写题、无评审放行。
