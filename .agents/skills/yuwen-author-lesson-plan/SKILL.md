# 教案编写与G1定稿（S2主skill）

第一阶段主skill，服务K1/K2/K4/K5、U4/U6/U8、J4/J7。它只编排S2输入、动作、状态与门禁，不复制教案方法。

执行前按需读取：

1. `work/methodology/lesson-preparation/语文备课操作规程.md`的“一、文件地位”“二、G0/G1”“三、证据准备”“四、第一阶段”“九、标准教案骨架”；这是教案流程与结构的唯一依据；
2. `work/methodology/manuals/S2-文本研究手册.md`全文；`MM-S2-01`—`MM-S2-07`管G0研究，`MM-S2-08`—`MM-S2-12`管教案候选与G1；
3. 只有创建或排查机器对象时，读取`../_shared/lesson-lineage-contracts.md`的通用规则、G0和G1节；字段契约不得反向改写人读教案。

## 数据流合同

**读取**：存在时消费S1 `unit_plan.md`；教材与课标PDF规范源及解析件；知识卡、单元图谱、册级汇总；可靠教参/研究资料；相关课文、规范真题、按需时代材料；真实班级证据。缺S1或班级证据时如实登记“暂无”，不虚构结论。

**写入**：同一课程目录中的证据档案、`_meta/evidence_manifest.json`、`教案.md`和供审核的`_meta/lesson_plan_candidate.json`；仅在所有者明确批准当前教案—合同—证据组合后，才写`_meta/G1_owner_approval.json`和`_meta/lesson_plan_lock.json`。

`yuwen-research-text`是可选的G0支持skill。它输出的KID、困难、解释、主线和问题全部是候选，不能代替本skill的教案裁决，更不能代替所有者G1审核。

## 教案阶段的初步教法边界

教案只写阶段的**初步学习机制家族**，不写具体口令、分组、分页、版式或逐页剧本。当前类别及其定义、适用范围、禁用边界和扩展规则只以`work/methodology/lesson-preparation/教学设计类别注册表.json`为准；skill不复制一张可能过期的固定菜单。

`initial_method`先写知识性质、目标深度、主要困难与达标证据，再据此引用一个或数个候选`AC`编号。`AC`描述学生主要怎样学习；“讲授、提问、示范”只属于教师动作，“讨论、分组”只属于学生动作或参与结构，不能拿这些表层形式冒充学习机制。既往课例或用户举例只用于发现候选，不自动成为正式类别；若现有类别边界与本篇不合，记录问题交S3审查，不在教案中临时造名。

## 步骤

1. **领取并定址（MM-S2-08，K1/J7）**：正式课使用`LES-{册代码}-{课文代码}-{两位序号}`稳定ID，并绑定唯一课程目录；同一ID不得出现在两个课程目录，同一课程目录也不得登记两个ID。先运行`python3 scripts/validate_knowledge_base.py`。账本失败则停止领取，不用未通过知识资产写教案结论。
2. **完成G0研究（MM-S2-01—07，K1/K2/K4/U4/U6/J4/J7）**：可调用`yuwen-research-text`，但必须回教材/课标PDF裁决。写证据档案与`evidence_manifest.json`，再运行：
   ```bash
   python3 scripts/validate_lesson_evidence.py <evidence_manifest.json>
   ```
   G0失败只补证据，不开始写确定性教案结论。最低实体门只排除空壳，不能代替人工回页与解释审查。
3. **起草人读教案（MM-S2-08—10、12，K1/K2/K4/K5/U4/U6/U8/J4/J7）**：严格按操作规程教案骨架成文。正文按教师熟悉的成品顺序呈现基本信息与教学判断、教材与文本分析、学情、目标、重点难点、完整教学内容、课时与整体教学逻辑、达标判断；五坐标明细、六向审计过程、来源、解释边界、KID/KP映射、defer、风险、哈希和审批进入依据/治理附录，不另写一套方案。机器字段完整进入候选合同，不逐项翻译成人读正文。先完成目标六向审计：语言建构与运用、思维发展与提升、审美鉴赏与创造、文化传承与理解、立德树人与价值形成、现实迁移与实践逐项记录“纳入目标/审计后不单列”及本课理由；语言、立德树人、现实迁移必须纳入，其他三向有据取舍。育人和迁移目标须从原文、教材与必教知识生长，写可观察证据、反口号失败信号和解释边界。再用14类、文化五类和作品整体解释三项做后台覆盖审计，但不把这些类别直接打印成人读目录；实际KID由本篇课文裁决，语义去重后按原文推进、意义结构、叙事/论证关系或学习依赖形成自适应知识簇。每个KID恰好归入一个主簇，簇写本篇组织依据与聚合理由；同一知识事实只定义一次，五个坐标、背景裁决、目标、阶段和审计通过KID回指。作品整体解释适用项形成有证据边界的课堂范围KID，确因文体不适用者写具体理由，只有成为核心学习结果时才进入目标。最后使目标、知识簇、全课主线与整体教学逻辑形成同一因果体系；调查全面不等于全部必教，高考必查但按价值决定是否入课。贯穿问题可以为零；古诗文按需列连续原文单元和全文译述证据。每个阶段的`initial_method`按本节规则引用候选活动家族，并写明“知识性质—目标深度—主要困难—达标证据—学习机制”的适配理由；这只是G1宏观教法，不得越界写成S3具体活动。
4. **做G1提交前对齐**：先核对六向审计与每项目标的`dimensions`双向一致，语言/立德树人/现实迁移三向均有真实目标引用；再核对`work_interpretation`三项裁决齐全，纳入项只通过`kid_refs`指向知识全账中的准确结论，另写证据边界，不得再设`statement`形成第二事实源；不适用项有文体理由。核对`knowledge_clusters`非空、全部KID（含`teacher_reserve/defer`）恰好归入一个主簇，簇名与理由确由本篇产生，无语义重复KID或审计类别式机械目录。随后逐项证明每个目标和`must_teach/retrieve_prior` KID有真实阶段，且每个KID的`stage_refs`与`stages[].kid_refs`反向投影完全一致。目标声明的每一个`目标—KID`关系必须在同一阶段共同承担，并能回到该阶段的进入理由、原文范围、初步教法、学生变化与达标证据。`teacher_reserve/defer`不得进入课堂阶段，`defer`另有理由；有贯穿问题时核对其统摄理由、目标与知识责任、阶段链及最终回收，问题为空也合法；整体逻辑的11类组成逐项标明纳入、延后或不适用。覆盖审计只查漏和回指，不得另写重复落实表冒充教学实现。发现内容或逻辑缺口就改教案，不用活动、页面或PPT补洞。
5. **生成可审核候选并停止（MM-S2-11，J7）**：把完整人读稿写到`work/teaching/<册>/<课>/教案.md`，再将人读稿投影为`_meta/lesson_plan_candidate.json`；候选只能使用`lesson-plan-candidate.v1`与`candidate_owner_review`，不含批准回执。运行：
   ```bash
   python3 scripts/validate_lesson_plan.py --candidate <lesson_plan_candidate.json>
   ```
   通过后状态仍只能是“G1教案候选·待所有者审核”。提交前执行教师三分钟扫描测试：不读附录即可回答为什么教、教什么、学生学到什么、全课怎样推进、凭什么算学会；若必须先穿过KID/KP表、审计矩阵或来源明细才能回答，则返工正文。附录只完成证据复核，不重复教学方案。向所有者一并提交教案路径与SHA-256、候选路径与SHA-256、机器合同canonical SHA-256、G0清单SHA-256及待裁决问题；作者不得生成、推断、代填或暗示批准回执。
6. **只在真实批准后锁定G1（MM-S2-11，P-11/J7）**：所有者明确批准上述当前组合后，保留同课已预检候选，按真实外部事件写`G1_owner_approval.json`，再以候选中完全相同的合同生成同课`_meta/lesson_plan_lock.json`。运行：
   ```bash
   python3 scripts/validate_lesson_plan.py <lesson_plan_lock.json>
   ```
   本地验证通过只证明字段与血缘一致，不认证人类身份，也不代表G4宿主放行。

## 状态与停止规则

- G0未通过：`S2 evidence_incomplete`；不写G1结论，不产生下游。
- G0通过、候选合同预检通过但未获所有者批准：`G1教案候选·待所有者审核`；候选预检不是批准。
- 只有回执、当前教案、G0清单和机器合同哈希全部一致，且`validate_lesson_plan.py`通过，才是`G1 approved`。
- 教案、证据清单或候选合同任一改变，旧候选须重建；已存在的旧回执立即失效，必须重新审核，不得只改哈希。
- G1锁定目标、必教/检索旧知KID、defer及理由、按需设置的贯穿问题、整体教学逻辑与阶段落实、完整母版总时长和宏观收束。以后若改变，必须修改教案、重新取得所有者批准并重建锁。
- 本skill到G1结束；未经用户继续授权，不自动进入S3，更不制作PPT。

## 禁止越界

- 不写逐分钟程序、页面标题、版式、颜色、插图、分组口令、逐屏台词或`lesson.json`；
- 不把研究候选、网络赏析、短空壳教案或机器校验通过冒充所有者批准；
- 不伪造班级学情、课堂效果、G1回执、宿主放行或任何`released`状态；
- 不因后续设计想法方便而删减知识全账、降低目标证据或改变整体教学逻辑。
