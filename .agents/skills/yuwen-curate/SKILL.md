# 语义策展（资料轴 · S0）

服务机制节点：**K1（界定）、U6（解释分层）**。规则：MM-S0-06（P0）、MM-S0-03（P0）。

## 输入

- 整理件 + 目标实体类型（knowledge_card / exam_item / material / note）

## 步骤

1. 定权威：为产出条目标注 S1-S4 权威等级——教材/课标直出=S1 派生；教参=S2；文献/新闻=S3；他人PPT/AI=S4（**可直接使用**，所有者裁决；来源登记不豁免）【MM-S0-06】。
2. 抽取：按目标 schema 产出（知识卡走 `_templates/`；题目走 item_bank schema；素材走 materials/README 规格）。
3. 血缘：每条挂 source（上游整理件/原件 ID）；原始未保留时写来源存根【MM-S0-03】。
4. 解释分层：抽取内容区分"原文事实/合理推断/他方观点"，不混写【U6】。
5. 入册：账本状态机登记（drafted→…→accepted）；candidate_only 条目标注并限制用途（不进学生产物）。
6. catalog 增量【MM-S0-04】。

## 门禁（放行条件）

- schema 校验通过；权威等级、血缘、（必要时）存根三必填【MM-S0-06 判据】；
- 血缘可解析（上游实体存在）；
- M0 未映射条目未出现在任何学生产物中。

## 产出

- 策展件（账本+catalog 登记）
