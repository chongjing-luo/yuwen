# Skill 索引（S0–S9 + 决策支持 + 全局）

每个 skill 是薄编排层，内容指向库而不复制库。教学主链与课堂证据skill可引用备课机制节点（`work/methodology/lesson-preparation/备课三目标与实现机制.md`）及原则ID（`work/principles/registry.yaml`）；资料与工程skill按自身契约执行，不为取得形式合法性强绑K/U/J。共享参考：`_shared/references.md`。
