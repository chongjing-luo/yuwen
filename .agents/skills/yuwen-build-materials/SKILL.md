# 教学物料制作（S4）

服务机制节点：**K2（学习单知识锚定）、U1（学习单分发时点拆件）、J3（学生作品为主视觉）、J4（前台朗读测试）**。同源纪律：P-11（多种材料同源，当前版本唯一）。

## 输入

- S3 课程数据（lesson.js 或通用 schema JSON）

## 步骤

1. 从课程数据同源生成全部物料——绝不手工分叉修改单一产物（P-11）：构建器见 `scripts/build_*`（md/docx/pptx 系列）。
2. 学习单按**真实分发时点拆件**（P-25）：会提前泄露后页信息的部分拆成独立物件，登记首次发放事件（U1）。
3. 学习单知识收纳区对应 KP 并注明出处诗句（K2）。
4. 学生前台文字过**课堂朗读测试**（P-13，J4）：教师读出来不生硬，学生第一次听就知道面对谁、想什么、做什么。
5. PPT 视觉遵守 `work/备课/视觉与插图功能规范.md`：首答态等大同色随机散放（P-42）；插图先过准入五问（V-02）；无图版为默认态（V-08）。
6. 逐字稿按物理画面最小单位写（P-40）：每画面独立剧本、时间盒、分支、切页句；备注含真实等待秒数。
7. 生成 manifest + SHA-256 清单。
8. 验证：对应 validate/build 测试 + `python3 scripts/checks/run_principle_checks.py`（前台禁词）。

## 放行条件

- 全部产物由同一数据源生成且哈希登记；
- 前台禁词扫描 0 命中；
- 学习单分发时点表完成；
- 朗读测试逐页通过（人检，记录在案）。

## 常见错误

- PPT 与母版措辞分叉（违反 P-11）；
- 学习单装订成一册导致提前泄答（U1 断裂）；
- 备注写"此处沉默三秒"上屏（舞台指令属于后台，P-07）。
