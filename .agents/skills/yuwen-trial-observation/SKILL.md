# 课堂实施与观察（S6）

服务机制节点：**课堂账的唯一来源**——全部 20 节点的课堂度量经此采集。这是桌面账与课堂账的分界（P-12）。

## 输入

- S4/S5 放行的物料包与逐字稿
- 观察表模板：`work/备课/选择性必修下册/氓/17_氓_V65_V4_分课时试教方案与观察表.md`（范式）

## 步骤

1. 试教前冻结课程数据版本与标准版本（审查链延续）。
2. 按三目标配置观察信号（每信号对应节点）：
   - **学懂**：首答阶段非空白抽样率（U1）；个人末答抽样正确率（U3）；修订痕迹率（U8）；学生用原词自证比例（U2）
   - **知识**：章意/字词闭卷复述质量（K2/K3）
   - **享受**：主动开口率与自愿发言面（J1/J3）；自发回读与课后谈论（J4）；沉默学生的真实完成路径（U7/J6）
   - **负荷**：实际耗时 vs 时间盒偏差（U5）；累计疲劳信号
3. 观察纪律：记录事实不记录评价；"这节课很顺"不是证据（J7 流畅错觉）。
4. 采集学生作品样本（学习单、末答、作业）并保留原件照片/扫描。
5. 课后立即汇入：观察数据 → S9 反思；作品与成绩 → mastery ledger（`scripts/analyze_mastery.py`）。
6. 更新课堂账：`work/evaluation/reports/` 中对应课程的 classroom_account 从"空"变为实测记录。

## 放行条件（观察有效性）

- 每个预设信号有真实记录或如实标"未采集到"；
- 学生作品样本可追溯到具体页/题；
- 无任何用桌面推演代替观察的条目。

## 常见错误

- 只记录"气氛好"；只采前排学生样本；把公开回答当个人掌握（P-41）；
- 试教后不回流数据——课堂证据断链，三目标失去验证。
