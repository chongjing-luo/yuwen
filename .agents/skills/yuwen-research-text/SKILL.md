# 文本研究（S2）

服务机制节点：**K1、K2、K4、U4 困难预判、U6 解释分层、J4 三问设计**。范式样本：`work/备课/选择性必修下册/氓/01_文本研究与证据档案.md`。

## 输入

- 教材源包：`Data/textbook_extract/<册>/mineru_result/<课>/full.md`（正文+注释）
- 知识卡：`work/knowledge/<册>/cards/CARD-*.md`（读"原子知识点"与"证据ID"两栏）
- 教师用书参考（若有，注意 N/A 边界）

## 步骤

1. **裸读**：先只读正文，记录第一遍的真实困惑与感受（不查注释）——这是学生困难的预演（U4）。
2. **文本事实清单**：逐段列出可指认的事实（谁、做了什么、写了什么景），每条标注出处句。区分：文本明写 / 教材注释 / 合理推断 / 现代延伸（U6，P-09 四层）。
3. **知识绑定**：从知识卡抄出本课"教"级 KP 清单，每条 KP 挂到具体诗句位置（K2，P-04）；未挂上的 KP 决定教/defer。
4. **困难预判**：按手法库 17 类困难（`work/备课/语文课堂教学手法库.md` §二）逐类过筛，列出本课前 5 类真实困难。
5. **三问设计**：以"学生视角真想知道"为标准起草 3 个贯通问题（J4）——问不出悬念的问题组要重写。
6. **关系边**：标注本课与已学课文的关系（引用 CARD-ID，K4）。
7. 产出 `work/teaching/<册>/<课>/01_文本研究与证据档案.md`，记录源包 SHA-256。

## 放行条件

- 解释边界四层标注覆盖全部关键判断；
- 每个"教"级 KP 有诗句锚点或 defer；
- 困难清单可归入 17 类且有文本依据；
- 三问通过"想知道"审查（模拟一名学生读第一遍后是否真的想问）。

## 常见错误

- 把教参与网络赏析当文本事实（U6 越界）；
- 困难清单写"学生基础弱"这类不可操作的描述——必须落到具体困难类型。
