# Tmp 临时区（设计方案 §3.7）

外部资料进入系统的唯一通道。**本目录永不入 git**（.gitignore 已排除）。

## 两区规则

| 区 | 性质 | 规则 |
|---|---|---|
| `inbox/` 落件区 | 外部文件的第一落脚点，**全世界唯一副本（危险区）** | 每件落盘即记 `inbox/LEDGER.jsonl` 一行（file/sha256/来源/日期/裁决状态）；**驻留时限 3 日**，超期未裁决进体检清单 |
| `work/` 加工区 | 预处理管线的中间产物 | 随时可删——由"保留的原始 + 代码"确定性重建 |

## 落件台账 LEDGER.jsonl（每行一件）

```json
{"file":"xxx.pdf","sha256":"…","source":"网址/来源描述","date":"2026-08-15","verdict":"pending|keep_raw|process_only|discard","decided_date":null,"note":"裁决四问的结论"}
```

## 裁决四问（决定保留原始与否，见设计方案 §3.7 判据表）

1. 权威等级？（S1/S2 必留原始）
2. 可再生吗？（不可再生必留）
3. 转换含判断吗？（纯格式转换可删；语义抽取建议留或至少存根）
4. 版权敏感吗？

不留原始 → 走 `yuwen-organize` 预处理后删原件，**必须留来源存根**（来源描述/获取方式/SHA/日期/可再生路径）。
