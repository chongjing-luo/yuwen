## 第一编　课堂教学技能分类体系

> **来源：** 微格教学（Microteaching）体系，由斯坦福大学 Allen & Ryan（1963）创立，中国采用北京教育学院孟宪凯课题组提出的十项分类（1992）。微格教学将课堂教学能力分解为可观察、可练习、可评估的子技能。

### 第一章　基本技能（六项）

| 技能 | 定义 | 核心要求 |
|------|------|---------|
| **语言技能** | 教师用准确、生动、富于启发性语言传授知识的行为 | 普通话标准、音量语速节奏恰当；学科性+科学性+启发性+逻辑性 |
| **提问技能** | 以提问形式进行师生信息交流的行为 | 把握动机和时机；提问后恰当停顿给予思考时间；准确分析作答、客观评价 |
| **讲解技能** | 运用口语或教学媒体进行讲述、讲解的技能 | 内容方法与学生认知阶段相当；逻辑清晰、用词确切；举例、提问、谈话结合 |
| **强化技能** | 对学生正确行为给予肯定和鼓励的行为 | 在重点、关键处运用；恰当、自然、灵活；语言+动作+标志等多种类型 |
| **演示技能** | 运用教具、实验、媒体进行示范操作的行为 | 目的明确、紧密结合重点；程序步骤清晰、示范规范 |
| **板书技能** | 利用黑板/白板书写文字、绘制图表的行为 | 紧密联系教学、结构合理；有条理、简洁、直观；与讲解结合恰当 |

### 第二章　综合技能（四项）

| 技能 | 定义 | 核心要求 |
|------|------|---------|
| **导入技能** | 引导学生进入学习状态的行为方式 | 自然引入、衔接恰当；引发兴趣、明确目标；时间紧凑 |
| **变化技能** | 通过改变刺激方式维持学生注意力的行为 | 音量音调变化；表情、手势、目光接触变化；媒体使用有变化 |
| **结束技能** | 教学结束时对知识系统化巩固的行为 | 目的明确、概括清楚；安排练习/提问/活动；拓展延伸 |
| **组织技能** | 对教学进行组织、调控的行为 | 语言要求明确；及时反馈调整；变换方式保持积极状态 |

## 第二编　提问技术

> **来源：** 布鲁姆教育目标分类学（认知层次提问分类）；罗威（Mary Budd Rowe）"等待时间"研究（1986）；课堂提问策略研究。

### 第三章　问题的设计

**布鲁姆认知层次提问分类：**

| 类型 | 功能 | 行为动词 |
|------|------|---------|
| **回忆提问** | 巩固所学，检查记忆 | 列举、识别、复述、说出 |
| **理解提问** | 检查本质理解 | 解释、总结、比较、举例 |
| **运用提问** | 检查迁移运用 | 运用、演示、解决、操作 |
| **分析提问** | 弄清关系、分解结构 | 区分、归因、解构、比较 |
| **综合提问** | 重组知识、形成新整体 | 设计、建构、创作、规划 |
| **评价提问** | 价值判断、批判辩护 | 判断、批判、辩护、评估 |

> **设计原则：** 一节课的问题不宜过多，应以2-3个"主问题"为核心驱动。主问题应具有"生发性"（能触及文本诸多因素和细节）和"整合性"（能将内容聚合形成清晰理解）。低层次问题和高层次问题搭配使用，不能全课停留在回忆和理解层次。

### 第四章　提问的执行

**① 等待时间（Wait Time）——最被忽视的技术**

来源：罗威（Mary Budd Rowe）"等待时间"研究。

研究发现：教师提问后平均等待不足1秒。将等待时间延长到**3-5秒**后，显著变化：
- 学生回答的**长度**增加
- **参与**回答的人数增加
- 学生回答的**正确率**提高
- 学生回答的**认知复杂度**提高
- 学生**主动提问**增多

**三段等待时间：**
| 时机 | 操作 | 停顿时长 |
|------|------|---------|
| 问完后 | 给全体学生思考时间 | 3-5秒 |
| 学生答完后 | 给该学生补充修正和其他学生反应的时间 | 2-3秒 |
| 学生问教师问题后 | 不急于回答，先抛给全班 | 3-5秒 |

**② 提问的分配策略**

- **面向全体**先提问，再指名回答——"大家想一想……"然后随机抽取
- **分配公平**——避免总是叫举手的学生，要给不举手的学生机会
- **难度匹配**——简单问题给基础薄弱学生（建立信心），复杂问题给学有余力学生
- **先问后名**——先提出问题，停顿后再指名；如果先指名再提问，其他学生就停止思考了

### 第五章　理答技术

> **来源：** 课堂提问策略研究。

理答不只是"对/错"，有四种核心技术：

| 技术 | 操作 | 示例 |
|------|------|------|
| **追问** | 顺着学生思路深入挖掘 | "你为什么会这么想？""能说得更具体一些吗？""你的依据是什么？" |
| **探问** | 学生答不出时，变换角度或分解问题 | "换个角度想——如果把这个问题分成两步，第一步是什么？" |
| **转问** | 将问题抛给更多学生参与 | "XX同学是这么看的，其他同学呢？有没有不同意见？" |
| **反问** | 激发认知冲突，促使反思 | "大家都同意吗？有没有发现什么问题？" |

**不加评判的接受：**

> 对于主观性强的学科（如语文），理解和应用往往具有很强的个体差异，本身没有绝对的对错。教师可通过以下方式表示接受：
- **确认**：点头、在黑板上写下学生的陈述、"嗯""我想我明白你的意思"
- **释义**：用自己的话解释、再组织、翻译或总结学生的回答——"你的意思是说……对吗？"

**具体化评价语：**

避免笼统的"回答得好"——这只会暗示其他学生"已经有人说过了，不用再想了"。要给出**具体**的反馈：

| ❌ 笼统评价 | ✅ 具体评价 |
|-----------|-----------|
| "你回答得真不错！" | "我很喜欢你回答时清晰的条理性以及对细节的把握。" |
| "很好，请坐。" | "你注意到了别人忽略的那个词，这种细心很重要。" |
| "谁还能补充？" | "你的回答提供了一个新角度——谁想顺着这个方向继续想？" |

## 第三编　导入技术

> **来源：** 微格教学导入技能体系；国家高等教育智慧教育平台课程。

### 第六章　八大导入法

| 方法 | 操作 | 适用场景 |
|------|------|---------|
| **直接导入** | 开门见山说明课题和学习目标 | 最简单最常用，适合内容本身有吸引力时 |
| **旧知识导入** | 复习已学知识，建立新旧联系 | 新旧知识联系紧密时，承前启后 |
| **问题导入** | 用一个核心问题引发思考 | 需要激发探究欲望时 |
| **实例导入** | 用学生熟悉的生活事例引入 | 抽象内容需要感性入口时 |
| **悬念导入** | 设置悬念引发好奇 | 故事性强的内容 |
| **故事导入** | 讲一个相关的故事 | 需要情境渲染时 |
| **直观导入** | 展示图片、实物、音频、视频 | 需要感性认识基础时 |
| **情境导入** | 创设情境让学生代入 | 需要情感共鸣或角色代入时 |

### 第七章　导入的技术原则

| 原则 | 含义 |
|------|------|
| **针对性** | 导入必须服务教学目标，不游离于教学内容之外 |
| **启发性** | 导入应激发思维，而不只是"引起注意" |
| **趣味性** | 导入应引发兴趣，但不为趣味而趣味 |
| **简洁性** | 导入不是正文，时间控制在3-5分钟 |
| **整体性** | 导入应与整节课形成有机整体，不突兀 |

## 第四编　讲解技术

> **来源：** 孟宪凯《微格教学基础教程》（1992）；国家高等教育智慧教育平台。

### 第八章　四种讲解类型

| 类型 | 适用内容 | 操作要点 |
|------|---------|---------|
| **解释式** | 解释概念、术语、定义 | 用学生已知的事物类比未知概念；从具体到抽象 |
| **描述式** | 描绘情境、场面、过程 | 语言生动形象，调动学生想象；适当使用感官描写 |
| **原理中心式** | 阐明原理、规律、法则 | 逻辑清晰，因果链条完整；先提出原理，再举例验证 |
| **问题中心式** | 围绕问题展开分析 | 明确问题→分析原因→提出方案→验证结论 |

### 第九章　讲解的技术要素

讲解不是"一口气讲到底"，而是由六个可辨识的要素构成的结构化行为：

```
① 引入讲解命题 → ② 提供感知材料 → ③ 指导分析 → ④ 提示要点 → ⑤ 指导推理 → ⑥ 检查效果
```

| 要素 | 操作 |
|------|------|
| ① 引入命题 | 用一句话点明"接下来要讲什么" |
| ② 提供材料 | 举例、引用、展示，给抽象概念一个感性锚点 |
| ③ 指导分析 | 引导学生分析材料的结构、特征、关系 |
| ④ 提示要点 | 明确指出"关键在这里"——避免学生淹没在细节中 |
| ⑤ 指导推理 | 帮助学生从已知推出未知，形成逻辑链条 |
| ⑥ 检查效果 | 通过提问、练习检测学生是否理解 |

**讲解的原则：** 逻辑清晰、用词确切、重点关键加以强调、注意学生反应、不断激励。每次连续讲解不超过10-15分钟，中间穿插提问或活动。

## 第五编　结课技术

> **来源：** 微格教学结束技能体系。

### 第十章　结课五环节

```
① 简单回忆 → ② 提示要点 → ③ 检验结果 → ④ 巩固应用 → ⑤ 拓展延伸
```

| 环节 | 操作 |
|------|------|
| ① 简单回忆 | 师生共同回顾本课学了什么 |
| ② 提示要点 | 教师明确指出本课的重点和关键 |
| ③ 检验结果 | 通过提问、小测检查目标达成情况 |
| ④ 巩固应用 | 设计练习或活动让学生运用所学 |
| ⑤ 拓展延伸 | 向课外、向下节课延伸，形成期待 |

### 第十一章　五种结课类型

| 类型 | 操作 | 适用 |
|------|------|------|
| **归纳式** | 系统总结本课要点，形成知识结构 | 知识密度大的课 |
| **比较式** | 将新旧知识对比，辨析异同 | 易混淆的概念 |
| **悬念启下式** | 留下悬念，引向下节课 | 连续性内容 |
| **练习式** | 用检测题巩固，即时反馈 | 技能训练课 |
| **拓展延伸式** | 向课外延伸，激发持续探究 | 开放性主题 |

## 第六编　板书技术

> **来源：** 微格教学板书技能体系；板书设计研究。

### 第十二章　五种板书类型

| 类型 | 特点 | 适用 |
|------|------|------|
| **提纲式**（最常用） | 层层推进、逻辑性强，呈现知识结构 | 系统性强的内容 |
| **对比式** | 把相近或相反的事物并置，辨析异同 | 易混淆的概念 |
| **线索式** | 揭示事物发展脉络或因果关系 | 有时间线或逻辑链的内容 |
| **图示式** | 用符号、简笔画直观呈现关系 | 抽象结构需要可视化时 |
| **词语式** | 用核心关键词构建意义网络 | 概念密集的内容 |

### 第十三章　板书设计原则

| 原则 | 含义 |
|------|------|
| **目的性** | 板书为教学目的服务，不是"写黑板上好看的" |
| **系统性** | 构成完整提纲，不零散 |
| **简洁性** | 少而精，"画龙点睛"——不把所有讲解内容都写上去 |
| **布局合理** | 主板书区（核心内容，通常左侧或中部）+ 副板书区（临时补充，右侧） |
| **与讲解同步** | 不要先写完再讲，也不要讲完很久才补写——边讲边写 |
| **与多媒体配合** | 手写板书记录结构和逻辑（可实时修改），多媒体展示直观情境——互补 |

## 第七编　作业设计与讲评技术

> **来源：** 作业设计研究；"双减"背景下作业优化研究。

### 第十四章　作业设计原则

| 原则 | 含义 |
|------|------|
| **素养导向** | 作业不只是巩固知识，更是发展素养的途径 |
| **层次性** | 分层设计，满足不同水平学生需求 |
| **针对性** | 针对本课重难点和学情，不搞题海 |
| **多样性** | 打破纸笔局限，融入实践性、探究性、生活化作业 |
| **生活联结** | 作业贴近学生生活实际，有真实情境 |
| **适量性** | 严格控制总量和时间，不加重学生负担 |

### 第十五章　分层作业设计

| 层次 | 目标 | 内容类型 |
|------|------|---------|
| **基础层** | 巩固基础 | 基本概念记忆、基础练习、标准习题 |
| **提高层** | 深化理解 | 分析应用、片段练习、简单探究 |
| **拓展层** | 创新探究 | 综合项目、创意表达、开放性研究 |

> **分层不只是数量不同，更是能力层次的分梯度。** 基础薄弱学生做基础层作业时，应让他能**自信地**完成，建立胜任感（参见动机理论——自我决定理论中的"胜任感"需求）。

### 第十六章　作业批改与反馈技术

| 技术 | 操作 |
|------|------|
| **全批全改** | 书面作业做到全批全改，了解全班整体情况 |
| **面批面改** | 对基础薄弱学生以面批为主，即时指导 |
| **符号反馈** | 用问号、圆圈代替叉号——降低挫败感，引导思考"哪里不对" |
| **二次评价** | 第一次评定等级→学生修改→再次评价——让学生体验"改进后能做好" |
| **多元评价** | 教师评价 + 学生自评 + 小组互评 + 家长评价 |
| **错题档案** | 帮助学生建立错题本，分类整理，定期回顾 |

### 第十七章　作业讲评技术

| 技术 | 操作 |
|------|------|
| **共性问题集中讲** | 针对全班普遍出错的问题课堂集中讲解 |
| **个性问题单独指导** | 个别学生的错误单独沟通，不在全班暴露 |
| **展示优秀作业** | 树立标杆，让学生看到"好"的标准是什么 |
| **讲思路不讲答案** | 讲评重点是"怎么想到的"和"为什么这么想"，不是"标准答案是什么" |
| **让学生讲** | 让做对的学生讲思路——同伴语言有时比教师讲解更有效 |

## 第八编　课堂管理与时间控制

> **来源：** 课堂教学控制论（北京教科院）；课堂组织管理研究。

### 第十八章　课堂纪律管理

**三级应对策略：**

| 干扰程度 | 具体表现 | 教师应对技术 |
|---------|---------|------------|
| **轻度干扰** | 玩文具、走神、发呆 | 走近轻敲课桌，不点名提醒；眼神凝视3秒配合暂停授课 |
| **中度干扰** | 交头接耳、小声说话、传纸条 | "选择式提醒"："你是需要时间调整，还是现在分享观点给大家？" |
| **严重干扰** | 冲突、对抗、严重影响教学 | 立即隔离当事人，课后启动"问题解决对话"，避免当众激化矛盾 |

**非语言管控技巧：**

| 技巧 | 操作 |
|------|------|
| **走动管理** | 靠近分心学生，用身体语言传递关注，不必中断教学 |
| **眼神信号** | 对小声说话的学生保持凝视，配合暂停2-3秒 |
| **手势暗号** | 与学生约定"安静手势"（如双手下压），减少口头打断 |
| **空间接近** | 边讲边走向注意力涣散的区域 |

### 第十九章　教学节奏控制

> 来源：北京教科院课堂教学控制论——"教学节奏应有张有弛，知识密度应有大有小，教学速度应有快有慢。如同一首乐曲，只有单一旋律必然枯燥乏味。"

**具体操作：**

| 技术 | 操作 | 依据 |
|------|------|------|
| **活动切换** | 每**15分钟**切换一次活动形式（讲解→讨论→练习→展示） | 利用大脑注意力周期 |
| **知识密度动态调整** | 知识容量和难易程度随课堂进程调整 | 过大学生焦虑，过小限制潜能 |
| **任务计时** | 用倒计时工具（PPT计时器）营造任务紧迫感 | 减少拖沓，提高效率 |
| **留白** | 关键问题后留出思考时间 | 参见等待时间技术 |

**时间分配原则：**

| 环节 | 建议占比（40分钟课） |
|------|-------------------|
| 导入 | 3-5分钟（8-12%） |
| 新课推进（含讲解+活动+讨论） | 25-30分钟（60-75%） |
| 练习与检测 | 5-8分钟（12-20%） |
| 结课 | 2-3分钟（5-8%） |

### 第二十章　环节过渡技术

| 技术 | 操作 |
|------|------|
| **自然衔接** | 用过渡语承上启下——"通过刚才的讨论，我们了解了……接下来我们一起探究……" |
| **承上启下** | 过渡内容既总结上一环节要点，又引出下一环节主题 |
| **避免生硬跳转** | 每个环节转换处都应有"桥梁"，不直接跳到下一个活动 |
| **信号提示** | 用语言信号（"好，我们进入下一个环节"）或视觉信号（PPT切换）帮助学生跟上节奏 |

## 第九编　小组合作组织技术

> **来源：** 互动教学策略；合作学习研究（Johnson & Johnson）。

### 第二十一章　分组策略

| 策略 | 操作 | 适用 |
|------|------|------|
| **异质分组** | 不同能力水平学生混合编组（4-6人） | 日常讨论、互补学习——让强学生带动弱学生 |
| **同质分组** | 相近水平学生编组 | 分层任务、差异化教学——给不同组不同难度任务 |
| **动态分组** | 根据实时掌握情况临时分组 | 形成"概念巩固组"与"深度探究组" |
| **自由组合** | 学生自主选择合作伙伴 | 需要高度投入和默契的创意任务 |

### 第二十二章　讨论组织技术

**思考-配对-分享（Think-Pair-Share）：**

来源：Lyman（1981），最经典的讨论组织技术。

```
① Think：先个人独立思考（1-2分钟）
② Pair：与同伴讨论（2-3分钟）
③ Share：全班分享（5-8分钟）
```

> 优势：保证每个学生都有思考时间（避免"快举手的学生垄断讨论"），再通过配对降低发言焦虑，最后全班分享整合多元观点。

**讨论组织要点：**

| 要点 | 操作 |
|------|------|
| **任务明确** | 讨论前明确要求——"讨论什么""讨论几分钟""最终要产出什么" |
| **声音控制** | "声音以组内听清为准"——防止噪音失控 |
| **角色分配** | 表达能力强的负责汇报，逻辑清晰的负责记录，组织能力强的负责计时和协调 |
| **教师巡视** | 掌握各组情况，适时介入但不包办——遇到困难组给予支架，遇到跑题组拉回 |
| **成果汇报** | 每组汇报后有追问和互动——不是"轮流念稿" |

## 第十编　多媒体使用技术

> **来源：** 板书设计研究中的多媒体与手写配合。

### 第二十三章　多媒体与手写板书配合

| 原则 | 操作 |
|------|------|
| **主次分明** | 多媒体展示直观情境（图片、视频、动画），手写板书记录核心结构和逻辑 |
| **适时切换** | 每次媒体切换都服务于教学目标，不是为了"用技术而用技术" |
| **避免信息过载** | PPT每页一个核心观点，避免满屏文字——学生读不过来就停止听课了 |
| **可实时修改** | 手写板书的优势在于可根据课堂实时情况调整——这是PPT做不到的。当课堂生成意外内容时，板书能即时记录 |
| **技术备选** | 始终准备"无电方案"——万一设备故障，能用手写板书完成教学 |

**PPT设计的技术规范：**

| 要素 | 规范 |
|------|------|
| 每页内容 | 一个核心观点或一个任务，不超过6行文字 |
| 字号 | 标题≥32pt，正文≥24pt，最后一排学生能看清 |
| 配色 | 深底浅字或浅底深字，对比度足够；避免红绿配色（色盲不友好） |
| 动画 | 只用于"需要逐步呈现的内容"，不用花哨的切换效果 |
| 互动留白 | 设置提问页、讨论页，给学生思考空间 |
