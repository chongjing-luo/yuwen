# 评估与治理

本目录回答“按什么程序检查、检查结果怎样记录、标准怎样冻结和修订”，不定义教学目的，也不存放备课方法论正文。

| 内容 | 位置 | 边界 |
|---|---|---|
| 标准收敛与冻结 | `convergence.md` | 管评审版本、不追溯否决与停止条件 |
| 评估标准 | 本目录现行标准文件 | 规定判据，不冒充真实课堂效果 |
| 检查报告 | `reports/` | 记录一次检查的输入、标准、结果与已知缺口 |

备课目标工作框架位于 `work/methodology/lesson-preparation/备课三目标与实现机制.md`；机器原则位于 `work/principles/registry.yaml`。报告可以引用它们，但不得在本目录复制或升格其内容。
