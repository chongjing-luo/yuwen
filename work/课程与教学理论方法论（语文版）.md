## 第一章　语文课程的性质与定位〔语文〕

> 来源：《普通高中语文课程标准（2017年版2020年修订）》；王宁（北京师范大学资深教授，高中语文课标组组长）

### 1.1 语文学科性质

> **"语文课程是一门学习祖国语言文字运用的综合性、实践性课程。"**（课标正文第1页；PDF第9页）

两个关键限定词：
- **综合性**——语文不是单一的技能训练，而是融语言、思维、审美、文化于一体的综合素养
- **实践性**——语文能力不是"讲出来的"，而是在语言实践中"练出来的"

### 1.2 工具性与人文性的统一

> 来源：课标；王宁

> **"工具性与人文性的统一，是语文课程的基本特点。"**

王宁的阐释：工具性和人文性不是两个可以分开的东西。语言本身就是人文的——你选择用什么词、什么句式、什么节奏说话，这个选择本身就在表达一种人文姿态。反过来，任何人文情怀如果不通过语言实现，就不存在。

> **如果认为语文是"一半工具+一半人文"，那就是对语文最大的误读。**

### 1.3 与通用课程论的关系

语文课程论遵循泰勒原理"目标—经验—组织—评价"的基本框架，但在"确定教育目标"环节有其特殊性：
- 目标来源不只是泰勒的三要素（学生需要+社会生活+学科专家），还有语文独特的"文史哲不分家"传统
- 目标筛选不只通过教育哲学和学习心理学，还有语文独特的审美判断和文化传承维度

## 第二章　语文课程的三个层级〔语文〕

> 来源：王荣生（上海师范大学教授，中国大陆第一位语文课程与教学论博士），《语文科课程论基础》《语文课程与教学内容》

### 2.1 三个层级的区分

| 层级 | 回答的问题 | 由谁决定 | 常见问题 |
|------|----------|---------|---------|
| **课程内容** | 应该教什么？ | 课程标准 | 研制缺失，"课标≈教材目录" |
| **教材内容** | 用什么去教？ | 教材编写者 | 教材名存实亡，被当成"课文汇编" |
| **教学内容** | 实际教了什么？ | 教师 | 需学理审议，常有内容错误 |

> **"语文课程的问题主要出在课程内容上。"**（王荣生）

三者不一致是语文教学效率低下的根源。

### 2.2 与通用版第八章"教学要素论"的关系

通用版的教学要素论要求协调"教师—学生—目标—内容—方法—环境—评价"七大要素。在语文中，"内容"这一要素尤其复杂——因为它涉及课程内容、教材内容、教学内容三个层级的区分和一致性。这是语文学科特殊的问题。

## 第三章　语文核心素养〔语文〕

> 来源：《普通高中语文课程标准》；王宁

### 3.1 四个方面及其关系

```
                    文化传承与理解
                         ↑
                         |
  语言建构与运用 ←→ 思维发展与提升
  （核心与基础）       （从语言中生生发）
                         |
                         ↓
                    审美鉴赏与创造
```

> **"语言建构与运用是语文课程独有的素养，其余三个方面都是从语言建构与运用中生发出来的。"**（王宁）

这意味着：
- 四个素养不是平行并列的四块，而是以语言为核心向外辐射的同心圆
- 不能把四素养割裂为"这节课讲语言、下节课讲思维"——它们在同一次语文实践中同时发生

课标进一步规定，四个方面“既各自独立，又相互依存；既各有侧重，又相互融通”（课标正文第5页；PDF第13页）。因此，核心素养不是给课文贴四个标签，也不要求每节课平均覆盖四项。备课必须先说明学生经历什么语言实践、产生什么可观察表现，再判断其中主要发展了哪些素养；没有语言材料、语境和学生表现证据的“素养对应”无效。

### 3.2 与通用核心素养框架的关系

通用版第六章讲的是中国学生发展核心素养的总体框架（文化基础、自主发展、社会参与三大领域）。语文核心素养是这个总体框架在语文学科中的具体化：
- "人文底蕴" → 语文的"文化传承与理解"
- "科学精神" → 语文的"思维发展与提升"（语言层面的思维）
- "学会学习" → 语文的"语言建构与运用"（元语言意识）
- "审美情趣" → 语文的"审美鉴赏与创造"

### 3.3 "三思三想"设计逻辑

> 来源：王宁

> **"从所思所想出发，以能思能想启迪，向应思应想前进。"**

| 层次 | 含义 | 对应心理学概念 |
|------|------|-------------|
| **所思所想** | 学生的实际情况、已有经验（起点） | 维果茨基：现有发展水平 |
| **能思能想** | 学生通过学习过程产生的变化（过程） | 维果茨基：支架支撑下的学习 |
| **应思应想** | 经过学习后的应然状态（终点） | 维果茨基：潜在发展水平 |

> **"学习任务群一定要超过学生现有水平，但又是学生能达到的。"**——即维果茨基"最近发展区"的中国化表述。

### 3.4 真实情境的界定

> 来源：王宁

> **"情境存留在语境之中，情境存留在思想接受的过程中，情境是师生共同营造的。"**

不是必须离开教室去找外在环境，而是在语文学习过程中师生共同营造的语境。

## 第四章　学习任务群〔语文〕

> 来源：王宁；《普通高中语文课程标准（2017年版2020年修订）》

### 4.1 定义

> **"所谓学习任务群就是确定与语文核心素养发展相关的主题，设计教学情境和多样的学习任务，让学生自己在体验中完成任务。"**（王宁）

课标的正式结构是：以语文学科核心素养为纲、以学生语文实践为主线，以任务为导向、以学习项目为载体，整合学习情境、学习内容、学习方法和学习资源（课标正文第8页；PDF第16页）。由此可得四条边界：

1. 任务群是课程内容的组织方式，不是一套固定教法或固定课型；
2. “有任务”不等于“任务群教学”，任务必须承载明确的语言文字运用；
3. 阅读与鉴赏、表达与交流、梳理与探究需要在任务中整合，而非三套孤立训练；
4. 情境、内容、方法和资源共同服务学习目标，不能用热闹情境替代文本学习。

### 4.2 与过去三种组织方式的区别

| 过去的组织方式 | 弊端 |
|---|---|
| 以文本为纲（系统化文本，不管学生） | 忽视学生主体 |
| 以知识为纲（布知识点，曾多达133个） | 负担重，消化不了 |
| 以行为训练为纲（听说读写平行分解） | 机械训练 |
| **学习任务群**（回到学生素养，综合训练） | 转型中 |

任务群中的选文和训练有了新定位：
- 文本——"只是作为言语资源，用来解决语言运用问题"
- 训练——"是一种综合的、总体性的、面向问题解决的训练"

### 4.3 高中语文学习任务群完整体系

《普通高中语文课程标准（2017年版2020年修订）》共设计**18个不同的学习任务群**。三类课程分别安排7、9、9个任务群，其中“整本书阅读与研讨”等任务群跨课程类型重复出现，因此不能把7、9、9直接相加。

| 层级 | 序号 | 任务群名称 | 核心目标 |
|------|------|-----------|---------|
| **必修首次安排（8学分）** | 1 | 整本书阅读与研讨 | 读整本经典，养成深度阅读习惯 |
| | 2 | 当代文化参与 | 关注当代文化生活，增强文化参与意识 |
| | 3 | 跨媒介阅读与交流 | 多媒介信息获取与整合，适应信息化时代 |
| | 4 | 语言积累、梳理与探究 | 语言文字现象的系统梳理，建立语言意识 |
| | 5 | 文学阅读与写作 | 文学审美，诗歌/散文/小说/戏剧读写 |
| | 6 | 思辨性阅读与表达 | 批判性思维，论述类文本读写 |
| | 7 | 实用性阅读与交流 | 实用类文体读写，服务社会生活 |
| **选择性必修新增（6学分）** | 8 | 中华传统文化经典研习 | 文言经典深度研习 |
| | 9 | 中国革命传统作品研习 | 革命文学作品研读 |
| | 10 | 中国现当代作家作品研习 | 现当代重要作家专题研习 |
| | 11 | 外国作家作品研习 | 外国经典文学作品研习 |
| | 12 | 科学与文化论著研习 | 科普类、学术类文本研读 |
| **选修新增（设计12学分）** | 13 | 汉字汉语专题研讨 | 语言文字应用专题深入研究 |
| | 14 | 中华传统文化专题研讨 | 传统文化专题研究 |
| | 15 | 中国革命传统作品专题研讨 | 革命传统作品专题研究 |
| | 16 | 中国现当代作家作品专题研讨 | 中国现当代作家作品专题研究 |
| | 17 | 跨文化专题研讨 | 在文化比较中拓展理解 |
| | 18 | 学术论著专题研讨 | 学术论著研读与专题探究 |

**三层级递进逻辑：**
- **必修**安排任务群1—7，面向全体学生，奠定共同语文素养基础。
- **选择性必修**安排9个任务群：任务群1—4贯穿或深化，新增任务群8—12；学生依据个人需求与升学考试要求选择修习。
- **选修**安排9个任务群：任务群1—3贯穿，新增任务群13—18；学生可自由选择学习。

> **教材编排体现：** 统编高中语文教材将上述任务群分配到5册（必修上下、选必上中下），每册约2-3个任务群，以人文主题和学习任务群双线组织单元。

### 4.4 高中语文课程结构

高中语文课程分**三类课程**，层层递进：

| 课程类型 | 学分 | 对应任务群 | 面向 |
|---------|------|-----------|------|
| **必修** | 8学分（144课时） | 任务群1—7 | 每名高中学生必须修习 |
| **选择性必修** | 6学分（108课时） | 任务群1—4、8—12 | 按个人需求与升学考试要求选择修习 |
| **选修** | 设计12学分，供自由选择 | 任务群1—3、13—18 | 自主选择、个性发展 |

### 4.5 学业质量水平

课标为语文核心素养设定了**5个学业质量水平**，明确不同水平的具体表现：

| 水平 | 定位 | 对应考试 | 关键特征 |
|------|------|---------|---------|
| **水平1** | 必修课程要求 | 必修阶段发展描述 | 能在具体语境中完成基础的理解、表达、鉴赏和文化学习任务 |
| **水平2** | 必修课程要求 | **高中学业水平考试依据** | 在水平1基础上提高信息评价、语言反思、文学评价和文化参与能力 |
| **水平3** | 选择性必修课程要求 | 选择性必修阶段发展描述 | 能建立复杂信息联系、质疑文本并用资料支持观点，开展评论与文化探究 |
| **水平4** | 选择性必修课程要求 | **高校考试招生录取依据** | 能比较多文本、提出探究问题、综合表达并作有依据的鉴赏和文化分析 |
| **水平5** | 选修课程较高要求 | 修习情况供高校或用人单位参考 | 能判断多源信息可靠性，开展专题探究并形成较成熟的研究性表达 |

> **备课启示：** 学业质量水平是对完成课程学习后综合表现的总体刻画，不是给单篇课文、单道题或一节课贴“难度等级”。课标对课程和考试的对应关系见正文第39页（PDF第47页）。备课时应引用与目标有关的具体表现描述来设计学习证据；只有课程层面的总体评价才使用完整水平判定。

### 4.6 与通用版大单元教学论的关系

学习任务群是课标层面的内容组织方式，大单元是教学层面的设计实施方式——两者是**一体两面**：
- 任务群回答"语文课程应该按什么组织内容"
- 大单元回答"教师怎么把这些内容组织成完整的学习事件"

### 4.7 统编教材的双线组织方式

统编高中语文教材采用**双线组织**的方式编排单元，这是理解教材结构的关键：

| 组织线索 | 内容 | 作用 |
|---------|------|------|
| **人文主题线**（明线） | 青春的价值、家乡的文化生活、伟大的复兴…… | 为学习赋予价值和意义，回应"为什么读" |
| **学习任务群线**（暗线） | 整本书阅读、文学阅读与写作、思辨性阅读…… | 为学习规定内容和路径，回答"读什么、怎么读" |

**双线如何协同：** 每个单元都是一条人文主题与一个/多个学习任务群的交集。例如：

| 册 | 单元 | 人文主题 | 学习任务群 |
|----|------|---------|-----------|
| 必修上 | 第一单元 | 青春的价值 | 文学阅读与写作（青春诗歌/小说） |
| 必修上 | 第三单元 | 生命的诗意 | 文学阅读与写作（古典诗词） |
| 必修下 | 第一单元 | 中华文明之光 | 中华传统文化经典研习（诸子散文） |
| 选必上 | 第一单元 | 伟大的复兴 | 中国革命传统作品研习 |
| 选必中 | 第二单元 | 苦难与新生 | 中国革命传统作品研习（报告文学/小说） |

> **备课启示：** 教师备课时，必须同时读懂两条线——只知道"这个单元的人文主题是什么"不够，还必须知道"这个单元对应哪个任务群，任务群规定了什么核心学习活动"。人文主题管"为什么学"，任务群管"学什么、怎么学"。

## 第五章　中国语文教育的传统〔语文〕

> 来源：王宁；陆志平引述

### 5.1 文史哲不分家

> **"我国语文教育本就有文以载道、以文化人的传统。语文教育与道德教育、历史教育、哲学教育融合在一起，所谓文史哲不分家。"**

历史脉络：周代国学教育 → 汉代经学教育 → 宋代理学教育 → 清代小学通经史 → 当代语文课程

### 5.2 与西方母语教育的根本差异

| | 中国语文 | 西方母语教育 |
|---|---|---|
| 语言与文化 | **不可分割**——语言教学即文化教学 | 分开的——语言课讲语法，文化课讲文学 |
| 教学传统 | 文以载道、以文化人 | 工具理性、分析分解 |

### 5.3 与通用版分析教育哲学的关系

通用版第四章赫斯特把知识分为七种形式。语文知识横跨其中至少三种：
- **美学知识与经验**（文学阅读与鉴赏）
- **对人与心理的理解**（通过文本理解人的经验）
- **道德知识与经验**（文化传承中的价值判断）

这正是语文"综合性"的体现——它不是单一知识形式，而是多种知识形式的交融。

# 第二编　语文教学论基础

> 核心问题：语文课怎么教？教学内容怎么确定？

---

## 第六章　"教什么比怎么教更重要"〔语文〕

> 来源：王荣生《语文课程与教学内容》

> **语文教学研究要从过多的关注教学方法，转移到确定合宜的教学内容。**

很多课的问题不是"教得不好"，而是"教的东西不对"——教学内容本身不合适、不准确、不需要教。

常见诊断：
- 把"定篇"当"例文"教（只讲手法不讲经典本身）
- 把"用件"当"定篇"教（把信息材料当经典精读）
- 所有课文用同一套流程教（不区分文体特征）

### 与通用版的关系

这对应通用版泰勒原理"选择学习经验"这一环节，但王荣生特别强调了语文教学的特殊性：很多其他学科教学内容是确定的（数学教什么很清楚），语文的"教什么"反而最不确定——这是语文教学效率低下的结构性原因。

---

## 第七章　选文四类型〔语文〕

> 来源：王荣生

| 类型 | 功能 | 课程内容 | 教学方式 |
|------|------|---------|---------|
| **定篇** | 学习经典本身 | 经典文本的丰厚内涵 | 逐字逐句研读，不替代 |
| **例文** | 学习某一语文知识/方法 | 文本中体现的某一规则或方法 | 以文为例，举一反三 |
| **样本** | 学习阅读这类文章的方法 | 在阅读过程中生成的读写方法 | 从样本中归纳方法 |
| **用件** | 作为信息/资料使用 | 文本提供的信息本身 | 提取信息，完成任务 |

### 与通用版"大概念"的关系

选文四类型决定了不同的"大概念"提炼方式：
- **定篇**：大概念 = 经典文本的丰厚内涵和文化价值
- **例文**：大概念 = 文本中体现的某一语文知识/方法/规则
- **样本**：大概念 = 阅读这类文章的策略
- **用件**：大概念 = 文本信息所指向的问题/议题

## 第八章　阅读教学设计的两个依据〔语文〕

> 来源：王荣生《阅读教学设计的要诀》

> **"依据体式来阅读，是阅读的通则；依据文本体式来解读课文，来把握一篇课文的教学内容，是阅读教学的基本规则。"**

### 8.1 依据一：文本体式（文体特征）

| 文体 | 关注重点 |
|------|---------|
| 小说 | 人物、情节、环境、叙事视角 |
| 散文 | "这一篇"独特的情感体验和语言表达 |
| 诗歌 | 意象、节奏、情感、韵律 |
| 文言文 | "一体四面"（文章、文学、文化、语言） |
| 实用文 | 信息获取、交际目的、表达方式 |

### 8.2 依据二：学情分析

三个关键问题：
1. 学生能独立读懂什么？（教学起点）
2. 学生反复阅读仍读不懂什么？（教学重点）
3. 学生的感受与文本要求之间的差距在哪里？（教学切入点）

> **"学生不喜欢的，使他喜欢；学生读不懂的，使他读懂；学生读不好的，使他读好。"**

### 与通用版的关系

学情分析对应通用版第十四章奥苏贝尔"有意义学习理论"——先探明学生已经知道了什么。但王荣生的学情分析更聚焦于阅读教学：不只是"学生知道了什么知识"，还要分析"学生读出了什么""还读不出什么"。

## 第九章　从"教的活动"转向"学的活动"〔语文〕

> 来源：王荣生

语文课堂长期以"教的活动"为基点（教师讲、教师问、教师总结），应转向以"学的活动"为基点。

三条标准：
1. 学生的"学的活动"有较充分的展开（时间保障）
2. 学习经验有较充分的表达与交流（学生动起来）
3. 班级每个学生都能获得共同的学习经验（面对学习共同体）

### 与通用版的关系

这对应通用版第十四章建构主义"教师角色转变"的理念，但王荣生把它落到了语文课堂的具体操作层面——不是抽象地说"让学生主动建构"，而是给出了三条可观测的标准。

## 第十章　教师角色定位〔语文〕

> 来源：王宁

> **"教师只是一个沟通者，一个组织者。"**

批评"错位"现象：教师常错位到"传意者"，自己把文本吞了以后，用自己的理解替代作者的思想，直接灌输给学生。

> **"首先要相信学生的智慧……不要过于相信自己而轻视学生。"**

### 与通用版的关系

这对应通用版叶澜"生命·实践"教学论中教师的角色——教师是"引导者"而非"灌输者"。王宁的说法更朴素，也更直接地指向语文课堂的具体场景。

# 第三编　文本解读理论

> 核心问题：语文教师怎么读出一般读者读不出的东西？怎么引导学生多元但有界地解读文本？

---

## 第十一章　文本解读学〔语文〕

> 来源：孙绍振（福建师范大学教授）

**核心著作：**
- 《文学文本解读学》（长江文艺出版社）
- 《名作细读：微观分析个案研究》
- 《月迷津渡：古典诗词个案微观分析》
- 《孙绍振如是解读作品》

### 11.1 核心主张

以文学创作论为武器，揭示作品的创作奥秘。

> 作品好比果实，我们拿到果实时，它从种子入土到开花结果的整个生成过程都不见了，被手里的果实遮蔽了。**解读就是还原它的生成机制。**

### 11.2 文本解读方法谱系（"十二法"）

| 方法 | 核心操作 |
|------|---------|
| **还原法** | 将艺术加工后的文本"还原"为原生状态，对比发现艺术加工的奥秘 |
| **矛盾法** | 找出文本内部的矛盾/不一致处，分析其产生的机制和效果 |
| **错位美法** | 人物之间的情感、认知"错位"产生审美张力 |
| **替换法** | 将原文词句替换为其他表达，对比发现原文的不可替代性 |
| **关键词语解读法** | 聚焦关键性词语，分析其独特的表达功能 |
| **形象三维组合解读法** | 从感知、情感、智性三个维度分析文学形象 |
| **三层揭秘法** | 表层意思→深层情感→文化意蕴，逐层揭示 |
| **感觉解读法** | 从作家独特的感觉方式入手，分析艺术感知特征 |
| **艺术形式规范知识解读法** | 运用文论/文体知识解读文本的艺术形式特征 |

> **文本解读是语文教学最重要的基本理念。** 教师的专业素养首先体现为文本解读能力——能读出一般读者读不出的东西。

### 与通用版的关系

通用版的教学设计理论（大单元、UbD等）回答"怎么教"，但语文教学有一个其他学科没有的特殊前提：**教师必须先对文本有专业化的独立解读**，然后才能设计教学。文本解读学就是培养这种能力的理论。

---

## 第十二章　多元有界解读观〔语文〕

> 来源：赖瑞云（福建师范大学文学院研究员、博士生导师）

**核心著作：** 《混沌阅读》、《文本解读与语文教学新论》

### 12.1 多元有界

> **"一千个哈姆雷特，还是哈姆雷特，不可能是李尔王或者贾宝玉。"**

多元解读是合理的（读者经验不同，理解必然不同），但必须有边界——这个边界由文本本身的规定性设定。

### 12.2 文言文教学"四结合"策略

1. **文野结合**——专业化解读与直觉体悟结合
2. **文白结合**——文言理解与白话疏通结合
3. **文史结合**——文本阅读与相关文献资料结合
4. **文道结合**——语言学习与文化理解结合

### 12.3 专业化解读的两个路径
- **第一类**：运用知识理论（文体知识、创作理论、解读方法）
- **第二类**：引入相关文献资料（特别是古典作品，背景/语言/内容有隔膜，文献的"助解"作用突出）

### 与通用版的关系

这对应通用版第五章后现代课程理论中多尔"4R"的"严密性"——后现代课程追求开放和生成，但不等于没有边界。赖瑞云的"多元有界"就是语文解读中的"有目的的寻找不确定性"。

# 第四编　思辨读写理论

> 核心问题：怎么把批判性思维引入语文阅读与写作教学？

---

## 第十三章　思辨读写（余党绪）〔语文〕

### 13.1 学者简介

- **上海市语文特级教师、正高级教师**
- **统编语文教材编写者**
- 上海师范大学附属中学语文教师，一线教学二十多年
- 教育部重点课题"中学生批判性思维培养与思辨读写教学实践研究"课题组组长
- 王宁教授（课标组长）为其《思辨读写十讲》作序推荐

### 13.2 代表著作

| 著作 | 出版年 | 主题 |
|------|--------|------|
| 《祛魅与祛蔽——批判性思维与中学语文思辨读写》 | 2016 | 批判性思维引入语文教学的理论基础 |
| 《说理与思辨——高考议论文写作指津》 | 2017 | 思辨性写作 |
| 《走向理性与清明——整本书阅读之思辨读写》 | 2019 | 整本书阅读的思辨化（母题/议题/问题体系） |
| 《思辨读写十讲》（商务印书馆） | 2024 | 二十年实践的总结 |

### 13.3 核心主张

> **读书为本，思辨为要，注重转化**

| 原则 | 含义 |
|------|------|
| **读书为本** | 原生态阅读是基础——先让学生真读、通读、完整读 |
| **思辨为要** | 批判性思考是核心——以分析论证为驱动 |
| **注重转化** | 转化性运用是落脚——把阅读所得转化为表达资源 |

对"批判性思维"的正名：**不是"找错""抬杠""否定"，而是"合理的、反思的思维"，目的是决定我们的信念和行动。**（引自罗伯特·恩尼斯的经典定义）

### 13.4 "三题定位，思辨读写"

从抽象到具体，三个层次：

```
母题（最上位——确立文本的核心价值，决定阅读方向）
  ↓
议题（中间层——确立教学的主要内容，提供思考框架）
  ↓
问题（最具体——驱动思辨读写的抓手，聚焦文本细读）
```

#### 母题——文本的核心价值

"母题"借自神话学，指**在文学作品中反复出现的人类基本的行为和精神现象**——如死亡、成长、野心、爱情、冒险、堕落。

母题确立的三个条件：
1. **基于文本**——而非主观臆造或强行粘贴
2. **考虑学生本位**——着眼于学生的思想启蒙与认知改进
3. **体现人生关怀**——作品与学生的现实人生发生关联

举例：
- 《鲁滨逊漂流记》→ 母题"冒险与生存"
- 《三国演义》→ 母题"功名与道义"
- 《红楼梦》→ 母题"青春与毁灭"

#### 议题——教学内容的结构化

- 在母题下，将整本书内容**议题化**，切割成不同的内容单元
- 议题要有**指向性和结构性**
- 议题之间是**螺旋上升**的关系

#### 问题——驱动思辨的抓手

好问题的两个标准：
- **"生发性"**——能触及作品的诸多因素和细节
- **"整合性"**——能将作品内容聚合起来形成清晰理解

> "有开有合，有聚有散，思维才能在感性与理性的对话中趋向清明与开放。"

### 13.5 思辨性阅读与思辨性写作

| 思辨性阅读 | 思辨性写作 |
|----------|----------|
| 理性的阅读、对话式的阅读、批判性的阅读、建构性的阅读 | 基于事实的具体分析与论证 |
| 澄清文本内涵，辨析作品主题 | 推动阅读向更深层次发展 |

读写不是两件事——**写作是阅读的深化和转化**。

### 13.6 与课标的对接

《普通高中语文课程标准（2017年版2020年修订）》设置**"思辨性阅读与表达"任务群**。余党绪是该任务群最重要的实践推动者和理论总结者之一，作为统编教材编写者，其理念已渗透进教材。

### 与通用版的关系

| 通用版理论 | 余党绪补的是什么 |
|-----------|-----------------|
| 马扎诺"自我系统"激活 | 母题就是激活自我系统的工具——当文本与学生人生关联，学习意愿被激发 |
| 威金斯"理解的六侧面"中的"移情""洞察" | 三题定位提供了具体的操作路径 |
| 高通路迁移 | "注重转化"就是读写迁移训练 |

# 第七编　语文教学设计核心原则

> 核心问题：以上理论如何整合为语文备课的校准框架？

## 第二十二章　四维校准框架

> 来源：教学讨论的提炼，整合王宁、王荣生、崔允漷、余党绪的理论

备课时任何一个语文教学设计，必须同时通过四个维度的校准：

| 维度 | 校准问题 | 理论对接 |
|------|---------|---------|
| **语言** | 学生在这节课里，对"语言本身"的敏感度有没有提升？ | 王宁：以语言建构与运用为核心；王荣生：依据体式确定教学内容 |
| **现实** | 学生在这节课里，有没有和文本发生真实的生命碰撞？ | 余党绪：母题体现人生关怀；阐释学：视野融合；马扎诺：自我系统 |
| **单元背景** | 这节课有没有为整个单元的研习任务服务、为后续课文埋下伏笔？ | 崔允漷：大单元整体设计；荣维东：统整内容 |
| **阶段位置** | 这节课的深度有没有达到该学段的要求？ | 王宁：三思三想（超越现有水平但能达到）；布鲁纳：螺旋式课程 |

四维校准之外还存在三个课标硬门槛：教学必须让学生实际运用语言文字；学习过程至少形成可观察的学习表现或成果；评价证据必须与目标和任务一致。四维回答“设计是否有意义”，三个门槛回答“学习是否真实发生”。

## 第二十三章　局部与整体的四重关联

> 来源：教学讨论中提出的设计原则

任何一个语文知识点的教学，都必须同时考虑四个维度的关联：

```
            ┌──→ ① 局部 → 整体知识体系（不能孤立教）
            │
  局部知识点 ┼──→ ② 局部在整体结构中的位置和作用
            │
            ├──→ ③ 知识的现实意义（为什么存在？回应什么问题？）
            │
            └──→ ④ 学生生涯纵向贯通（初高中如何递进深化？）
```

与大单元教学论的对应：
- 第①条 ↔ 大概念统摄
- 第②条 ↔ 结构化重组
- 第③条 ↔ 大情境驱动（母题体现人生关怀）
- 第④条 ↔ 螺旋上升

## 第二十四章　语言与现实的不可分割

> 来源：教学讨论的提炼

语文课最深的悖论：**它用"语言的事"来教"现实的事"，又用"现实的事"来驱动对"语言的事"的敏感。**

- 如果只讲现实意义不讲语言 → 语文课变成班会课/心理课，文本变成"案例"，语言消失了
- 如果只讲语言形式不讲现实 → 语文课变成修辞分析课，学生不知道为什么要读

> **好的语文课必须让学生感到：正因为用了这种语言，这个现实才被说成这样；换个说法，它就不是它了。**

### 与通用版理论的关系

这条原则是语文学科特有的——通用版的教学设计理论（大单元、UbD等）不需要考虑"语言与现实"的张力问题，但在语文中这是核心矛盾。

# 第八编　语文评价理论

## 第二十五章　语文教学评价

### 25.1 基本框架（同通用版第五编）

教—学—评一致性、过程性/结果性评价、表现性任务均适用于语文（详见通用版第五编）。

### 25.2 语文评价的特殊性

| 维度 | 通用版原则 | 语文调整 |
|------|----------|---------|
| **评价标准** | 目标可观测、可测量 | 语文目标中有些属于"隐性体验性知识"（如审美感受），不能简单量化——需用表现性评价 |
| **答案性质** | 标准答案 vs 开放答案 | 语文以多元有界为原则——开放解读，但有文本边界（赖瑞云） |
| **评价方式** | 选择题、简答题、表现性任务 | 语文评价方式更多样：朗读、批注、札记、仿写、改写、评论、演讲、辩论 |
| **过程性评价** | 提问、观察、学习任务单 | 语文的过程性评价须关注学生的阅读过程——不仅是结果对不对，更关注学生怎么读的（元认知） |

课标把评价嵌入阅读与鉴赏、表达与交流、梳理与探究的具体情境和活动任务中，并明确“评价的过程即学生学习的过程”（课标正文第44页；PDF第52页）。因此，评价不能只留在课末：

```text
目标中的素养表现 → 能引出该表现的任务 → 学生留下的过程/成果证据 →
描述性反馈与自我反思 → 教师据证调整教学
```

可用证据包括批注、读书笔记、口头交流、小组研讨成果、调查报告、文学创作、表演和反思日志。使用多元证据不等于降低标准；每项证据仍需提前规定观察点、底线要求和反馈方式。

### 25.3 语文课程与教学论教材体系

| 学者 | 教材 | 特点 |
|------|------|------|
| **潘庆玉**（山东师范大学） | 《语文课程与教学论》（高等教育出版社） | 按课标体系编写，覆盖五大课业 |
| **张心科**（华东师范大学） | 《语文课程与教学论》 | 三编结构：概论→分论→新论 |
| **郑国民**（北京师范大学） | 《语文课程与教学论》 | 新标准学科教育系列 |

张心科教材框架：
- 第一编 语文教育概论：课程概论、教材概论、教学概论
- 第二编 语文课业分论：识字教育论、写字教育论、阅读教育论、写作教育论、口语教育论
- 第三编 语文教学新论：跨学科学习、项目化学习、任务型学习、整本书阅读、思辨性阅读、情境式写作、过程性写作

# 第九编　语文备课操作框架

> 核心问题：以上所有理论如何整合为一套可操作的语文备课流程？

---

## 第二十六章　语文备课程序

> 综合王荣生 + 王宁 + 孙绍振 + 赖瑞云 + 崔允漷 + 余党绪 + 威金斯 + 马扎诺的理论

```
Step 0：现实之问（前置思考）
    → 这个文本能回应学生什么真实的困惑？
    → 余党绪：母题体现人生关怀；马扎诺：自我系统激活
    → 不是"文本有什么可以教"，而是"文本能回应什么"

Step 1：教材定位
    → 这课在教材单元中是什么角色？
    → 崔允漷：大单元视野中的位置
    → 单元主题、学习任务群、在选文脉络中的独特角色

Step 2：确定选文类型
    → 王荣生：定篇/例文/样本/用件
    → 决定这篇课文在课程中的功能

Step 3：文本体式分析
    → 王荣生：依据体式确定教学内容
    → 依据文体特征确定"读什么""学什么"

Step 4：文本的专业化解读（裸读）
    → 孙绍振：以创作论为武器
    → 不看教参，先独立读文本
    → 运用还原法/矛盾法/替换法等读出一般读者读不出的东西

Step 5：学情分析
    → 王荣生：依据学情选择教学内容
    → 奥苏贝尔：探明学生已经知道了什么
    → 确定学生起点、落差、困难点
    → 王宁：三思三想（所思所想→能思能想→应思应想）

Step 6：确定核心素养目标
    → 王宁：四维度对齐，以语言建构与运用为核心
    → 布鲁姆/安德森：目标覆盖适当的认知层次
    → 目标可观测、可评价

Step 7：设计评价任务（逆向设计阶段2——先于教学过程）
    → 崔允漷/威金斯：评价先行
    → 什么是"读懂了"的证据？
    → 赖瑞云：评价标准须遵循多元有界

Step 8：设计教学活动（逆向设计阶段3）
    → 崔允漷：逆向设计（先定评价，再定活动）
    → 王荣生：从教的活动转向学的活动
    → 余党绪：三题定位（母题→议题→问题）
    → 加涅：九大教学事件作为完整性检查
    → 情境创设→任务驱动→活动展开→成果展示→评价反思

Step 9：设计迁移与反思
    → 威金斯：促进远迁移——高通路迁移
    → 余党绪：注重转化——读写迁移
    → 崔允漷：学后反思支架
    → 元认知培养：教学生监控自己的阅读理解
```

## 第二十七章　语文备课自检标准

| 维度 | 自检问题 | 理论依据 |
|------|---------|---------|
| **现实意义** | 这节课回应了学生什么真实的困惑？ | 余党绪：母题；马扎诺：自我系统 |
| **教学内容** | 教的东西对不对？是不是这篇课文应该教的？ | 王荣生：教什么比怎么教更重要 |
| **选文类型** | 这篇课文的选文类型定对了吗？教学方式匹配吗？ | 王荣生：选文四类型 |
| **文本体式** | 教学内容是否契合这篇课文的文体特征？ | 王荣生：依据体式确定教学内容 |
| **学情** | 是否基于学生已有的阅读经验？落差找准了吗？ | 王荣生：依据学情；奥苏贝尔：有意义学习 |
| **解读深度** | 教师自己读出了什么独特的东西？ | 孙绍振：专业化解读 |
| **素养目标** | 是否以语言建构与运用为核心？四维是否关联？ | 王宁：四素养不可分割 |
| **任务设计** | 是否从学生"所思所想"出发？有无思辨空间？ | 王宁：三思三想；余党绪：三题定位 |
| **学的活动** | 学生有没有充分的阅读、表达、交流机会？ | 王荣生：以学的活动为基点 |
| **解读边界** | 多元解读是否有文本依据？ | 赖瑞云：多元有界 |
| **单元整体** | 是否服务于单元大概念？是否为后续课文埋下伏笔？ | 崔允漷：大单元设计 |
| **阶段深度** | 是否达到该学段的要求（如选修的"研习"而非"赏析"）？ | 王宁：超越现有水平但能达到；布鲁纳：螺旋式 |
| **语言与现实** | 有没有做到"语言与现实不可分割"？ | 四维校准：语言×现实 |
| **评价先行** | 评价任务是否先于教学过程设计？三者是否对齐？ | 威金斯：逆向设计；崔允漷：教—学—评一致性 |
| **迁移设计** | 学的东西能不能在其他文本/情境中用？ | 威金斯：高通路迁移；余党绪：注重转化 |
| **元认知** | 有没有让学生反思自己的阅读过程？ | 弗拉维尔：元认知；崔允漷：学后反思 |

## 第二十八章　教学模式在语文中的应用

### 28.1 基本框架（同通用版第二十二章）

乔伊斯四大类教学模式均适用于语文（详见通用版第二十二章）。

### 28.2 四大类在语文中的典型应用

| 类别 | 语文中的典型模式 | 具体应用场景 |
|------|----------------|------------|
| **信息加工类** | 归纳思维、概念获得 | 诗歌意象归纳——从多首诗中归纳"月"意象的文化内涵；文体特征概念获得——从多篇散文中归纳"形散神聚" |
| **社会互动类** | 合作学习、角色扮演、辩论 | 戏剧片段演出（《雷雨》《哈姆莱特》）；"氓是不是坏人"的辩论；小组比较阅读 |
| **个人发展类** | 非指导性教学、自由写作 | 读书笔记、自由写作、个性化阅读计划；学生的"阅读史" |
| **行为系统类** | 直接教学、练习 | 文言文翻译训练、古诗文默写、答题策略训练 |

> **对语文备课的意义：** 不同文体、不同课型适用不同的教学模式。诗歌适合归纳思维模式，戏剧适合角色扮演模式，文言文翻译适合直接教学模式。教师不能"所有课文一个上法"。

## 第二十九章　语文深度学习

### 29.1 基本框架（同通用版第二十三章）

郭华的深度学习五个特征均适用于语文（详见通用版第二十三章）。

### 29.2 五个特征在语文中的具体表现

| 特征 | 通用含义 | 语文中的具体表现 |
|------|---------|----------------|
| **① 活动与体验** | 在主动活动中体验知识 | 朗读中体验诗歌的节奏和情感；写作中体验语言的锤炼过程 |
| **② 联想与结构** | 建立新旧知识的关联 | 学《氓》时联系初中学过的《关雎》《蒹葭》，建立《诗经》知识网络 |
| **③ 本质与变式** | 把握本质属性，分辨变式 | 把握"比兴"的本质（以物起兴、托物言志），在不同诗作中识别其变式 |
| **④ 迁移与创造** | 在新情境中运用 | 把"弃妇"母题的洞察迁移到当代文本解读；用四言体创作 |
| **⑤ 价值与评判** | 对所学进行价值判断 | 判断"亦已焉哉"的决断是否有价值；评价女主人公的选择 |

### 29.3 语文深度学习与"研习"的关系

选择性必修阶段的"研习"要求（区别于必修的"赏析"和初中的"感受"），本质就是深度学习：
- 不是记忆知识点（浅层）
- 不是简单理解文意（中层）
- 而是分析本质、建立关联、迁移运用、价值评判（深层）

### 30.1 基本框架（同通用版第二十四章）

### 30.2 语文PBL的特殊性

| 维度 | 语文调整 |
|------|---------|
| **核心知识** | 项目须指向语文核心知识（如"叙事视角""比兴传统""思辨论证"），不能脱离语文搞纯活动 |

| **学习实践** | 语文项目化学习的核心实践：深度阅读、思辨讨论、多形式写作、跨媒介表达 |
| **成果展示** | 语文成果可以是：研究报告、改编剧本、评论文章、播客节目、文学杂志、主题展览 |

### 30.3 语文PBL的设计案例（示例）

> **驱动性问题：** "如果让你编一本《中国弃妇诗选》，你会选哪些诗？按什么顺序编排？写一篇编者前言。"
>
> 这个项目同时调动：
> - 深度阅读（《氓》《孔雀东南飞》《琵琶行》等）
> - 比较研究（不同时代"弃妇"母题的演变）
> - 思辨表达（编者前言须论证选目和编排的逻辑）
> - 创造性输出（编排一本"诗选"）

## 第三十一章　语文差异化教学

### 31.1 基本框架（同通用版第二十五章）

汤姆林森的四维度差异化均适用于语文（详见通用版第二十五章）。

### 31.2 语文中的差异化操作

| 维度 | 语文中的具体操作 |
|------|----------------|
| **内容差异化** | 同一文本：基础薄弱学生聚焦疏通文意和基本理解；学有余力学生聚焦深层解读和比较研究 |
| **过程差异化** | 有学生独立精读，有学生小组共读，有学生听音频辅助；古文基础差的学生配翻译支架 |
| **产品差异化** | 写札记、画思维导图、做口头汇报、录制朗诵音频——多种方式展示同一学习目标 |
| **环境差异化** | 安静独立阅读区 vs 合作讨论区；不同阅读速度的学生给不同时间 |

> **关键原则：** 差异化的不是"学什么文本"（同一文本所有学生都要读），而是"读到什么深度""用什么方式读""怎么展示读懂了"。

## 第三十二章　语文教师的PCK

### 32.1 基本框架（同通用版第二十六章）

舒尔曼的教师知识七分类和PCK概念适用于所有学科（详见通用版第二十六章）。

### 32.2 语文PCK的特殊性

语文教师的PCK有其独特的复杂性：

| 维度 | 语文PCK的特殊性 |
|------|----------------|
| **学科内容知识** | 语文教师的"学科知识"不只是文学知识或语言知识，还包括文本解读能力、文学审美能力、文化理解力——这些带有"隐性体验性"特征 |
| **学科教学知识（PCK）** | 语文PCK的核心：知道"这篇课文该教什么""这一类文体该怎么教""这首诗该怎么引导学生读出什么"——这是王荣生说的"教什么比怎么教更重要"的心理学基础 |
| **学情知识** | 语文教师需要知道"学生读这首诗时会有什么感受""他们会卡在哪里""什么样的提问能激发他们深读" |

> **对备课的意义：** 每一次备课都是PCK的增长过程。教师的专业成长，本质上是"文本解读→学情判断→教学转化"这条链路的持续精进。

## 第三十三章　语文课例研究

### 33.1 基本框架（同通用版第二十七章）

### 33.2 于漪的"三次备课"在语文中的典范意义

> 于漪（人民教育家，语文特级教师）的"一篇课文，三次备课"是语文课例研究的经典范式：
>
> | 备课 | 内容 | 语文中的具体操作 |
> |------|------|----------------|
> | 第一次 | 不看参考，裸备 | 凭自己的文本解读功力，独立设计教学方案 |
> | 第二次 | 对照参考，反思差距 | 对比教参、优秀课例，发现自己的解读盲区 |
> | 第三次 | 课后反思，记录落差 | 根据学生实际反应，记录"预设"与"生成"的差距 |

> **对备课的意义：** 语文备课不是"写完教案就结束"，而是"裸读→对照→实施→反思→再设计"的循环。孙绍振的"文本解读学"为"裸读"提供了方法论工具（还原法、矛盾法、替换法等）。

## 第三十四章　SOLO在语文评价中的应用

### 34.1 基本框架（同通用版第二十九章）

SOLO五层次适用于语文（详见通用版第二十九章）。

### 34.2 SOLO在语文阅读理解评价中的具体应用

以"分析《氓》中女主人公的情感变化"为例，学生回答可能处于不同SOLO层次：

| SOLO层次 | 学生回答的表现 | 思维特征 |
|---------|-------------|---------|
| **前结构** | "她很伤心" —— 无法说明为什么伤心，逻辑混乱 | 无有效分析 |
| **单点结构** | "她被氓抛弃了所以伤心" —— 只找到一个原因 | 点状思维 |
| **多点结构** | "她先是恋爱，后来被抛弃，最后决绝分手" —— 能说出多个阶段，但未建立关联 | 线状思维 |
| **关联结构** | "全诗以淇水为暗线，女主人公的情感从热恋的甜蜜→被弃的痛苦→自省的清醒→决绝的独立，四个阶段构成完整的情感弧线" —— 多个要点建立了有机联系 | 面状思维 |
| **抽象拓展** | "《氓》的情感结构开启了中国文学'怨而不怒'的抒情传统，后世的弃妇叙事——从《孔雀东南飞》到《红楼梦》——都可以看作这个原型的变奏" —— 上升到理论高度，拓展了问题意义 | 系统思维 |

> **对备课的意义：** SOLO让语文评价有了"思维质量"的标尺。教师可以预设"这节课的目标应该达到关联结构层次"，然后设计相应深度的任务和评价。

## 第三十五章　语文评价量规设计

### 35.1 基本框架（同通用版第三十章）

量规设计四要素和真实性评价原则适用于语文（详见通用版第三十章）。

### 35.2 语文评价量规的设计特点

| 维度 | 语文评价中的具体维度 |
|------|--------------------|
| **内容理解** | 对文本的理解是否准确、深入？有没有读出独特的东西？ |
| **语言表达** | 语言是否准确、得体、有表现力？ |
| **思辨深度** | 有没有独立判断？论证是否充分？ |
| **文化理解** | 有没有把文本放在文化脉络中理解？ |

> **语文量规的特殊性：** 语文评价不能只看"对错"，要看"质量"。好的语文量规必须用**描述性语言**写出每个等级的具体表现，而非简单的分数量化。

# 第十三编　语文教学流派〔语文〕

> 核心问题：中国当代语文教学有哪些代表性实践流派？它们的核心理念是什么？

以下是中国语文教学一线的实践智慧，与理论层的学者（王荣生、王宁、孙绍振等）形成互补。

---

## 第三十六章　中国当代语文教学流派

### 36.1 钱梦龙——"三主四式"导学式

> 钱梦龙，上海市语文特级教师

核心理念：

| "三主" | 含义 |
|--------|------|
| **学生为主体** | 学习的主人是学生 |
| **教师为主导** | 教师的作用是引导而非灌输 |
| **训练为主线** | 语文能力在实践中生成 |

| "四式" | 含义 |
|--------|------|
| **自读式** | 学生独立阅读，形成自己的理解 |
| **教读式** | 教师在学生自读基础上引导深化 |
| **练习式** | 通过练习巩固和迁移 |
| **复读式** | 回头再读，在新的认知水平上重新理解 |

### 36.2 魏书生——六步教学法

> 魏书生，辽宁省语文特级教师

```
①定向 → ②自学 → ③讨论 → ④答疑 → ⑤自测 → ⑥自结
```

| 步骤 | 操作 |
|------|------|
| **定向** | 明确学习目标和重点 |
| **自学** | 学生独立阅读、思考 |
| **讨论** | 小组交流，解决自学中的问题 |
| **答疑** | 教师解答小组无法解决的问题 |
| **自测** | 学生自测学习效果 |
| **自结** | 学生总结收获和不足 |

> 核心精神：培养学生的自我管理能力和自学能力。

### 36.3 于漪——情感教育

> 于漪，上海市语文特级教师，人民教育家

核心主张：

> **"语文教学要打动人心。"** ——情感熏陶与语言训练的统一。

- 语文教学不能只有理性的分析，必须有情感的浸润
- 教师自己先被文本打动，才能打动学生
- "文道统一"——语言形式和思想情感是一枚硬币的两面

> 于漪的理念跟王宁"工具性与人文性的统一"一脉相通，但更强调教师的情感投入和课堂的情感氛围。

### 36.4 黄厚江——本色语文

> 黄厚江，江苏省语文特级教师

核心主张：

> **"把语文当语文教。"** ——回归语言本位。

- 语文课不能上成思品课、历史课、文化课——它必须是"语文"课
- 所有活动最终落点在语言建构与运用
- 反对过度包装、过度活动——让语文回归朴素

### 36.5 程翔——语文教师专业化

> 程翔，北京大学附属中学语文特级教师

核心主张：

- 语文教师须具备"母语觉悟"——对母语的敏感、热爱和自觉
- 语文教师的专业素养首先是文本解读能力和语言示范能力
- 强调语文教师作为"文化传承者"的使命感

### 36.6 各流派的共同精神

| 人物 | 核心理念 | 共同精神 |
|------|---------|---------|
| 钱梦龙 | 三主四式导学式 | 以学生为主体 |
| 魏书生 | 六步教学法 | 培养自学能力 |
| 于漪 | 情感教育 | 语言与情感的统一 |
| 黄厚江 | 本色语文 | 回归语言本位 |
| 程翔 | 母语觉悟 | 文化传承使命 |

> 这些流派虽然侧重点不同，但都指向同一个方向：**语文课必须是"语文"的课——以语言为核心，以学生为主体，以文化传承为使命。**

# 第十四编　扩展理论在语文中的应用

---

## 第三十七章　多模态读写与跨媒介语文学习

### 37.1 基本框架（同通用版第三十一章）

New London Group的多模态读写理论适用于语文（详见通用版第三十一章）。

### 37.2 在语文中的应用

课标"跨媒介阅读与交流"任务群的理论支撑：

| 多模态 | 语文中的应用 |
|--------|------------|
| **语言** | 传统文本阅读与写作 |
| **视觉** | 图文转换、影视改编分析、绘本阅读 |
| **音频** | 诗歌朗诵、广播剧、播客 |
| **多模态整合** | 新媒体阅读（图文推送、短视频脚本）、数字叙事 |

> **对语文备课的意义：** 当代学生接触的信息大量是多模态的。语文教学不能只教文字读写，还要教学生如何"阅读"和"生产"多模态文本。

## 第三十八章　批判教育学对语文教学的启示

### 38.1 基本框架（同通用版第三十二章）

阿普尔、弗莱雷、布迪厄的理论适用于语文（详见通用版第三十二章）。

### 38.2 对语文教学的启示

| 理论 | 对语文的启示 |
|------|------------|
| **阿普尔"谁的知识"** | 语文教材选文选择本身就是价值选择——选谁的诗？谁的散文？"经典"的标准是谁定的？这些追问让选择变得有意识 |
| **弗莱雷"提问式教育"** | 语文课堂应该是师生共同探究文本的场域，而非教师把"标准解读"灌输给学生——这跟余党绪"思辨读写"的理念一致 |
| **布迪厄"文化资本"** | 语文素养（阅读量、文学品味、语言能力）受家庭文化资本影响巨大。好的语文教学要为文化资本薄弱的学生提供补偿性支持 |

> **核心启示：** 语文教育不只是技术问题，更是文化政治问题。语文教师需要有意识地反思"我在传递谁的文化？这种传递对谁有利？谁被排除在外？"
