# 证据层目录（L4 · 只追加 · 永不清理）

课堂证据的安家之处——设计方案 §3.1 L4 与证据轴的落点。**所有者裁决：学生内容不脱敏，如实入库。**

## 目录约定

每个班级一个目录（命名如 `高2026级3班` 或你习惯的班级名）：

```
work/teaching/_classes/<班级>/
  observations.jsonl     # OBS-*：课堂观察记录（S6 产出）
  grading.jsonl          # GRD-*：批改记录（S7b 产出）
  mastery_ledger.jsonl   # MR-*：掌握记录（S8 产出；格式见 scripts/analyze_mastery.py）
  reflections/           # REF-*：课后反思（S9 产出）
  profile.json           # W2.1 学生画像（观察类标签带来源/置信度/有效期）
```

## 三条铁律（血缘）

1. 每条记录绑定：课程版本哈希 + 来源（观察表/作业/试卷引用）+ 机制节点编号——**无节点绑定的课堂数据不收录**；
2. 只追加不改写：订正以新行表达，旧行保留；
3. 任何"学生学会了/享受了"的断言只能引用本目录记录（两本账的课堂账）。

## 画像标签规则（§3.6 + §12 Q7 默认）

- 可推导类（成绩→短板）：随新数据自动刷新，无固定期限；
- 观察类（性格/态度）：带来源、置信度；**默认一学期有效期**，到期自动降权待复核【默认方案待所有者确认】；
- 无证据不落标签（U6 延伸）。
