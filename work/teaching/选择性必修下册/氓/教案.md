## 二、教材与学情分析

**教材地位**：与《离骚》共同构成"风""骚"传统源头；学生第一次完整细读一首以当事人身份回望整段婚姻的叙事诗——她不是被讲述的对象，而是讲述者本身。

**学情**：高二已修必修上诗词单元；真实困难有二：一是**投射**（自带"她自己选的"受害者归责与"他全伪装、她出走"苦情放大两套剧本）；二是**稀疏文本的补写冲动**（暴的方式、家人全貌、离开与否诗皆未写）。另：通假与活用（说、贰、二三）易混，全文翻译需要逐词落实。

## 三、教学目标

### （一）素养目标

1. **语言·全文翻译**：能独立完成全诗的全文翻译——逐句说出每句的意思，句内每个关键字词（实词义、通假、词类活用、特殊句式、注音）都能解释；错漏处能持教材自行修复。
2. **思维·形式**：以相邻原句为证，说明桑叶比兴与处境转折、新旧对照与责任失衡、誓言回环与叙事断裂，以及四言叠词的声音怎样承载记忆与悲伤——形式分析回到人物故事。
3. **思维·证据与伦理（本课核心之一）**：区分文本明写、合理推断与诗外补写（三桩边界：暴／兄弟之笑／亦已焉哉）；把"他为何伤害"与"她为何难以离开"分开归置，不使受伤者承担伤害的解释责任。
4. **文化·坐标**：合书立住《诗经》最低坐标（首部诗歌总集、305篇、风雅颂、《卫风》）。

### （二）现实目标：《氓》是一篇避坑文

**借她的经历，让学生获得亲密关系的风险素养——识坑、防坑、能止损，身临其境地想"如果是我，我怎么做"。**

**一、识坑：这首诗写出的六个坑（名字即内容：文本证据 → 现实形态）**

1. **把样子当为人**：蚩蚩的“忠厚”是出场的样子，不是为人的底色；抱布贸丝的表面来意之下是谋婚。→ 现实：看起来老实 ≠ 为人老实，追求期的表现不能当人品。
2. **婚前就开始迁就**：“将子无怒”——还没成婚，她就在替他的情绪负责、哄他消气；无良媒仍自己定下婚期（秋以为期）。→ 现实：关系里一方不断退让、把对方消气当分内事，退让换不来对等。
3. **把判断交出去**：“尔卜尔筮”——终身大事交给卦象；不见则泣、既见则笑——喜怒全交给对方。→ 现实：交给感觉、交给“他说了算”、问遍别人，唯独没有自己的观察与主见。
4. **懂道理也照样栽**：“女之耽兮，不可说也”是她**自己写下的警告**——她全懂，仍在耽。→ 现实：人会合理化警告（“他不一样／我不一样”）；坑往往是当事人自己标注过的，这是全诗最深刻的一层。
5. **把誓言当行动**：恋爱期言笑晏晏、信誓旦旦；婚后士贰其行、二三其德，“信誓旦旦”走到“不思其反”。→ 现实：说得好听 ≠ 做得可靠；判断人看长期行为的一致性，不看承诺的强度——前后不一本身就是答案。
6. **退到无人可说**：兄弟不知（平时无沟通）、咥其笑矣（出事被讥笑）、躬自悼矣（独自消化）；靡室劳、夙兴夜寐的多年付出，成了走不掉的理由。→ 现实：支持系统失联是危险放大器，“没人可说”本身就是信号；投入越多越难止损，退路要在线。

**二、防坑：带得走的判断纪律**

看行为不看言辞（誓言由行动核验）｜看长期不看短期（恋爱期样本不足）｜看一致性不看强度（前后不一即答案）｜自己的判断不外包、警告不被合理化｜保住自己的支持系统、节奏与退路。

**三、能止损：避坑文的出口——"反是不思，亦已焉哉"**

她最终形成并说出停止的判断。避坑的最高级不是永不犯错，而是**在坑里能喊停**：及时止损是一种能力，也是这首诗留给学生的力量，而不只是哀伤。

**四、身临其境（课堂发生方式）**

站在她的四个节点想"此刻我看到了什么信号？如果是我，我怎么做？"：定婚期时（把样子当为人／婚前就开始迁就／把判断交出去）→迁嫁时（懂道理也照样栽）→暴显现时（把誓言当行动）→兄弟讥笑时（退到无人可说 与止损）。

**伦理护栏**：避坑≠受害者归责——她不是错在被爱与付出，是这段关系失信在前；防坑教的是识别信号、守住自己，不是教人不再信任。

## 四、重点难点

- **重点**：全文翻译（目标1，逐句逐词）与三组形式（目标2）。
- **难点（核心）**：审慎态度的生成（现实目标）与证据边界（目标3）——前者防"空喊口号"，后者防"诗外补写与受害者归责"。

### （二）文言知识分类清单（重点词目逐条——供逐条核对）

**1. 通假字（4）**
1. 匪：同"非"，不是（句2 匪来贸丝、句4 匪我愆期）
2. 无：同"毋"，不要（句5 将子无怒）
3. 说：同"脱"，解脱，读 tuō（句14/15 犹可说也／不可说也）
4. 泮：同"畔"，边、岸，读 pàn（句27 隰则有泮）

**2. 古今异义（7）**
1. 布：古代货币（今义布匹）（句1）
2. 至于：到达（今义表另起话题）（句3）
3. 泣涕：眼泪，涕指眼泪（今义鼻涕）（句7）
4. 贿：财物，此指嫁妆（今义贿赂）（句10）
5. 爽：差错（今义爽快）（句19）
6. 宴：欢乐（今义宴席）（句28）
7. 思：料想（今义思考）（句29）

**3. 词类活用与数词（2）**
1. 贰：不专一、有二心（数词义）（句19 士贰其行）
2. 二三其德：三心二意、反复无常（数词活用）（句20）

**4. 注音清单（16 音）**
氓 méng｜将 qiāng｜愆 qiān｜垝垣 guǐ yuán｜筮 shì｜咎 jiù｜于嗟 xū jiē｜说 tuō｜徂 cú｜渐 jiān（浸湿，不读 jiàn）｜汤汤 shāng shāng｜夙 sū 兴｜寐 mèi｜咥 xì｜隰 xí｜泮 pàn

**5. 核心字（1）**
耽 dān：沉溺、沉醉——全诗诗眼之一，"女之耽兮不可说也"的坑由此字立（句13-15）

**6. 特殊句式与固定结构（3）**
1. 以……为：把……定作（句5 秋以为期）
2. 载……载……：一边……一边……（句8 载笑载言）
3. 之：主谓之间取消独立性（句14/15 士**之**耽兮、女**之**耽兮）

**7. 叠词（5）**
蚩蚩（忠厚貌）｜涟涟（泪流不止）｜汤汤（水大貌）｜晏晏（和悦貌）｜旦旦（诚恳貌）

### （三）内容与结构知识（逐条成句）

1. **叙事链**：全诗第一人称回望——恋爱（一、二章）→结婚（二章末）→婚变（三、四章）→孤立（五章）→回望与停止（六章）；情绪线由情意绵绵、悲伤无助转向激愤决绝。〔KP-003〕
2. **比兴**："桑之未落，其叶沃若"（句11）与"桑之落矣，其黄而陨"（句16）以桑叶荣枯比喻女子容颜与婚姻处境的变化，兴中含比，且与叙事推进同时发生——不是外挂的修辞，是叙事本身。〔KP-004〕
3. **对照**："女也不爽"对"士贰其行"（句19）以相邻并置呈现婚姻中的责任失衡；判断这一对照必须以相邻诗句为证，不得引诗外材料。〔KP-005〕
4. **收束回环**："信誓旦旦"（句29）回收恋爱期誓言，"反是不思，亦已焉哉"（句30）完成情感与叙事的双重断裂——全诗在她自己说出的停止判断中结束。〔KP-006〕
5. **词句复现与反折**：两个"老"（句26 及尔偕老／老使我怨）让旧愿折返为怨；"反"与"不思"（句29/30）回环核验誓言；淇水两见（句3 送子涉淇／句18 淇水汤汤）标记来路与婚变同一条河。〔已提案立卡〕
6. **四言与叠词的声音**：四言匀步承载回望的语气，叠词（涟涟、汤汤、晏晏、旦旦）让声音本身携带记忆与情感——形式即内容的一部分。〔已提案立卡〕

### （四）文化知识（逐条）

1. 《诗经》是我国第一部诗歌总集。
2. 现存 305 篇。
3. 作品大致产生于西周初年至春秋中叶。
4. 传统上分风、雅、颂三类（《氓》属"风"）。
5. 《氓》收于《卫风》；本诗是"她自己在说话"——第一人称的价值。

### （五）伦理边界（逐条，审查与讨论的铁线）

1. "至于暴矣"只写行为转粗暴，方式与情节一个字未写——不得虚构具体情节。
2. "兄弟不知，咥其笑矣"只写兄弟讥笑，未写全家抛弃或求助被拒——不得扩大。
3. "反是不思，亦已焉哉"是她形成的停止判断，诗未写实际离开——不得续写出走。

### （六）诵读与背诵

1. 全诗背诵（教材要求）。
2. 重点句：13-15（劝诫三连）、19-20（对照两句）、29-30（收束两句）。
3. 易错音落实："说"读 tuō、"渐"读 jiān、"泮"读 pàn、"咥"读 xì、"汤汤"读 shāng shāng。
