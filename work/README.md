## 四层八份文档说明

### 第一层：课程与教学理论方法论

> **功能：** 为备课提供理论基础——"语文是什么""语文课程怎么设计的""教学依据什么理论"

| 文档 | 章节数 | 核心内容 |
|------|--------|---------|
| **通用版** | 33章 | 课程论基础（泰勒/杜威）、教学理论、认知发展（皮亚杰/维果茨基）、学习理论、动机理论、迁移理论、元认知、教学模式、深度学习、PBL、差异化教学、PCK、课例研究、评价理论 |
| **语文版** | 38章+附录 | 以2020年修订课标为执行基线，覆盖：课程性质、四项核心素养的整体关系、18个学习任务群、三类课程与五级学业质量、真实语文实践、教学与评价建议，以及选文、文本解读、思辨读写和当代教学流派 |

**使用方式：** 备课前查阅相关理论，确认"我这么备课的理论依据是什么"

### 第二层：备课方法论

> **功能：** 指导备课的全流程操作——从拿到课文到写出教案

| 文档 | 章节数 | 核心内容 |
|------|--------|---------|
| **通用版** | 16章 | ADDIE模型、迪克-凯里模型、备课层次（学年/单元/课时）、九步备课流程、学情分析、教学目标编写、教学策略选择、教案编写、教学反思 |
| **语文版** | 21章+附录 | 将课标落实为“课程定位—语言实践—目标—任务—证据—反馈”备课链，并覆盖母题、文本细读、AI配图、逐句分析、选文四类型、完整教案模板和于漪三次备课 |

**使用方式：** 按流程逐步执行，每一步都有具体操作指导和检查清单

### 第三层：教学环节技术与技巧

> **功能：** 指导课堂上的每一个具体环节怎么操作——提问怎么提、导入怎么导、朗读怎么指导

| 文档 | 编数 | 核心内容 |
|------|------|---------|
| **通用版** | 12编 | 微格教学十项技能、提问技术、导入八法、讲解四类、结课五型、板书设计、作业设计、课堂管理、小组合作、多媒体使用 |
| **语文版** | 17编 | 在通用版基础上增加任务群课堂五步协议，以及朗读、作文、文言文、群文阅读、口语交际、整本书阅读、跨媒介活动和复习课技术，强调成果证据与反馈闭环 |

**使用方式：** 备课中设计每个课堂环节时查阅对应编

### 第四层：PPT设计与演示方法论

> **功能：** 指导课件制作和课堂演示——PPT怎么设计、文字怎么排、图怎么选

| 文档 | 章节数 | 核心内容 |
|------|--------|---------|
| **通用版** | 16章 | Mayer十二原则、Sweller认知负荷理论、格式塔原则、CRAP设计四原则、Presentation Zen理念、Duarte演示结构、Alley断言-证据式幻灯片 |
| **语文版** | 13章 | 在通用版基础上增加语文PPT美学、课型差异、文本批注、任务页和跨媒介任务页，贯彻“技术服务真实语言运用、不替代文本阅读” |

**使用方式：** 制作课件时对照设计原则，避免认知过载

## 执行计划

### 语文备课系统_知识点提取研究计划.md

> **功能：** 从5本学生教材中系统提取81张知识点卡和28份单元图谱；1本教师用书仅作参考证据，最终形成可追溯、可量化验收的高中语文知识体系

**包含：**
- 2023—2026四川实际用卷的来源建档、逐题解构与教材映射
- 高考评价体系"一核四层四翼"对接坐标
- 双维度知识分类（人文维度×语言维度）
- 四层映射（核心价值/学科素养/关键能力/必备知识）
- 纵向贯通标注（初中→必修→选必→选修）
- 原子知识点/每课/每单元/每册/全局五级数据契约
- 特殊单元处理方案（活动单元/整本书阅读/古诗词诵读）
- 证据分级、稳定ID、状态机和依赖门禁
- 100分量化评分、硬性否决项、双审与返工机制
- 10张卡、5份图谱的代表性校准方案

**素材支撑：** `Data/textbook_extract/{册}/mineru_result/` 144个教材MinerU解析源包（113个学生教材源包 + 31个教师用书参考包），另有1个现行课程标准参考解析包；后者不计入教材产物数量。

## 使用建议

### 备一节语文课的完整流程

1. **查理论** → 读《课程与教学理论方法论（语文版）》中相关章节
2. **走流程** → 按《备课方法论（语文版）》八编流程逐步操作
3. **学技术** → 查《教学环节技术与技巧（语文版）》中对应编
4. **做课件** → 参照《PPT设计与演示方法论（语文版）》

### 快速定位

| 需求 | 去哪找 |
|------|--------|
| 这篇课文在教材体系中的定位 | 课程理论（语文版）→ 第四章学习任务群 + 第四章双线组织 |
| 这篇课文应该教什么 | 备课方法论（语文版）→ 第十章文本细读 + 第十五章逐词逐句分析 |
| 文言文怎么教 | 教学环节技术（语文版）→ 第十二编文言文教学 |
| 怎么设计课堂提问 | 教学环节技术（语文版）→ 第二编提问技术 |
| 作文课怎么上 | 教学环节技术（语文版）→ 第十一编作文教学全流程 |
| PPT怎么做 | PPT设计（语文版）→ 全文 |
| 提取知识点怎么做 | 知识点提取研究计划 → 第三部分提取规范 |
