# work 工作区导航

`work/` 保存系统的现行知识、方法、原则、评估与教学产物。它不是把所有文档平铺在一起的“杂物间”；每类内容只有一个规范根。这是存放、寻址与迁移契约，不以备课K/U/J节点作为工程依据。

| 规范根 | 唯一职责 | 不应放入 |
|---|---|---|
| `methodology/` | 人读方法论、单篇备课规程、S0—S9手册 | 机器注册、评估报告、单课产物 |
| `principles/` | 原则机器注册与强制方式 | 方法论长文、课堂证据 |
| `evaluation/` | 评估制度、收敛规则与检查报告 | 教学目标框架、教学实施产物 |
| `knowledge/` | 教材知识、高考资料、素材与总目录 | 方法论副本 |
| `teaching/` | 单元/单课设计数据与真实课堂证据 | 通用方法论 |

使用方法论从 `work/methodology/README.md` 进入；使用高考资料从 `work/knowledge/exams/README.md` 进入。全项目重要路径见根目录 `AGENTS.md`，机器存放契约见 `docs/architecture/storage-layout.json`。

历史知识点提取计划已移至 `docs/plans/语文备课系统_知识点提取研究计划.md`。它记录项目形成过程，不替代现行架构、手册、skill或账本。
