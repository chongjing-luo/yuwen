## 二、逐题答案·解析·评分量规

### （一）论述类文本阅读（1-3，9分）

**1. C**（核验：题面证据）
- A 正确依据：首段"对于人文研究来说，计算方法以往只是作为辅助手段而存在的，而今天已取得了不可替代的地位。一种新的人文研究形态应运而生，这就是'数字人文'"。
- B 正确依据：第2段"数据化之后所得到的文本替代物（集合、向量、概率）虽然损失了原始文本的丰富语义，但终究是可以计算的了""尽管计算机能处理海量的语料"。
- **C 错误（答案）**：原文"尽管计算机能……执行复杂的统计、分类、查询等任务，但它**并不能理解**文本的内容"——理解文本内容恰恰是计算机之所短，不是其任务能力的前提；"因此它所得的结果最终需要由人来解读"的因果也不成立（结果需人解读是因为结果是超越具体内容的抽象表示，见第3段）。干扰方式：强加条件＋强加因果（曲解文意）。
- D 正确依据：末段"数字人文不仅仅是新的手段和方法，更重要的是，它赋予我们提出新问题的能力"。

**2. D**（核验：题面证据＋解析逻辑）
- A 正确依据：首段由"计算方法……辅助手段→不可替代"引出"数字人文"概念，再以莫莱蒂设想引出"远读"。
- B 正确依据：第2段"擅长的是'计数'，而非理解"与第3段末"一句话，人的阅读不可替代"的铺垫关系。
- C 正确依据：第3段"基本上可以归为两类……米歇尔等人……这属于前者；莫莱蒂用地图、树结构……这属于后者"——两例分别对应两类远读。
- **D 错误（答案）**：末段"五千年来全人类使用最频繁的词是什么"是论证数字人文"赋予我们**提出新问题**的能力""获得观察超长历史时段文化现象的**新视角**"，并非论证"远读在解答传统人文问题方面已超越细读"；"超越人的细读"与全文"人的阅读不可替代"的总论相反。干扰方式：无中生有＋论点错置。

**3. C**（核验：题面证据）
- A 正确依据：末段"只有当数据量或者数据精度超出了个人阅读理解的能力范围时，才有理由借助计算机……"（必要条件表述相符）。
- B 正确依据：第3段"对远读结果的解读，仍然是依赖学者在细读文本的基础上所建立起来的对本领域的认知和理解"。
- **C 错误（答案）**：第4段明言"当考查单篇文本的文本特征……或者分析其内部结构……时，数据量**也会增长到个人无法处理的程度**。所以，上述对文本集合所做的讨论在单篇文本层面也是成立的"——C 与原文相反。干扰方式：曲解文意（正话反说）。
- D 正确依据：末段"透过这类问题，可以获得观察超长历史时段文化现象的新视角"。

**论述类核验结论**：三题答案 C／D／C，均经题面证据逐项比对；干扰方式覆盖"强加条件因果／无中生有＋论点错置／正话反说"，属 JIA 期主流干扰方式（§2.1）。**核验通过。**

### （二）实用类文本阅读（4-6，12分）

**4. D**（核验：题面证据）
- A 正确依据：材料一"保护技术推进的核心是找到与遗产变化状况相适应的保护方法，以便及时对藏品进行预警、干预，使藏品保持健康的状态"。
- B 正确依据：材料一"治理是通过外界的干预直接作用于可移动文化遗产的保护行为，是为了消除正在损毁遗产的外界因素，从而使遗产恢复到健康的状态"。
- C 正确依据：材料二表中 15℃ 行数值随湿度降低而增大（2.74→5.81→9.05→20.70），全表最大值 20.70 出现在温度 15℃、湿度 10% 处。
- **D 错误（答案）**：材料三"技术人员认为采用氢氧化钙溶液去酸法比较好"的理由是"可根据纸张酸化的程度调节去酸溶液的浓度和去酸时间，去酸彻底，可操作性强，在操作处理过程中也不会使文件出现新的损坏"——"去酸速度快、成本低"无中生有；"文件可以正常翻阅，甚至可以拿起抖动"是修复完成后的整体效果，不是选用去酸法的理由。干扰方式：无中生有＋张冠李戴。

**5. A**（核验：题面证据）
- **A 错误（答案）**：材料三"酸是纸张纤维发生化学降解的催化剂，能**加快**纸张纤维的水解反应，使纸张脆化变黄、机械强度下降"——加快水解的是**酸**，去酸的目恰在于**避免**酸性损害；A 项"目的在于加快纸张纤维的水解反应"与原文相反。干扰方式：正话反说。
- B 正确依据：材料一"预防是所有的减缓文化遗产恶化和损毁的行为的总称，它涉及光照度、环境条件、安全、防火和突发事件的准备等方面"。
- C 正确依据：材料一"根据可移动文化遗产遭受'病痛'情形的差异，治理技术可以分为杀虫、去酸、脱水和清洁等类型""是为了消除正在损毁遗产的外界因素"。
- D 正确依据：材料一"修复是对已经发生变形或变性的遗产进行处理，使之恢复到原有的形态或性质。修复的内容……一是清除……二是修补……"。

**6.（6分）受损原因与修复方案的针对性（评分：原因从①②③任答2点、方案从④⑤任答1点，两部分须各至少答1点，每点2分，共6分；意思对即可）**
① 气候原因：毛里求斯位于赤道南部，气候湿热多雨，高温高湿使纸张寿命大幅缩短（据材料二，温湿度越高寿命倍数越低）；
② 材质原因：文件纸张为破布浆机制纸，字迹材料为酸性烟黑墨水且双面手写，酸性加快纸张纤维水解，纸张严重酸化、柔韧性极差（材料三）；
③ 年代原因：文件形成于18世纪，年代久远，纸张自然老化（材料三）；
④ 去酸方案针对性强：依据档案损坏程度和特点选用氢氧化钙溶液去酸法，可根据酸化程度调节溶液浓度与去酸时间，去酸彻底、可操作性强、不产生新的损坏（材料三）；
⑤ 修复方案扬长避短：针对纸浆补书机对书页边缘残缺、书口断裂处补后强度不足的缺陷，辅以边缘、局部裱，既增强强度又不遮挡字迹（材料三）。

③ 效果：大量留白使叙述简洁、含蓄蕴藉，读者由对话自行想象补充，言约意丰，正合"冰山"之喻。

### （五）古代诗歌阅读（14-15，9分）

**14. B**（核验：题面证据＋解析逻辑）
- **B 错误（答案）**：颈联"垂纶雨结渔乡思，吹木风传雁夜魂"以雨中垂纶、风中雁声两个场景，寄托的是诗人羁旅漂泊的身世之感和孤高自守的情怀（干谒诗中自明心迹之笔），并非"归隐田园、终老江湖的志趣"——诗人正以求取功名（"只望至公将卷读"）为念。干扰方式：曲解情感＋过度推断。
- A 正确依据：首联"此身虽贱道长存"。
- C 正确依据：颔联"只望至公将卷读①，不求朝士致书论"及注①。
- D 正确依据：尾联"男子受恩须有地，平生不受等闲恩"。

**15.（6分）颈联写景的表达效果（评分：每点2分，共3点）**
① 心志形象化：以"雨中垂纶""风中雁魂"两个具体场景，把诗人羁旅漂泊的身世之感与孤高耿介的情怀化为可见可感的画面，使读者直观体会其心志；
② 节奏得舒缓：在多联直陈心志之间插入景语，宕开一笔，使全诗委婉从容，避免通篇直白说尽的平直之感；
③ 形象得深化：景中清苦之境与尾联"平生不受等闲恩"的宣言相互映照，强化了诗人贫贱自守、气节不屈的形象。
（复核：库 answers.jsonl Q05（2）要点两点——"颈联所写场景是作者孤高耿介情怀的形象化表达，可使读者更加直观地感受到作者的心志""舒缓诗歌全篇的节奏，使整首诗有委婉从容之致"——本卷①②与库答案两点一致，③为本卷新增深化点，赋分结构 3×2=6 不变。）

### （七）语言文字运用（17-21，20分）

**17. A**（核验：语境辨析）
- ①"配合"：各部分协同运作，与"首尾呼应"连用写三大工程协同关系最恰当；"搭配"侧重按目的排列组合，"联合"指独立个体的结合，"呼应"与前文"首尾呼应"重复。
- ②"顺应"：顺从并遵循其规律（中性偏褒），与"因势利导"衔接自然；"迎合"含贬义（曲意逢迎），"适应"的主语应是自身作出调整以适合环境的一方。
- ③"哺育"：喂养培育，常用于水土、文化滋养人民（"哺育着一代又一代的蜀地百姓"）；"养育"多指父母抚养子女，"喂养"多指给牲畜喂食，"培养"指训练造就人才，均不合语境。
