# 四川适用高考语文试卷处理协议 v0.1

> 适用范围：`Data/2008-2024·（四川）语文高考真题/` 的 2008—2024 主批次。
> 当前状态：2008 年校准切片及 2009—2024 全部结构化批次已生成并通过机器结构门禁；尚未通过人工复核门；不得据此直接生成教材—真题 M1/M2 映射。

## 1. 来源和分层

正式主批次为 17 个考试年度、每年一份空白卷和一份解析卷，共 34 个 PDF。2008—2015 为四川自主命题，2016—2020 为四川适用新课标Ⅲ卷，2021—2024 为全国甲卷（四川适用），不得写成“四川原卷”。当前文件均为 `unverified_local_provided`，在来源主体、原始下载地址和答案权威性核验前，不称“教育部/考试院官方原卷”。

处理角色严格分开：

- `question`：空白卷，承担原题主链；
- `analysis`：解析卷的题文副本，承担候选答案和解析锚点；
- `answer_scoring_candidate`：解析卷中“参考答案/试题解析”独立成 bundle，不能并入题干事实源；
- `advertisement`：资料推广、二维码和页眉/页脚推广块，隔离且不进入题目正文。

原始 PDF、MinerU `full.md`、`content_list_v2.json` 和版面文件只读保存。所有清洗结果另存，并保留 `clean → full.md → PDF` 双链。

## 2. 目录和稳定 ID

2008 校准切片位于：

`Data/2008-2024·（四川）语文高考真题/exam_extract/GK-SC-2008/`

每年使用稳定 `exam_id`（如 `GK-SC-2008`），每道编号题使用 `GK-SC-2008-Q001`；材料使用 `MAT-2008-SC-01` 等；答案/解析通过同一 `question_id` 配对。题型归并索引只放双链，不复制题目正文。

题目级记录至少包含：年份、卷别、角色、section/question/subquestion、题型 L1/L2、材料 ID、分值（可空）、原始 PDF、原始 MinerU、清洗 Markdown、PDF 0-based page index 与印刷页码、版块 ID/bbox、raw/clean 哈希、清洗状态、分割状态、题型置信度、复核状态、空白—解析关系。当前校准切片的版块 ID/bbox 是页面级粗定位，`source_locator_status=page_level_fallback`；未完成精确块仲裁前不得把它称为题级精确定位。

## 3. 清洗规则

1. 先按 `content_list_v2` 的 `page_idx` 建页账；`page_header/page_footer` 推广块按类型过滤，正式页眉（如“绝密★启封前”）列入白名单。
2. `full.md` 末尾的资料广告页单独标记 `advertisement` 并截离；不能把广告页当作试卷页。
3. 孤立页码/水印残片（如 `1`、`Z`、`N`、`V`、`Q`、`不X`）可从清洗副本移除，但每一处必须写入 `review/exceptions.jsonl`；不改原始文本。
4. `郑波/握得/仲足/苏武` 等 OCR 疑似错字只标 `[OCR疑似污染]` 或写入异常表，不能静默改正；回看 PDF 或空白—解析交叉核对后才可登记修订。
5. 清洗稿保留题干、材料、选项和图片链接的顺序；不因排版方便而删除原文。答案/解析不得进入空白卷清洗稿。

## 4. 题目分割和材料关系

先识别卷、七个大题和材料，再识别题号和小问；不能仅凭全文第一次出现的数字切题。材料独立成文件，题目以 `material_id` 和双链回指。

2008 校准结构：Q1—4 语言基础，Q5—7 论述类阅读，Q8—10 文言选择，Q11 翻译，Q12 元散曲，Q13 名篇名句，Q14—17 现代文阅读，Q18—20 语言表达，Q21 作文。编号题 21 道，作答单元约 24 个，Q13 有 1 个任选组；这三个口径必须分别登记。

受控题型初版：

| L1 | L2 示例 |
|---|---|
| `language_use` | `word_pronunciation`、`idiom_usage`、`sentence_error`、`sequence`、`summary`、`completion`、`metaphor_series` |
| `objective_choice` | `modern_reading_informational`、`ancient_vocab`、`ancient_text_evidence`、`ancient_text_content` |
| `reading_subjective` | `classical_translation`、`poetry_appreciation`、`literary_reading`、`meaning_explanation`、`structure_effect` |
| `memorization` | `classical_memorization` |
| `writing` | `topic_writing` |

无法稳定判断时使用 `uncertain`，不强行归类；自动归类置信度低于 0.90 或跨类型时必须人工复核。

## 5. 空白—解析配对

空白卷题文是 canonical 主体；解析卷只通过稳定题号挂接。答案/解析单独写入 `answers/answer_bundle.md`，并用 `answers/answer_index.jsonl` 逐题登记 `GK-…-Qxxx`、答案片段、解析片段和来源状态，标注 `source_status=unverified_local_provided`。客观题若源 bundle 只有选项答案，`analysis_text=null` 必须同时写 `analysis_status=not_present_in_source_bundle`，不视为缺失。若某小问没有可核验答案或评分材料，填 `N/A` 并说明原因，不把第三方解析升级为官方答案或评分标准。

## 6. 验收标准（G0—G4）

### G0 来源完整性

- manifest 记录与主批次 PDF、MinerU `full.md` 100% 一一对应；PDF 页数一致；源 PDF SHA-256 不变；
- 额外文件显式登记：2017 `(1)`（9 页、疑似不完整）与 2018 `(1)`（重复副本）不得无标记混入主批次。

### G1 清洗完整性

- 清洗稿与原始 `full.md` 均可双链打开；原始文件未改写；
- 2008 校准集广告触发词在清洗正文中为 0，残留水印为 0；广告隔离准确率 100%；
- 每个删除/规范化动作有 `exceptions.jsonl` 记录；OCR 疑似错字 100% 进入人工复核队列。

### G2 分割和回溯

- 2008 编号题集合恰为 Q001—Q021，重复 0、漏题 0；后续年份按实际卷面题号登记，不预设固定题量；
- 每题有题干、题型、材料关系、PDF 页码和至少一个版块 ID/bbox；2008 抽检覆盖率 100%；
- 每题可沿 `segment → clean_md → full.md → PDF` 双链回溯，空白—解析配对率 100%。
- 解析卷 `answer_index.jsonl` 对 Q001—Q021 一题一行；答案/解析不能只停留在整卷 bundle。

### G3 题型归并

- L1/L2 覆盖率 100%；低置信度项均显式 `uncertain` 并进入复核；
- `work/knowledge/exams/views/by_type/` 只保存索引双链，不能产生正文副本漂移；同一 canonical 题目不得出现在两个互斥 L2 中，除非登记多标签理由。

### G4 研究可用性

- 题目、材料、答案/解析、广告四类边界无混淆；
- 通过双人独立复核后，2008 试点才可扩展 2009—2024；
- 在 `SG-EXAM-CAL` 通过前，所有教材—真题关系保持 `N/A | M0 | N/A`，不把题型相似性写成直接衔接。

教材上游绑定：试卷校准包必须记录 `TEXTBOOK-LOCK-2.0-textbook`、教材 deliverables SHA、validator run/SHA、rubric SHA 和 taxonomy SHA；锁定快照变化时，校准包回到 `review_required`。

## 7. 执行顺序

1. 先完成来源/页账清点和 2008 双角色抽检；
2. 运行 `scripts/split_sichuan_gaokao.py --year 2008`，人工核验异常、材料边界、答案分层和双链；
3. 通过 G0—G3 后冻结 exam schema、taxonomy、rubric 和 review package；
4. 已完成 2009—2024 结构化批次；年份题数配置、缺失题号占位规则与验证入口见 `scripts/split_sichuan_gaokao.py`、`scripts/validate_sichuan_gaokao_batch.py` 和 `exam_expectations_2009_2015.json`；
5. 待完成双人 PDF/OCR 抽检、答案来源核验与逐小问—教材 KP 双向证据映射。
