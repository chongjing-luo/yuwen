# PAPER-JS-2019 第13题（二、名著阅读题（15分））

【题目】
13.（5分）下列对有关名著的说明，不正确的两项是（）A.《三国演义》中，张飞在长坂桥上睁圆环眼厉声大喝，吓退曹兵，然后迅速拆断桥梁，  
以阻追兵，可见张飞十分勇猛，又很有智谋。B.《家》中，许倩如倡导女子剪发，带头剪掉自己的辫子，还以梅的遭遇来激发琴拒绝  
包办婚姻，鼓励琴做一个跟着时代走的新女性。C.《狂人日记》中，狂人说将来的社会“容不得吃人的人”，最后喊出“救救孩子”，作  
者借此表达了对社会变革的强烈渴望。D. 《欧也妮·葛朗台》中，夏尔在父亲破产自杀后，不愿拖累心上人安奈特而写了分手信  
给她，这一良善之举让偷看信件的欧也妮发誓要永远爱他。E. 《老人与海》中，圣地亚哥经过生死搏斗最终将大马林鱼残骸拖回港口，有游客把它  
当成了鲨鱼骨，这一误会让小说结尾更加意味深长。
