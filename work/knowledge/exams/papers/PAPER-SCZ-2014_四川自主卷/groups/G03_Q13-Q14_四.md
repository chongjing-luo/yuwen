# PAPER-SCZ-2014 第13-14题组（四）

【材料】
秋暮吟望

赵执信

小阁高栖老一枝[润]，闲吟了不为秋悲。  
寒山常带斜阳色，新月偏明落叶时。  
烟水极天鸿有影，霜风卷地菊无姿。  
二更短烛三升酒，北斗低横未拟窥。

[注]“一枝”语出《庄子·逍遥游》》：“鷦鷯巢於深林，不过一枝。”“老一枝”意为终老山林。
