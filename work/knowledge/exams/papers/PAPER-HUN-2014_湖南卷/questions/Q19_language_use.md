# PAPER-HUN-2014 第19题（选作题）

【材料】
一次，妈妈忽见杨必一脸狼狈相，鼻子上抹着一道黑，问她怎么了，她装作若无其事的。只说：“我囫囵着跌下来的。”“囫囵着跌下来”，用语是幼稚的创造，思想却很明显，就是整个人从楼上滚下来了。问她跌下多远，滚下多少级楼梯，她也说不清。她那时才两岁多，还不大会说，也许当时惊魂未定，自己也不知道滚了多远。

她是个乖孩子，只两件事不乖：一是不肯洗脸，二是不肯睡觉。

每当佣人端上热腾腾的洗脸水，她便觉不妙，先还慢悠悠地轻声说：“逃——逃——逃—”等妈妈拧了一把热毛巾，她两脚急促地逃跑，一迭连声喊：“逃逃逃逃逃！”总被妈妈一把捉住，她哭着洗了脸。

(节选自杨绛《记杨必》)
