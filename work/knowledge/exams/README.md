# 高考资料唯一入口

本目录统一保存高考试卷实体、派生视图、研究报告和加工过程件。分层的目的不是按文件名好看地分类，而是让使用者先知道一份材料“能否当事实、能否重建、能否作为结论引用”（K1/J7）。

| 目录 | 性质 | 使用规则 |
|---|---|---|
| `papers/` | 唯一试卷实体真相源 | 每卷的原件、清洗件、题目、卷内题组、答案候选和账本均在卷目录内；不得复制到其他层 |
| `views/by_type/` | 全库题型派生视图 | 由 `scripts/split_paper_questions.py --all` 重建；只作检索入口，不手编，不视为第二套题库 |
| `research/` | 研究报告 | 必须读取frontmatter；只有状态与来源等级允许时才能作为定论，`drafted/candidate_only`须连同边界引用 |
| `workbench/` | 加工过程件 | 保存垂直切片、KP批次、候选答案、复核队列和草稿；不得绕过评审直接当研究结论 |
| `_meta/` | 协议与治理元数据 | 保存处理协议、映射、校准回执、状态与期望清单 |

## 固定规则

1. 一道题的正文只能以 `papers/PAPER-*/questions/` 中的文件为规范实体；题型页只存索引信息。
2. 研究必须通过稳定题号或路径回指 `papers/`；过程件晋升为研究报告时移入 `research/`、补全状态与证据边界，原过程件不复制正文。
3. `work/knowledge/assessment/` 是命题与组卷资产，不是来源真题库，保持独立。
4. 所有路径变更同步更新 `docs/architecture/ID解析表.md`、账本、脚本和根目录 `AGENTS.md`，并运行存放契约、catalog与知识账本校验。

原始四川资料入口仍为 `Data/2008-2024·（四川）语文高考真题/`；进入知识层后的规范实体统一使用本目录。
