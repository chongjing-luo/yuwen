# 知识点卡：必修上册 U1 L03 百合花 / 哦，香雪

## 基本信息
- 册次：必修上册
- 单元：第一单元（青春的价值）
- 课文：《百合花》茹志鹃 / 《哦，香雪》铁凝（两篇小说合编）
- 作者/出处：茹志鹃，1958年；铁凝，1982年
- 文本类型：现代短篇小说
- 教读/自读：教读

## 人文维度
- 单元人文主题：青春的价值
- 母题：战火中的纯真 / 山村少女对文明的渴望
  - **《百合花》**：战争年代的青春美与人性美——在残酷战争中发现纯真与温情
    - 文本依据①：通讯员枪筒里"插了几根树枝""又多了一枝野菊花"——细节中的天真
    - 文本依据②：新媳妇将自己唯一的嫁妆（百合花被子）盖在牺牲的通讯员身上——从"不肯借"到"主动献"的情感转变
    - 文本依据③："这是象征纯洁与感情的花，盖上了这位平常的、拖毛竹的青年人的脸"——点题
  - **《哦，香雪》**：封闭山村被现代文明唤醒——一个少女为了一个铅笔盒走三十里夜路
    - 文本依据①：香雪用四十个鸡蛋换铅笔盒，明知可能被骂——渴望知识与尊严
    - 文本依据②："她第一次意识到这是不光彩的，因为贫穷，同学们才敢一遍又一遍地盘问她"——贫穷带来的羞耻感
    - 文本依据③："古老的群山终于被感动得战栗了"——青春的脚步唤醒了沉睡的大山
- 文化主题：
  - 《百合花》：革命文化——解放战争背景下的军民关系、革命战争中的人性光辉
  - 《哦，香雪》：改革开放初期（1980年代初）的社会主义先进文化——山村对现代文明/教育/尊严的向往
- 育人指向：
  - 《百合花》：感受革命年代特有的崇高情操、人性在战争中的美丽
  - 《哦，香雪》：理解教育公平、城乡差异、个人追求尊严的权利

## 语言维度
- 文体知识：现代短篇小说
  - **诗化小说**：两篇都不以情节曲折见长，而以氛围营造和细节描写取胜
  - **第一人称叙事**（《百合花》用"我"的视角）：限知视角，增强真实感和抒情性
  - **全知视角中的聚焦**（《哦，香雪》）：聚焦香雪的心理，外部世界通过她的眼睛被呈现
- 语言知识（本课特有）：
  - **《百合花》——细节描写技术**：
    - 反复出现的物象：枪筒里的树枝/野菊花（天真）、衣服上挂下的布片（命运的伏笔）、两个干硬的馒头（最后的告别）、百合花被子（核心象征）
    - 人物刻画：通讯员的害羞（"飞红了脸""讷讷半晌"）vs 英勇（扑在手榴弹上）；新媳妇从"咬着嘴唇笑"到"庄严而虔诚地缝"
    - 侧面烘托：通讯员的牺牲不直接写战斗场面，而是通过担架员的转述
  - **《哦，香雪》——心理描写技术**：
    - 排比与感叹："大山原来是这样的！月亮原来是这样的！核桃树原来是这样的！"——顿悟式的内心独白
    - 对比手法：火车一分钟 vs 山村几千年的沉寂；铅笔盒的"嗒嗒"声 vs 小木盒的沉默
    - 象征意象：火车（现代文明）、铅笔盒（知识/尊严/平等）、隧道（恐惧与跨越）、月光（觉醒后的澄明）
    - 叙事节奏：从缓慢到加速——结尾香雪走夜路的心理变化推动情节加速
- 读写方法：
  - 细节品析法：找反复出现的物象，分析其叙事功能和情感功能
  - 联系时代背景法：《百合花》联系1946年解放战争，《哦，香雪》联系1980年代初改革开放
  - 心理分析阅读法：追踪人物心理变化的弧线（如新媳妇从"笑"到"缝"到"献被"）
  - 诗化小说鉴赏法：注意"散文式的"笔调——淡化情节，强化氛围和情感
- 学习任务群：文学阅读与写作
- 文言积累：鹿寨（zhài，军事障碍物）/讷讷（nè nè，说话迟钝）/讪讪（shàn shàn，难为情的样子）

## 高考映射
- 必备知识：茹志鹃《百合花》的文学史地位（诗化小说/战争文学的人性化书写）；铁凝《哦，香雪》的时代背景（改革开放初期）；细节描写/心理描写/侧面描写的概念
- 关键能力：
  - **细节分析能力**——识别反复出现的物象并分析其功能（百合花被/枪筒里的野菊花/干硬的馒头）
  - **人物心理弧线分析**——追踪新媳妇从"笑"到"缝"到"献"的情感变化
  - **叙事视角分析**——第一人称限知视角的效果（《百合花》中"我"不知道通讯员后来怎样了，读者和"我"一起发现）
  - **象征手法辨识**——百合花被（纯洁/牺牲）、铅笔盒（知识/尊严）、火车（现代文明）
- 学科素养：
  - 语言建构与运用：细节描写语言的精准性分析
  - 审美鉴赏与创造：诗化小说的审美特征（淡化情节/强化氛围/情感克制）
  - 思维发展与提升：从文本细节到时代背景的推理
  - 文化传承与理解：革命文化的人性维度、改革开放的时代精神
- 核心价值：人性美与崇高情操、对知识和平等的追求、山村少女的尊严觉醒
- 直接衔接题型：
  - 文学类文本阅读Ⅱ（小说阅读：人物形象分析/叙事手法/细节描写/主旨理解/标题含义）
  - 语言文字运用（词语理解/表达效果分析）

## 纵向贯通
- 初中关联：初中阶段读过《荷花淀》（孙犁）——同为革命文学中"诗化战争"的传统，本课深化了对战争与人性的思考。初中读过鲁迅小说——建立了小说三要素的基本认知，本课在此基础上进入"诗化小说"的审美层次。
- 必修关联：本课是第一单元的小说部分，与同单元诗歌形成"抒情方式"的文体对照——诗歌用意象抒情，小说用细节和氛围抒情。必修下册将继续出现小说（《祝福》《林教头风雪山神庙》等），叙事手法分析将深化。
- 本册定位：第一单元最后一课，也是高中阶段第一组小说文本。建立了"诗化小说"的审美范式，为后续小说学习（必修下第六单元古典小说、选必中的现当代小说研习）奠定基础。
