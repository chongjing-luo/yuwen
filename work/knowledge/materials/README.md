# 素材库（L1 策展件 · MAT-*）

写作素材、情境素材、跨课文比较素材的策展之家。每条素材一个文件：`MAT-<主题>-<序号>_<人类可读名>.md`。

## 条目规格（五件套 + 素材特有字段）

```yaml
id: MAT-诗经-001
type: material
title: 《诗经》婚恋诗对照素材
authority: S1-S4           # 教材原文=S1；教辅/他人PPT=S4（可直接使用——所有者裁决；来源登记不豁免）
status: drafted|accepted
source: [SRC-PKG-X3-001]   # 血缘或来源存根
relations: [CARD-X3-U01-01, CARD-B1-REC-01]
summary: 一句话——这是什么素材、适用什么作文题/教学情境
updated: 2026-08-15
```

正文：素材内容 + 适用情境（哪类题/哪篇课文延伸）+ 使用注意（解释分层：素材事实 vs 引申）。

## 规则

1. 教辅与他人 PPT 内容**可直接采用**为素材（所有者裁决 2026-08-15），但来源登记不豁免；作为"知识断言"引用时仍按其权威等级处理；
2. 入册即登记 catalog（`work/knowledge/_meta/`）；
3. 同一素材多用途走 tags 索引，不复制文件（§3.2）。
