# U03/U04 新 SHA 独立主审准备矩阵

- 编制者：`book_x2_audit`
- 适用对象：`CARD-X1-U03-01—04`、`CARD-X1-U04-01` 的后续返修版
- 依据：`2.0-textbook` 冻结契约；研究计划 §6.1—§6.16；`rubrics.json`；`taxonomy.yaml`
- 权限边界：本矩阵只指导独立内容主审；评审者不修改卡片、ledger、transition 或 DG4 receipt。
- 版本原则：旧报告只保留历史缺陷，不向新版本滚存分数、R/P 或结论；每个新 version/SHA 必须从零完整重审。

## 1. 领取门与停止条件

| 检查 | 进入条件 | 失败动作 |
|---|---|---|
| 新版本 | version 已升版且内容 SHA 不等于本轮已退回的旧 SHA | 不领取，不对旧 SHA 重复出报告 |
| 账本同步 | card front matter 与 `deliverables.jsonl` 的 ID、路径、version、status、source_ids 一致；status=`linted` | 停在 DG0/DG1，回报漂移 |
| 绑定快照 | 锁定 card version/SHA、ledger SHA、rubric SHA、taxonomy SHA、canonical Artifact SHA、validator run/report SHA | 任一未锁不启动语义主审 |
| 独立性 | 未读取同 SHA 另一审的正文、分数、R/P 或结论 | 若独立性被破坏，更换评审者 |
| 上游与来源 | Source—Artifact 注册可解析，canonical 唯一且 hash 一致 | 停止内容评分，记 R07/R08 或 blocker |

基础 validator `passed` 只证明已实现的机械检查通过，不关闭 Markdown 表义、Claim、quote span、locator、来源适配、枚举、M0/N/A 或教学提示分层问题。

## 2. 固定执行顺序

### Task 1：锁定新版本快照

**验收标准：**

- [ ] 新 version 与新 file SHA 均已记录，且不同于退回旧 SHA。
- [ ] ledger 与 front matter 六项一致：ID、路径、version、status、owner、source_ids。
- [ ] rubric、taxonomy、canonical Artifact、validator run/report 均有 SHA。

**复核：** `sha256sum`、ledger 精确检索、validator 全库运行。

**依赖：** 生产者发布新 SHA。

### Task 2：结构与受控枚举 semantic lint

**验收标准：**

- [ ] 10 个必填模块、正确特殊内容模板、子文本边界齐全。
- [ ] KP 类型、主层级、置信状态，EV 类型/关系/核验状态全部属于冻结枚举。
- [ ] M0 使用结构化 N/A；所有 N/A 有允许的 `na_kind`、理由与边界；不存在范围串冒充稳定 ID。

**复核：** 逐表列数、ID 唯一性/可解析性、枚举对照 `taxonomy.yaml`。

**依赖：** Task 1。

### Task 3：canonical 逐页目视与 Q 分段核验

**验收标准：**

- [ ] 每个 canonical PDF 按声明范围全部渲染目视，OCR/`full.md` 只作导航。
- [ ] 一条 Q 含多段引文时拆成多个 quote span；每段逐字、逐标点匹配。
- [ ] 每段同时验证规范物理页、印刷页/栏目、切分页；页范围不得掩盖越界片段。

**复核：** 保存目视范围、Artifact SHA、异常 EV/quote span ID；适用 Q 准确率与 locator 有效率均为 `分子/分母=100%`。

**依赖：** Task 2。

### Task 4：冻结并全审 Claim 分母

每条正式最小命题使用以下行级矩阵；复合单元格先拆命题，不能只检查“正文大意正确”。

| claim_id/field_path | 类型 | 最小命题 | 绑定 EV | 目标可解析 | 来源适配 | exact span 完整 | locator 有效 | I 独立双证 | 判定/缺陷 |
|---|---|---|---|---|---|---|---|---|---|
| 待新 SHA 冻结 | Q/F/I/M/R/E/D | 待拆分 | 待核 | 是/否 | 是/否 | 是/否 | 是/否 | 是/否/N/A | pass / R/P |

**验收标准：**

- [ ] §1—§9 所有非 N/A 正式命题均进分母；自检、问题清单、版本记录不进分母。
- [ ] Claim→适配 Source→canonical Artifact→exact span→locator→target 全链闭合。
- [ ] I 类至少两处承担不同推理前提的独立文本依据；同段、OCR/PDF 同内容不重复计数。
- [ ] 正式主张覆盖率、目标绑定率、来源适配率、合法 N/A 率、ID/路径解析率均为 100%。

**依赖：** Task 3。

### Checkpoint A：A 层硬门

- [ ] 先逐项判 R01—R10，再判断 P0/P1/P2。
- [ ] 任一 R 为“是”：总分固定 `N/A`，决定 `fail/rework`；诊断观察不得包装成正式得分。
- [ ] R 全否后才进入七维计分；任何 accepted 前 P0/P1/P2 必须为 `0/0/0`。

### Task 5：七维观察项复算

| 维度 | 权重 | 最低分 | 固定检查点 |
|---|---:|---:|---|
| 证据链与可追溯性 | 25 | 21 | 正式主张覆盖5；定位可解析5；引文与 canonical 一致5；来源适配5；证据元数据5 |
| 事实与术语准确性 | 20 | 18 | 书目信息5；课标术语5；事实/解释边界5；内外一致5 |
| 字段完整与知识粒度 | 15 | 12 | 必填字段5；合编/子文本覆盖5；原子化与文本特异性5 |
| 双维度与母题质量 | 15 | 12 | 人文5；语言与三类活动5；母题两证据及学生关怀5 |
| 四层与高考映射 | 10 | 8 | 主层级及理由4；官方定义2；M0—M3及证据3；不确定性1 |
| 纵向贯通 | 8 | 6 | 目标册次2；关系类型2；递进说明2；双方证据2 |
| 教学可用性与表达 | 7 | 5 | 三类提示分离2；核心素养/QD依据2；可操作性2；边界/N/A1 |

计算只用冻结观察项：`checkpoint_weight × pass/applicable`，各维 `ROUND_HALF_UP` 到 0.5，总分不二次取整。知识卡须总分≥85且每维过线；合法 N/A 切换等值治理观察项，不删除维度。

**依赖：** Checkpoint A 中 R01—R10 全否。

### Task 6：封存与回报

**验收标准：**

- [ ] 报告记录对象 version/SHA、全部绑定 SHA、目视范围、R01—R10、七维或 N/A、P0/P1/P2、validator 和决定。
- [ ] 报告只绑定一个内容 SHA；内容一旦再改，旧报告立即失效。
- [ ] 封存后立即回报报告路径/SHA、对象 SHA、validator run/report SHA、评分、R/P、结论。
- [ ] 不自行写回 ledger/transition；DG4 由协调者串行完成。

**依赖：** Task 4；R 全否时另依赖 Task 5。

## 3. R01—R10 判定矩阵

| 代码 | 必检问题 | 最小失败证据 |
|---|---|---|
| R01 | 作者、篇名、册次、年代、题号等关键事实与 canonical 一致吗？ | 错误字段 + canonical 页/行 |
| R02 | 每段 Q 可定位吗？每条正式 Claim 有适配来源吗？每条 I 有独立双证吗？ | EV/quote span/claim ID + 缺口或错页 |
| R03 | 合编子文本、必填模块、特殊内容模板完整吗？ | 漏项 ID/字段路径 |
| R04 | 研究解释、教材提示、教师用书、网络/OCR 层级分开吗？ | 冒充文本 + 实际来源层级 |
| R05 | 每个 KP 均有主层级、理由和真正支持完整命题的有效证据吗？ | KP-ID + 无效/错绑 EV |
| R06 | 非 M1 是否被称作“直接衔接”？是否使用未登记真题？ | 映射行/真题 ID |
| R07 | 下游是否只消费 accepted 且 hash 匹配的上游？ | 上游 ID/status/SHA |
| R08 | 数量、ID、version、路径、链接是否造成断链？ | 冲突两端与 SHA |
| R09 | 是否使用现行课标、任务群规范名称，且不把任务群固定化为课型/教法？ | 错误术语与规范页 |
| R10 | 核心素养是否有语言实践依据？是否误判单卡完整 QD 水平？ | 字段路径与缺失/越界判断 |

## 4. U03/U04 新版回归探针

以下只用于确保旧缺陷不会逃逸，不构成对新 SHA 的预判；新版仍须按 §2 全量从零检查。

### U03 小说卡

- §1—§3 的复合 Claim 是否逐项闭合到 exact span，尤其人物、结构、心理、环境、细节与结尾链。
- §4 课标/核心素养 Claim 是否有正式 EV、官方定义和本课语言实践依据。
- 每个 KP 的证据是否适配自身命题，避免把“人物任务”绑给环境 KP、把“环境任务”绑给内心独白 KP。
- §8.1 是否只写教材真实学习提示并回链；自拟表格/讨论程序只在 §8.3。
- KP 类型、EV verification status、M0 N/A 是否全部使用冻结枚举/结构。

### U04 逻辑专题卡

- 重新逐段检查 EV-002、EV-004、EV-005 的页位边界，不假定旧 locator 已修好。
- “文学语言表面违背逻辑”KP 必须绑定该教材段落，不能绑定袁滋/《十五贯》的推理案例。
- 内容边界若包含任务1—3、辩论和驳论文，须显式绑定承载这些任务的 EV。
- “虚拟论敌”、概念界定、攻防和限定结论的 Claim 不得只回链间接论证证据。
- canonical 专题是“学习活动/任务”；§8.1 若使用“教材学习提示”栏目，只能忠实摘要并回链，不能写自拟五列表或教学顺序。
- 核心素养、EV status、M0 N/A 与每个 KP 的有效证据继续全量检查。

## 5. 最终放行标准

单件只有同时满足以下条件，主审才可写 `pass`：

1. R01—R10 全否；P0/P1/P2=`0/0/0`。
2. 所有适用证据硬指标、引用解析率和来源适配率均为 100%，并报告分子/分母；`0/0` 写 `N/A + reason`。
3. 七维均达到最低分且总分≥85。
4. 版本/SHA/validator/量表/来源绑定完整，报告可由第三人复算。
5. 第二复审独立封存且同绑定后，双方结论一致、总分差≤5、单维差≤2；否则进入仲裁。
6. `pass` 只闭合 DG3；协调者完成 DG4、账本为 `accepted` 且 receipt 完整后，才可计进度和供下游消费。

## 6. 风险与处置

| 风险 | 影响 | 处置 |
|---|---|---|
| 生产者只改已报错行，遗漏同类 Claim | P0 再现 | 新 SHA 全量重建分母，不做差异抽审 |
| 宽页范围掩盖某段引文越界 | R02 逃逸 | Q 按 quote span 拆分并分别记录实际页 |
| validator passed 被误当内容通过 | DG2 假闭合 | 强制 semantic lint 与 canonical 目视矩阵 |
| 两审相互看到结论 | 一致性指标失真 | 原始报告封存前互不可见；只由协调者汇总 |
| 评审过程中内容再改 | 评审绑定失效 | 立刻停止，重新锁新 SHA，从 Task 1 开始 |
