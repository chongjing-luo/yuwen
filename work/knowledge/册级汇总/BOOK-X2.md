## 4. 册级语言主线与任务群分布

| 单元 | 文体/语言现象 | 任务群与共同能力动作 |
|---|---|---|
| U01 | 理论文章的概念界定、事实/例证、立论驳论、辩证限定、类比设问和跨文本比较。 | 科学与文化论著研习；`背景/问题 → 概念 → 主张 → 证据 → 异议 → 限定 → 修订`。读后感、事实论证、辩论和800字文章均要求来源可核验。 |
| U02 | 纪念性散文的反复、反讽、排比和抒情；报告文学的事实—文学双线；小说的方言、物象、场景、细节和人物—环境关系。 | 中国现当代作家作品研习；`历史语境 → 人物事实 → 形式/情感 → 价值判断 → 记忆与行动`。批注、札记、人物分析和红色作品集保留分工与修订。 |
| U03 | 史传剪裁、叙议结合、典型语言、人物对比；史论铺陈、反差和因果论断；实词、特殊句式、名词作状语和翻译。 | 中华传统文化经典研习；`原句/史实 → 句法或叙事形式 → 人物/论点功能 → 译释或质疑`。年表、史传短评、史论辩驳和背诵记录不能越出正文边界。 |
| U04 | 戏剧对白、信件、物件、舞台动作和态度突转；诗歌意象、呼告、象征、分节、押韵、自由节奏；申论的材料归纳、问题—对策论证。 | 外国作家作品研习；`事件/材料 → 语言/形式 → 冲突或情绪 → 主题/问题 → 受众化表达`。朗读、诗体改写、结局设想和申论分别保留创作边界。 |

全册语言主线是：**准确定位材料 → 识别形式/结构 → 复原解释或论证链 → 面向受众表达 → 依据反馈修订**。它是 accepted KP、EV 和任务成果的索引，不是新增 KP。
