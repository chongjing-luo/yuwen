# PPT 制作操作手册（三层方法论 · 裁决版）

## 一、四源分工

| 来源 | 贡献 | 使用方式 |
|---|---|---|
| 通用版方法论 | 认知科学底线（Mayer 12 / Sweller / CRAP / 格式塔 / Alley / Tufte）与数值参数 | 底线，任何场景不得违反 |
| 语文版方法论 | 页面功能四分法（文本/任务/资源/反馈）、课型差异、批注与任务页规范 | 学科约束，覆盖通用版的美学自由度 |
| 项目实践层（视觉规范 + V6.6 构建器 + 审查判例） | 最严格可执行标准：首答态保护、以静代动、B0/B1/B2 三态、字号下限、设计系统 | **优先级最高**——教学场景判例 > 通用数值 |
| 外部 skill（pptx / nature-paper2ppt） | pptxgenjs 工程细节、渲染 QA 环、证据布局学（hero 主导 + 窄解释栏 + 非对称分栏） | 工程与质检层 |

冲突时裁决顺序：**项目实践层 > 语文版 > 通用版 > 外部 skill**。

## 二、字号与可读性（统一裁决线）

通用版 L3 正文 18-22pt 面向会议室投影；教室后排距离更远，判例反复出现的修复线更高（chapter2_visual_v8：核心释义 22pt 起步）。**语文课堂统一取项目线**：

| 元素 | 下限 | 依据 |
|---|---|---|
| 原文诗句（核心文本） | **28pt**（≤2 行 39pt / ≤4 行 32pt） | 视觉规范 + v66 poem() 实测 |
| 短语卡/随机散卡 | **26pt** | ART_RANDOM_FONT_SIZE 判例 |
| 产物槽标题/文化释义 | **22pt** | chapter2_visual_v8 修复标准 |
| 页标题 | 36pt（>20 字降 31pt），标题:正文层级差 ≥1.4× | v66 + CRAP |
| 标签/页码/模块名 | 14.5-15.5pt（非内容性） | v66 base() |

规则：**字号是内容的函数不是剩余空间的函数**——核心文本（学生必须读的原文、要生成的产物）永远拿最高档；指令、流程、注释降档。指令字号压过产物字号 = P2（判例 N022）。

## 三、色彩系统（起点 → 课文派生）

1. 起点从通用版五套气质预设选（墨水经典/靛蓝瓷/森林墨/牛皮纸/极简白，《氓》系 = 牛皮纸细化）；一页 ≤3 色，语义全程一致（色彩即批注维度：蓝=语言、绿=结构、红=情感、紫/金=文化）。
2. 派生课文级 24 色板：中性 6 + 暖调 6 + 章节循环 4 对（深+浅底）+ 深色页 2（night 28231F / 383129）——结构照抄 v66 C 模式，色值按课文气质替换。
3. 深浅节奏：深色页（single_dark_verse / ending_boundary / final_reading 等）与浅色页交替 = 全课节奏的视觉面（J5）；深底必须深字是灾难，深底配 white/gold2。
4. 60-30-10 支配律（外部 skill）：底色 60-70% 视觉重量、章节色/暖调 30%、强调色 10% 一处最重。

## 四、版式与布局

1. **断言式标题的裁决（N-04）**：Alley 断言-证据式标题（完整判断句）与"标题与首眼泄答测试"（A-T13）在首答态冲突——**后置完成态/讲解页可用断言式标题；首答态页面标题只命名文学对象或留开放问题**（"我们把这句读清楚"，不是"桑叶暗示婚姻变化"）。
2. 非对称分栏（nature skill）：拒绝默认 50/50；证据主导 70/30、75/25；图随内容走，几何服务证据——语文课"证据"= 原文与学生作品，原文卡与现场作品永远占主导，解释栏收窄。
3. 视觉 motif 唯一且全程重复：v66 = 左缘 0.15" 章节色条 + 左上模块名 + 右上页码；禁止标题下划线（AI 生成物标志，外部 skill 铁律）。
4. 版式多样性（J5）：≥3-4 种版式骨架交替；连续三页底层协议同构判 P2（A-T17）；正文文字左对齐，仅标题与诗行可居中。
5. 版式即泄答渠道（P-42）：首答态材料等大同色随机散放，不用行群/两栏/视觉重心暗示答案；版式替学生完成任务至少 P1。
6. 留白即意境（语文版）：任务页只放问题不放答案；一页原文 ≤200 字，超出用省略号+页脚定位；信息要点 ≤7。

## 五、语文课页面类型速查

页面功能四分（语文版）：**文本页**（原文展示行距 1.6-1.8 / 注释左右对应 / 翻译对照）/ **任务页**（时间+形式+分步+评价标准+成果证据+反馈修订六要素）/ **资源页**（文化语境锚点，插图过准入五问）/ **反馈页**（学生作品为主视觉）。课型差异：古诗文 7 页型、现代文批注式、作文 Before-After、复习课检索式（放问题不放答案）。AI 生成内容必须标注工具与用途，不得作文本原貌证据。

## 六、构建工程规范（pptxgenjs）

画布 13.333×7.5"（LAYOUT_WIDE 自定义）；字体 Noto Serif CJK SC（标题/诗行）+ Noto Sans CJK SC（正文）；多行文本逐项 `breakLine: true`，不用手写 •；对齐时 `margin: 0`；圆角矩形才可用 rectRadius 且不叠矩形贴片；阴影 offset ≥0；色值 6 位无 #；渐变不支持（用背景图）；charSpacing 做字距。**每页恰好 1 条备注 = 该物理状态的逐字稿**（物理画面是剧本最小单位，P-40）；构建器内置 validate：页数==合同 target、备注数一致、对象不越画布（±0.01）。

## 七、QA 渲染环（首渲染必有缺陷）

pptx skill 的 QA 纪律与项目双审一致并补足工程面：

1. 生成 → soffice 转 PDF → pdftoppm 逐页 PNG；
2. **新鲜眼检查**（非作者视角）：子代理按清单找问题——重叠/溢出/裁切、低对比、间距 <0.3"、边距 <0.5"、版式错配、占位残留、**字号低于 §二 下限**、首答态泄答（版式/标题/箭头/配色暗示）；
3. 一轮零发现 = 检查力度不够，重查（P-29）；
4. 修复后**复验受影响页**（一修常引一新问题）；
5. 全部缺陷入审查 JSON（页面/证据/严重度/可执行修复），进入 S5 双审。

## 八、跨课文复用（主题抽取）

v66 的色板/字号/版式函数硬编码在单课构建器中——新课文从本手册 §二§三 直接取参数表，把 MODULE 章节色映射与 render_mode 按课文重新声明；通用主题库（theme.json：色板+字号下限+motif 参数）在第二课文切片（沁园春·长沙）时抽取定型，属登记待办。

## 九、不做的事（空白点裁决）

- **PPTX 原生动画**：不使用。项目"以静代动"——稍后出现的信息拆成独立物理画面（B0 首答 / B1 中间 / B2 校准），可审查、可审计、防抢答（P-34/P-40）；动画至多 fade 且仅引导注意力。
- **图表可视化**：Tufte 规则备用（通用版第十章），语文判例暂无图表页；结构分析优先 drawio 流程图转图。
- **教师手工改页保底**：轻量规范未立（登记待办）——手工改动破坏同源性（P-11），短期以"改数据源重新生成"为唯一路径。
