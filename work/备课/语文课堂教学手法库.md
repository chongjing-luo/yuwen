# 语文课堂教学手法库

## 一、选法原则

先诊断学生为何读不进去，再选手法。手法的价值不在名称新颖，而在能否让学生以不同方式接触文本、形成自己的材料、听见他人并返回原文修订。每次使用都要登记：对应原句、具体困难、学生动作、可见产物、反馈边界和后用位置。

## 二、按学习困难选手法

| 学习困难 | 可选手法 | 学生真正经历 | 可见产物/检验 |
|---|---|---|---|
| 记不起相关作品 | 静默检索、篇目目录阶梯、作品接龙、主题卡墙 | 从个人记忆出发，听见全班更广的文学谱系 | 个人清单、带作者来源的卡墙；教师不预填主题 |
| 进入不了整体声音 | 教师连续听读、节拍跟读、分部和声、停顿句捕捉 | 先让作品整体发生，再保存个人停顿 | 停顿句、问号、节奏标记 |
| 字音词义阻断 | 先猜后查、注释接力、词义替换、误译诊所 | 先形成自己的自然话，再用有限释义校准 | 有修改痕迹的口译；不把完整译文提前投影 |
| 句法关系模糊 | 分句剪条、主谓宾复位、对称句对读、虚词开关 | 操作句子结构，看见词序和虚词怎样改变意义 | 复位句、两栏对读、删换对比 |
| 人物行动混乱 | 动作着色、主体追踪、事件阶梯、撤答复述 | 追问“谁做了什么”，再离开屏幕重建 | 行动链、第一人称旁白 |
| 空间距离无感 | 路线描画、站位图、视线线条、身体走位 | 把“送、涉、至、乘、望”变成可感距离 | 有原词标注的路线或站位图 |
| 时间过程被压平 | 时间绳、日历折叠、一天还原、前后状态叠片 | 体验诗歌怎样压缩等待与多年生活 | 时间轴、日常片段、前后对照 |
| 对照/反复只会报术语 | 遮词辨别、并排对读、替换实验、声纹比较 | 先感到形式造成的差别，再命名手法 | 原词对齐、替换后的意义损失、朗读差异 |
| 情绪被标签化 | 双速度朗读谱、闭眼听辨、角色语气选择、沉默长度实验 | 把解释转成声音，让听者检验是否听见 | 朗读谱、听者回执、第二遍改读 |
| 意象被讲成答案 | 多假设观察、意象生长图、前后颜色/状态对照、证据投票 | 先看物象，再提出并比较多种解释 | 假设卡、原词证据、保留分歧 |
| 容易倒灌结局 | 当下档案、证据强度三栏、暂停预测、回看修订 | 区分初读感受、文本事实和暂不能断言 | 初见札记、全文后修订痕迹 |
| 文化背景陌生 | 微型物件台、图物配对、一步文化支架、古今边界句 | 只取得当前句所需背景，不被知识讲座淹没 | 一条文化小注和“不足以证明”句 |
| 叙事仍是碎片 | 遮答行动链、三十秒旁白、六人接力、故事地图 | 把局部知识重新组织成连续人生 | 口头旁白、章意、听众补缺 |
| 现实处境难以想象 | 生活镜头、定格画面、一天账本、双人旁白 | 将诗句还原成具体生活，同时守住想象边界 | 场景卡、原诗依据、越界修订 |
| 观点讨论浅或被教师垄断 | 立场光谱、证据席、圆桌、鱼缸讨论、同伴追问、反方钢人 | 先形成个人判断，再倾听、质询、改写 | 立场句、追问记录、修订后判断 |
| 私人议题存在风险 | 只谈作品、第三人称案例、匿名投递、可跳过选项 | 不要求暴露家庭或恋爱经历，也能参与价值讨论 | 作品依据或案例判断，不采集私人自述 |
| 以为“看见答案就是会” | 遮答检索、错误诊断、同伴出题、迁移小诗句、退出条 | 从记忆重建并解释，而非抄结论 | 检索痕迹、错因、迁移证据 |

## 三、互动结构库

同一认知任务可以采用不同社会结构，但结构必须服务目的：

- 独立静默：保证每个人先拥有自己的材料；
- 同桌见证：一人表达，一人只按限定标准反馈，再交换；
- 四人编号轮说：避免自愿发言长期被少数人占据；
- 拼图接力：各组掌握不同章节，必须彼此依赖才能完成全貌；
- 走动观摩：学生携带明确观察单查看他组作品，不作漫游式参观；
- 鱼缸讨论：内圈讨论，外圈只记录证据、追问和观点变化，再交换；
- 立场光谱：用位置呈现分歧，但移动后必须说出原诗依据并允许不站队；
- 现场卡墙：类别由学生命名、合并、移动，教师不预制完整框架；
- 热座/角色访谈：只在文本能支持人物回答时使用，不能替人物虚构心理；
- 匿名投递：适合婚姻、家庭等私人议题，公开讨论作品或第三人称案例。

## 四、反馈手法库

- 原词追问：“哪一个字托住你的说法？”
- 断点提示：只指出叙事在哪一步跳跃，不报完整顺序；
- 听者回执：只写实际听见的变化，不笼统评价“有感情”；
- 强度调节：将“就是、一定、证明”改为“可能、此刻可以看见、尚不能证明”；
- 替换检验：删掉或替换一个词，比较声音、节奏或判断损失；
- 补缺不代答：听众指出缺少人物、动作、对象、原因或依据，由作者回诗补回；
- 钢人复述：反驳前先准确复述对方最有力的文本依据；
- 可见修订：保留前稿，用另一颜色改写、重排或补证，不把教师答案抄成“修订”。

## 五、去同质化审计

每个模块完成后，建立“认知动作×社会结构×产物形态”矩阵。若连续三页在三个维度中有两个完全相同，必须解释其必要性；若只是换标题，返工。多样性不要求热闹：一次安静的长听读、一次真正的停顿、一次重读也可能比多个小游戏更有体验。

严禁以下假丰富：

- 把空格改成卡片、把卡片改成便签，但仍由教师公布同一答案；
- 每页都写“独立一分钟—同桌交流—教师总结”；
- 活动前把答案放在学习单、讲者台词或图像里；
- 为了活跃而加入与原文无关的竞速、抢答或表演；
- 要求所有学生必须产生感动、愤怒、新发现或观点改变。

## 六、选法处方：先写困难，再准入手法

任何新活动在进入教案前，先填一张六句处方；无法填全，不准因为“有趣”而采用。

| 处方项 | 必须写成什么 |
|---|---|
| 原文停点 | 精确到一句、一组词或一次声音变化，不写泛泛主题 |
| 当前困难 | 学生究竟看不见动作、听不见声音、分不清证据，还是离屏后无法重建 |
| 体验变化 | 学生经过本活动后，将从哪一种经验变成哪一种经验 |
| 不可替代动作 | 为什么必须读、听、画、排、演、辩、写或走动；换成教师讲解会失去什么 |
| 留下的作品 | 具体落在教材批注、学习单、纸卡、口头录音、板书还是故事轨道 |
| 后续调用 | 哪一页会打开、引用、反驳或修订这份作品；只有“课后复习”不算 |

活动名称最后才写。若去掉名称后只剩“填空—交流—教师总结”，处方无效，回到当前困难重新选法。

## 七、体验节奏矩阵

每页至少登记以下五个维度。连续三页若有三个维度完全相同，原则上判为P2；若确因反复练习需要同构，必须说明学生能力如何逐级增加。

| 维度 | 可用类别 | 检查问题 |
|---|---|---|
| 认知动作 | 检索、定位、口译、感受、比较、假设、排序、归因、质询、重建、迁移、自评 | 学生大脑真正换了工作吗？ |
| 感官通道 | 默读、出声读、闭眼听、凝视、身体走位、书写、观看他人作品 | 是否总在“看屏幕—填空”？ |
| 社会结构 | 独立、同桌互证、角色对读、四人轮说、全班听辨、走动观摩、鱼缸、匿名投递 | 谁在生产，谁在倾听，谁有修改权？ |
| 作品形态 | 原词标记、路线、朗读谱、听者回执、假设卡、判断句、排序链、故事旁白、立场修订 | 每页是否只是不同样式的空格？ |
| 情绪节奏 | 安静进入、好奇寻找、感官停留、声音碰撞、分歧悬置、责任辨明、回望收束 | 课堂是否一直在高强度接收或机械忙碌？ |

体验丰富不等于每页换花样。好的节奏可以是“完整静读—一处凝视—两人声音碰撞—独立判断—全班听辨—合书重建—安静收纳”，关键是每次变化都由文本困难引起。

## 八、常见手法的准入边界

| 手法 | 只有满足以下条件才使用 | 常见误用 |
|---|---|---|
| 图片/视频导入 | 学生随后必须观察、比较或引用其中可核验细节 | 只制造气氛，抢走原文第一印象 |
| 角色表演 | 台词、动作和心理均能由文本托住，表演后回到原词修订 | 虚构人物内心，把热闹当理解 |
| 小组讨论 | 个人先有材料，小组必须形成共同作品，听众有明确任务，作者有二次修订 | “讨论一下”后随机叫人回答 |
| 辩论/立场光谱 | 文本确有可争议解释，双方都能获得证据，不以私人经历作站队压力 | 把事实问题伪装成观点问题 |
| 思维导图/表格 | 结构关系本身是学习对象，并由学生生成或修订 | 教师先展示完整图，学生照抄 |
| 朗读 | 声音选择能改变理解，并有听者回执或第二遍改读 | 齐读一遍即声称体验情感 |
| 创意写作 | 明确区分诗中所写与想象补写，写后用原句核验边界 | 用现代故事覆盖古诗文本 |
| 游戏/竞赛 | 速度不是唯一优势，错误能进入解释和修订 | 抢答奖励快学生，其他人旁观 |

## 九、活动注意力预算

活动写入教案前，把学生需要记住的事项逐项计数：角色、顺序、时间、分支、纸张、符号、产出、反馈和修订位置都算一项。学生前台优先保留以下三步闭环：

> 面对文学对象做一个主动作 → 接受一项有界反馈 → 亲自修订一次

超过三步并非绝对禁止，但每多一步都要说明它新增了哪一种文本理解。以下手续通常不应进入学生前台：来源编号、原提议者签认、重复内容查核、为了可追溯而设置的卡号、多个状态标签、没有后用的个人参与证明。它们若确有管理需要，放入教师后台，由教师承担。

## 十、广泛表达后的教师归纳

作品回忆和主题导入可采用“文学接龙”：每人用“《篇名》写了……”提供一条自然话；重复篇目允许补另一层意思，不执行查重淘汰。教师在黑板保留篇名与学生原话，待材料充分后再引用现场例子，归纳作品共同关心的相遇、等待、阻隔、相守、背叛、离开等命题。归纳词必须服从现场，不要求六项齐全，也允许学生指出教师归纳过满或遗漏。

这一手法的价值在于扩大文学记忆和公共发言面；不适合在导入阶段继续发展为卡片编号、学生分类评审或深度证据辩论。深入分析应留到新文本提供共同证据以后。

## 十一、手法结束的故事回接

每种局部手法都须有自然出口：

| 手法 | 回接人物故事的出口示例 |
|---|---|
| 字词口译 | “所以，这句话里是谁做了什么？” |
| 空间描画 | “这段路让我们看见她怎样投入这次相送？” |
| 对照朗读 | “见与不见，使她的等待发生了怎样的转折？” |
| 文化支架 | “这次占问把当时的婚事推进到哪里？” |
| 意象假设 | “女子为什么在迁嫁之后忽然让一片桑叶进入回望？” |
| 删句比较 | “原诗让这声劝告怎样来到人耳边？” |

出口不必再增加一张表或一次大型活动；一句自然复述即可。章末只保留一次完整旁白，用来把本章重新放回六章人生轨道。
