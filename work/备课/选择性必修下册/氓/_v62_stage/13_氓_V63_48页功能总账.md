# 《氓》V6.3四十八页功能总账

## 一、裁决口径

本账不是旧页面说明书，而是每页重新取得存在资格的证据。局部裁决只有五种：候选保留、重写、合并、移动、删除。候选保留不等于放行；完整母版形成后，任何一页被独立审查判为P0、P1或P2，全课不得冻结，且其他页面优点不能抵消。

每页必须同时证明：只有一个主要学习变化；学生留下可见作品；作品在后页第一次真实使用；相邻页不能无损替代；主视觉服务该动作；结束时回到人物和故事。插图不在本轮替页面制造意义，待功能冻结后再按角色圣经和逐图用途进入。

## 二、全课脊柱

广泛唤回爱情与婚姻文学 → 完整听见《氓》 → 沿六章逐句进入人物生活 → 每章撤答重建 → 回答经历、不幸表现与原因 → 建构婚姻结构理解 → 检索语文知识 → 个人整合与完整朗读。

### 01｜O01｜我们还记得哪些爱情与婚姻故事？

- 存在意义：让每名学生先从自己的文学经验中检索至少一篇作品，用一句话唤回故事，再留下一个低门槛的爱情或婚姻主题
- 学生作品：不带《氓》题名与后续答案的个人作品—故事—朴素主题回忆单
- 第一次后用：O02同桌互说和四人汇聚直接读取个人清单中的篇名、故事与朴素主题
- 删除损失：没有个人准备，并行互说仍会被记忆快的学生占据，其他人也没有可修改的主题初稿
- 主视觉职责：承载从个人文学记忆到朴素主题的开放检索
- 活动手法：静默检索＋低门槛主题句

## 第一章

### 10｜C101｜第一章｜两个人怎样走近婚事

- 存在意义：让第一章先作为一段完整相遇进入，并由每名学生辨认两个人物的行动主体，形成后续细读的真实初稿

- 第一次后用：C102—C104逐段调用圈划初稿
- 删除损失：没有整章先行，后面三个意义句群会重新退化为词义卡，学生也没有可以修订的初始行动轮廓
- 主视觉职责：让第一章原诗成为唯一主视觉，并给人物行动圈划留下足够投影与纸面空间

### 11｜C102｜抱布而来，是为了什么？

- 存在意义：让学生从重复的‘贸丝’和转折字‘匪’读出诗句怎样由眼前动作转到婚事来意，并守住此刻证据边界
- 学生作品：细读单C102处的两句自然口译、转折字圈记和一处教师校准后的修订
- 第一次后用：C105旁白必须讲清男子怎样来
- 删除损失：若把两句分开或直接给译文，学生会失去‘贸丝—匪—谋’形成的叙事转弯，也无法建立初见判断的证据边界
- 主视觉职责：让‘贸丝’的重复、‘匪’的转折和‘谋’的位置在同一视野中可比较，原诗仍高于问题
- 活动手法：自然口译＋转折字比较
- 相邻页因果：C101留下“第一章初读卡上的人物动作圈划和暂时不懂处的问号” → 本页新增“男子以贸丝的样子走近，女子告诉我们，他真正来同她商量婚事；故事从一次带着转折的接近开始” → C103将面对“‘送子涉淇，至于顿丘’中送、涉、至三个连续动作形成的空间投入”
- 首轮裁决：候选保留｜唯一功能、产物和后用已成立；仍须接受完整母版的两路独立否决审查。

### 12｜C103｜她把他送了多远？

- 存在意义：让学生用身体或笔迹使送、涉、至连续发生，获得女子主动远送的空间经验，再把距离感翻回原句和人物行动

- 第一次后用：C105章末旁白必须讲清女子怎样回应

- 主视觉职责：用留白和三个原词的距离制造可操作空间，让学生的笔迹而不是完成地图成为答案
- 活动手法：空间行迹＋动作叙述
- 相邻页因果：C102留下“细读单C102处的两句自然口译、转折字圈记和一处教师校准后的修订” → 本页新增“女子不只送别，还渡过淇水，一直把男子送到顿丘；她的投入先被诗写成了一段路” → C104将面对“‘匪我愆期，子无良媒。将子无怒，秋以为期’构成的一轮解释、安抚和约期对话”

### 13｜C104｜她怎样把婚事继续说下去？

- 存在意义：让学生把两句作为一轮完整话语自然口译并读出三层言语行动，理解婚事怎样暂缓又被约定，同时保存‘无怒’的解释边界
- 学生作品：细读单C104处的完整对话口译、一处语气标记和一个留给全文后重看的问号
- 第一次后用：C105旁白要讲清婚事怎样暂缓又约定
- 删除损失：若把两句拆成两个页面或只讲词义，学生会失去一轮完整对话的声音和婚事推进，也会误把‘良媒’、‘无怒’、‘秋期’存成三条孤立知识
- 主视觉职责：让两句完整同屏，并用四个空白话语位置接纳学生自己的概括；原诗比活动支架更醒目，不预写三层分类，也不使用人物表情替代语气证据
- 活动手法：完整对话口译＋语气听辨
- 相邻页因果：C103留下“细读单C103处一条由学生亲自完成的送行线和一句空间叙述” → 本页新增“婚事没有在顿丘立刻完成，却也没有被拒绝；女子解释条件、安抚对方，最后把秋天定作婚期” → C105将面对“第一章完整原诗、前三页学生留下的来意转折、送行线、对话口译和无怒问号”
