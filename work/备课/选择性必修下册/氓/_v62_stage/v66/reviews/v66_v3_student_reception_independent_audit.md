## 五、连续理解链与学生实际所得

固定输入支持以下连续路线：

`个人文学记忆 → 全班爱情与婚姻文学长卷 → 《诗经》身份 → 六章完整初听 → 三问 → 第一章来、送、约 → 第二章等待、哭笑、卜筮与迁嫁 → 第三章桑叶、劝告、处境差异 → 第四章桑落、食贫、渡水与责任 → 第五章劳作、粗暴、笑声与独自悲悼 → 第六章旧愿反折、双真相与止息边界 → 个人六章人生长卷 → 生活表现个人末答 → 原因与边界个人末答 → 共同生活支点 → 文化、字词、诗法撤架检索 → 完整终读`

从普通后排学生的接收看：

1. **字面层可成立。** 首句六个易误词有独立校准；其他古义沿所在原句处理；结尾再用愆、筮、说、爽、咥、泮做六章最低复检。
2. **情节层可成立。** 每章都有完整进入、关键句细读和章意；54—57把六章个人稿、公共长卷、答案校准与撤架复述拆开。
3. **语言层可成立。** 送—涉—至、两个见、桑未／桑落、两个老、反／不思等先被听见、圈画、比较，再由78命名；76没有提前替学生分组。
4. **人物层可成立。** 女子的投入、等待、劳作、孤立、回望和止息均有原词；男子的失信、反复与粗暴直接归责；旧日欢乐不为后来伤害免责。
5. **主题层可成立。** 61和65分别给第二、第三问留下个人末答；66—69让婚姻理解从原诗生长并回到开头文学长卷，而不是只展示教师价值条款。

## 六、学生前台语言与体验推进

本版没有再把“学习目标、理解链、学生画像、评估标准”等后台话术写到学生屏幕。前台大体保持三种语体：原诗本身、能引人回到动作与声音的自然问题、必要而准确的知识命名。

尤其有效的语言包括：“她把他送了多远”“两个‘见’字，怎样牵动她的哭与笑”“笑声散去以后”“一间屋子里的许多年”“旧日与后来，两面都不能抹去”。这些句子不是项目标签，而是把学生重新带回人物、时间、空间与声音。

体验推进也不只靠讲述：初听与静默、指路、同桌互译、删句再听、双声部时间体验、外声—沉默—内声、原词卡混排、人生长卷、匿名猜诗、原因质询、给未来的卡与完整终读共同构成节奏。桌面设计已经避免“连续接收知识”的单一课堂；是否真正成为享受，仍取决于教师等待、不过度追问和活动不拖沓。

## 七、P3受控试教观察合同

P3必须在试教前预注册，课后不能凭印象宣布成功。

1. **导入覆盖：** 固定观察前、中、后排至少4个四人组；统计是否每人说出“篇名＋一句故事／朴素主题”。点头、代表发言不算本人开口。
2. **初听与后排接收：** 05—10记录错行、看不清、听不清和重新进入次数；末句十五秒静默单独计时。
3. **双人活动：** 19、22、24、26、35、42、49—50、72分别记录双方是否各完成一次；允许“没听出来、没有新增、暂时保留问号”。
4. **真实作品页：** 15、40、55、63、67、77必须确认黑板或投影材料确来自当堂首答且后排可读，不得用预制范例冒充学生作品。
5. **三问个人闭环：** 对固定分层样本收取54、61、65的公共答案前后个人稿；只抄类别、不含生活事实或原诗者不计为掌握。
6. **高负荷页：** 54统计18个落点的空项率；65统计六层末答的有效层数、原诗回接率和超时率。两页均不得用延长下课时间换取“成功”。
7. **诗法收纳：** 76保存个人首排；79抽样四类各一例和两类深做，分别统计，不能由“任选两类”倒推四类全会。
8. **课堂体验：** 每20分钟记录一次无任务等待、学生自发返诗、真实笑声或沉默、重复指令和疲劳信号；活动数量不能替代体验质量。
9. **终课：** 80的终课句区分含原词、人物事实、空泛口号和真实问题；完整终读至少180秒，末句后静默15秒。

## 八、独立放行意见

本固定输入可进入**无插图受控试教**。放行理由不是“页数多”或“文件完整”，而是核心证据链已经闭合：学生先答、看见真实同伴材料、接受后置校准、再亲自修订；三个全文问题和四类知识都没有停在公共答案。

放行边界：

- 不声称280分钟自然课堂内容已经适配任何具体课时；压缩必须等受控试教数据后另做。
- 不声称P3已经通过；全员开口、声场、时间、疲劳和真实作品质量仍是未发生的课堂事实。
