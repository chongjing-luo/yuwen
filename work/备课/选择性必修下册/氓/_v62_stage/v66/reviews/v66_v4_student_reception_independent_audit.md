## 三、四项P2否决证据

### P2-41｜把句内责任判断扩大成对女子全部判断的绝对评价

- 原诗“女也不爽，士贰其行”的判断对象是这段婚姻中双方的行为与责任：“爽”为差错，“贰其行”指男子行为前后不一。
- 第41页前台却直接显示“女子没有差错”，教师稿也无范围限定。普通学生最容易把它接收成“女子在相识、判断、投入与婚姻全过程中没有任何值得反思之处”，而不只是“男子的失信、反复和粗暴不能归责于她”。
- 这与第45、64页要求学生辨认婚前警讯、保持审慎并区分“可反思自己的判断”与“不能倒置伤害责任”发生语义冲突。问题不在支持受伤者，而在把责任边界写成了无范围的全称判断。
- 最小修复条件：把前台与逐字稿收紧为句内、行为层面的表达，例如：“‘女也不爽’：她在婚后的操持中并无差失；男子却行为前后不一。”另用一句明确区分：“她过去的判断可以反思，但男子的失信与伤害不能归责于她。”

### P2-57｜屏幕撤了，黑板上的六章答案没有撤

- 55页要求六组将六张章卡“依次贴卡”，接成黑板公共长卷。
- 56页再用屏幕完整显示六章校准答案，并声明下一页撤去。
- 57页确实撤去了**屏幕**上的六章短语，但真实剧本只说“谁都不要看黑板长卷”，没有覆盖、翻转、摘下或擦除55页形成的公共长卷。
- 因此“撤去全部答案”和“真正离屏复述”并未在物理环境中完成。我在后排仍可看到公共六章线索；只靠口头要求“不要看”，无法使这份个人检索证据成为可验证的撤架证据。
- 最小修复条件：切入57前必须将六张黑板章卡整体覆盖、反扣或摘下，且把这一舞台动作写进57页剧本和备注。

### P2-61｜强制“必须有一项是新增”，使原稿已齐全者无法诚实完成

- 学生屏幕要求“把自己原先漏掉的一项补进去”；教师逐字稿更明确要求“其中一项必须是你最初旧稿没有、经过交流才补到的”。
- 如果我在47页旧稿与58页补证后已经写齐贫困劳作、失信粗暴、兄弟不解、独自悲伤四个方面，本页没有诚实完成路径：我只能伪造一个旧稿缺项，或在已正确答案上做一次假修订。
- 这与整套文件声明的“已经准确者可保留、不伪造改变”直接冲突，并会污染第二问的个人末答证据。
- 最小修复条件：改成条件双分支——“原稿有漏项，补一项；原稿已齐全，圈一项最容易只抄古词的内容，改成生活事实并重新返诗”。

### P2-68｜剧本声称后置分层，静态PPT却在学生卡出现前已全部显示

- 备注和真实剧本声明：先把一张当堂真实“给未来的卡”放到左侧，请原作者读，再请同学返诗或保留分歧；此后右侧才出现“诗中写到的／由诗想到今天”两层。
- 但V4的第68页是单一静态物理页；其slide XML中 `p:timing=0`、`p:anim=0`、`p:set=0`。该页一加载，右侧的“承诺落空｜日子失衡｜兄弟不知而笑｜她作出止息判断”和“求助／必要时离开”已全部可见。
- 因此学生真实卡尚未成为主视觉，教师结构已先抢走注意和问题方向；备注所声明的信息时序无法由当前PPT演出。
- 最小修复条件：拆成两个可审查物理状态。A态只留真实卡放置区、原作者读卡和同学返诗任务；B态再显示诗中事实与现代建议。静态PDF必须能分别验证两个时序。

## 五、指定重点与历史问题独立复验

### 1. 导入01—03

- 01没有预列三篇或要求“幸福的本质”之类超出学生框架的深问；落笔只要篇名、一句故事、一条朴素主题。
- 02先同桌、再四人全员轮说，全班阶段只交一条增量；学生发言广度而非少数人深析是设计中心。
- 03要求教师关屏回到现场长卷，只引用本班真实语句后再揭题。
- 因此导入结构符合“广泛回忆—人人先说—朴素主题—教师后置归纳”。真实覆盖与材料广度仍是P3试教指标。

### 2. 05—10完整初听与12页三问

- 六张原诗页渲染清晰，字号、行距和对比度适合后排；每页分支已针对跟丢诗行、生字卡顿、提前翻注释和末句后出声。
- 初听时不显示主题、人物判断或三问；11保存个人停点，12先引用真实初听文字、此后才发三问书签。
- 12的切页句已直接进入第一章，没有再返回重复文化微讲。

### 3. 31、35、51—52、58、60—61、64—65、68—69、76

- 31明说是在已读完第三章后的有意删句，没有冒充未知前文的首答。
- 35的学生指令已改成“用三四句话，把桑叶、劝告和她的处境连起来”，不再只给抽象后台任务名。
- 51为中性六词首排，52才显示旧日/后来两组事实。
- 58在物理页上取回47旧稿，不是新建无消费者的写作。
- 60—61已把“家人”收紧为原诗明写的“兄弟”；但61强制每人产生一项新增，因此本轮仍为P2。
- 64只是公共校准，65要求撤架完成六层个人末答，没有只收四层。
- 68对现代求助/离开与诗中止息判断做了准确边界，但静态页时序未实现，因此仍为P2；69则真正回投开头文学长卷。
- 76已改为16张等大同色、同颗粒原诗短卡，中性网格不等于类别分区，卡序未把四类预先聚在一起；但这只能排除“版式泄答”，不能证明普通学生能在250秒内完成有效自拟分组，故为P3而非PASS。

## 七、连续理解链、前台语言与学生实际所得

除四项P2外，V4支持下列连续路线：

`个人文学记忆 → 班级爱情婚姻文学长卷 → 《诗经》最低文化坐标 → 六章完整初听 → 三问 → 来、送、约 → 等待、哭笑、占问、迁嫁 → 桑叶、劝告、处境差异 → 桑落、食贫、渡水、责任 → 劳作、粗暴、兄弟笑、独自悲悼 → 旧愿反折、双真相、止息边界 → 六章人生长卷 → 婚后生活与原因结构 → 共同生活讨论 → 文化、字词、诗法收纳 → 完整终读`

前台大体已隐去学生画像、理解链、评估指标和项目管理话术。“她把他送了多远”“两个见字怎样牵动她的哭与笑”“笑声散去以后”“一间屋子里的许多年”等问法能把我带回人物、时间、空间和声音。“校准”“现在只写自己的答案”等指令性语句属于当下真实任务，不是把教师方法论当学生内容。

学生可以获得的稳定内容包括：

1. 六章叙事从相识议婚、等待迁嫁，走向婚后贫困、劳作、失信、粗暴、兄弟不解和女子止息判断。
2. 首句六词、六章六个最低门槛词与其他句中古义都被放回人物和事情。
3. 桑叶比兴与前后对照、赋的铺陈叙事、词句复现反折、四言节奏叠词与声音都经过“先见关系、后命名”。
4. 责任在男子的失信、反复与粗暴；女子的投入、等待和劳作不是男子伤害她的原因。
5. 婚前细节可以提醒审慎和长期核验，但不能倒推已证预谋；末句写止息判断，不能续写成诗中已经发生的离开。

## 八、P3受控试教合同

即使四项P2修复，55页P3也不能靠教师课后印象宣布通过。至少应预注册：

1. **导入覆盖：** 抽查前中后排固定四个四人组，每人必须亲口说“篇名＋故事/朴素主题”；点头和代表发言不计。
2. **初听接收：** 05—10记录错行、重新进入、因生字中断次数；末句十五秒静默单独计时。
3. **双人和四人活动：** 不以“小组完成”代替“个人开口”；固定抽样双方完成率、组长包办率和有效返诗率。
4. **现场材料真实性：** 03、15、40、55、60、63、67、77页的黑板、卡片、分类必须保存当堂原件或照片，不得用预制范例冒充。
5. **高负荷页：** 54分别统计18个落点空项率；65统计六层有效完成、原诗回接和超时率；79分开统计四类例句底线与两类深做。
6. **课堂体验：** 记录无任务等待、真实沉默、自发返诗、重复指令和疲劳信号；活动数量不能代替体验质量。
7. **高密度收纳：** 75统计六项逐一返句率、机械抄整页率与两词加深完成率；76统计16卡有效分组启动率、无从下手率、超时率和小组代分率。
8. **终读：** 完整终读不少于180秒，末句后十五秒不另加总结；终课句分实质理解、语言发现、真实问题和空泛口号。

## 九、独立否决意见

V4不能进入无插图受控试教。必须先关闭四个固定输入缺口：

1. 41页把“女子没有差错”收紧为句内行为与伤害责任判断，并明确“判断可反思，伤害不归责”。
2. 57页撤去黑板六章长卷，不只撤屏。
3. 61页为“原稿已齐全”提供不伪造新增的诚实完成路径。
4. 68页将学生真实卡阶段与教师分层归纳阶段拆成静态渲染可分别核验的物理状态。

修复后必须重新冻结PPTX、母版、剧本、总账、PDF和80页渲染，并重做学生接收全量复审；不允许仅用备注解释静态页不存在的信息时序。本轮也不为插图提供任何合入授权。
