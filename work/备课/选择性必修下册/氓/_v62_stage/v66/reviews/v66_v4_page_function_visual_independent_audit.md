## 二、方法、等级与总裁决

本轮不是检查“每页有没有内容”，而是逐页验证四件事：

1. **唯一功能与删除损失：** 一句话说清该页为何存在；删除后若没有具体学习损失，必须删或并。
2. **主视觉服从功能：** 学生第一眼看见的东西必须推动当前动作；不能泄答、预分组、暴露后台方法，也不能让装饰图抢走原诗或真实学生作品。
3. **信息时序与边界：** 首答、同伴比较、校准、撤架必须按时出现；诗中事实、解释假设和现代建议必须分层。
4. **剧本可演性：** 逐字稿要能在当前画面真实说出，包含等待、巡视、听者任务、真实分支与切页触发，而不是后台流程条目。

等级定义：

- **P0：** 伦理、课程事实或安全层面的致命问题，必须停止使用。
- **P1：** 直接破坏页面唯一功能、泄答、暴露后台或使该页无法照稿执行的阻断项。
- **P2：** 页面仍可能运行，但会显著削弱课堂真实性、阅读公平、文本边界或学生所得，必须返工。
- **P3：** 局部实现风险；建议修复，不单独阻断。
- **PASS：** 在本冻结输入内未发现P0—P3，不等于真实课堂效果已经证成。

**总裁决：NOT_RELEASED。** 页级最高等级：P0=0，P1=0，P2=1，P3=1，PASS=78。按“任一P0/P1/P2存在即不放行”的既定规则，V4尚不能作为正式发布版，也不能直接进入批量插图生产。

V4已经实质关闭上一轮的主要缺陷：第5—10页具备听读场景专属分支；第12页切页直接进入第一章；第35、60、61页措辞与原诗主体边界已修正；第68页已把真实学生卡设为主区，并分开诗中事实与现代建议；第70—75页分支已与文化、字词检索任务相配；第76页已拆成16张原子卡。此次裁决是对V4冻结输入重新检查后的新结论，不沿用V3等级。

## 三、阻断项与可控风险

### G1｜P2｜第76页仍以空间位置暗示关系，且19pt卡片字影响全班同步辨认

第76页的唯一功能，是让学生面对同层级、无预分组的原诗证据，自行发现关系并命名。V4已经消除了斜杠配对和一张卡内预组关系，但4×4摆放仍不是视觉中性的：

- 第3列为“抱布贸丝／送子涉淇／老使我怨／以我贿迁”，三张明显叙事或动作证据纵向聚集；
- 第4列同时放入“不思其反／既见复关／反是不思／不见复关”，两组最显眼的复现、反折关系集中在同一列；
- 桑叶、于嗟与叠词材料主要偏在左侧。

因此，页面口头声称“随机散放、没有预先分组”，画面却以列和左右位置提供了类别提示。学生仍需完成分类，但发现关系的难度已被版式不均匀地降低。另据PPT XML，16张卡片正文为`sz="1900"`，即19pt；卡框有充足余量，却没有把文字放大。此页要求全班同时比较16条短句，19pt在后排和一般教室投影条件下构成功能性可读风险。

**必须修复：** 将卡文增至约24—28pt；生成并冻结新的排列；用预先声明的反聚簇检查验收：明显成对材料不得同列、同行或紧邻，同一候选类别不得在任何一列异常聚集。类别只可用于后台检查，不得用颜色、边框、间距或位置告诉学生。修复后应让一名不知道教师预设分类的审查者只看首答页，无法从布局猜出四类。

### G2｜P3｜第68页真实学生卡的显示路径与分步显现尚未冻结

第68页左侧已经留出大面积真实卡槽，右侧明确区分“诗中写到的”和“由诗想到今天”，并写明现代离开建议不是诗中已发生的结局；核心边界已经成立。风险在于静态PPT一打开，右侧两块成熟教师归纳同时可见，而左侧仍只是“请把一张真实卡放在这里”的占位。若现场没有固定的黑板、实物投影或即时拍摄路径，真实学生话语仍可能在视觉上输给教师答案。

**建议修复：** 在课前冻结一种实际路径：优先用实物投影/即时拍摄把真实卡放满左侧，再显现右侧归纳；或让黑板学生卡持续成为主视觉、投影只在教师归纳时开启。若使用动画，必须先读学生原话、再逐层出现两个右框。不得预制“优秀学生卡”冒充当堂生成。

## 五、01—04导入专项判断：课堂，不是培训页

用户要求导入“求广而不抢深”。V4的四页分工已经成立：

- 第1页不是让学生回答“爱情幸福的本质”，而是先独立找回篇名、故事和朴素主题；写纸形态正好保护慢想者。
- 第2页的目标不是做概念分类，而是确保每个人说过，并把不同篇目、不同主题增量写到真实黑板长卷。屏幕只是低压句式入口，不是公共答案。
- 第3页先让教师准确引用本班原话，再以极简题名聚焦；它是现场文学版图与新文本之间的桥。
- 第4页只给三分钟最低文化坐标；其卡片形态承载必要事实，不扩展成百科讲座。

因此，01—04目前**不需要删、并、拆**。若将第1—2页合并，个人回忆会被同伴声音污染；若将第3—4页合并，现场长卷的文学转场与文化微讲会互相抢焦点。未来只允许做语气和留白的轻量美化，不应增加预制作品封面、爱情人物拼贴、主题分类图或“幸福婚姻公式”。这些图会缩窄学生检索范围，并让导入重新变成教师展示。

## 六、视觉总评与增删并拆结论

1. 80张渲染图未见明显遮挡、越界、裁切、缺字、乱码或低对比；整体配色、页码、标题层级与暗/亮场切换一致。
2. 绝大多数首答页让原诗、自然问题和留白成为主视觉；校准页才出现知识关系；撤架页能撤去成句答案。第76页是唯一明显违例：卡片内容虽原子化，空间仍提供关系提示。
3. 第2、15、40、55、59、63、67、68、77页依赖真实黑板、卡片或投影。正式试教必须保证后排能看见，并禁止用预制“学生答案”代替现场生成。
4. 本轮没有应删除、合并或拆开的物理页。必须**改写/重排**的是第76页；建议**改显示次序**的是第68页。其他页面若为了缩时而合并，需在真实试教数据之后另做压缩版，不能在本完整体验版中提前牺牲首答、同伴验证、校准或撤架。

## 七、未来插图的角色连续性、信息泄漏与美感门禁

当前无图版不是缺陷。插图只有在能说明具体教学损失时才准入，不能以“重要场景都要有图”替代逐页功能判断。

### 1. 逐图准入合同

每幅候选图必须先写五项：服务哪一页哪一个功能；删图会损失什么；学生在看图前后分别知道什么；图是否提前给出人物性格、情绪、象征或因果；图在投影中占多少面积、文字是否仍满足后排阅读。任一项说不清，图不得进入PPT。

### 2. 角色圣经必须先冻结

先建立女子和男子的角色设定页，再生成场景：正面、侧面、背面；少年相识、婚后劳作、末章回望三个阶段；固定脸型、眼距、发式、服色、身高比例、常用道具和衣料磨损递进。每幅图都要引用同一角色参考图与版本号。年龄变化只能改变有合同的项目，不能换脸、换发式逻辑或把男子从少年画成不同人物。

### 3. 统一视觉圣经

采用温润、克制的手绘动画气质：清晰轮廓、低饱和土色、统一纸张纹理、固定光源方向和留白比例。不得一页厚涂、一页水彩、一页写实；不得以夸张眼泪、阴影脸或戏剧性肢体替代原诗证据。画面须有中国古代人物和环境的可信感，但没有史料支持时只能称“先秦生活意象化示意”，不得冒充精确服饰复原。

### 4. 信息泄漏红线

- 初听第5—10页、首答第14、18、21、29—34、39、51、54、58、62、66、70、73、76页原则上不放会规定答案的叙事插图。
- 第18页不得预画送行路线；只可在第20页校准后使用极简路线示意。
- 第29—33页不得用繁茂/凋落桑叶表情化地直接写出青春、衰老或婚变；若使用，第37页学生完成旧稿修订后才可出现非答案化物象纹理。
- 第45页不得把“婚前警讯”画成男子早有预谋；第53页不得画女子已经出走。
- 第68页不得用理想伴侣图取代真实学生卡；第76页禁用颜色、位置、连线或图标替学生分组。

### 5. 美感不是装饰堆积

插图应小、静、留白足，承担空间、声场、时间、情节节点或文化物象中的一项，不同时承担多项。人物视线不能把注意力引出页面；图的高饱和区域不得比原诗更抢眼；装饰图若删去后学习体验无损，应删除。建议先做2—3幅A/B原型并在真实投影距离下测试，而不是批量生成后再寻找用途。

## 八、强制修复顺序与复审边界

1. 先修第76页：字号增至约24—28pt，重新生成并冻结反聚簇排列；导出后核查PPT XML与高清渲染。
2. 同步更新第76页PPT备注、逐页真实剧本、功能总账中的“随机散放”证据，不能只改视觉文件。
3. 固定第68页真实卡的现场显示路径和分步显现次序；这是P3，但应在试教前关闭。
4. 重新导出PPTX、PDF和80张渲染图，更新全部SHA；任何冻结输入SHA改变，本报告自动失效。
