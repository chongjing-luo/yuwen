# 《氓》V6.6 V3｜80张物理画面真实课堂剧本

每张物理画面只写该画面出现期间真正会说、会等、会看、会修的内容。多状态逻辑节点不得在每张备注中重复整段流程。

## 01｜O01-A｜我们还记得哪些爱情与婚姻故事？（300秒）

**这张画面的唯一意义：** 让每个人从自己的阅读经历中先得到至少一条可说材料，并尽量扩大爱情与婚姻文学的篇目和主题范围。

**所属逻辑节点：** 01｜让每个人从自己的阅读经历中先得到至少一条可说材料，并尽量扩大爱情与婚姻文学的篇目和主题范围。

**学生此刻看见：** 我们还记得哪些爱情与婚姻故事？｜从小学想到高中：课文、小说、整本书……｜篇名｜用一句话唤回故事｜它写到爱情或婚姻中的什么？｜先写你真正记得的一篇；想起新的，再添下去。

**学生实际动作与证据：** 检索篇名和一句故事；写它谈到爱情或婚姻中的什么；O01文学回忆单；公共作品出现前的时间封存照片或翻面状态

**场景：** 屏幕只留下此刻要面对的原诗、问题或学生真实作品；教师说完邀请后退开，让阅读、表达和等待真实发生。

**教师可直接演出的逐字稿：**

今天先不急着翻到新课。请从小学一直想到高中：语文课文、小说、整本书里，哪些作品写过爱情，哪些写过婚姻？先写篇名，再用一句平常话把故事唤回来；最后写它谈到爱情或婚姻中的什么。这里不需要分析得很深，也没有三篇规定答案。真正记得什么，就先写什么。现在安静两分半。（教师不报篇名，退到后排巡视。）一时想不起，可以翻本班读过的篇目目录；只记得情节，也先留下情节。时间到，我会请大家把纸翻面一瞬，封住这一刻真正想起的内容，然后再与同学说。

**舞台动作：**

- 教师从零篇名开场

- 学生独立检索并静写

- 教师后排巡视而不报答案

- 学生封存个人首答

- 切到同伴互说

**本画面时间盒：** 说明三个落点45秒；个人静默检索165秒；补写和时间封存60秒；转场30秒

**现场分支：**

- 一时想不起作品：允许翻看本班读过的篇目目录；只记得情节，也先留下真实情节。

- 只能想起篇名：先写最确定的一点故事；主题可以暂写‘还说不准’，不借同伴答案补抄。

**听者任务：** 此页没有听者任务；每个人先保护自己的文学记忆。

**切页触发：** 每个人手里先有了一点自己的文学记忆。现在说给身边的人听，也听听自己没有想到的故事。

**删除损失与相邻反证：** 多数学生失去独立检索时间，公共发言被快想者占据。；O02负责表达和扩展，不能替代O01不受同伴影响的个人检索。

## 02｜O02-A｜一间教室，能想起多少种爱情与婚姻？（480秒）

**这张画面的唯一意义：** 分别实现每个人低压开口和全班文学版图的广度，让作品与朴素主题从学生话语中相遇。

**所属逻辑节点：** 02｜分别实现每个人低压开口和全班文学版图的广度，让作品与朴素主题从学生话语中相遇。

**学生此刻看见：** 一间教室，能想起多少种爱情与婚姻？｜我想起《　　　　　》：它写了　　　　　　　　　｜听见一篇自己没有想到的，就把它添进自己的清单。

**学生实际动作与证据：** 同桌和四人组内每人说一篇；公共阶段只贡献一条增量并补记新作品；O01新增栏；黑板篇名＋学生主题长卷

**场景：** 屏幕只留下此刻要面对的原诗、问题或学生真实作品；教师说完邀请后退开，让阅读、表达和等待真实发生。

**教师可直接演出的逐字稿：**

先和同桌互相说：‘《什么》写的是怎样的爱情或婚姻故事。’说的人可以看自己的纸，听的人只在没听清时问一句；一分钟后交换。（等待。）现在前后四个人依次说一圈，每个人都说完以前不选代表、不替别人总结。四个人说完，只留下两三条彼此不同的作品或主题。接下来每组只向全班带来一条增量：黑板上没有的篇目，或者同一篇不同的朴素主题。请先说篇名，再说那句自然话。我只把你们真正说出的篇名和关键词写到黑板上，此刻不分类。听见自己没想到的，请添进个人清单。若本组没有新增，可以如实说‘我们先听记’，不制造差异。

**舞台动作：**

- 接回个人封存清单

- 同桌依次说与听

- 四人全员轮说并保留差异

- 各组贡献一个公共增量

- 个人补记后切页

**本画面时间盒：** 同桌互说95秒；四人依次轮说150秒；公共增量和板书190秒；个人补记45秒

**现场分支：**

- 本组没有新增：如实说‘我们先听记’，把别组新篇目补进个人清单，不制造虚假差异。

- 主题说得过深或过空：请先回到一句故事，再用‘它写到……’说一条朴素认识。

**听者任务：** 听清篇名、那句故事和朴素主题；只补一篇自己没有想到的作品或一个真实不同的理解。

**切页触发：** 先别擦掉这面黑板。我们沿着大家真正说出的故事，去听一位更早的女子怎样讲自己的相识与后来。

**删除损失与相邻反证：** 失去全员声音或公共文学广度。；O01只能证明个人检索，O03只负责教师归纳；本页不可由两者代替。

**这张画面的唯一意义：** 在不打断初听的前提下，给学生阅读《氓》所需的最低文化坐标，并只点名后文会亲自遇见的赋、比、兴。

**所属逻辑节点：** 04｜在不打断初听的前提下，给学生阅读《氓》所需的最低文化坐标，并只点名后文会亲自遇见的赋、比、兴。

**学生实际动作与证据：** 听取必要文化微讲；在题下注记诗经—卫风—氓的归属；教材题名旁的‘诗经—卫风—氓’归属批注

**场景：** 屏幕只留下此刻要面对的原诗、问题或学生真实作品；教师说完邀请后退开，让阅读、表达和等待真实发生。

**教师可直接演出的逐字稿：**

翻开课文前，只给《氓》一个最小的来处。《诗经》是我国第一部诗歌总集，现存三百零五篇，作品大致产生于西周初年至春秋中叶。传统上分为风、雅、颂；《氓》在十五国风的《卫风》中。古人还用赋、比、兴谈《诗经》的写法。今天此刻只记住这三个名字，不背定义；读到第三章时，我们会亲自听见‘兴’怎样发生。请在题名旁只留下‘诗经—卫风—氓’这条归属，不抄整页。

**舞台动作：**

- 题名页后给最低文化坐标

- 教师短讲而不展开百科

- 学生只做归属批注

**本画面时间盒：** 最低文化坐标微讲115秒；学生归属批注35秒；回到讲述者30秒

**现场分支：**

**听者任务：** 听清作品身份和归属；赋、比、兴只记名字，不提前抄定义。

**切页触发：** 来处已经清楚。现在不再介绍，让她从第一句讲到最后一句。

**删除损失与相邻反证：** 初读失去作品身份，结尾检索变成第一次讲授。；题名页无法同时承担文化坐标；结尾检索不能作为第一次讲授。
