## C301｜第三章｜迁嫁以后，诗先让什么进入眼前？｜4分钟

【本页不可替代的意义】

先让第三章完整响起，由学生自行留下一个眼前物象和一处声音转折，形成后续细读的真实初稿

【删除本页会失去什么】

没有完整章声和初稿，后页会从教师指定的桑叶与劝诫开始，学生不能经历叙述突然换声的发现

【场面】

屏幕只显示第三章全文和两个读后问题；教师范读时站在侧面，学生低声读和落笔时退到后排，不在屏幕上染色提示答案。

【教师实际说】

“第二章最后，车来了，财物迁了，女子的生活也换了地方。请从故事轨道把前两格连着说一遍，然后只看第三章。先不要问桑叶象征什么，也不要找手法；让五句诗完整地响一遍。读到你自己觉得说话方式变了，可以轻轻停半拍；没有这种感觉，就照原来的节奏读完。（教师范读后，全班个人低声再读。）现在才落笔：迁嫁以后，眼前最先出现了什么？哪一句开始不像叙事，像是在劝告？每一项都抄回一个原词或原句。没有听出转折，可以留问号。同桌只检查你写的是不是这五句里的东西，不替你解释。（等待核对与修订。）我们先保留两件事：桑叶先进入眼前，声音随后改变。它为什么这样写，先不急着回答。”

【动作、等待与走位】

- 恢复前两章故事位置：35秒
- 教师范读与学生完整低声读：85秒
- 个人读后生成：55秒
- 同桌来源核对和修订：40秒
- 引用初稿并转场：25秒
- （连说前两章故事轨道）
- （教师完整范读）
- （学生个人完整低声读）
- （读后才写两项初稿）
- （同桌只核对来源）
- （学生亲自修订）

【现场分支】

- 没有听出变化：声音栏诚实留问号，只写最先看见的物象；C303再用两句对读帮助耳朵发现。
- 先报比兴：把术语暂放纸边，追问初读时先看见哪一物、从哪句开始听见劝告。
- 写活动词：将‘朗读、圈词’改成诗中真实出现的物象或一句原诗。

【听者同时做什么】

只核对同伴所写物象和转折句是否来自第三章，不评判解释深浅。

【证据留在哪里】

## C302｜桑之未落，其叶沃若｜6分钟

【本页不可替代的意义】

先从‘沃若’形成可感的桑叶经验，再让每人提出两种有原词依据、等待第四章筛选的联想

【删除本页会失去什么】

删除本页会把桑叶退化成教师直接公布的象征义，第四章也失去可被后文修订的个人初始解释

【场面】

屏幕只放大原句、沃若词义和两个开放问题；教师说完后真正静默，学生纸上有两项假设位，屏幕不显示范例。

【教师实际说】

“把这句先说成自然话。‘沃若’是润泽的样子。现在先不写象征，不让一个熟悉答案盖住眼前的叶子。请静静看这行诗十秒，想一想它的色泽、质地和生命状态；在纸上写两个能被‘沃若’托住的词。（静默十秒后继续等待。）有了感觉，才允许联想：它可能让你想到怎样的青春、情感或关系状态？请留下两种可能，每一种旁边都写出刚才哪个词托住它。同桌只问一句：‘你的联想从沃若的哪一种感觉生出来？’不替对方选择。（等待。）如果你写的是‘桑叶就是爱情’，请把话放轻，改成‘可能让我想到……’；找不到依据，也可以删去联想，保留感官词和问号。第四章还有‘黄而陨’，我们会带着今天的两种想法回来筛选。”

【动作、等待与走位】

- 个人口译与词义校准：65秒
- 静默观察和感官词：65秒
- 两项假设独立生成：95秒
- 同桌依据追问：65秒
- 个人修订和转场：70秒
- （个人自然口译）
- （静默观察十秒）
- （写两个感官词）
- （写两项可能联想）
- （同桌只追问依据）
- （学生改弱或保留问号）

【现场分支】

- 只写固定象征：将‘就是’改成‘可能让我想到’，再补一项不同层次的可能或诚实问号。
- 无感官依据：先删去联想，只保留沃若所能托住的颜色、质地或生命状态。
- 没有联想：允许只写感官词和问号，第四章对照黄而陨后再生成。

【听者同时做什么】

只追问联想的感官依据，不判断谁的象征义更像标准答案。

【证据留在哪里】

## C303｜两声‘于嗟’，劝告怎样来到人身边？｜9分钟

【本页不可替代的意义】

在同一组原句中先读出两声呼告的转移，再用蒙句反事实听辨检验物象和回声如何让劝告抵达人

【删除本页会失去什么】

删除会使斑鸠句只剩难懂旧说，比兴也只剩教师术语；学生无法从声音转移和蒙句损失理解劝告怎样抵达人

【场面】

屏幕只放三句原诗和递进问题；学生在自己的学习单上真实遮住前两句，不另开A/B程序页。

【教师实际说】

“请先把三句说成自然话。‘于嗟’读xū jiē，是一声感叹；‘无’同‘毋’，是不要；‘耽’是沉溺。斑鸠食桑葚易昏醉是教材旧说，只看它在诗里怎样引出劝告。（等待。）圈住两声于嗟，框住鸠和女，再把两种劝告接好。两人一组，一人读斑鸠句，一人接女子句，交换一次。现在把手轻放在学习单上，蒙住桑叶和斑鸠，只让同桌读‘于嗟女兮，无与士耽’。你真实听见了什么变化？可以说画面、回声少了，也可以说直劝更利落；只要回到一处原词。（等待。）同桌只问：你说的变化在原诗哪里？有依据就写‘能找到，不改’，没有就亲自改。等你们先听见以后再命名：由物引出所咏是兴，物与人的相似又引发比的联想。女子的劝告正是从桑叶和斑鸠的一声叹息中走到人身边。”

【动作、等待与走位】

- 口译与最低词义：85秒
- 圈框与两轮接读：105秒
- 蒙句听辨和个人原词：115秒
- 同桌依据追问与按需修订：90秒
- 公开两种判断、后置命名和重读：145秒
- （个人自然口译）
- （圈声音框对象与劝告）
- （双人接读并交换）
- （手遮前两句听直劝）
- （个人写变化和原词）
- （同桌依据追问）
- （按需修订后教师命名）

【现场分支】

- 只报术语：划去术语，补写蒙句后真正少掉的一幅画或一声回响。
- 认为完全一样：分别说原诗和直劝第一眼看见什么、第一耳听见谁；仍认为一样可以保留。
- 偏爱直劝：允许保留更直接，同时指出原诗多出的具体画面或回声，不统一审美。

【听者同时做什么】

只问声音落点和蒙句变化能否在原词中找到；不替同伴报完整关系，不强制修改。

【证据留在哪里】

## C305｜同是‘耽’，两个人都能脱身吗？｜6分钟

【本页不可替代的意义】

借同词异词的正面对照读出退出处境不等，同时把原因和责任边界准确后置到婚后事实

【删除本页会失去什么】

删除会失去全诗关键的不平等处境，也会给性别本质化和受伤者归责留下未纠正的解释空洞

【场面】

屏幕两句左右或上下正面对举，只给说的通假义；原因栏在学习单保持空白，教师站在两句中线位置主持对照。

【教师实际说】

“最后两句要并在一起读。‘说’在这里读tuō，同‘脱’，是摆脱、脱身。先各自口译，再圈出完全相同的词，框住真正改变结果的词。（等待。）请用一句现代话，只说诗中明写的处境差异，不解释为什么。原因写成‘后文待证’。（等待生成。）交换看同桌的句子，只做一件事：若看见‘女性天生、她活该、因为她沉溺所以他才……’这样的越界词，把那个词轻轻圈出来，不替对方重写。作者自己删改，回到士/女、犹可/不可。（等待修订。）这两句写明：同样沉溺，男子尚可脱身，女子却更难脱身。它没有写女性天生如何；更不能把女子的投入变成男子后来失信或粗暴的原因。为什么难，第四、第五章会让婚后的日子一件件出现。”

【动作、等待与走位】

- 个人口译与通假义：70秒
- 同异词圈框：60秒
- 无归因处境句生成：75秒
- 同桌越界词核查：55秒
- 作者修订与教师边界校准：70秒
- 连读和转场：30秒
- （个人口译）
- （圈同词框异词）
- （写无归因处境句）
- （同桌只圈越界词）
- （作者亲自删改）
- （连读校验并保存待证）

【现场分支】

- 性别本质化：圈出‘天生’，改回诗中明写的士/女、可/不可处境差异。
- 受伤者归责：立即删去女子投入导致男子伤害的因果，把造成伤害与退出困难分开。
- 追问原因：把问题登记为后文待证；不凭第三章补造婚后结构。

【听者同时做什么】

只检查同伴是否准确陈述处境差异、是否加入无证归因；不提供完整改写句。

【证据留在哪里】

## C306｜把五句诗，讲成她回望中的一段话｜5分钟

【本页不可替代的意义】

完整重读后撤去教材、学习单与投影，用自然旁白把局部理解恢复为女子回望中的连续一章，并接入六章故事轨道

【删除本页会失去什么】

没有撤答整章重建，前五页仍只是活动片段，不能证明学生获得了连续的第三章和跨章故事

【场面】

屏幕先供完整重读；随后合教材、翻背03C、同桌互查并按B键熄屏。检索后只开教材定位，最后只恢复03C写第三格。

【教师实际说】

“第三章每一句都已经走过。请先完整重读一遍；把刚才真正听见的声音自然读进去，不表演术语。（读完。）现在合上教材，把03C翻到背面，同桌互相看一眼，桌面不露原诗。我按B键熄暗屏幕。（等待撤答。）用三十秒把第三章讲给同桌听，只讲三件事：眼前先出现什么，劝告怎样从物来到人，最后写出怎样的脱身处境。听者不要接管故事，只在讲完后补一个真正遗漏；没有遗漏就如实说完整。交换。（等待。）讲述者可以只开教材找到遗漏的一句，随后立即合书补说。现在只把03C翻回来，在故事轨道第三格写一句自己的自然章意；把桑叶两项假设和‘为什么难脱身’的问号保留，下一章继续。谁愿意读自己的第三格？（引用两条，只修事实断点。）迁嫁以后，女子的回望停在桑叶和劝告上，并看见两个人脱身处境不等。下一章，桑叶会转黄，婚后的日子也终于进入叙述。”

【动作、等待与走位】

- 完整重读第三章：50秒
- 撤去教材、学习单和投影：40秒
- 双方三十秒旁白：80秒
- 听者补缺与返诗补说：45秒
- 写第三格和保留待证：50秒
- 引用章意与转场：35秒
- （完整重读第三章）
- （合书并翻背03C）
- （同桌互查无原诗）
- （按B键熄屏）
- （双方各讲三十秒）
- （只开教材定位后合书补说）
- （写故事轨道第三格）

【现场分支】

- 完全空白：先说最确定的一段，再只开教材找它前后各发生什么；不抄完整章意。
- 只报术语：把比兴、反复、对照改成桑叶、斑鸠、女子和脱身处境的自然话。
- 固定桑叶答案：恢复可能语气，把两项假设留到第四章黄而陨出现后筛选。
- 听者代讲：收窄为只报哪一处断点，把定位和补说权还给讲述者。

【听者同时做什么】

只核对桑叶、劝告由物及人、脱身处境三项是否连成回望；不代讲完成章意。

【证据留在哪里】
