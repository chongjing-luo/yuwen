# 《氓》V4全量页面功能—视觉意义独立否决审查

## 一、结论先行

**结论：NOT_RELEASED，不进入试教。**

固定V4并非“没有沿原文走”：第9—38页确实依次经过六章，而且多数章采用“整章出现—局部细读—章末回连”。真正的结构性问题是：**原文顺序存在，但学生的共同语义底本、理解修订和六章个人复述没有持续在前台显形。** 许多关键解释只存在于教师逐字稿、口头转场、学习单或小组公共产物中。于是“教师讲过”“全班做过”和“每个学生能够独立讲清”被混成了一件事。

## 四、学生实际接收结论

按“陈晓雨”完整复演，她大概率能在教师标题、转场和班级长卷帮助下说出六段粗线索：

1. 男子来谋婚，女子远送并约在秋天；
2. 女子登垣等待，由哭到笑，占问后迁嫁；
3. 诗由桑叶、斑鸠转入对女子的劝告，并写男女脱身处境不等；
4. 婚后贫苦，男子行为和品德反复；
5. 女子多年劳作，遭粗暴、嘲笑和孤立；
6. 她回看偕老愿、旧日欢乐和誓言，最终作出停止判断，但诗没有续写实际去向。

这已经证明V4不是纯“知识点拼贴”。但现有证据不足以证明她能脱离标题和公共长卷，逐章说准关键句自然义、人物主语、事件位置及章间变化。最明显的个人断点是：

- 第27页没有让每个人留下可检查的第四章章意；
- 第38页六组分章共建代替了每个人独立拥有六章；
- 第40页分组原因卡代替了每个人重建完整因果；
- 第43页任选两词不能兜底个人基础词义盲点；
- 第44页先显示成品术语，学生没有经历“从原句发现到后置命名”；
- 第45页只有审美收束，没有在终读前修复上述个人缺口。

## 五、V6.6最小结构重构

### 1. 每章建立同一条“章句回路”

保留现有丰富探究，但每章末必须新增或重写为：

> 整章原文重现 → 教师沿原句作60—90秒朴素串讲 → 每人写“本章三件事/一处关键句自然义/与前章怎样变化” → 闭卷30秒口述 → 断点立即返诗修复

这里的“朴素串讲”不是教师抢答，而是在学生局部探究之后建立全班共同语义底本。六章标准必须一致，不能只有第一章强收口。

### 2. 问题态、活动态、回收态物理分离

10、11、12、20、26、38、44必须拥有可QA的B0问题态、B1学生生成态、B2后置校准态。不能靠教师声称“之后才揭示”，而固定屏幕从一开始就显示结构或术语。

### 3. 公共产物不得代替个人掌握

38页先个人六格，再小组互证；40页全班原因长卷完成后，每人重画一条主因链；43页六章门槛词全员通关；44页个人至少完成两类；45终读前做一次六章60秒检索。抽样作品只证明样本，不证明全员。

### 4. 学生前台只保留意义所需操作

02、41的“合并不同、带来增量、一组只留一张”等管理信息应缩到页脚或教师后台。视觉主位应给真实篇目、原诗、学生原话和它们之间的意义关系。流程图只有在学生不看就无法完成任务时才保留。

### 5. 不以插图数量修复理解链

多数原诗页不需要人物插图。19和35需要的是帮助理解“沃若”质感与“岸/泮”字面空间的功能视觉；38—40需要的是真实学生产物与可读关系图。无功能的古风人物图不能替代串讲、个人复述和返诗修复。

## 六、放行条件

下一候选只有同时满足以下条件才可重新审查：

1. 六章均有可见、可听、可留痕的个人章意闭环；
2. 38页不再以六组分章代替个人六章检索；
3. 43页完成六章基础语义全员兜底；
4. 10、12、20、44等页首答前不显示核心分析框架；
5. 真实学生文字、班级长卷和原因证据图有明确上屏与回收状态；
6. 学生能够第一人称说明：“我刚读了哪句、它自然地说了什么、它让前面的故事怎样变化、我刚修正了什么”；
7. 独立视觉审查与独立学生接收审查P0/P1/P2全部清零。

在完成上述重构并重新渲染全量QA前，固定V4只能作为问题定位基线，不应继续标注“桌面放行”。
