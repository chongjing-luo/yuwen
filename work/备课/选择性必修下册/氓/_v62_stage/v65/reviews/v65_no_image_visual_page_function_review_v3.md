## 二、审查视角：学生看到什么，页面才算做了什么

本轮固定代入一名普通高二学生“林川”：古汉语基础中等，未预习，能在明确的原句和单一任务下完成短时书写；不会自动把散落术语拼成全文，也会在教师先给分类、答案或代表例时转为抄记。

每页依次检查：

1. **首屏接收：**学生在独立形成答案前真正看见、听见什么；
2. **参与动作：**他是否实际读、圈、译、排、写、说、听或修订；
3. **思考生成：**活动是否迫使他在原词之间建立人物、动作、时间、声音或因果关系；
4. **可见产物：**离开页面时是否留下可检查的口译、标记、双行句、原词卡或长卷；
5. **首次后用：**产物是否在后页被读取，而不是活动结束即作废；
6. **不可合并性：**相邻页是否承担不同认知停顿；若可无损合并，则当前页功能不足。

核心时序为：**先遇见原文 → 个人形成 → 公开比较 → 教师命名/校准 → 回到全文复述或迁移。**V3已在关键枢纽页守住这一顺序。

## 三、原文讲解链与学生所得

本课并非“知识点拼盘”。学生先在05—06完整听到全诗，再由08的三问获得长期导航；09—13、14—17、18—22、23—27、28—32、33—38依次细读六章，每章均有“整章进入—局部细读—章意回收”，最后39—44再处理生活转译、原因、关系支点、文化字词、诗法和完整终读。

学生在五课时中有机会形成如下连续叙事：

> 相识议婚 → 等待与迁嫁 → 叙事暂停并由桑叶转入劝告 → 婚后贫困与男子失信 → 日复一日的劳作、粗暴和孤立 → 旧愿在后来事实中反折 → 女子作出停止判断，但诗不替她补写之后的人生。

与这条经历线同时生长的，是一条语文理解线：空间动作、话轮层次、由物及人的比兴、前后对照、双重时间、责任证据、声场、同词反折、叙事边界，最后才后置命名为《诗经》文化知识和诗法知识。由此，学生获得的不是彼此悬空的“比兴、叠词、人物形象”等标签，而是“我在哪句原诗里怎样得出并修订这个判断”的路径。

## 四、全局视觉与页面功能判断

### 1. 功能性差异已足以支撑逐文讲解

09—37虽始终保持原诗主位，但不再只是同一张“原文框＋问题”：10承担叙事转弯，11承担空间，15承担正面对照，16承担因序，20承担声音由物及人，21承担处境对照，24承担同物异态，25和29承担不同尺度时间，30承担证据边界，31承担声场，34承担同词反折，36承担双真相分类，37承担叙事边界。版式变化服务阅读动作，未用装饰变化掩盖同质任务。

章首页09、14、18、23、28、33使用相近的“整章原文＋底部入口”骨架具有学科合理性：它们让学生每次先重新进入完整章句，再拆读局部。真实试教仍应做“隐藏标题辨功能”抽查，验证差异也存在于学生理解中。

### 2. 无插图策略成立

无插图不是缺陷。人物肖像、婚礼场景、哭泣女子或情绪插画会预设人物面貌、时代细节和价值立场，不应为了“每页有图”而加入。条件性视觉空位仅有：11/14极简空间线、24同枝桑叶前后态、25/29时间结构、35无人地貌。这些均须经A/B证明能更快把学生送回原词，才有加入资格；不构成受控试教前的必修项。

### 3. 相邻页不宜因同章而机械合并

章首、细读和章意页分别承担“完整进入—关系形成—重新讲成一段”的认知停顿。39/40分别处理生活转译与原因分析，42/43分别处理知识检索与诗法共建；合并会使个人首答被完成知识图吞没。当前44页标称225分钟、约5课时，真实耗时仍须试教验证，但未发现仅靠合并页面即可无损解决的问题。

## 六、P3受控试教条件

20个P3不是桌面失败，而是静态文件无法证明的现场风险。受控试教至少记录：

1. **导入广度（02）：**每名学生是否至少完成个人写、同桌说、四人组说三项中的两项；完全零发言人数；公共贡献是否由固定熟练者包办。
2. **后排跟读（05—06）：**真实投影尺寸、距离和照度；最后一排连续朗读误定位人数不超过10%。
3. **章首功能辨识（14、18、23、28、33）：**隐藏标题随机抽页，至少80%学生能说清该页要找视线、换声、三层对象、主体或回望，而不是统一回答“看原文、讨论”。
4. **程序收益（15、25、29）：**闭眼听、分部朗读或时间程序必须产生可观察的新理解；若只延长流程，下一轮删减。
5. **操作合同（20、26）：**20页应明确操作对象含教材中的三句；26页前台动作宜表述为“释义、辨主体、画关系”，避免与已经按原文顺序列词的页面发生“排序”名义冲突。
6. **声场（31）：**学生能否在真实教室分辨外声—沉默—内声，而不是按教师提示猜答案。
7. **字面门槛（35）：**若多数学生在岸/泮地貌处受阻，再A/B测试无人地貌线图；不得直接写寓意。
8. **现场长卷（38）：**六组接续、贴入、追问和个人复述能否在10分钟内完成；代表不得替组内其他人完成全部思考。
9. **真实文字注入（39）：**匿名、切换、后排字号和45秒内投屏必须排演；若无法稳定完成，改用预收或实体展台。
10. **后段负荷（41—43）：**记录连续结构化任务中的疲劳、参与广度与实际耗时；42尤其验证6分钟内“四问＋选四词＋自修＋修复”是否可行。

整套标称225分钟，实际总时长不得超过排定时长10%，且不能通过删除个人首答来追时。

## 八、最终裁决与边界

该固定哈希候选已达到桌面层面的视觉与页面功能放行条件：**无P0/P1/P2，可进入受控试教。**V3最重要的改进不是“多了知识”，而是关键页重新把解释形成权交给学生，并以原诗顺序、章内回收和全文后用构成连续理解链。

本结论不等于正式规模化放行。只有完成至少一次真实教室试教，并以本报告的P3观察项和学习结果闸门收证，才能决定是否转为正式课堂版本。若试教失败，应优先修时序、操作合同和任务负荷；不得用装饰性插图掩盖学生没有真正读、写、说和修订的问题。
