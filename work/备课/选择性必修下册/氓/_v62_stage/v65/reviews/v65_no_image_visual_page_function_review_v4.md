## 四、受控试教条件

1. **05—06后排跟读：**记录真实投影尺寸、距离和照度；最后一排连续朗读误定位人数不超过10%。
2. **07现场注入：**分别测试20字、40字学生句的定位、换行和后排可读性；超长内容必须截取而非缩至不可读。
3. **39真实文字展：**排演匿名、45秒内投屏、字号和切换；无法稳定完成时改用预收或实体展台。
4. **程序与时长：**全套标称230分钟，约5课时。记录每页实际耗时、学生等待和后段疲劳，总时长不得通过删除个人首答来追赶。
5. **学生理解另设闸门：**必须由独立学生角色记录“看到—听到—做到—想到—留下—后用”，验证能否按六章复述事件、解释关键句并说出理解转变。未通过前不得因本视觉报告而宣布正式发布。

## 五、边界

本轮结论仅为：固定哈希候选在静态视觉、文件完整性和书面页面功能上无P0/P1/P2，可进入受控试教。它没有证明后排真实可读性、现场注入、230分钟执行、全员参与，也没有证明学生已经获得沿原文推进的连续理解。后者若失败，应重构教学信息流，而不是以视觉装饰或更多知识卡片补偿。
