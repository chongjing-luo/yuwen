## 二、审查所用的“学生角色”

本轮不以教师意图为默认事实，而固定代入一名普通学生“林川”：高二，古汉语基础中等，不预习，不会自动把散落知识拼成结构；能跟随清楚的原句、单一问题和短时书写，但若首屏已经出现分类、箭头或结论，会自然把它当作老师答案并转入抄记。公开发言意愿一般，小组内愿意说；在长时同构页面中容易把任务统一理解为“看诗句、等老师讲”。

对每页只问四件事：

- 他首屏看见和听见了什么；
- 他实际参加了什么，而不是教案声称安排了什么；
- 这一活动迫使他完成了哪一步思考；
- 切页以后，他手里是否留下可复述、可举证、可迁移的理解。

据此形成硬标准：**先遇见原文，再独立形成，随后公开比较，最后教师命名或校准。**任何页面或逐字稿若在“独立形成”前给出核心分类、排序、例证或边界答案，均不得用“学生仍可讨论”抵消。

## 三、全局学生接收链判断

### 1. 原文推进已经存在，但必须保护“形成时刻”

04揭题，05—06完整听读，07保存初听，08提出三问；09—13、14—17、18—22、23—27、28—32、33—38依次走过六章，39—44再回收生活、原因、关系、文化和语言知识。这条宏观链条是成立的。学生不是只接收到知识碎片，而是有机会经历：

> 相识议婚 → 等待迁嫁 → 回望劝告 → 婚后失衡 → 劳作、粗暴与孤立 → 回望旧愿并形成停止判断。

问题不在“完全没有沿原文讲”，而在若干关键节点首屏直接给出教师完成态，学生会跳过排序、分类、边界生成，只记住几个教师术语。26、36、37正位于责任判断和结尾边界，是全文理解的枢纽，泄答影响大于普通字词页。

### 2. 09—37版式同构已下降，但“信息图即答案”成为新风险

V1中段长期是“章名＋大标题＋居中原文框＋底部问题”。V2已出现多种功能化布局：10转弯，11空间线，15正面对照，16因序链，20由物及人，21处境对照，24同物异态，25双时间，29嵌套时间，31外声—沉默—内声，34同词反折，36双真相。

这是真改善。不过，功能图一旦在学生首答前呈现完整关系，便从“认知工具”变成“教师答案图”。当前风险集中在12、26、27、34、36、37：其中26、36、37已达到P1；12、27、34暂记P3，因为还可解释为教师后置校准页，但静态文件和逐字稿没有可靠的分步显示证据。

章首09、14、18、23、28、33仍保持类似的整章原文骨架。这种重复有语文学科合理性，不判P2；真实试教必须隐藏标题抽查：若学生不能仅凭页面入口说清“本页是在找行动、视线、换声、事实/判断、主体还是旧事”，就说明功能差异仍主要存在于设计者头脑里。

### 3. 导入广度与发言机会

01先保护每个学生的个人检索，02安排同桌各说、四人组每人说、全班只贡献增量，机制上比直接点少数人更公平，也能避免快想者垄断。林川即使不公开发言，也至少应经历“个人写一次—向同桌说一次—在四人组说一次—公共阶段补记一次”。

风险在真实执行：7分钟内既要完成全员低压表达，又要收集8—12条公共材料并准确板书，转场很紧；公共发言者也可能仍被小组中熟练学生包办。故02记P3而非页面否决。试教应记录“完全没有说过的人数”“只读他人答案的人数”“公共贡献是否来自不同学生”，不能仅用黑板上作品数量证明广度。

### 4. 05—06后排可读性

两页各15行，正文约23pt，渲染无裁切、对比充足，分成两页优于压成一页；但中央窄列和真实投影距离尚未验证。桌面证据只能证明技术可读，不能证明最后一排能跟读定位。维持P3，必须做真实教室实投。

### 5. 图像与“功能空位”

无插图不是缺陷。人物肖像、爱情场景、哭泣女子、婚礼器物等会预先规定人物面貌、时代细节和情感立场，不应为了“每页有图”而添加。

真正存在的只有条件性功能空位：

- 11、14：极简站位—视线—终点关系，可用线图，不需要人物图；
- 24：同一枝桑叶的沃若／黄而陨同构对照，只有在A/B证明能更快回到原词时才加入；
- 25、29：多年／当下、一天／多年应优先用时间结构，不用叙事插画；
- 35：无人的“水有岸、隰有泮”地貌示意可能帮助字面理解，但不得在图上写寓意；
- 39：最重要的视觉不是素材图，而是真实匿名学生文字的可读注入。

这些空位均不是当前P1的修复手段。先修首答时序，再谈插图A/B。
