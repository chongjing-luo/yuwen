# 《氓》V6.3全文综合教学母版

- 逻辑页：7页
- 自然时长：81分钟

<!-- V63_PAGE:S01 -->
## S01｜一｜她经历了什么？｜12分钟

- 唯一功能：让每名学生以一章自然话参与小组六章人生长卷，并通过观众找断点与返诗补说形成连续、可修订的第一问答案
- 学生动作：六人组每人从故事轨道认领一章，把章意写到一张长条纸对应位置；全组不发言拼成长卷，另一组沿长卷只贴一个‘故事断在这里’的问号；原作者返诗补回人物、动作或转折，全组共同读出修订后的六章人生
- 作品：每组六章人生长卷、观众断点问号与原作者可见修订；每名学生至少贡献一章
- 有界反馈：观众只指出哪一步缺人物、动作或变化，不给成品故事；教师只修事实顺序和停止判断边界
- 修订：原章作者亲自返诗补一处，不能由组长代改；全组重新连读验证
- 回到故事：女子从相识议婚、等待迁嫁，走入食贫劳作、失信粗暴与孤立，回看誓言后形成停止判断
- 后用：S02把长卷中第四、五章转成现实生活分镜；课末退出条用长卷回答第一问
- 删除损失：若只有教师时间轴或组长汇报，大多数学生没有组织六章人生，也无法发现局部章意之间的真实断点
- 合并反证：不能并入S02：本页先回答发生顺序，S02才把婚后经历转成现实画面；叙事完整与现实转述是两种能力
- 视觉职责：给六章长卷提供清楚的六个空位置与一个共同问题，不显示成品时间轴
- 第一人称：我亲自写了一章，并看见它怎样接进完整人生；观众指出断点后，我回原诗补好了自己的那一步。

```text
一｜她经历了什么？

把六章铺成一条人生长卷。
每人守住一章，只写一句自然话。

让这一章中的人、事与变化，
在你的话里重新发生。
```

<!-- V63_PAGE:S02 -->
## S02｜二｜她婚后的不幸，在生活中是什么样子？｜14分钟

- 唯一功能：让每名学生把婚后原句转写为无诗词、无抽象标签的现实生活分镜，再由另一组反向配回原句，证明现实阐释没有离开文本
- 学生动作：每人选择第四或第五章一处原句，写一个20—35字第三人称现实生活分镜；小组删去重复镜头，排成‘日常负担—关系伤害—支持处境’分镜墙，但类别名最后才由学生生成；另一组为每帧配回最能托住它的原句；配不回者由作者改弱或撤回
- 作品：每人一个生活分镜、每组一面可反向配诗的纪录片墙，以及至少一帧修订或撤回
- 有界反馈：观众只配原句和标记越界，不评价谁更惨；教师不提供现代术语清单，只用现场分镜后置命名
- 修订：配不回原句者删去虚构细节或降低强度；重复空泛者改成可观察的一天、行为变化或支持缺口
- 回到故事：婚后不幸落在长期家务和时间负担、生活贫苦、伴侣失信粗暴、家人不理解与独自悲悼中
- 后用：S03将分镜中的伤害责任和退出困难分区；婚姻结构讨论从反面生活结构提出必要支点
- 删除损失：若直接列‘贫困、劳作、背叛、孤立’，学生只接收标签，不能把古诗转成现实生活，也无法检验阐释是否有原句依据
- 合并反证：不能并入S03：本页只回答不幸怎样发生在生活里，不处理为什么发生和谁负责；先保事实才能讨论原因
- 视觉职责：提供空白胶片格和原句回配区，承载学生作品；屏幕不放教师完成的现代总结
- 第一人称：我把一处原句写成了别人能看见的生活镜头，另一组能为它配回诗句；配不回时，我亲自删掉了过度想象。

```text
二｜她婚后的不幸，在生活中是什么样子？

从第四、五章选一句，
把它拍成一帧日常生活。

让观众看见：
谁在做什么，日子怎样过。

另一组要从这一帧，找回原诗。
```

## S03｜三｜这场婚姻为什么走到这一步？｜16分钟

- 唯一功能：通过四区证据分置与公开辩护，严格区分婚前警告、直接伤害责任、使退出更难的条件和诗中不能断言，形成不归责受伤者的原因解释
- 学生动作：每人从全诗抄一处证据，先独立放进四区之一，并写一句理由；小组对最有争议的一张证据作‘原位置辩护—质询—允许移动’，保存少数分歧；全班只处理四张争议证据；作者根据质询移动或保留，并写一段区分责任和阻力的第三问答案
- 作品：全员证据卡、四区证据地图、四张公开争议卡和个人修订后原因段
- 有界反馈：质询只问原句直接证明什么、是否把退出困难写成伤害原因；教师立即阻断受伤者归责，不宣布动机
- 修订：学生移动错区证据、降低无证断言，把女子投入/劳作/家人不解从伤害原因移到退出困难；伤害责任落回失信、反复、粗暴
- 回到故事：早期来意差别和无怒值得警惕；男子失信、反复、粗暴直接造成伤害；女子长期投入、共同记忆、支持缺失与处境不等使停止更困难
- 后用：S04以四区地图为反面证据提出健康关系结构；S07最终三问收纳读取个人原因段
- 删除损失：若只讨论‘原因’，学生极易把女子沉溺、付出和没有早离开混入男子伤害的责任，或把现代猜测当诗中事实
- 合并反证：不能并入S02：S02建立生活事实，本页才进行归因和伦理边界；同时进行会让事实尚未站稳就开始评判
- 视觉职责：四个清晰但空白的证据区域承载学生移动；不显示教师预填例子和结论
- 第一人称：我放置并辩护了一张证据，也因质询移动或保留它；我能区分谁造成伤害、什么使她更难停止、哪些只是猜测。

```text
三｜这场婚姻为什么走到这一步？

把证据送到它真正属于的位置：

婚前值得警惕　｜　直接造成伤害
使停止更困难　｜　诗中不能断言

每张证据只能先落一处；移动必须说理由。
```

## S04｜如果把《氓》说给后来人听｜15分钟

- 唯一功能：让每名学生从文本反证出健康婚姻不可缺少的结构支点，经小组建模、外圈质询和个人修订形成有文学根基的婚姻观
- 学生动作：每人写一个结构支点和一处《氓》反面证据，允许命名为尊重、责任、行动一致、劳动平衡、支持、边界等或自拟；四人组用五根纸梁搭‘关系结构’，必须保留一个真实分歧，不做全票口号；鱼缸内圈展示结构并接受外圈‘哪根梁缺证据/哪根梁承重过多’的质询；每人最后修订自己的婚姻提醒
- 作品：每人一张结构梁、每组关系结构模型、一条公共分歧、外圈质询与个人最终婚姻提醒
- 有界反馈：外圈只质询证据和结构平衡，不评价私人选择；教师最后引用学生命名归纳，不预填五项标准
- 修订：学生增删或改名一根梁，补原句证据，最终提醒从空泛口号改为可观察的关系行为
- 回到故事：《氓》的悲剧不只在选错一个人，也在承诺与行动、劳动与权力、伤害与支持、投入与边界长期失衡
- 后用：S05—S07知识收纳保存个人婚姻提醒；退出条以诗句和结构支点作答
- 删除损失：若教师直接讲‘婚姻避坑指南’，学生只接收正确口号，没有表达、分歧、质询和自我修订，也失去语文课的文本根基
- 合并反证：不能并入S03：S03厘清诗中原因，S04从反面证据走向价值建构；事实审判与规范讨论需先后分开
- 视觉职责：以一座未完成的五梁结构承载学生命名和调整；教师标准不上屏
- 第一人称：我从一处诗句提出了婚姻结构支点，听见了同伴的分歧，也因质询把自己的提醒改得更具体。

```text
如果把《氓》说给后来人听

一段值得珍惜的婚姻，
最不能缺少什么？

请让《氓》中的一处反面证据替你说话。
只谈作品或第三人称案例。
```

## S05｜合上书，你还认得它们吗？｜8分钟

- 唯一功能：以先检索后核对的方式收纳《诗经》常识和本课核心字词，暴露个人不稳项而非整页抄写
- 学生动作：合书独立检索三块《诗经》路标和八个核心字词；同桌互相出四个词，只核音义；随后开屏核对并给一个不稳项加星；回原句为星标项补一个语境，不整页抄写
- 作品：个人检索稿、同桌四词小测与一个带原句语境的星标项
- 有界反馈：同桌只核音义，教师只处理共性错项；已掌握者不制造错误
- 修订：学生用另一颜色改音义并补原句，保留前稿
- 回到故事：语言知识回到女子的叙述语境，而不是离开故事的词表
- 后用：S07总收纳与退出条读取星标；课后只复习个人星标项
- 删除损失：没有检索，知识只散在逐句活动中；若直接展示整页答案，又不能判断学生真正掌握什么
- 合并反证：不能并入S06：常识字词是准确记忆，写法结构是关系解释，检索对象与反馈不同
- 视觉职责：只显示空白检索邀请；真实等待后，学生翻开原句和课堂批注核对，不用屏幕整页公布答案
- 第一人称：我先从记忆里写，再核对；我知道自己真正不稳的是哪一个词，并回到原句补好了。

```text
合上书，你还认得它们吗？

《诗经》的三块路标
最容易读错、讲错的字词

先凭记忆写下。
三分钟后，再翻开原句相认。
```

## S06｜这些诗句，为什么这样写？｜9分钟

- 唯一功能：从学生已体验的原句反向检索比兴、对照、反复、叠词、时间压缩与回环，形成‘原句—形式—作用—人物处境’的可迁移知识
- 学生动作：六人组每人认领一组原句，先写形式名和它造成的故事/声音作用；组内逐人用20秒教会同伴，听者只追问‘人物或故事怎样改变’；每人完成一条可迁移公式，并用另一处原句验证
- 作品：六组原句知识卡、每人一次微讲解与一条可迁移阅读公式
- 有界反馈：不接受只报术语；听者只追问作用是否回到人物和故事，具体落在声音、时间或处境
- 修订：学生把‘运用了……生动形象’改为具体的原词关系与叙事/情感作用
- 回到故事：写法不是贴在人物外面的标签，而是桑叶转黄、声音转向、时间拉长、誓言回环的具体方式
- 后用：S07把知识与三问、解释边界共同收束；迁移到其他叙事诗时使用公式
- 删除损失：若只列术语，逐句体验不能沉淀为可迁移知识；若只讲故事，又缺少语文学科的形式认识
- 合并反证：不能并入S05：本页需六人互教和作用解释，字词核对页的安静检索无法同时承担
- 视觉职责：六组原句以六岛呈现，学生认领后在纸上生成形式与作用；屏幕不显示完整答案
- 第一人称：我不只记住一个术语，还能用原句说明它怎样改变声音、时间或人物处境，并迁移到另一句。

```text
这些诗句，为什么这样写？

桑叶荣枯｜不见／既见｜两声于嗟
靡……靡……｜信誓／反／不思｜六章第一人称回望

它叫什么，可以最后再说。
先听一听：声音、时间和人物的处境，怎样变了？
```

## S07｜把理解和问题一起带走｜7分钟

- 唯一功能：把三问答案、语文知识、婚姻结构提醒和文本边界整合为个人退出作品，并以最后完整朗读结束而非教师口号
- 学生动作：独立完成五句退出作品，每句至少有一处原诗或课堂作品可回看；同桌只核查责任/阻力是否混淆、实际离开是否越界；作者亲自修订；全班最后完整朗读六章，把自己的理解放入声音；不表演统一结论
- 作品：每名学生一份五句退出作品、一处同伴核查修订和最终完整朗读
- 有界反馈：同桌只核边界不统一观点；教师引用三种不同带走句，不把婚姻观收成唯一模板
- 修订：学生补原诗、区分责任和困难、把实际离开降回停止判断；保留一个仍愿继续追问的问题
- 回到故事：女子的一生被重新完整看见，同时她的经历进入学生对关系、责任、支持和边界的思考
- 后用：作为真实试教后的学习证据与下一轮压缩依据；课后只复习个人星标和未解问题
- 删除损失：没有个人退出作品，全课成果只停留在小组公共作品和教师归纳，不能知道每名学生最终理解了什么、改了什么
- 合并反证：不能并入S06：知识互教后需要安静的个人综合和最终朗读，不能被术语活动占用
- 视觉职责：只给五句有文学语气的开放句架与大量留白，最后切回全文朗读；不展示教师答案
- 第一人称：我用自己的话完整回答了三问，写下婚姻结构理解和最重要诗句，也修正了责任与行动边界。

```text
把理解和问题一起带走

她从________走到________。
她的婚后生活，让我看见________。
这场婚姻走到这一步，责任在________；
使她难以停止的，还有________。

《氓》最值得我带走的一句是：________。
```
