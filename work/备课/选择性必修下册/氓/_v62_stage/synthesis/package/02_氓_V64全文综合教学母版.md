# 《氓》V6.4全文综合教学母版

- 逻辑页：8页
- 自然时长：79分钟
- 活动主链：个人生成 → 真实核查 → 本人按需修订。
- 正常反例：不强制问号、修改、争议、分歧或未解问题。

<!-- V64_PAGE:S01 -->
## S01｜一｜她经历了什么？｜10分钟

- 文学对象：学生在C606排好的六张章末卡，以及女子从相识议婚到形成停止判断的完整人生顺序
- 当前困难：六章分别能够复述，但跨章因果仍可能断裂；若改做小组长卷，个人理解会被组长和程序遮住
- 唯一功能：让每名学生沿自己的六章母轨道写出六句连续人生，经同桌只查真实断点后形成第一问的个人答案
- 学生动作：每人沿C606排好的六张章末卡，用六句自然话写出完整人生；同桌从第一句听到第六句：有真实断点才指出；没有断点就说出最清楚的一处因果；作者只在需要时返诗补说，并把六句收成第一问的一段答案
- 作品：每名学生一份六句人生、一个真实断点或清楚因果，以及按需修订后的第一问答案
- 正常路径：没有断点、故事已经连贯者不制造问号和错误，只标出最清楚的一处因果；缺章末卡者沿C606临时便笺补格后再写
- 有界反馈：同桌只查人物、事件、变化和先后因果，不提供成品时间轴；教师只修事实顺序与‘已经离开’的越界
- 修订：作者根据真实断点补人物、动作或转折；原稿准确者写‘连贯，保留’，不强制改动
- 教师后置：从学生六句人生中引用不同叙述，后置收束相识议婚、等待迁嫁、婚后劳作与伤害、孤立反思、回望誓言和停止判断
- 回到故事：女子从相识、等待和迁嫁走进多年婚后生活，在失信、粗暴和孤立中回望旧誓，最后作出到此为止的判断
- 后用：S02从第四、五章抽取婚后日常；S08直接读取本页第一问答案压缩为两句
- 删除损失：没有个人六章重建，第一问只剩教师时间轴或小组代表答案，无法证明每名学生真正拥有完整故事
- 合并反证：不能并入S02：本页回答人生发生顺序与因果，S02把其中婚后原句翻成现实日常；能力和产物不同
- 视觉职责：只显示一条连续章序和一个因果追问，提示学生读取桌面真实六张卡，不用六个空框冒充作品
- 第一人称：我沿自己的六张卡把她的一生写成六句；同桌没有替我讲，只在真实断点处提醒，或指出我最清楚的一处因果。

```text
一｜她经历了什么？

沿着桌上的六张章末卡，
用六句话，把她的一生讲清。

一 → 二 → 三 → 四 → 五 → 六

哪一步改变了下一步？
```

## S02｜二｜她婚后的不幸，在生活中是什么样子？｜10分钟

- 文学对象：第四、第五章关于食贫、长期劳作、男子失信粗暴、兄弟不知而笑和女子独自悲悼的原句
- 当前困难：学生容易复述‘贫困、背叛、压榨、无支持’等标签，却不能把古诗还原成可观察的日常，也容易补写诗中没有的伤害
- 唯一功能：让每名学生把一处婚后原句写成第三人称日常片刻，再由同伴反向配诗检验现实阐释是否仍站在文本上
- 学生动作：每人从第四、第五章选一句，写一个20—35字、第三人称、可观察的日常片刻；同伴为这段文字配回最能托住它的原句；配不回或越界才标问号；原作者删除虚构、降低强度或写‘可配回，无需改’，再读出自己的片刻
- 作品：每名学生一个现实日常片刻、一处同伴配回原诗的证据和一次按需修订或保留说明
- 正常路径：同伴能够准确配回者可以写‘可配回，无需改’；不要求每人犯错或改写，暂时写不出者先把原句译成谁在做什么
- 有界反馈：同伴只配诗或指出越界，不评价谁更悲惨；教师不列现代术语清单，只引用现场片刻后置归纳
- 修订：作者删去具体暴力、完整求助史、全部家人等无证细节，或把抽象标签改成一天中的行为；准确者保留
- 教师后置：由现场片刻归纳长期贫苦与劳作、伴侣失信粗暴、理解支持缺失和独自悲悼，不以标签替换学生作品
- 回到故事：她的不幸不是一个抽象的‘悲剧’，而是多年贫苦与劳作、伴侣态度改变、外部不理解以及最终独自悲伤的日子
- 后用：S03读取学生片刻中的事实，区分直接伤害责任、退出困难和诗中不能断言；S08压缩回答第二问
- 删除损失：若直接公布四个概念，学生无法从古诗走向现实生活，也无法检验自己的现代阐释是否仍有原句依据
- 合并反证：不能并入S03：本页先让生活事实可见，下一页才讨论原因和责任；事实未站稳就归因会导致受伤者归责
- 视觉职责：以一个大幅日常片刻书写区和原句回配入口承载个人作品，不展示完成的生活分类
- 第一人称：我把一处原句写成一个能看见的日常片刻；同伴能为它找回诗句，若找不回，我自己删掉了诗中没有的内容。

```text
二｜她婚后的不幸，在生活中是什么样子？

从第四、第五章选一句，
写成一个能被看见的日常片刻：

谁在做什么？
日子怎样一天天过去？

让同伴从你的文字里，找回原诗。
```

## S03｜三｜这场婚姻为什么走到这一步？｜12分钟

- 文学对象：全诗中的婚前细节、婚后失信粗暴、女子长期投入与劳作、共同记忆、支持缺失及文本未写边界
- 当前困难：原因讨论容易把早期警告、男子伤害责任、女子难以停止的条件和现代猜测混成一句，甚至把伤害责任转给女子
- 唯一功能：让每名学生写清婚前警惕、直接伤害责任、停止困难和不能断言四层，同桌只核责任/阻力混淆与证据越界，形成不归责受伤者的第三问答案
- 学生动作：每人写四层原因段：婚前警惕、直接伤害责任、使停止更难的条件、诗中不能断言；同桌只查两处：是否把退出困难写成伤害原因，是否把猜测写成事实；作者按需改弱、移层或保留；全班只讨论现场真实出现的分歧
- 作品：每名学生一段有原句依据的四层原因解释、一处双边界核查和按需修订记录
- 正常路径：原答案责任清楚、证据稳妥者写‘两项均通过，保留’；全班没有真实分歧时不人为制造争议，直接比较两种准确表述
- 有界反馈：同桌只问原句直接证明什么，以及有没有把她为何难停写成他为何伤害；教师阻断受伤者归责但不替学生猜男子动机
- 修订：把女子投入、劳作、共同记忆和支持缺失放回‘难以停止’；把失信、反复、粗暴放回直接责任；无证动机降为不能断言
- 教师后置：早期来意差别和‘无怒’值得警惕但不足以证明完整预谋；男子的失信、反复和粗暴直接造成伤害；女子投入、长期劳作、共同记忆、处境不等和支持缺失使停止更困难，但不分担男子责任
- 回到故事：悲剧既有婚前被忽视的信号，也有婚后明确的失信与粗暴；她的投入和孤立解释为何难以及时停止，却不能解释他为何伤害
- 后用：S04用本页原因反证共同生活中需要观察的行为；S08读取第三问答案和诗写/未写边界
- 删除损失：若只问一个笼统的‘原因’，学生容易把女子沉溺和未早离开写成男子伤害她的原因，伦理和文本边界都会失守
- 合并反证：不能并入S04：本页解释诗中悲剧如何形成，S04才从旧主题走向个人婚姻理解；事实归因和价值讨论需先后分开
- 视觉职责：用四个递进的自然问题组织思考，不预填答案、不要求移动卡片或固定数量争议
- 第一人称：我写清了婚前警告、伤害责任、难以停止和不能断言四层；同桌只查两个边界，我也没有把她的投入写成他伤害她的原因。

```text
三｜这场婚姻为什么走到这一步？

婚前，有哪些细节值得警惕？
谁直接造成了伤害？
为什么那么难停下来？
诗里还有什么不能武断？

请让每一层，都有原句可回。
```

## S04｜读完《氓》，再看开课时的爱情与婚姻主题｜13分钟

- 文学对象：O03保存的本班爱情与婚姻文学主题谱照片、学生开课时的一条朴素主题及《氓》反面证据
- 当前困难：开课主题谱若不被重新打开，只是一场热闹导入；婚姻讨论又容易变成教师口号、私人自曝或抽象的‘要有爱’
- 唯一功能：让每名学生用《氓》补充、修正或保留开课时的一条主题，并把婚姻理解落到共同生活中可观察的行为
- 学生动作：重新观看O03班级主题谱照片，每人任选自己或同学开课时的一条朴素主题；写下《氓》使自己补充、修正或保留什么，并用一处原句和一种可观察行为托住；四人各读一次，听者只问原句和行为是否对应；作者按需修订，有真实分歧才公开
- 作品：每名学生一条从开课主题到《氓》新理解的修订链、一处原诗反证和一项可观察的共同生活行为
- 正常路径：原主题经《氓》后仍成立者可以写‘保留’，但须说明它因此多了哪一层；小组一致时不强制制造分歧，不愿公开者只在组内完成
- 有界反馈：同伴只核文本和行为是否对应，不评价私人选择；教师只谈作品或第三人称，不收集学生恋爱、婚姻与家庭经历
- 修订：把‘要幸福、不要恋爱脑、要有爱’改成承诺是否经得起行动、劳动与决定是否长期失衡、伤害后是否承担责任、困难时是否有理解托举等可观察行为；也允许学生自拟
- 教师后置：引用现场语言归纳审慎了解、言行一致、劳动与权力平衡、责任承担、理解支持和及时止损等方向，但不宣布唯一婚姻模板
- 回到故事：《氓》让开课时的爱情与婚姻主题走进共同生活：誓言要由行动验证，长期失衡和伤害不能被投入与旧日美好遮蔽
- 后用：S08读取本页个人修订链，形成‘我从《氓》带走的一条共同生活提醒及原句’
- 删除损失：没有本页，O03主题谱成为孤儿产物，婚姻讨论也只剩教师处方，学生没有完成从旧文学经验到个人关系理解的闭环
- 合并反证：不能并入S03：原因解释要求证据分类和伦理边界，本页需要回看旧主题并形成价值判断；两种思考节奏不同
- 视觉职责：以开课主题的回声和三行个人修订入口承载入口—终点闭环；真实主题谱照片先由教师投影，不放预制答案
- 第一人称：我重新看见开课时班级说过的话，用《氓》补充、修正或保留其中一条，并把婚姻理解落到一种能够观察的共同生活行为。

```text
开课时，我们曾这样谈爱情……

读完《氓》，
你愿意替当时的自己补上哪一句？

我原来想到：________
《氓》让我补充／修正／保留：________
放进共同生活，我会观察：________
```

## S05｜这些字，离开注释还认得吗？｜8分钟

- 文学对象：《诗经》三项最低身份知识及《氓》中影响理解的字音、通假、古今义和语境义
- 当前困难：字词已经在逐句讲解中出现，但看过注释不等于能独立读准、解释并放回原句
- 唯一功能：让学生先合书检索，再用原句校准个人不稳项，并把真实错空项交给S07个人知识清单
- 学生动作：合书独立写出《诗经》三项路标，并从十个字词中选择六个注音或释义；同桌互相抽问三个，只核本句音义；随后翻开原句，用另一颜色校正真实错空项；将一个真实不稳项或一个最易混但已能解释的词带入S07个人知识清单
- 作品：个人检索稿、同桌三词口测、带原句语境的错空项修复，以及交给S07的一项个人知识记录
- 正常路径：全部准确者不制造错误，选择一个最易混但自己已经能解释的词进入S07；想不起者允许留空，核对后保留前稿并补准
- 有界反馈：同桌只核本句音义，不排名；教师只处理班级共性错项，不让学生整页抄标准答案
- 修订：学生保留原稿，用另一颜色补音义并在原句旁准确读一次；错项当场完成处置，不把‘课后复习’当虚拟消费者
- 教师后置：校准《诗经》最早诗歌总集、305篇、风雅颂与《卫风》归属，并只处理真实出现的愆、将、筮、说、徂、汤汤、渐、咥、隰、泮等错项
- 回到故事：字词不是离开人物的表格：说关系能否脱身，渐写水湿车帷，咥写外面的笑，已写停止判断
- 后用：S07必须打开本页错空项修复，写入个人知识清单第一栏；S08最后朗读用准确字音完成全诗
- 删除损失：没有先检索后核对，无法知道学生真正记住什么；若直接展示整页答案，只会再次产生熟悉感而非掌握
- 合并反证：不能并入S06：本页检验准确记忆和语境义，S06解释写法怎样改变声音、时间和人物处境，认知任务不同
- 视觉职责：让十个易错字词和三项文化路标成为清晰检索对象，答案不在首屏出现
- 第一人称：我先凭记忆读写，再回原句校正；我知道自己真正不稳的是什么，也在本页把它补准并带到个人清单。

```text
这些字，离开注释还认得吗？

《诗经》是什么？｜分哪三类？｜《氓》收在哪里？

愆　将　筮　说　徂
汤汤　渐　咥　隰　泮

先凭记忆读、写、解释；
再回到原句相认。
```

## S06｜这些诗句，为什么非得这样写？｜9分钟

- 文学对象：桑叶沃若/黄而陨、两声于嗟由斑鸠到女子、信誓/反/不思在末章回来的三组原句
- 当前困难：学生可能会报比兴、对照、反复、回环等术语，却不能说明原词关系怎样改变声音、时间和人物处境
- 唯一功能：让每名学生从三组原句任选一组形成‘原词关系—声音或时间变化—人物处境’短卡，经同桌用另一组原句检验后交给S07
- 学生动作：每人任选一组原句，写清原词关系、它造成的声音/时间变化以及人物处境；同桌交换短卡，用另外一组原句检验同一说法是否仍成立，只指出关系与作用断在哪里；作者按需修订，准确者保留；教师在体验后核对比兴、反复、对照与回环等名称
- 作品：每名学生一张形式—声音/时间—人物处境短卡、一处同桌迁移检验和交给S07的修订版
- 正常路径：术语一时想不起者先准确写原词关系和人物变化；短卡已经准确者写‘迁移成立，保留’，不强制修改
- 有界反馈：同桌只指出哪两个原词没有形成所说关系、作用是否回到人物；教师后置命名，不接受‘生动形象、表达感情’作为终点
- 修订：把空泛作用改为具体：桑叶荣枯把青春/关系盛衰置于时间中，两声于嗟让劝告由物抵达人，反/不思的回环让旧誓在结尾接受核验
- 教师后置：形式知识从原句关系生长：先看原词怎样相照，再说声音和时间怎样改变，最后回到女子的生活与判断
- 回到故事：诗不是给悲剧贴标签，而让桑叶由荣到落、叹息由物到人、信誓在结尾折返，从写法中显出女子处境的变化
- 后用：S07打开本页修订短卡，写入个人知识清单第二栏；S08可选其中一处原句作为最值得带走的语言发现
- 删除损失：若只列手法表，全文逐句体验不能沉淀为语文知识；若只讲故事，又没有形成可迁移的形式解释
- 合并反证：不能并入S07：本页仍在生成和互证形式解释，S07撤去原句群后只做个人收束与自我检索
- 视觉职责：让三组原句成为三个清晰可比较的文学对象，问题指向原词、声音、时间和人物，不显示完成术语答案
- 第一人称：我用一组原句说明了词语怎样相照、声音或时间怎样变化、人物处境怎样显出；同桌用另一组诗检验，我再决定改或保留。

```text
这些诗句，为什么非得这样写？

任选一组

桑之未落，其叶沃若。
桑之落矣，其黄而陨。

于嗟鸠兮……　于嗟女兮……

信誓旦旦，不思其反。
反是不思，亦已焉哉！

原词怎样相照？
声音、时间与人的处境，怎样改变？
```

## S07｜把字词和写法，收回手中｜7分钟

- 文学对象：S05个人错空项修复、S06形式短卡及全课必须守住的两条文本边界
- 当前困难：S05与S06已产生个人知识，但若不在一页真实打开并组织，它们仍会成为散落的练习痕迹
- 唯一功能：让每名学生把一个字词语境、一条形式解释和两条文本边界组成个人知识清单，经同桌只查可定位性后完成收束
- 学生动作：打开S05错空项修复，写一个字词及所在原句语境；打开S06修订短卡，写一条原词关系—变化—人物处境解释；补一组诗写/未写边界；同桌只查三项是否都能定位，作者按需补准
- 作品：每名学生一张含字词语境、形式解释和文本边界的个人知识清单，以及一处定位核查
- 正常路径：S05没有错项者写最易混但已掌握的一词；三项均可定位者写‘可定位，保留’，无需改动
- 有界反馈：同桌只问原句在哪里、解释靠哪两个词，不统一选择；教师只处理无法定位的知识，不再增加新清单
- 修订：学生补回原句、改准音义、把形式作用从空泛口号改回人物处境，并守住‘停止判断不等于实际离开’等边界
- 教师后置：知识清单只收真正能够定位和解释的个人所得，不以教师整页答案覆盖；字词、写法和边界共同服务完整阅读
- 回到故事：学生不仅知道故事悲剧，还能准确读原句、说明诗怎样组织声音与时间，并辨认诗写到哪里为止
- 后用：S08朗读前读取字词清单保证准确发音；退出作品可引用本页一处语言发现，不再让S05、S06成为孤儿产物
- 删除损失：没有独立知识收束，S05星标和S06短卡仍无真实消费者，最终退出页也会被迫同时承担过多知识和观点
- 合并反证：不能并入S08：本页专门组织学科知识并允许安静检索，S08回答人物三问、关系理解和朗读；合并会使终页过载
- 视觉职责：以一张清楚的个人书页承载三类可定位知识，不展示教师成品答案或后台‘知识收纳’标签
- 第一人称：我真正打开了前两页的个人痕迹，把一个字词、一处写法和一组文本边界收进自己的书页，并能指出它们在哪里。

```text
把字词和写法，收回手中

一个我已读准、说清的字词：________
一处我能讲明的写法：________
它怎样改变声音、时间或人物处境：________

诗写了：________
诗没有写：________
```

## S08｜把理解与问题一起带走｜10分钟

- 文学对象：S01—S04的个人答案、S07知识清单、《氓》全文及学生仍愿保留的真实问题
- 当前困难：全课产物丰富但仍需由每名学生亲自浓缩；若终页再塞进知识测验或教师口号，人物、关系理解和完整声音都会被压扁
- 唯一功能：让每名学生浓缩回答三问、保存一条共同生活提醒及原句和一个可选问题，经单一事实边界核查后以完整朗读结束
- 学生动作：打开S01—S04，独立写三问浓缩、共同生活提醒及原句，并可选择留下一个问题；同桌只核一个事实边界：有没有把投入写成伤害原因，或把停止判断写成实际离开；作者按需修订；用S07校准字音后，全班从第一章完整读到‘亦已焉哉’，教师不追加结论口号
- 作品：每名学生一份三问浓缩、关系提醒及原句、可选未解问题、一处事实边界处理和最后完整朗读
- 正常路径：暂时没有问题者可以留白，不制造问号；观点与同桌相同可以保留；边界准确者写‘边界准确，无需改’
- 有界反馈：同桌只核一个事实边界，不统一婚姻观和最喜欢诗句；教师引用不同声音，不把讨论收成唯一模板
- 修订：学生补原句、分开伤害责任与停止困难、把实际离开降回停止判断；真实问题允许保留，不要求全课封口
- 教师后置：教师只引用三种不同的个人收束，确认事实边界后把解释权交回完整朗读，不再增加新结论
- 回到故事：女子从相遇、投入和共同生活走到失衡、孤立与停止判断；她的声音进入学生对审慎、责任、平衡、支持和边界的个人思考
- 后用：作为真实试教后的个人学习证据，用于判断哪些理解已经形成、哪些字词和问题仍需回访，并作为后续课时压缩依据
- 删除损失：没有个人退出作品和完整朗读，全课成果只停在小组交流与教师归纳，无法知道每名学生最终带走什么
- 合并反证：不能并入S07：S07收束字词、写法和边界，S08回到人物三问与关系理解并完成整诗朗读；合并将终页再次过载
- 视觉职责：只呈现有文学语气的个人收束句架和可选问题，保持足够留白；最后朗读回到教材全文
- 第一人称：我用自己的话回答了三问，留下了有诗句托住的共同生活提醒；我可以诚实保留一个问题，也用准确字音把全诗完整读完。

```text
把理解与问题一起带走

她从________走到________。
她婚后的日子，让我看见________。
这场婚姻走到这一步：________。

我从《氓》带走的一条共同生活提醒：________
托住它的诗句：________

我仍愿继续追问：________（可留白）
```
