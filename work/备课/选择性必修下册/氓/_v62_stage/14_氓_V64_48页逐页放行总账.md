# 《氓》V6.4四十八页逐页放行总账

## 放行规则

本账对每页分别证明存在意义。局部失败不能被全课优点抵消；若某页不能同时说明前页输入、当前困难、唯一功能、学生动作、可见产物、第一次后用、正常反例、删除损失、主视觉职责、第一人称接收与相邻不可合并性，该页必须重写、合并、移动或删除。自动测试通过只证明文件合同成立，不等于教学放行。完整PPT、备注、学习材料和本账须锁定同一哈希，原视觉审查者和原学生接收审查者均判P0=P1=P2=0后，才可冻结。

## 全课理解脊柱

广泛唤回小学至高中爱情与婚姻文学 → 教师据现场原话后置归纳 → 完整听见《氓》 → 沿六章原文细读与章末重建 → 回答经历、生活表现、婚姻原因 → 回看开课主题并形成共同生活理解 → 检索字词与写法 → 带着理解、问题和完整朗读离开。

### 01｜O01｜我们还记得哪些爱情与婚姻故事？

- 前页输入：学生既有的小学至高中爱情、婚姻文学经验
- 当前困难：若直接全班发言，记忆快的学生会先占据作品范围，其他学生没有自己的发言底稿
- 唯一功能：让每名学生先从自己的文学经验中检索至少一篇作品，用一句话唤回故事，再留下一个低门槛的爱情或婚姻主题
- 学生主动作：独立写下篇名和一句故事；用几个自然词写它让自己想到的爱情或婚姻处境
- 可见产物：不带《氓》题名与后续答案的个人作品—故事—朴素主题回忆单
- 第一次真实后用：O02同桌互说和四人汇聚直接读取个人清单中的篇名、故事与朴素主题
- 正常反例：暂时想不起者可翻本班篇目目录；只想起情节者先写故事，O02听见同伴表达后再补主题，不需要装深刻
- 删除损失：没有个人准备，并行互说仍会被记忆快的学生占据，其他人也没有可修改的主题初稿
- 主视觉职责：承载从个人文学记忆到朴素主题的开放检索
- 教学手法：静默检索＋目录恢复

### 42｜S02｜二｜她婚后的不幸，在生活中是什么样子？

### 43｜S03｜三｜这场婚姻为什么走到这一步？

- 前页输入：S02留下：每名学生一个现实日常片刻、一处同伴配回原诗的证据和一次按需修订或保留说明

### 46｜S06｜这些诗句，为什么非得这样写？

- 当前困难：学生可能会报比兴、对照、反复、回环等术语，却不能说明原词关系怎样改变声音、时间和人物处境
- 唯一功能：让每名学生从三组原句任选一组形成‘原词关系—声音或时间变化—人物处境’短卡，经同桌用另一组原句检验后交给S07
- 学生主动作：每人任选一组原句，写清原词关系、它造成的声音/时间变化以及人物处境；同桌交换短卡，用另外一组原句检验同一说法是否仍成立，只指出关系与作用断在哪里；作者按需修订，准确者保留；教师在体验后核对比兴、反复、对照与回环等名称

- 主视觉职责：让三组原句成为三个清晰可比较的文学对象，问题指向原词、声音、时间和人物，不显示完成术语答案
