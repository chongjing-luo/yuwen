# 《氓》教案与配套 PPT 实施计划

## 总体原则

按“证据先行、教案定链、学习单承载、PPT 服务课堂、质量记录放行”的依赖顺序执行。任何下游文件不得反向改变已冻结的目标、时间与评价标准；确需调整时，先更新设计规范并登记理由。

## Phase 1：证据与内容基础

### Task 1：建立来源清单和文本证据档案

**说明：** 回看教材 PDF、单元任务、现行课标、已接受知识卡和单元图谱，形成正文、注释、学习提示、任务与边界的可回查记录。

**验收标准：**

- [ ] 六章正文、关键字词、叙事节点、比兴/对照/反复证据均有规范定位；
- [ ] 明确教材要求、项目建议与研究性解释三者边界；
- [ ] 所有课堂核心断言至少有一处有效教材证据。

**验证：** 引文逐项对照 PDF；扫描无 `TBD/TODO`；核查六章而非三章。

**依赖：** 无。

**主要文件：** `01_文本研究与证据档案.md`。

### Task 2：形成学情假设与诊断任务

**说明：** 在没有真实班级测评数据的前提下，建立“显式假设 + 课堂诊断 + 分支调整”方案，不伪造学情。

**验收标准：**

- [ ] 阅读、古汉语、诗歌形式与表达四类基础均有诊断点；
- [ ] 每项诊断结果对应具体增减支架规则；
- [ ] 诊断总时长不超过第一课时 5 分钟。

**验证：** 桌面计时；诊断—调整规则逐项对应。

**依赖：** Task 1。

**主要文件：** `01_文本研究与证据档案.md`、`03_学生学习单.md`。

### Checkpoint A

- [ ] 来源、引文与文本边界通过 H01/H02；
- [ ] 研究材料能够支持全部教学目标；
- [ ] 不存在伪造学情、教师用书或课堂数据。

## Phase 2：教案与学习证据

### Task 3：完成 2+1 课时教案 V0.1

**说明：** 写出课题信息、教材与学情分析、目标、重难点、两核心课时、可选拓展、板书、作业和反思预设。

**验收标准：**

- [ ] 每一活动包含教师动作、学生动作、成果证据、观察点、反馈、设计意图和时间；
- [ ] 两课时各精确汇总为 45 分钟，学生语言实践比例不少于 55%；
- [ ] 核心课与可选拓展清晰分隔。

**验证：** 时间复算；目标—活动—证据矩阵；H03—H07 检查。

**依赖：** Tasks 1—2。

**主要文件：** `02_氓_2+1课时教案.md`。

### Task 4：完成学习单与评价工具 V0.1

**说明：** 让学习单承载完整诗句定位、诊断、六章证据图、形式—作用表、主张—证据卡、微评论和比较矩阵。

**验收标准：**

- [ ] 学习单可以独立支撑学生课堂活动，不依赖抄写 PPT；
- [ ] 12 分微评论量表与教案一致；
- [ ] 基础、提高、拓展任务边界明确。

**验证：** 教案逐环节映射学习单区块；黑白打印可辨。

**依赖：** Task 3。

**主要文件：** `03_学生学习单.md`。

### Task 5：内容自评与第一轮返修

**说明：** 按 100 分量表审查 V0.1，针对低于 85% 的维度和所有硬门问题修改为 V0.2。

**验收标准：**

- [ ] 问题记录包含证据、严重度、修改动作和复验结果；
- [ ] 教案与学习单达到内容侧放行条件；
- [ ] 不以语言润色代替结构性修复。

**验证：** 量表复算；H01—H08 复验。

**依赖：** Tasks 3—4。

**主要文件：** `05_质量评估与迭代记录.md`。

### Checkpoint B

- [ ] 教案与学习单内容同步；
- [ ] 两核心课时可在 90 分钟内实施；
- [ ] 内容侧各维度得分率不低于 85%。

## Phase 3：正式文档与 PPTX

### Task 6：生成并检查 DOCX

**说明：** 将最终 Markdown 内容排版为教师教案与学生学习单 DOCX，保持标题、表格、页眉页脚、分页和打印友好。

**验收标准：**

- [ ] DOCX 与 Markdown 的目标、时间、任务和量表一致；
- [ ] 表格不越页失控，标题层级和页码清楚；
- [ ] 教案可彩色或黑白打印，学习单留有足够书写空间。

**验证：** DOCX 转 PDF 后逐页检查；文本抽取比对关键字段。

**依赖：** Checkpoint B。

**主要文件：** `02_氓_2+1课时教案.docx`、`03_学生学习单.docx`。

### Task 7：制作配套 PPTX V0.1

**说明：** 按冻结的信息架构和视觉系统制作核心课约 20—22 页、可选拓展 4—5 页的课件；课堂动作、学习单和教师备注保持同步。

**验收标准：**

- [ ] 每页只有一个主要教学功能并有视觉元素；
- [ ] 核心页与可选拓展页明确分隔；
- [ ] 学生思考页不提前展示参考答案；
- [ ] 标题、正文、来源字号和安全边距符合规范。

**验证：** PPT 文本抽取；逐页渲染；占位符、字体、溢出与对比度检查。

**依赖：** Checkpoint B。

**主要文件：** `04_氓_课堂教学课件.pptx`、课件生成脚本。

### Task 8：PPT 视觉 QA 与返修

**说明：** 将 PPTX 转 PDF/图片，逐页查找遮挡、溢出、拥挤、低对比、版式重复和课堂节奏问题，至少完成一轮修复和复验。

**验收标准：**

- [ ] 初检明确列出发现的问题，不能以“未发现问题”跳过返修；
- [ ] 所有严重和主要视觉问题关闭；
- [ ] 受影响页面修复后重新渲染检查，最终全量复验。

**验证：** 全量缩略图、逐页图像和内容抽取；H09/H10。

**依赖：** Task 7。

**主要文件：** `05_质量评估与迭代记录.md`、PPTX 与 QA 渲染件。

### Checkpoint C

- [ ] DOCX 可打印；PPTX 可打开、可投影；
- [ ] 所有核心文件内容一致；
- [ ] 视觉返修闭环已记录。

## Phase 4：整体模拟与最终放行

### Task 9：90 分钟桌面模拟和跨文件一致性检查

**说明：** 按教案顺序模拟两课时，核对每个页面、学习单位置、教师提示、学生产出和转场时间。

**验收标准：**

- [ ] 每个课堂环节都能找到对应 PPT 页和学习单区块；
- [ ] 无重复讲解、答案提前出现或材料切换障碍；
- [ ] 时间超支有明确删减优先级和补救方案。

**验证：** 模拟清单、交叉文件矩阵和时间复算。

**依赖：** Checkpoint C。

### Task 10：最终评分与 V1.0 交付

**说明：** 按冻结量表评分。未达到 92 分、任一维度低于 85% 或任一硬门失败时，返回相应任务继续修订。

**验收标准：**

- [ ] 总分 ≥92，各维度得分率 ≥85%，H01—H10 全部通过；
- [ ] 质量记录公开初评、修改和终评，不伪造课堂实测效果；
- [ ] 最终目录和文件用途说明完整。

**验证：** 最终评分表、文件打开测试、哈希与目录清单。

**依赖：** Task 9。

## 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 古汉语疏通挤占细读时间 | 高 | 用 5 分钟诊断决定是否启用字词支架；完整注释放学习单 |
| 现实议题滑向道德评判或私人暴露 | 高 | 问题始终回到诗句证据；禁止强制分享个人经历 |
| PPT 信息过密 | 高 | 每页一个动作；全文放学习单；投影字号硬门 |
| 单元比较挤占单篇教学 | 中 | 第三课时明确可选，核心课只保留迁移接口 |
| 无真实学情和课堂数据 | 中 | 只写假设和诊断分支，不伪造实施效果 |
| DOCX/PPT 字体替换 | 中 | 检查本机字体；使用稳定中文字体并完成实际渲染 QA |

## 计划审查结论

- 任务依赖完整，先证据、后教案、再文档与课件；
- 每项任务都有可检查的验收标准和验证方法；
- 核心交付被拆为可单独验证的小任务；
- 不存在 `TBD/TODO`；无未决范围问题；
- 实施前仅待用户对本书面规范作最终确认。
