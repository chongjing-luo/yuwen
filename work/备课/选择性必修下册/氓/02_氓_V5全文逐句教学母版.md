# 《氓》V5全文逐句教学母版

## 一、课型与设计边界

本母版以六章原文为唯一课堂主线，完整覆盖30组诗句，按12个意义句群组织，天然时长230分钟。它不是固定两课时教案，而是可在章末安全停点拆分的完整教学内容。

学生先完整听读全文，再逐章完成“章读—逐句释义—叙事推进—关键语言—短活动—完整重读—连续章意”；全文读懂后才集中回答三问。活动服务诗句，不另起平行主题。

未真实试教前，本文件只证明设计覆盖和桌面可实施条件，不声称学生已经理解、喜欢、享受或完成迁移。

## 二、三个待解问题

1. 女主人公经历了怎样的关系与婚姻过程？
2. 她的不幸婚姻，在现实生活中表现为哪些现象？
3. 诗把失信、粗暴和关系失衡的直接责任指向哪里？哪些信息、投入、支持和时代条件使这段关系更难及时停止？

三问边界固定：Q1只收人物行动、关系阶段和认识变化；Q2只收诗中明确呈现的不幸处境及有边界的现代转述；Q3分为责任线与困境线，二者不画相互致因箭头。

## 四、教材与解释边界

- 教材依据：`Data/textbook_extract/选择性必修下册/01_U1_导语_课1_氓_离骚.pdf`。
- 课标依据：`Data/reference/curriculum/普通高中语文课程标准（2017年版2020年修订）_教育部官方版.pdf`。
- “蚩蚩”先按教材注释理解为忠厚的样子，不直接等同“装老实”。
- “贸丝/谋”能证明表面来意与真实来意有别，不能证明男子有计划地伪装完整人格。
- “将子无怒”能提示女子在安抚男子情绪，不能据此补写婚前暴力程度。
- “至于暴矣”先理解为粗暴，不擅自补写具体伤害方式。
- “亦已焉哉”写出停止判断，是否实际离开及现实退出条件未继续叙述。
- “恋爱脑”不作为人物标签。若学生提出，教师转换为“情感投入下的浪漫化解释/确认偏向”，并说明它不是粗暴原因。

## 八、逐章教学总谱

### 第一章　相识、求婚与婚期（P16—P26）

> 氓之蚩蚩，抱布贸丝。匪来贸丝，来即我谋。<br>送子涉淇，至于顿丘。匪我愆期，子无良媒。<br>将子无怒，秋以为期。

- 行动链：接近 → 求婚 → 远送 → 说明条件 → 约定婚期
- 连续章意：男子以贸丝为表面来意接近并求婚；女子远送、说明媒妁条件，又在安抚中约定秋期。
- 关键句：第2、5组；其余诗句保证释义和行动，不强行增加手法任务。
- 短活动：第一次看：这些行动给你什么印象？
- 活动问题：从“蚩蚩、贸丝、谋、无怒”中任选两处：只看第一章，你怎样理解男子的接近方式？
- 产出：原词：__________　我此刻的理解：________________；原词：__________　我仍想追问：________________
- 讨论后回收：憨厚、主动、热烈、执着，都可能是第一次阅读的真实印象。；“贸丝/谋”“无怒”留下了尚未解释完的细节。；等读完婚后经历，再回来判断这些细节的意义。
- 章末证据：完整重读本章；不用列表，一口气口述本章行动怎样连接。 

### 第二章　等待、占卜与迁嫁（P28—P38）

> 乘彼垝垣，以望复关。不见复关，泣涕涟涟。<br>既见复关，载笑载言。尔卜尔筮，体无咎言。<br>以尔车来，以我贿迁。

- 行动链：登墙望 → 不见而泣 → 既见而笑 → 卜筮 → 迁嫁
- 连续章意：女子的视线和情绪围绕复关迅速变化；卜筮无不吉后，她带着财物乘车迁嫁。
- 关键句：第2、3组；其余诗句保证释义和行动，不强行增加手法任务。
- 短活动：让等待拥有两种速度
- 活动问题：排列“望—不见—泣—见—笑—迁”，为前半和后半各设计一种速度、停顿与重音。
- 产出：慢下来的一处：__________　因为：________________；加快的一处：__________　因为：________________
- 讨论后回收：望—不见—泣：视线受阻，时间和声音都被拉长。；见—笑—言：信息突然改变，情绪快速释放。；迁嫁不是孤立事件，而是等待获得确定后的行动结果。
- 章末证据：完整重读本章；不用列表，一口气口述本章行动怎样连接。 

### 第三章　桑叶、斑鸠与回望中的劝诫（P39—P49）

> 桑之未落，其叶沃若。于嗟鸠兮，无食桑葚！<br>于嗟女兮，无与士耽！士之耽兮，犹可说也。<br>女之耽兮，不可说也！

- 行动链：桑叶丰润 → 劝鸠勿食 → 劝女勿耽 → 比较男女处境
- 连续章意：叙事暂时停下，回望中的女子由桑叶和斑鸠起兴，转向对情感沉溺及其不平等后果的劝诫。
- 关键句：第1、3组；其余诗句保证释义和行动，不强行增加手法任务。
- 短活动：桑叶首先让你看见什么？
- 活动问题：先写“沃若”的颜色、质地和生命状态，再提出两种可能联想；暂不选择唯一答案。
- 产出：感官词：__________ / __________；可能联想A：____________　依据：____________；可能联想B：____________　依据：____________
- 讨论后回收：桑叶先是可感的颜色、质地和生命状态。；青春、情感、关系都可以成为联想方向。；第四章“黄而陨”出现后，再用位置、对照和叙事筛选。

### 第四章　桑叶转黄与责任判断（P51—P61）

> 桑之落矣，其黄而陨。自我徂尔，三岁食贫。<br>淇水汤汤，渐车帷裳。女也不爽，士贰其行。<br>士也罔极，二三其德。

- 行动链：桑叶坠落 → 多年食贫 → 渡淇回忆 → 辨明责任 → 指出反复
- 连续章意：桑叶由丰润转为枯黄，婚后贫困和渡淇场景进入回忆；叙述者明确指出自己无过而男子反复失信。
- 关键句：第1、4组；其余诗句保证释义和行动，不强行增加手法任务。
- 短活动：哪些是事实，哪些是责任判断？
- 活动问题：把本章诗句放入“经历事实”和“责任判断”两栏，并说明判断由哪组对照形成。
- 产出：经历事实：____________________________；责任判断：____________________________；语言依据：____________________________
- 讨论后回收：食贫、淇水、车帷被浸，是叙述中的经历。；“女也不爽，士贰其行”直接辨明双方责任。；现代评价可以继续讨论，但必须先站稳诗中的事实和判断。
- 章末证据：完整重读本章；不用列表，一口气口述本章行动怎样连接。 

### 第五章　长期劳动、粗暴与孤立（P62—P72）

> 三岁为妇，靡室劳矣。夙兴夜寐，靡有朝矣。<br>言既遂矣，至于暴矣。兄弟不知，咥其笑矣。<br>静言思之，躬自悼矣。

- 行动链：多年为妇 → 早起晚睡 → 遭遇粗暴 → 家人讥笑 → 独自悲悼
- 连续章意：多年劳动被压进日复一日的早起晚睡；男子愿望满足后转为粗暴，家人不理解，女子只能独自反思悲悼。
- 关键句：第2、3组；其余诗句保证释义和行动，不强行增加手法任务。
- 短活动：把“多年”还原成一天
- 活动问题：用“原句证据｜现代生活转述｜诗中未写明”三栏，还原她的一天和她周围的支持网络。
- 产出：清晨：________　白日：________　夜晚：________；能否得到理解：________；诗中没有写明：________________________
- 讨论后回收：长期家务与早起晚睡，使一方持续承担生活成本。；粗暴与家人不解叠加，关系外的支持并未出现。；诗没有写她是否求助，也没有写具体退出条件；这些空白不能被想当然填满。

### 第六章　回望盟誓与作出停止判断（P74—P84）

> 及尔偕老，老使我怨。淇则有岸，隰则有泮。<br>总角之宴，言笑晏晏。信誓旦旦，不思其反。<br>反是不思，亦已焉哉！

- 行动链：偕老愿望破裂 → 自然边界反衬 → 回忆少年 → 核验违誓 → 作出停止判断
- 连续章意：女子将偕老愿望、少年欢笑与当下违誓并置，核验男子“不思其反”，最终说出“亦已焉哉”。
- 关键句：第4、5组；其余诗句保证释义和行动，不强行增加手法任务。
- 短活动：把“亦已”读出两种声音
- 活动问题：设计A“疲惫克制”和B“清醒决绝”两版：标出停顿、重音、速度，并为每版写一条经历依据。
- 产出：A版：停顿____ 重音____ 速度____ 依据____；B版：停顿____ 重音____ 速度____ 依据____

## 九、第一章双重观看

第一次阅读只问“这些行动给你什么印象”，允许憨厚、主动、热烈、执着等初始理解；不显示警告信号、伪装、恋爱脑或信息遮蔽。全文读完后才回看：

| 层次 | 内容 |
|---|---|
| 文本事实 | 表面来意为贸丝，真实来意为谋婚；“蚩蚩”是忠厚的外在印象；女子说“将子无怒” |
| 合理推断 | 可能存在初期印象管理；婚前印象与婚后行为形成反差 | 
| 文本不能证明 | 有计划地伪装完整人格；女子长期不知真实意图；“无怒”已达到婚前暴力 | 
| 现代工具 | 确认偏向、浪漫化解释；不是心理诊断、不是女性专属，也不是粗暴原因 | 

## 十、全文后的三项综合活动

### 活动一　关系与婚姻过程

> 相识议婚 → 等待成婚 → 迁嫁食贫 → 长期劳作 → 失信粗暴 → 家人不解 → 回望核验 → 作出停止判断

每一步必须回链至少一章；第三章劝诫不误写为新的故事事件。 

### 活动二　原句—现实转述—解释边界

按“表里差异、劳动与伤害、支持与停止”三组完成。现实语言不能直接抄诗句，也不能把“初期伪装、未及时识别”写成无争议事实或受伤者责任。 

### 活动三　责任线与困境线

> **责任线**：士贰其行 → 二三其德 → 至于暴矣 → 不思其反<br>诗把失信、反复、粗暴和违誓的责任指向男子，但没有解释他为何选择这样做。

> **困境线**：初期信息有限 → 情感和生活投入 → 单边劳动 → 支持缺失 → 停止更加困难<br>这条线只解释停止为何困难，不解释男子为何失信和粗暴。

> 她为何难以及时停止，与他为何失信、粗暴，是两个不同问题；困境线不能分担责任线中的责任。 

## 十一、从《氓》反推关系结构

讨论题：一段关系要避免走向失衡，需要哪些可以长期观察和验证的条件？只讨论作品或第三人称案例，不要求学生公开私人经历。 

课堂共同形成的观察维度：审慎了解、言行一致、权责平衡、相互尊重、可靠支持、清晰安全边界，以及可获得的求助渠道和退出保障。它们是由作品提出、仍需在现实中检验的维度，不是简单处方。 

## 十二、最终知识收纳

1. 故事与人物：六章叙事、关系过程、认识变化和责任判断。 
2. 字词与《诗经》：风雅颂、四言、赋比兴及本课重点古义和读音。 
3. 意象与写法：桑叶、淇水、赋比兴、对照、反复、叠词、呼告、时间压缩、时间回环、第一人称回望。 
4. 三问与方法：关系过程、现实处境、责任/困境；准确释义—行动叙事—声音情感—形式观察—证据判断—现实转换。 

## 十三、形成性评价与课堂安全

- 事实错误、字音和关键古义直接纠正；情绪不同不纠正，只追问诗句来源。 
- 开放回答按“有原句—推理连续—边界克制”评价。 
- 第五章及关系讨论默认允许匿名书写、不公开分享和第三人称回应。 
- 每个模块结束记录学生实际作品、负担和意外回应；未实施前不填“学生已经学会”。
