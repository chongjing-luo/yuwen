# 《氓》V5逐页无生试讲稿

本稿与V5完整母版及五个模块课件同源。每页只对应一个学生可见状态；台词中的学生回应均以条件分支书写，不虚构真实课堂已经发生。

## P1｜氓

- 模块：M1
- 页型：cover / opening
- 预计时间：1分钟
- 学生可见：氓<br>她怎样走到“亦已焉哉”？<br>反是不思，亦已焉哉！

【页码与模块】P1｜模块一·从旧故事走进初见
【连续课堂剧本】
【承接上一页】教师站在屏幕侧面，让标题和末句静置八秒，不用开场说明淹没诗句。
【教师原话】“先轻声读‘反是不思，亦已焉哉’。你听见的是疲惫、愤怒、清醒，还是暂时说不清？不用证明，只在纸角留下一个词或问号。”
【学生动作与等待】学生静默十秒后落笔；教师不点名检查情绪，只确认每个人拥有进入作品的方式。
【可能回应与接话】如果有人立即说‘觉醒’或‘渣男’，教师回应：“把它保存成猜想；我们要看六章能不能给这个词足够重量。”如果无人落笔，允许写问号。
【可观察证据】一个初始声音词或问号。
【明确切页句】“在走进这个更早的故事前，先从我们已经认识的关系故事出发。”

## P2｜你记得哪一种关系？

- 模块：M1
- 页型：prior / opening
- 预计时间：2分钟
- 学生可见：你记得哪一种关系？<br>选择最熟悉的一篇。<br>《静女》｜相遇与等待<br>《小二黑结婚》｜选择与阻力<br>《玩偶之家（节选）》｜婚内结构与离开

【页码与模块】P2｜模块一·从旧故事走进初见
【连续课堂剧本】
【承接上一页】教师把学生从结尾的陌生声音带回熟悉作品，只使用班级确已学过的材料。
【教师原话】“三部作品不需要全部回答。选你最熟悉的一部：选择最熟悉的一篇。 请先在记忆里找到一个人物行动或一句原文。”
【学生动作与等待】个人检索三十秒，同桌各用四十秒说一部作品；听者只追问“依据是什么”。
【可能回应与接话】可能出现‘真诚、选择权、尊重、经济和权力、外部支持’等回答。教师不排成标准答案，只把能由作品支撑的词写在板书边缘。
【可观察证据】一部已学作品、一处记忆锚点和一个关系条件。
【明确切页句】“这些故事把问题带到了关系内部。现在去听《氓》中的当事人怎样讲自己的多年经历。”
