# 《氓》首批I01/I02场景候选独立视觉与边界审查

## 一、批次结论

两幅候选均通过单图准入，没有P0、P1或P2。它们可以进入“独立裁切资产＋无图/入图页面A/B”阶段，但这不是最终PPT放行：候选图仍须证明在页面面积不超过25%时，确实提高学生对动作或空间的辨认，并且不压低原诗与问题的视觉层级。

| 候选 | P0 | P1 | P2 | P3 | 单图裁决 |
|---|---:|---:|---:|---:|---|
| I01 抱布而来 | 0 | 0 | 0 | 2类 | **APPROVE_FOR_PAGE_AB** |
| I02 送子涉淇 | 0 | 0 | 0 | 3类 | **APPROVE_FOR_CROPPING_AND_PAGE_AB** |
| 批次独立问题类 | 0 | 0 | 0 | 4类 | **通过单图准入，未获最终入页批准** |

批次P3按独立根因计数：小图人物身份辨认、布卷跨图连续性、I01静态姿态的功能收益、I02大留白缩放/空间辨认。

## 二、I01｜“抱布贸丝／来即我谋”

### 2.1 唯一教学功能与事实边界

画面只给出学生当下可见事实：M01双手抱着一卷天然麻布来到W01面前，两人相对站立。它没有把“来即我谋”画成隐藏交易或预谋欺骗，也没有以画面替学生解释“匪来贸丝”的转折。W01只是看向来者，未出现“她已经知道结局/已经认定阴谋”的表情或动作。

男子神情平静克制，无诡笑、斜视、黑影、藏物、反派色码或威胁姿态；女子也无恐惧、哭泣或后见之明。因此图像仍允许课堂执行原合同：先说“眼前看见什么”，再回原词找“匪”完成“所见—女子随后说明的来意”转弯。

### 2.2 逐项审查

| 项目 | 可核验证据 | 裁决 |
|---|---|---|
| W01身份 | 柔和椭圆侧脸、平眉杏眼、中分低髻、桑叶灰青交领衣、暖米内层与小朱砂系带均延续冻结锚 | 通过；真实PPT小图辨认列P3 |
| M01身份 | 方椭圆脸、直眉、顶部束发、普通青年体格、褐灰交领短袍、深色腰带、束口下装和低帮布履延续冻结锚 | 通过；无婚前换脸或反派化 |
| 布匹连续性 | 天然麻布色，圆柱卷、端面同心层、束带关系与冻结道具同属一套卷法；没有丝绸光泽、文字或交易标签 | 通过；与I02远景卷的尺寸感列P3 |
| 动作单一性 | 只有“男子抱布来到女子面前”这一动作；低矮夯土残墙只提供乡野位置，不形成第二剧情 | 通过 |
| 留白与裁切 | 人物集中在右半，左侧有大面积干净暖纸留白；人物全身和布卷未被边缘切断 | 通过，适合右图左文或独立裁切 |
| 文字/水印 | 无文字、箭头、编号、水印、印章、边框和答案 | 通过 |
| 越界叙事 | 无阴谋表情、隐藏货物、浪漫婚礼、后文暴力或结局暗示 | 通过 |

### 2.3 P3与入页验证

| ID | 风险 | A/B验证合同 |
|---|---|---|
| I01-O01 | 两人相对静立，画面能清楚显示“抱布”，但“而来”的运动性较弱；若学生只说“他在给她看一卷布”，图像未必比原诗增加动作辨认 | 不展示题句，先让学生用一个动词描述男子；若“抱/来”不能稳定出现，尝试更紧裁切或保留无图版，不为已生成而强留 |
| I01-O02 | 缩至页面25%后，侧脸细节可能不足，人物主要靠发式和衣色认出 | 以实际入页尺寸做W01/M01盲认；若身份漂移，不重画整图，先调整裁切面积，仍失败则退回候选 |

### 2.4 I01裁决

**APPROVE_FOR_PAGE_AB。** 单图事实和伦理边界通过；只有A/B证明它帮助学生更快区分“可见抱布动作”与“诗中随后说明的来意”，才可进入最终PPT。

## 三、I02｜“送子涉淇，至于顿丘”

### 3.1 唯一教学功能与空间边界

画面明确显示两人正在涉过灰青缓流水面：M01在前、W01在后，脚步落在可见浅滩石块附近；水面环绕脚部并产生局部波纹，足以支持“涉”而不是岸边散步。河对岸和远处低丘同时可见，形成“近岸—水中—彼岸—远丘”的空间层次。

图中没有箭头、虚线、编号、地图、地名或精确路线，不替学生完成“送—涉—至”三动词关系。两人保持前后距离和中性步态，无牵手、对视、依偎、婚礼服饰、花轿或旅游式欢快姿态；因此不是浪漫旅行海报。远丘只是概括性空间对象，不被图中文字宣称为精确的顿丘地貌。

### 3.2 逐项审查

| 项目 | 可核验证据 | 裁决 |
|---|---|---|
| W01身份 | 低髻、灰青衣、暖米裙层和纤细体态与冻结锚一致；神情平静，无夸张依恋 | 通过；小图脸部辨认列批次P3 |
| M01身份 | 顶部束发、方椭圆脸轮廓、褐灰短袍、深色腰带、束口下装、低帮布履与冻结锚一致 | 通过 |
| 布匹连续性 | 男子背后可见天然麻布卷的圆形端面和束卷体，方向因携行改为纵深透视；未变成包袱、华丽礼物或丝绸 | 基本通过；与I01的大小/卷层一致性列P3，不构成换道具 |
| “涉淇”可见性 | 两人双脚处于水中浅石间，水纹绕石与脚部；河面占据有效场景大部 | 通过 |
| 距离/顿丘感 | 对岸线和远处低丘可见，形成空间纵深；没有把丘画成城楼或宫殿 | 通过，属于艺术化示意 |
| 单一动作与复杂度 | 仅两人涉水前行；植被、石块、远丘均服务空间定位，无旁人、车辆和第二剧情 | 通过 |
| 留白与裁切 | 场景集中在左半，右半大面积空白；原图16:9，适合左图右文，但若整图缩小人物会过小 | 通过候选，必须先裁取有效场景并做A/B |
| 文字/水印 | 无文字、箭头、编号、水印、印章、边框和路线答案 | 通过 |
| 越界叙事 | 无精确地图、浪漫旅行、婚礼、奔逃、危险渡河或确定迁嫁 | 通过 |

### 3.3 P3与入页验证

| ID | 风险 | A/B验证合同 |
|---|---|---|
| I02-O01 | 原图右半为空白；若把整幅直接缩到单页25%，人物、脚步、水纹和远丘会随之过小，图像唯一功能可能消失 | 先导出保留“人物—脚下水石—彼岸—远丘”的独立裁切，再按实际入页面积测试；不能只把原图整体缩小 |
| I02-O02 | 远丘与河岸空间清楚，但学生可能只说“两人在过河”，未必感到“送得远/至于顿丘”的延伸 | A/B让学生用“送、涉、至”三个词复述行程；若图版不能比无图版更准确地连起三词，保留无图版 |
| I02-O03 | I02布卷为远景背负端视，I01为近景横抱；透视与携行方式合理，但小图中可能被看成另一个小包/席卷 | 输出I01/I02布卷同尺寸局部供新观察者判断是否同一道具；若不能，I02可删除布卷以避免非必要连续性干扰，或局部重做，不动人物和河景 |

### 3.4 I02裁决

**APPROVE_FOR_CROPPING_AND_PAGE_AB。** 单图已满足“涉淇可见、距离有层次、无路线答案和浪漫旅行”的合同；最终批准取决于有效裁切后是否仍能在PPT小图中看见脚下水势、对岸与远丘。

## 四、批次跨图一致性

1. W01在两图均保持低髻、灰青交领衣和暖米裙层；M01均保持顶部束发、褐灰短袍、束口下装和布履。未出现跨图换脸、换朝代或婚前反派化。
2. I01的“横抱近景布卷”与I02的“背负远景端视布卷”在材质、卷筒逻辑与天然麻色上可视为同一类固定道具；由于尺度和视角不同，仍须按I02-O03做同尺寸辨认，当前登记P3而非P2。
3. 两图均采用暖纸底、柔和侧光、低饱和手绘和低细节乡野，没有电影海报式大场面；构图一右一左，可为PPT文字提供方向互补的留白。
4. 两图都没有用图像直接交付语义答案：I01不证明“谋婚/欺骗”，I02不绘制三词路线。学生仍须回到原诗表达。

## 五、批准边界与后续要求

1. 当前批准对象仅为固定SHA候选源图，不得同名覆盖后继续沿用本报告；
2. 导出每幅独立裁切资产并登记尺寸、用途和SHA；I02必须保留人物脚下水石、彼岸和远丘三层空间；
3. C102、C103分别制作原无图版和候选入图版；图像面积原则上不超过25%，核心原文不得低于28pt，问题入口仍须第一眼可见；
4. A/B必须检验具体学生动作：I01先看动作再找“匪”；I02用“送—涉—至”讲清行程。若只是让页面更好看，候选退回；
5. 入页后重新检查裁切、文字对比、原诗主位、答案时序和相邻页重复；任一P0/P1/P2出现即返工；
6. 单图通过不授权生成图替代原诗，也不证明教学效果。最终是否保留须由学生接收审查和真实试教证据共同决定。

## 六、审查边界

本报告依据固定SHA源图、冻结角色圣经和设计规范判断单图准入。它不能证明真实投影后学生一定认出人物、布卷与远丘，也不能证明图像比原有无图页更有效；这些问题已明确留给实际尺寸裁切、页面A/B和试教观察。
