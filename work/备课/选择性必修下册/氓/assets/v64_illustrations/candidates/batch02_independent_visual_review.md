# 《氓》第二批I03—I05场景候选独立视觉与边界审查

## 一、批次结论

三幅图都没有文字、水印、反派化或现代影楼偏移，画风和色系也与冻结角色板一致；但三幅分别在自己的唯一功能上出现P2，不能进入页面A/B：

- I03把“乘彼垝垣”画成女子站在平地扶墙远望，墙没有成为她登上的观察位置；
- I04的两枝确为严格同枝状态，但裁切左缘残留无关车轮与车辕，污染物象比较；
- I05的车辕完整终止在画内却没有牵引者或动力，W01又扶着车站在水中，容易形成“女子独自拖/推车”的诗外事实。

| 候选 | P0 | P1 | P2 | P3 | 单图裁决 |
|---|---:|---:|---:|---:|---|
| I03 垝垣望复关 | 0 | 0 | 1类 | 2类 | **RETURN：重做站位/高差** |
| I04 同枝荣枯 | 0 | 0 | 1类 | 1类 | **RETURN：只需洁净重裁** |
| I05 淇水渐车帷裳 | 0 | 0 | 1类 | 2类 | **RETURN：消除无动力车与女子拉车歧义** |
| 批次独立问题类 | 0 | 0 | 3类 | 5类 | **DO_NOT_ADMIT** |

P3按每图独立观察根因登记，不与P2重复计数。

## 二、I03｜“乘彼垝垣，以望复关”

### 2.1 可见事实

W01位于画面右侧，脚掌完整落在墙后平地，身体没有站上墙顶或残墙高处；右手掌搭在墙顶，身体前倾并朝左方远望。残墙低矮、破损、夯土质感明确，远方开阔且M01没有出现。

因此本图能支持“扶着低墙向远处望”，也能支持“她没看见男子”；但不能支持“乘彼垝垣”中的登临动作和由登高取得视线的空间关系。墙在当前构图中只是扶手/遮挡物，不是她已经登上的观察位置。

### 2.2 逐项裁决

| 项目 | 观察证据 | 裁决 |
|---|---|---|
| W01身份/服饰 | 椭圆侧脸、平眉杏眼、中分低髻、灰青交领衣、暖米裙层和小朱砂系带与冻结锚一致 | 通过；小图辨认列P3 |
| 垝垣形制 | 低矮、残损、夯土质感，无城楼、女墙、砖砌宫墙或高台 | 通过 |
| “乘彼垝垣”站位 | 双脚在墙后地面，手扶墙顶，未登墙、未立于残墙较高基座，也没有可辨台阶/高差 | **P2 I03-V01**：唯一空间功能未成立 |
| “望”的方向/距离 | 身体和脸朝左，视线越过开阔平野，远方低地提供距离感 | 通过；小图视线方向列P3 |
| M01是否出现 | 画面仅W01，无男子剪影、远处人影或提前“既见复关” | 通过 |
| 情绪与边界 | 无夸张哭泣、跪地、绝望特效；不能从图直接得出悲剧结局 | 通过 |
| 留白/裁切 | 人物与墙集中右侧，左侧大留白可放文字；全身未裁切 | 通过源图构图 |
| 文字水印 | 无字、箭头、标签、水印、印章和边框 | 通过 |

### 2.3 最小返工

不需要改脸、服装、墙材质或视线方向，只需让“登临”可见：

1. W01双脚明确站在残墙较宽、较低的一段顶部，或站在紧邻墙体的残损夯土高基/踏步上；
2. 她的眼线应因高差越过墙体，不能仍是地面扶墙；
3. 保持低矮残墙，不得为了显示登高改成城楼或危险高墙；
4. M01继续不出现，情绪保持克制。

### 2.4 P3

| ID | 风险 | 后续验证 |
|---|---|---|
| I03-O01 | 实际入图小于25%时，W01侧脸可能主要依赖衣色和低髻辨认 | 用实际裁切做W01盲认；不能靠放大到压过原诗解决 |
| I03-O02 | “望”的方向在原图清楚，但大留白整体缩小会降低眼线和前倾姿态可见性 | 有效裁切须保留W01头部、墙体高差和足够远景；A/B要求学生能说出“站在哪里、望向哪里” |

### 2.5 I03裁决

**RETURN / P2。** 当前只能作为“扶墙远望”，不能按I03合同进入A/B。

## 三、I04｜“桑之未落／桑之落矣”同枝状态

### 3.1 同枝严格核对

两版桑枝延续冻结角色板：相同主干斜向和弯折、相同左侧无叶短分枝、相同三个成对叶节点和同一顶梢；两版均为7片叶，顶叶及上/中/下三组左右叶可逐一映射。黄版只改变颜色、含水感、轻微下垂与叶缘状态，没有换枝、换节点或增删叶。

同枝比较本身通过；阻断来自裁切污染：405×410图像最左缘保留了明显的木车轮局部和水平车辕。它们与桑枝没有教学关系，在小图中会形成突兀黑褐形状，并把I04与“车”的叙事错误连接起来。

### 3.2 逐项裁决

| 项目 | 观察证据 | 裁决 |
|---|---|---|
| 主干/分叉/节点 | 两枝结构逐层对应 | 通过 |
| 叶数/叶位 | 两版均7叶，可逐叶配对 | 通过 |
| 状态变量 | 青绿饱满对黄褐失水，叶缘和角度轻微变化 | 通过，不泄露“青春/婚变”等寓意 |
| 裁边污染 | 左缘露出车轮弧、车架和车辕，明显来自设定板邻近道具 | **P2 I04-V01**：无关物进入比较资产 |
| 背景 | 暖纸底总体一致，无文字和水印 | 除左缘污染外通过 |
| 小图可用性 | 两枝并排、尺寸相近、间距足，405×410可在PPT作为比较小图 | 结构通过；清洁重裁后再做实际尺寸检查 |

### 3.3 最小返工

只需从冻结设定板重新裁切，不生成新桑枝：

1. 左边界移到青枝外侧，彻底去除车轮、车架和车辕；
2. 保留两枝完整顶叶、全部7叶、下部短分枝与斜切枝端；
3. 两枝周围使用一致内边距，不让某枝更接近边缘；
4. 输出新SHA后核对背景没有残留邻近资产像素。

### 3.4 P3

| ID | 风险 | 后续验证 |
|---|---|---|
| I04-O01 | 405×410在实际PPT 25%面积内，叶脉与轻微下垂差异可能不如色差显眼，学生可能只说“绿/黄” | A/B先要求描述颜色以外的含水感、叶姿和叶缘；若只能识别色差，不应夸大图像的比较收益 |

### 3.5 I04裁决

**RETURN FOR CLEAN RECROP / P2。** 同枝状态合格，不得重生成；清除左缘车具污染后可直接复审。

## 四、I05｜“淇水汤汤，渐车帷裳”

### 4.1 可见事实与主要歧义

画面显示W01站在较深且有明显波浪的淇水中，左手提素布包袱，右手扶住车帷上缘；木轮小车半浸水中，素色布帷下部呈较深的湿污带，水浪直接拍到车轮与帷裳下缘。“渐”的主要对象可从水—车轮—湿帷关系中识别，且没有豪华婚车装饰。

但两根车辕向右伸出并完整终止在画内，没有牲畜、牵引者或任何画外延续；W01又站在车侧以手扶车。水面同时画出明显运动浪花。组合后最自然的视觉叙事是“女子独自在水中推/拖一辆无动力车”或“她在处置一辆停在河中的车”，这不是诗中写明事实，也不是I05唯一功能所需。缺失动力不是中性省略，而是造成了新的行动主体歧义。

### 4.2 逐项裁决

| 项目 | 观察证据 | 裁决 |
|---|---|---|
| W01身份/服饰 | 椭圆脸、平眉杏眼、低髻、灰青交领衣、暖米裙层和朱砂系带与冻结锚一致 | 通过；小图辨认列P3 |
| 车帷连续性 | 木轮、弧顶木框、素色布帷、低装饰与冻结车帷锚一致 | 通过 |
| “渐”的对象 | 帷裳下部明显变深，水浪贴近轮与帷下缘；包袱和衣裙也受水，但车帷仍是最大、最清楚湿物 | 基本通过；小图湿带可见性列P3 |
| 车的动力/行动主体 | 车辕完整露出并终止于空白，无牵引者；W01扶车站水中，画面暗示她独自拖/推或控制车辆 | **P2 I05-V01**：把未写明行动固化成事实 |
| 水势 | 灰青水面、车轮处浪花清楚，可支持“汤汤”；未出现翻车、溺水和救援 | 原尺寸可接受；临界灾难感列P3而不单独阻断 |
| 婚车/浪漫化 | 无红绸、花饰、华盖、婚服、笑脸或仪式队伍 | 通过 |
| 明确逃离/结局倒灌 | 有包袱但无门、目的地、男子驱逐或胜利出走姿态；然而独自控制车辆使“独行返归”倾向增强 | 主要并入动力P2处理 |
| 留白/裁切 | 人车集中左中部，右上留白可放文字；轮、帷和水关系完整 | 通过源图构图 |
| 文字水印 | 无字、箭头、标签、水印、印章和边框 | 通过 |

### 4.3 最小返工

目标是让图只回答“水怎样渐到车帷”，不回答“谁在拉车/她是否独自返归”：

1. 首选重构为车帷与水的局部空间：车身占主位，W01只在车旁/车内作为身份参照，不握车、不呈发力姿态；
2. 车辕应延伸出画外，不在画内完整终止，使动力主体保持未说明；或完全裁掉车辕端部，只保留轮、帷与水；
3. 不新增明确男子、车夫或牲畜来填补事实，因为诗句同样未指定；
4. 包袱若保留，应降为次要，不能与“独自扶无动力车”共同形成确定返归剧情；
5. 保持帷下湿带与水线清楚，水势不可升级成灾难现场。

### 4.4 P3

| ID | 风险 | 后续验证 |
|---|---|---|
| I05-O01 | 小图中帷下湿污带可能与布帷原有阴影混合，学生只看见“车在水里”而不能指出“渐”的对象 | 实际裁切A/B先问“水湿了什么、从哪里看出”；若不能指向帷裳，退回无图版 |
| I05-O02 | 原尺寸浪花较强，缩小后或能支持“汤汤”，但也可能被感知为危险涉水/受困 | 学生自由描述若大量出现“洪水、遇险、车被冲”，须降低浪花戏剧性，不以“汤汤”作为灾难化许可 |

### 4.5 I05裁决

**RETURN / P2。** “渐”的对象基本清楚、车帷身份也成立，但无动力车与W01扶车组合越过了中性示意边界。

## 五、批次回归通过项

1. I03和I05中的W01均与冻结身份锚一致，未换脸、换高髻或换华丽服装；
2. I03没有M01或远处男子，守住“不见复关”；
3. I04严格沿用冻结同构桑枝，未重新生成两枝近似植物；
4. I05车帷为素布木轮小车，无汉唐婚车、豪华装饰和现代车辆；
5. 三图均为低人物数、低背景细节、柔和纸本色系，无电影海报特效；
6. 三图均无文字、水印、答案标签、箭头、假古籍印章和边框。

## 六、再次复审与入页边界

1. I03只改站位/高差，不改已通过的人脸、服装、低矮夯土墙和空旷远景；
2. I04只从冻结板洁净重裁，禁止重新生成桑枝；
3. I05只消除车动力和W01拉/推车歧义，保持车帷湿带与水势功能；
4. 每幅返工产生新SHA后须单图复审；任一P0/P1/P2仍在，不进入页面A/B；
5. 单图清零后仍须导出实际入页裁切，并分别验证：I03“站位＋望向”、I04“同枝状态描述”、I05“渐的对象”；
6. 入图不得使原诗低于28pt、任务入口失去第一层级，也不得用图像替学生完成修辞或叙事结论。

## 七、审查边界

本报告只判断三幅固定SHA候选是否满足单图准入。它不把生成画当作先秦地理、车制或服饰史料，也不证明修复后的图一定优于无图页面；后者必须通过实际尺寸裁切、页面A/B和学生接收证据判断。
