## 二、I03 v2｜“乘彼垝垣，以望复关”

### 2.1 v1 P2关闭

v2中W01两只布履的完整鞋底均位于残墙顶部同一平面，脚下是连续、可承重的宽阔夯土墙顶；前方左侧残墙逐级降低，墙体与地面形成清楚高差。她左手轻扶较高残段，身体和脸朝左远望。画面现在能同时回答“她站在哪里”和“她望向哪里”，不再只是站地扶墙。

| 核查项 | v2证据 | 裁决 |
|---|---|---|
| 双脚与墙顶关系 | 双脚完整落在宽阔墙顶，鞋底下方有连续夯土承重面；不是透视重叠或脚仍落地 | **v1 P2闭环** |
| 垝垣形制 | 低矮、残损、夯土结构，有断口和高度变化；不是城楼、宫墙或危险高台 | 通过 |
| 望的方向/距离 | 头、眼线和躯干朝左，视线越过开阔平野；远景低、淡、连续 | 通过 |
| M01绝不出现 | 无男子、远处人影、剪影或“既见”提示 | 通过 |
| W01身份/服饰 | 椭圆侧脸、平眉杏眼、中分低髻、灰青交领衣、暖米裙层与布履延续冻结锚 | 通过 |
| 情绪与边界 | 姿态前倾但克制，无夸张哭泣、跪地或悲剧特效 | 通过 |
| 留白/无字水印 | 人墙位于右侧，左侧和上方留白；无字、箭头、水印、边框和答案 | 通过 |

### 2.2 P3与A/B

| ID | 风险 | 验证合同 |
|---|---|---|
| I03R-O01 | 墙顶很宽、可安全站立，能清楚表达“乘”；但实际小图若裁得过紧，双脚—墙顶—地面高差可能被切断 | 裁切必须同时保留双脚承重面、左侧下降残墙和少量地面；后排能指认“她站在残墙上”才保留 |
| I03R-O02 | 大留白整图直接缩小会降低眼线和远望方向可见性 | A/B要求学生不看题句先回答“站在哪里、看向哪里”；只说“一个女子站着”则退回重裁或无图版 |

### 2.3 I03裁决

**APPROVE_FOR_PAGE_AB。** v1站位P2清零；不得在入页时裁掉墙顶高差。

## 三、I04a/b/c v5｜同枝“沃若—黄陨”

### 3.1 裁切洁净度

三份资产已分别核验：

- I04a青枝：画面只含暖纸背景和完整青枝，无车轮、车辕、车架、黄叶或另一枝；
- I04b黄枝：只含暖纸背景和完整黄枝，无青叶、车具或邻近资产；
- I04c双枝：两枝完整并排，无左缘车轮/车辕污染，也没有文字或分隔标签。

青枝单图和双枝图左下极边有一个不足以辨认为物体的微小深色边缘像素/抗锯齿角点；它不形成车具轮廓、不引导叙事，在当前及PPT缩小尺寸下不可作为独立视觉对象，故不升级P2。若后续做透明抠图，可顺手清洁，但不阻断A/B。

### 3.2 双态同源

| 结构 | 青枝 | 黄枝 | 裁决 |
|---|---|---|---|
| 主干与下部短分枝 | 相同斜向、弯折、节疤和无叶短分枝 | 一一对应 | 同源 |
| 节点 | 顶梢及上/中/下三组成对叶节点 | 同位置、同层级 | 同源 |
| 叶数 | 7片 | 7片 | 同源 |
| 叶位/叶柄 | 顶叶及三组左右叶可逐片追踪 | 同一叶柄根部，姿态仅轻微下垂 | 同源 |
| 状态变量 | 青绿、饱满、较舒展 | 黄褐、失水、下垂和叶缘变化 | 合规 |

### 3.3 P3与A/B

| ID | 风险 | 验证合同 |
|---|---|---|
| I04R-O01 | 单枝资产只有175×285，源尺寸足以做小图，但不适合大幅放大；插值后叶缘和叶脉会发虚 | 按原生像素和页面25%上限控制显示，不做人为大幅放大；后排至少能辨叶姿和含水感 |
| I04R-O02 | 色差非常强，学生可能只说“绿色/黄色”，忽略含水感、下垂和叶缘 | A/B先让学生描述颜色以外的变化；若只能得到色名，图像比较收益有限，不强制入页 |

### 3.4 I04裁决

**APPROVE_FOR_PAGE_AB。** v1裁切污染P2清零；三份资产可分别支持先看青枝、再看黄枝、最后并排揭示的时序。

## 四、I05 v2｜“淇水汤汤，渐车帷裳”

### 4.1 v1 P2关闭

v2完全移除W01和包袱，画面只保留素布帷木轮车、水面和远岸。两根车辕从车体向左延伸并被画幅左边界截断，动力源明确保持在画外未说明；没有人物扶车、发力或控制车辆。因此不再暗示女子独自拖/推车，也没有通过新增男子、车夫或牲畜伪造动力事实。

| 核查项 | v2证据 | 裁决 |
|---|---|---|
| 人物与动力主体 | 无人物；车辕延伸出左边界，未在画内空终止 | **v1 P2闭环** |
| 车帷连续性 | 弧顶木框、木轮、素色布帷、低装饰与冻结锚一致 | 通过 |
| “渐”的对象 | 帷裳下部形成连续深褐湿带，水线贴近车轮和帷下缘；湿带是最大、最明确的状态变化 | 通过；实际小图可见性列P3 |
| 水势 | 浅灰青水面、低幅波纹与轮旁轻微扰动；无洪水浪花、倾覆和遇险感 | 通过，不灾难化 |
| 婚车/逃离叙事 | 无人物、花饰、红绸、婚服、队伍、目的地或确定出走 | 通过 |
| 单一功能 | 只显示水—车轮—湿帷关系，没有第二动作和情节 | 通过 |
| 留白/无字水印 | 车位于左中部，右上留白充足；无字、箭头、水印、印章和边框 | 通过 |

### 4.2 P3与A/B

| ID | 风险 | 验证合同 |
|---|---|---|
| I05R-O01 | 原图大留白若整体缩小，湿带和水线会随车体一起变小 | 有效裁切须保留整段帷下湿带、车轮入水线和左侧车辕出画关系；后排能回答“水湿了什么、哪里看出”才保留 |
| I05R-O02 | 帷下深色带也可能被当成泥污、原始阴影或旧布色差，而非水浸 | A/B先不说“渐”，让学生定位湿的对象和依据；若多数不能把湿带与水线连接，应强化湿/干边界或保留无图版 |

### 4.3 I05裁决

**APPROVE_FOR_PAGE_AB。** v1动力与女子拉车P2清零；A/B只验证“渐”的对象，不追问或补画动力主体。

## 六、进入A/B的共同边界

1. 当前批准仅授权导出实际入页裁切并制作A/B，不等于最终PPT放行；
2. I03裁切必须保留双脚、墙顶承重面和高差；I04不得放大到像素发虚；I05必须保留湿带、水线和车辕出画关系；
3. 图像面积原则上不超过页面25%，不得使原诗低于28pt或问题入口失去第一层级；
4. 不在图上加文字、箭头、标签或答案；
5. A/B分别检验：I03站位与望向、I04同枝状态描述、I05“渐”的对象；不能提高这些动作就保留无图版；
6. 入页后必须重跑完整视觉和学生接收审查，旧无图版PPT的放行结论不得沿用。

## 七、审查边界

本复审只证明固定SHA候选已清除单图阻断。它不把场景当作先秦建筑、车辆或地理史料，也不能证明真实后排一定看清细节或图版优于无图版；这些仍由实际裁切、页面A/B和试教证据决定。
