# 《氓》角色设定板CB01 v1独立视觉否决审查

## 一、结论

本设定板不是失败稿：W01和M01的核心脸型、发式、色系已经形成可用身份锚；人物数量克制，背景低细节，无文字、水印、边框或复杂剧情海报化，绝大多数单体也可裁切。

但它尚不能冻结为九幅场景的共同引用源。当前有3类P2：M01服装形制明显偏离已批准的“交领短袍＋布履”；两枝桑叶不是同一枝的荣枯状态；W01婚后阶段把未被诗句限定的具体桶具劳动写入身份锚。三项都会被后续场景反复继承，不能以整体画风协调抵消。

- P0：0类
- P1：0类
- P2：3类
- P3：3类
- 裁决：**返工，不得冻结，不得作为后续九图的唯一身份/道具引用源。**

计数口径：同一根因跨多个局部只计一个问题类；P3不重复计算P2。

## 二、七项逐项裁决

| 审查项 | 观察证据 | 裁决 |
|---|---|---|
| 1. W01跨头像、全身、四阶段是否同一人 | 正面与四分之三头像具有稳定的椭圆脸、平眉、杏眼和低髻；全身及“初见—迁嫁—婚后—回望”小像保持中分低髻、灰青衣色与纤细体态。婚后低头劳动像和回望侧像因角度、尺寸很小，主要靠发式和色系识别，但未达到换脸程度 | **通过身份连续性；P3小图测试。** 后续场景必须同时引用头像与全身锚，不能只参考四阶段小像 |
| 2. M01跨头像、全身、婚前婚后是否同一人 | 正面、四分之三、全身保持方椭圆脸、直眉、深棕眼、顶部束发和褐灰色系；婚前相向像与婚后背离像的发束、肩背和腰带体系一致。背面像本就不提供脸部识别，但姿态变化没有靠换脸完成 | **通过身份连续性。** 服装形制另列P2，不把服装问题误判为换人 |
| 3. 服饰是否有明显汉唐宋明或现代影楼偏移 | W01整体为克制交领、低髻、低饱和布衣，无华丽高髻或宫廷装。M01全身外袍接近踝部，宽袖、长身、黑色高帮靴明显偏离规范锁定的“褐灰交领短袍、深炭腰带、布履”；整体更接近泛汉服/影视古装青年，而非批准的概括性先秦乡野短袍系统 | **P2。** 不是要求考据复原，而是必须回到已批准的短袍、窄袖、布履和低装饰体系 |
| 4. B01/B02是否与M01可分 | B01脸较圆、蓝灰衣；B02脸更窄、嘴角上扬、土黄衣；与M01的方椭圆脸、重直眉、褐灰衣存在差异。三者都用顶部束发，在小尺寸下B02与M01仍可能因相近轮廓被混认 | **基本通过；P3小尺寸辨认测试。** 不构成当前冻结阻断，但后续I07不得把兄弟放大成主角 |
| 5. 布匹、车帷、桑叶是否可复用 | 麻布卷卷法清楚、背景干净；木轮小车与素色布帷关系可辨，未画成豪华婚车。两枝桑叶虽一青一黄，但主枝弯折、侧枝节点、叶片数量、叶位与朝向均不同：青枝右侧叶群和黄枝两侧下垂叶群无法一一对应 | **布匹、车帷通过；桑叶P2。** 当前不是“同一枝失水变黄”，而是“两枝相似植物”，无法支撑I04严格状态比较 |
| 6. 是否简洁可裁、适合PPT小图 | 米纸背景统一、人物和道具多数有独立留白、轮廓清楚，没有场景背景和特效；1536×1024足以作为不超过页面积25%的小图参考。女性头像之间、婚前双人像以及下方阶段像的安全裁切缝较窄，但仍可处理 | **通过；P3登记裁切安全与最终尺寸。** 它是设定板而非复杂海报 |
| 7. 有无文字、水印、越界叙事 | 图内无文字、编号、水印、印章、箭头或答案；没有阴险表情、殴打、围攻、出走等硬边界违规。W01婚后阶段却加入桶、长棍/搅拌或汲取动作，把“室劳”冻结为一种具体家务；这超出身份阶段只需通过衣色、袖口和姿态表达的范围，也会诱导I06复制未被诗句指定的劳动细节 | **P2。** 删除具体桶具动作，改用不限定职业/家务种类的劳作后姿态、磨损袖口或空手晨昏姿态 |

## 三、P0—P2阻断清单

| ID | 级别 | 位置 | 问题 | 为什么阻断后续场景 | 最小返工合同 |
|---|---|---|---|---|---|
| CB01-V01 | P2 | 右上M01全身及其服装体系 | 外袍近踝、袖身偏宽，配黑色高帮靴；与规范明确的“交领短袍、深炭腰带、布履”不一致 | 人物圣经一旦冻结，I01、I02、I05、I08会反复复制这套泛影视古装形制，使时代边界持续漂移 | 保留现有脸、发束、褐灰色板和体格；只重做衣长、袖宽、腰带与鞋。外袍改至短袍层级，鞋改低帮布履，不增加冠饰和纹样 |

| ID | 涉及对象 | 风险 | 后续验证方式 |

## 五、明确通过项

1. W01和M01没有通过换脸表达婚姻变化，基本身份连续性成立。
2. W01低髻、低饱和灰青布衣没有明显唐宋明宫廷化或现代影楼妆造。
3. B01/B02数量正确，没有增加父母、邻居或围观群体，也没有形成“全家围攻”。
4. 麻布卷天然、卷法清楚；木轮小车和素布车帷克制，无豪华婚车叙事。
5. 无阴险婚前表情、暴力场面、夸张哭泣、确定出走或胜利者海报姿态。
6. 无文字、编号、水印、箭头、答案、假古籍印章和装饰边框。
7. 画面是身份/道具集合，非电影海报式大场面；多数单体有可裁切留白。

## 六、返工后复审条件

下一版只需围绕三个阻断变量返工，不应重做已经成立的脸部身份：

1. M01保留脸、发束、体格与褐灰色，只改为短袍、窄袖和布履；
2. 生成严格同构的桑叶双状态，复审时必须能逐叶配对；
3. W01婚后小像删除桶和具体工具，仅保留同人、旧衣、轻微疲态或晨昏姿态；
4. 新文件产生新SHA-256后，原尺寸复核整板，并另做W01四阶段、M01多姿态、三男头像、两枝桑叶的实际PPT小尺寸裁切测试；
5. 新版只有P0=P1=P2=0，才可冻结为人物圣经并进入九幅候选场景生成。旧图保留为被否决版本，不得覆盖后冒充已通过资产。

## 七、审查边界

本报告判断的是设定板能否作为后续生成的身份与道具锚，不把生成图当作先秦服饰史料，也不宣称视觉一致已经提高学习效果。历史精确性、学生辨认速度和入页教学收益仍须分别通过资料边界说明、小尺寸盲测和无图/入图A/B比较验证。
