# 《氓》角色设定板CB01 v2独立视觉复审

## 一、结论

v2已闭环v1的两项阻断：M01改为短袍、窄袖、低帮布履；W01婚后小像由桶具劳动改为一般折布家务。后者有“靡室劳矣”的文本范围支持，不宣称诗中明确写了折布，作为非特指家务示意已达到人物阶段锚的边界，降为P3而非继续P2。

但桑叶双状态仍未闭环。青枝与黄枝的主干弯折、分叉节点、侧枝方向、叶片数量和叶位不能一一对应；它们仍是两枝相似桑枝，不是同一枝“沃若—黄陨”。I04的唯一教学功能正是控制物象身份、比较状态变化，因此该问题必须维持P2。

- P0：0类
- P1：0类
- P2：1类
- P3：3类
- 裁决：**DO_NOT_FREEZE**。只重做桑叶双状态；人物、服装、兄弟、布匹、车帷和画面结构不应再无故重生成。

## 二、v1三项P2逐项闭环

| v1阻断 | v2可核验证据 | 复审裁决 |
|---|---|---|
| CB01-V01：M01近踝宽袖长袍、高帮黑靴违背短袍/布履体系 | 右上全身像外袍已收至膝附近，袖口更窄；下装成为束口长裤，鞋为低帮布履。脸、顶部束发、体格、褐灰色板和深色腰带保持稳定 | **闭环。** 没有引入冠饰、纹样、华丽宫廷衣或现代影楼感 |
| CB01-V02：荣枯桑叶不是同一枝 | 青枝主干呈明显左弯再向上，右侧有成组大叶和不同高度的侧枝；黄枝主干更直，侧枝层级、叶数和叶位不同。青枝约有多组密集叶片，黄枝叶片更少；无法按节点逐叶配对 | **未闭环，维持P2。** 颜色和下垂差异不能补偿枝形身份漂移 |
| CB01-V03：桶和长棍把未限定劳动冻结为具体事实 | 桶和长棍已删除，改为W01在简单木案前折叠无纹素布；动作平常、无职业工具和额外人物 | **闭环为P3。** “靡室劳矣”支持一般家务劳动；折布仅作为非特指示意，不得在讲解中说成诗中明确事件，也不应成为I06唯一画面答案 |

## 三、桑叶严格对应审查

当前双枝未达到“同一枝形和叶脉体系”的冻结线：

| 对应层 | 青枝 | 黄枝 | 是否可一一对应 |
|---|---|---|---|
| 主干 | 底部向左上弯折，中段再转向上；轮廓有明显曲率变化 | 整体更直立，底部与中段弯曲节奏不同 | 否 |
| 一级分叉 | 中下部右侧、上部两侧形成多组不同长度侧枝 | 分叉位置和方向重新排列，右侧中部枝条关系不同 | 否 |
| 节点 | 青枝多个叶柄节点集中成密集冠部 | 黄枝节点更疏、层级更少 | 否 |
| 叶片数量 | 叶群更密，顶部和中右部有黄枝不存在的对应叶 | 叶片明显更少，部分位置改成新叶位而非同叶下垂 | 否 |
| 叶位/叶柄 | 多片叶向左右外展，叶柄角度各异 | 叶片总体下垂，但不是从青枝同一叶柄旋转/失水形成 | 否 |
| 可允许状态变量 | 绿色、饱满、上举 | 黄色、失水、下垂、边缘卷曲 | 这些状态差异本身正确，但对象身份未固定 |

最小返工不是“再画一枝更像的黄叶”，而是复制同一线稿骨架：主干、全部分叉、节点、叶柄、叶数和叶脉保持一致；仅改变色相、明度、含水感、下垂角和叶缘卷曲。若允许落叶，也必须保留空叶柄/落叶痕迹，使原叶位仍可追踪。

## 七、再次复审边界

1. 下一版只替换桑叶双状态，不应重生成已经通过的W01、M01、B01/B02、布匹和车帷；
2. 新PNG必须产生新SHA-256，旧v1/v2与报告均保留；
3. 复审必须同时查看整板，以及两枝同尺寸独立裁切、半透明叠放或交替闪切结果；任一主干、分叉、节点或叶位无法追踪，继续判P2；
4. 只有新候选P0=P1=P2=0，才可裁决FREEZE并进入九幅候选场景；
5. 即使角色板冻结，每幅场景仍须单图准入和入页A/B比较，冻结不等于插图已经提高教学效果。

## 八、审查边界

本复审只判断v2能否作为后续生成的统一身份与道具锚。折布的放行意味着它没有把人物阶段锁成无依据的具体职业或工具劳动，不意味着诗中明确记载折布。时代服饰判断也只针对批准的概括性先秦乡野边界，不把生成图当作服饰史料。
