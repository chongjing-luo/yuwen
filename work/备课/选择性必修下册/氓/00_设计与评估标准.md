# 《氓》V6全文逐页功能重构：设计与评估标准

本标准服从项目上位文件`work/备课基本原则.md`；本课专项规则只负责把通用原则落实到《氓》的六章原文、三问和课堂材料。

2026-08-13全量重审已解除导入及第一至第三章旧桌面冻结状态。当前重构页面以`12_氓_V6逐页功能压缩重构规格.md`为唯一执行规格；旧冻结凭证仅作历史基线。

## 1. 首要目标

学生通过一系列有内在联系的声音、空间、动作、意象、讨论和表达经历，逐步理解《氓》的叙事、人物、语言形式与复杂意义。课堂首先唤起体验，再让分析解释体验；教师不以连续讲述替代学生阅读，不以活动热闹替代理解证据。

完整母版不预设课时数。V5以六章原文30组诗句为主线；独立复核发现公开讲述时间不足后，天然时长调整为274分钟，以保证接力讲述、生活镜头、婚姻圆桌、同伴追问和可见修订真正发生，并在章末及综合活动结束处设置安全停点。以后形成的任何压缩版都必须从完整母版派生，不能留下缺少原文前提的知识结论。

## 2. 十二项原则

### 2.1 体验先于命名

先让学生听见、看见、等待、朗读、比较和表达，再出现“比兴、对照、时间压缩、主体性”等理性术语。术语只用于澄清已经发生的学习，不作为课堂入口。

### 2.2 感受不是标准答案

后台可以设计可能体验范围，但不得规定学生必须感动、愤怒或喜欢。学生没有预设情绪时，教师追问文本来源，不纠正情绪本身。

### 2.3 学习必须留下证据

每个关键学习节点都要完成：

> 体验触发 → 个人反应 → 文本追问 → 形成解释 → 表达/修订

证据包括原文标记、逐句口译、连续章意、朗读方案、解释假设、接力讲述、生活镜头、责任判断、停止判断后的现实阻力解释、婚姻提醒、检索结果和修订痕迹。

### 2.4 学生前台与教师后台分离

PPT只显示学生此刻必须看见的原文、视觉关系、问题、必要任务和活动后共同发现。教师目标、学情画像、方法论、分流算法和管理口号只进入教案与讲者备注。

### 2.5 剧本必须可以演出

讲者备注的主体是连续课堂剧本：教师台词、切屏、站位、板书、停顿、真实等待、学生可能回应、教师接话、证据出现和自然转场。结构化字段只能附在剧本之后，不能代替剧本。

### 2.6 以学生接收而不是教师发送为准

每个课堂节点必须回答四个问题：学生接收到了什么信息、参加了什么活动、可能怎样思考、形成了什么收获。教师“讲过”不等于学生“接收到”；PPT“出现过”不等于学生能够解释。每章必须按“整章在场—逐句释义与行动—关键语言—学生产出—完整重读与连续章意”闭合，任何脱离原文位置、缺少前提或无法留下证据的知识点均不得放行。

学生角色只作为后台压力测试。角色姓名、能力画像、预测误区和审计结论不得进入学生投影或教师课堂台词。

### 2.7 学生前台要有语文的质地

学生前台优先呈现人、动作、生活时刻、声音、原诗和自然提问。后台可以说“责任归属、解释强度和时代处境”，前台不以“责任线、困境线、关系结构、观察维度、现代生活转述、解释边界、共同回收”等研发语言组织课堂。标题与问题必须通过朗读测试：教师在课堂中说得自然，学生第一次听就明白；文学味来自贴近作品和人物，不来自华丽修辞。

### 2.8 参与必须进入意义生成

三问综合活动必须让全体学生经历个人准备、小组共作、全班表达、听众任务、同伴追问、返回原诗和可见修订。排序、找句和表格可以作为支架，但不能取代讲述、还原生活、表达判断和观点交锋。教师总结只能在学生产出后出现，并应保留学生原话和有证据的分歧。

### 2.9 每页必须有唯一且必要的意义

每页按`前页输入—当前困难—唯一功能—学生动作—可见产物—有界反馈—可见修订—后页调用—删除损失`登记。相邻页能够无损替代，或学生只看见若干知识点而不能说清本章此刻发生了什么，该页不得放行。页面意义必须决定学生前台、逐字稿、学习单落笔位和视觉层级，不能先有版式再补写目标。

### 2.10 学生能够第一人称复述接收变化

独立审查者逐页模拟学生，检查其能否说清：“我刚读了什么、做了什么、现在多明白什么、依据哪句或哪个字、我改了什么。”并非每页要求课堂公开背诵这五项，但材料与剧本必须足以让这条链真实发生。教师讲过、PPT出现和学生形成理解不得混写。

### 2.11 手法丰富以真实体验差异为准

教学手法从声音、字词、句法、空间、动作、意象、结构、证据、判断、表达和记忆等具体困难出发。连续页面不得只是“个人填空—同桌核对—教师公布—换笔”的改名版本；朗读、闭眼听辨、路线描画、撤答复述、卡墙、生活镜头、证据质询、圆桌和检索等手法必须各自造成不同的认知动作、互动关系和作品形态。具体选择参照`work/备课/语文课堂教学手法库.md`。

### 2.12 插图先证明功能，再追求美感与一致性

插图后置到全文页面功能冻结以后。每幅图须说明它帮助学生辨认哪一个动作、空间、时间或物象，以及学生将如何观察、比较或引用；只负责“好看”的图不进入课堂PPT。先冻结W01/M01角色设定板、先秦服饰、固定道具、色调、光源、镜头和画风，再生成场景图；人物漂移、事实误画、提前泄答或挤压原诗，至少判为P1/P2。具体规范见`work/备课/视觉与插图功能规范.md`。

## 3. 学生前台准入规则

允许显示：

- 此刻需要朗读、凝视、比较或标记的诗句；
- 帮助进入声音、空间、动作和意象的关系图；
- 学生当下必须回应的真实问题；
- 完成任务不可缺少的步骤、时长和产出要求；
- 讨论之后才出现的共同发现。

禁止显示：

- 学生角色、学情画像、教学目标和评价方法；
- “不填表、不概括、不抢答、不解释、不急着、读通即可”等否定式管理口号；
- “知识碎片、理解链、认知断点、硬门、机器校验”等设计术语；
- “责任线、困境线、关系结构、观察维度、现代生活转述、解释边界、共同回收、建线”等项目式和研究式语言；
- 分流档位、恢复阈值和后台支持算法；
- 活动发生前的标准答案；
- 删除后不影响学生当下学习的装饰性说明。

每个可见文本框执行“删除测试”：删去后学生仍能完成当下学习，则移入后台或删除。

|---|---|---|---|---|
| 一　问题与首读 | 三个待解问题与六章整体声音 | 留初始短答；不中断听读；抄一句停顿句 | 从“我大概知道主题”转向“我有待验证的猜想” | 三个初始猜想、一句个人停顿句或问号 |

| 七　知识收纳与终读 | 故事人物、字词、意象写法和阅读方法的可检索结构 | 先遮答检索再核对；最后一次完整朗读；完成退出条 | 从“看见答案就觉得会”转向“能从原诗重建” | 四组检索痕迹、最终解释、跨章依据与保留问题 |

## 5. 文本与解释边界

- 全诗六章，诗句、字音、词义与教材一致；
- 桑叶、淇水和“有岸/有泮”允许多义，但必须由位置、词变和语境支持；
- “淇则有岸”是空间/边界语言，不写成第三次明确渡水；
- 责任判断以“不爽、贰其行、罔极、二三其德、至于暴矣、不思其反”等直接证据为核心；
- 区分文本事实、合理推断和现代评价；
- 不把《孔雀东南飞》的礼教直接成因无证套回《氓》；
- 不以现代励志话语覆盖人物的历史处境和复杂感情。

## 6. 连续课堂剧本标准

每一实际页面均须有讲者备注，并至少包含：

1. 页码、阶段和预计时间；
2. 连续课堂剧本正文；
3. 教师可直接说出的逐句台词；
4. 切屏、站位、指向、板书、分发、朗读与静默动作；
5. 明确的阅读、书写、排练或讨论时间；
6. 至少一种可能回应和教师接话；
7. 现场沉默、误解或过度推断时的应变；
8. 学习证据；
9. 体验、思考、学习三轨；
10. 自然转场。

剧本使用“如果学生……教师……”等条件表达，不虚构具体学生已经说出某句话。真实授课可依现场调整，不能机械背诵导演本。

### 6.1 页面状态必须与剧本动作一致

- 复合问题保留统一措辞，但按A/B等不同判断任务拆成可见工作记忆单位；
- 问题页只组织独立生成、比较分歧和保存产出，回收页才允许核对共同答案；
- 备注中的等待、交流、抽样和转场秒数之和不得超过页面标称时间；
- 接力讲述、生活镜头、责任质询、现实阻力讨论、首章回看和婚姻圆桌分别使用专用脚本，不以“独立一分钟、小组两分钟”的通用模板代替真实任务；
- 每项综合活动明确台上与台下的同时任务；公开呈现后至少发生一次补充、质疑或改写；
- 教师不得连续复用“保留一处、修正一处、补回原句”等机械核对话术；
- 首次听读、章首朗读、章末重读、全文再读和最终朗读分别承担停顿、进入、重构、核验和收束功能，不复制同一套指令。

### 6.2 接收审计与学习单负担

接收审计只记录学生实际可接触的信息、实际参加的活动、可能发生的思考、形成的收获和可观察证据；不得把页码、页面类型和设计目标复述成“学生已接收”。学习单采用选择性记录：30组诗句都要能口译，关键句、个人停顿句、活动证据和修订痕迹必须落笔，其余诗句可只在教材旁批关键词。

## 7. 视觉与材料标准

- 视觉母题：桑叶荣枯、淇水行线、时间痕迹；不用泛古风情侣插画替代文本；
- 主色墨褐、暖纸、桑叶青、朱砂、旧金与淇水青；
- 标题原则上不小于34pt，课堂正文不小于22pt，来源不小于10.5pt；
- 四周安全边距不小于0.5英寸，相邻内容块间距不小于0.3英寸；
- 原文页完整、清晰、后排可辨；无溢出、遮挡、低对比度和孤字行；
- 学习单按体验顺序保存真实学习痕迹，不以知识点表格为骨架；
- 教案、学习单、PPT、讲者备注和逐页试讲稿同源或有明确页码映射。

| H33 | 各页动作秒数不超过标称时间，综合活动使用任务专用脚本。 |
| H34 | 学习单明确区分必须落笔、选择性记录和只需口译的内容。 |
| H35 | 三问学生前台不出现“责任线、困境线、关系结构、观察维度、现代生活转述、解释边界、共同回收、建线”。 |
| H36 | 三问标题、问题、指令和教师主要台词通过课堂朗读测试，不以抽象名词串联，不大面积复用同构句式。 |
| H37 | 三项综合活动均包含个人生成、小组共作、全班表达、听众任务、同伴追问、原诗核验和可见修订。 |
| H38 | 每名学生至少留下转折判断、生活处境句、责任判断和婚姻提醒四项个人证据。 |
| H39 | 婚姻圆桌在教师总结前完成；班级收束允许依据学生原话现场增删，不作为预先抄写的标准答案。 |
| H40 | 每一逻辑页均完成十五项功能合同，且唯一功能、学生动作、可见产物、可见修订、真实后用和删除损失不为空。 |
| H41 | 学生接收审查逐页通过第一人称复述测试：能说明发生了什么、怎样理解、依据何处和修改何处。 |
| H42 | 所有信息暴露渠道同步；教师台词、学习单、教材指令、纸卡、板书和图像均不得在学生生成前泄露核心答案。 |
| H43 | 每个模块完成“认知动作×社会结构×产物形态”去同质化审计；连续三页同构须证明必要性，否则返工。 |
| H44 | 独立视觉审查与独立学生接收审查均以同一组SHA-256冻结输入；任一P0/P1/P2即否决，平均分不得抵消。 |
| H45 | 插图逐幅通过功能准入、文本边界和人物一致性审查；全文功能未冻结前不批量生成场景图。 |
| H46 | 学生前台每项活动原则上不超过“主动作—反馈—修订”三步；超出时逐项证明新增理解，编号、签认、查重和状态管理不得遮蔽文学对象。 |
| H47 | 文学回忆和开放讨论先保证广泛学生表达，再由教师引用现场原话后置归纳；不得预填主题，也不得把分类、去重和评审全部转嫁给学生。 |
| H48 | 每个字词、声音、空间、意象或手法页面均有自然的故事回接句；每章只保留一次正式整体重建，重复排序、复位与旁白须删并。 |

|---|---:|---|

## 10. 真实性声明

机器检查只能证明确定性合同，代理审查和学生角色模拟只能暴露设计风险。未试教前不得声称学生已经学会、感动、享受或完成迁移。真实课堂必须另行记录学生作品、朗读变化、讨论证据、负担和意外回应，再决定压缩与迭代。
