# 备课三目标与实现机制（工作框架）

## 一、总纲

### 1.1 来源边界与暂定关系

“让学生学到更多有价值的知识、真正学懂、享受学习”是项目所有者早期为备课工作随手提出的方向性表达，**不是课程标准原句，也不是已经验证的完整教学目标理论**。本文件暂把它们整理成一套备课工作框架，后续可以依据课标、教学理论和真实课堂证据改写、合并或删除。

当前版本暂把三者理解为一条关系链：

- **知识学习**回答"学什么、学多少"（内容层）；
- **能够学懂**回答"知识怎样变成学生自己的"（过程层）；
- **享受学习**回答"这个过程的体验质量，使学生愿意持续投入"（体验层）。

享受不是娱乐化，而是学懂过程本身的体验质量：学生因为自己生成过、修订过、被听见过、被文学打动过而愿意继续。降低认知要求换来的"快乐"是流畅错觉（见 J7），不是享受。

### 1.2 备课方法内部的机制节点四层对齐

每个目标拆解为若干**机制节点**（K/U/J 编号，共 20 个）。每个节点必须对齐四层：

| 层 | 问题 | 形态 |
|---|---|---|
| 因果依据 | 为什么这样做会产生该结果 | 学习科学结论 + 项目原则 + 课标依据 |
| 环节落点 | 在哪个教学环节、哪个字段/产物上落实 | 九环节（S1–S9）中的具体设计字段与产物 |
| 强制点 | 什么机制保证它不被遗漏或冒充 | machine_check / design_trace / review_gate |
| 度量 | 怎么知道它生效了 | 桌面判据与课堂判据分账 |

**适用规则**：只有当一项内容明确在规定备课目标、教学活动、课堂体验、学习证据或教学效果解释时，才需要引用相应机制节点。资料实体、目录、采集协议、通用脚本、schema与工程检查器按各自契约验收，不因未引用K/U/J而被拒绝。节点映射用于检验教学规则是否说明了预期作用，不得反过来把本框架包装成一切工作的上位依据。

### 1.3 九环节

S1 单元与学期规划 / S2 教案与证据研究（文本研究为内部支持） / S3 教学设计 / S4 教学物料制作 / S5 质量审计与放行 / S6 课堂实施与观察 / S7 作业设计与批改反馈 / S8 命题组卷与学情诊断 / S9 反思与知识沉淀。

### 1.4 原则编号约定

下文 `P-N` 指 `work/methodology/lesson-preparation/备课基本原则.md` 第 N 条原则；`G-n` 指逐页功能审计六门（G1 前置缺失 / G2 功能重复 / G3 覆盖虚假 / G4 变化不可观察 / G5 产物孤儿 / G6 可无损合并）。

## 二、目标一：知识学习（学到更多、内容丰富）

**操作性定义**：一个知识点（KP）算"学到了"，当且仅当它走完四站闭环：**课堂有落点 → 作业有检索 → 测评有回收 → 掌握有记录**。"学更多"的前提是更多有价值的知识被精确界定，并被闭环追踪而不是一次性经过。

### K1 教什么先于怎么教（知识界定）

- **因果依据**：王荣生"教什么比怎么教更重要"；课标学习任务群规定了各学段的知识范围与学业质量水平；项目知识库（81 卡 + 28 图谱 + 5 册表）已把"教什么"证据化。没有这一层，课堂再精彩也可能在教低价值内容。
- **环节落点**：S2 产出"本课教级 KP 清单 + 解释边界"（消费知识卡）；S3 课程数据 `knowledge_refs` 引用 CARD/UNIT ID，每页 `literary_object` 绑定 KP；S7 作业每题绑定 KP；S8 blueprint 的 KP 权重来自单元图谱。
- **强制点**：machine_check——lesson schema 校验 `knowledge_refs` 必须解析到真实卡片，卡内"教"级 KP 每条有落点页或显式 defer（defer 必须给理由）。
- **度量**：桌面 = 四站覆盖闭合率；课堂 = 各 KP 掌握率与延迟保持率。
- **关联原则**：现有 43 条原则几乎全部关于"怎么教"，"教什么"由知识库线承载——两线在此节点汇合。这正是当前知识卡未被课件管线消费所断掉的第一环。

### K2 知识在文本位置生长（情境锚定）

- **因果依据**：编码特异性原则——知识在与习得情境相似的语境中更易提取；语文知识（字音、词义、句式、手法）的价值本来就在读懂具体文本，脱离语句的知识清单无法迁移到下一次阅读。
- **环节落点**：S3 每个知识落点页在相应原句处讲清；S4 学习单知识收纳区对应 KP 并注明出处诗句；全文结束后经"先检索、后回收"总结（P-4）。
- **强制点**：design_trace——落点页声明 `literary_object`（具体词句）与 KP 的绑定；machine_check——绑定非空且诗句在文本契约内。
- **度量**：桌面 = KP 情境锚定率（有具体诗句绑定的落点比例）；课堂 = 学生答题时引用原句的比例。
- **关联原则**：P-4（知识在相应文本位置生长）、P-2（原文是主线）。

### K3 检索与间隔（知识巩固排程）

- **因果依据**：检索练习效应（Roediger & Karpicke）——提取比重读更能巩固记忆；间隔与交错（spacing / interleaving）使知识在变化的时间与语境中反复激活，形成长期保持。
- **环节落点**：S7 作业以闭卷检索形式复现当日核心 KP（巩固层），单元作业交错复现前单元 KP；S8 单元卷覆盖本单元全部教级 KP，期中期末卷按遗忘曲线回投；S1 单元规划显式排程"哪些 KP 在哪些周被再次激活"。
- **强制点**：machine_check——作业包校验含闭卷检索题；blueprint 校验回投 KP 清单非空；design_trace——单元规划的复现排程表。
- **度量**：桌面 = 每个 KP 的激活次数（≥2 间隔分布）；课堂 = 延迟测验收率。
- **关联原则**：**缺口**——现有 43 条原则不含课后检索安排，此节点由 S7/S8 新机制承载，Phase C 落地。

### K4 知识网络化（纵向贯通）

- **因果依据**：图式理论——知识以网络组织时，新知识有挂靠点，提取路径多；课标"学习任务群"本身就是跨册递进结构。孤立的清单知识在遇到新文本时无法被调用。
- **环节落点**：S1单元规划引用图谱的上下游卡；S2内部文本研究提出关系边，G1教案裁决真正进入本课的上下游关系；S7延伸作业设计跨课文比较；S9反思更新班级知识地图。
- **强制点**：machine_check——课程数据的关系边引用真实卡片 ID；design_trace——图谱跨册关系字段。
- **度量**：桌面 = 卡间引用边数与跨册边比例；课堂 = 学生在新文本前主动调用旧知识的频次（观察表）。
- **关联原则**：**缺口**——现有卡片"纵向贯通"栏大量为空，此节点是被登记未执行的既有目标。

### K5 丰富受负荷预算约束（防过载）

- **因果依据**：认知负荷理论（Sweller）——工作记忆容量有限，材料多不等于学得多；"丰富"必须以学生实际经历的文本经验与思考量计，不以教师发送量计（P-1 的知识侧对应）。
- **环节落点**：S3 单页只承担一个主要认知对象（P-35），活动程序注意力成本显著低于语文收益（P-22）；S5 页面簇负荷累加审计；S7 作业总时长上限；S8 试卷容量与时长匹配。
- **强制点**：machine_check——单页主对象数、时间盒守恒、作业/试卷总时长；review_gate——页面簇疲劳审计。
- **度量**：桌面 = 单页主对象 ≤1 的比例、超时页数；课堂 = 负担反馈与完成率。
- **关联原则**：P-1、P-22、P-26、P-35、P-43。

## 三、目标二：能够学懂（理解真实发生）

**操作性定义**：学懂 = 学生能**用自己的话、带原文证据**说清"这句写了什么、人物处境怎样变化、前后怎样连接、我的判断依据是哪个字词"，并且**发生过一次亲手修订**。理解分四层：辨认 → 解释 → 连接 → 迁移。"教师讲过"和"学生懂了"是两件事（P-1）；"公共答案出现过"和"这个学生拥有了"也是两件事（P-41）。

### U1 生成先于告知（首答态保护）

- **因果依据**：生成效应——先自己尝试再获知答案，记忆与理解显著优于直接被告知；必要难度（desirable difficulties）——提取时的费力感恰恰是深加工的标志。答案先到，生成就不会发生。
- **环节落点**：S3 问题页设计独立生成时间与保存分歧机制（P-5）；首答态跨渠道保护：屏幕、教师台词、学习单、**版式本身**四个渠道都不提前泄答（P-16/34/42）；S7 作业先做后对答案。
- **强制点**：machine_check——首答页四渠道泄答扫描（前台禁词、版式等权、学习单分发时点）；review_gate——形成时刻沿"数据源→物理画面→台词→学习单→板书"时间线核对。
- **度量**：桌面 = 首答页渠道审计通过率；课堂 = 首答阶段学生笔迹/口头产出抽样非空白率。
- **关联原则**：P-5、P-16、P-34、P-42。

### U2 证据锚定（理解的文本根据）

- **因果依据**：自我解释效应（Chi）——学生为自己的判断寻找文本根据时才真正建构因果模型；语文学科特性的根本：理解的对象就是语言文本，"懂了"却指不出字词等于没懂。
- **环节落点**：S3 每页接收链五问（读了什么/做了什么/多明白了什么/依据哪句/改了哪里，P-19）；局部学习回接人物故事（P-24）；S5 审查者沿画面证明接收链。
- **强制点**：design_trace——`first_person_reception` 字段含"依据哪一句"；machine_check——字段非样板（反模板检查）；review_gate——接收链审查。
- **度量**：桌面 = 接收链非样板率；课堂 = 抽样学生能否用原词自证。
- **关联原则**：P-2、P-19、P-24。

### U3 校准后亲自修订（学懂的物理动作）

- **因果依据**：反馈模型（Hattie & Timperley）——反馈的价值在于触发下一步行动；理解是状态的改变，亲手修订一次胜过听十次正确答案；公共答案出现后不撤答，个人永远可以用"抄过了"冒充"会了"（P-41）。
- **环节落点**：S3 公开校准后撤答、个人末答/闭卷复述/带原文修订（P-41）；教师归纳后置、引用学生原话（P-23）；教师精讲放在学生生成之后最能有效被理解和修订的位置（P-32）；S7 作业批改反馈必须触发修订动作（错题订正带原文依据）。
- **强制点**：design_trace——核心 KP 的"撤答→个人末答"配置；machine_check——答案回收页先核对学生已有产出；review_gate——修订真实发生（学习单修订痕迹）。
- **度量**：桌面 = 核心 KP 个人末答配置率；课堂 = 修订痕迹率、末答抽样正确率。
- **关联原则**：P-23、P-32、P-41。

### U4 困难诊断 → 手法匹配

- **因果依据**：学不懂的根源通常是某类具体困难（字词、句法、空间、动作、结构、想象、证据、判断、表达、记忆）未被针对性处理；手法是困难的解，不是风格装饰（P-20）；维果茨基最近发展区——教学应落在"够得着+需努力"的困难上。
- **环节落点**：S2内部文本研究提出候选困难，G1教案裁决本课难点；S3每页 `unique_difficulty` 声明并匹配手法；S5审计困难-手法匹配度。
- **强制点**：design_trace——`unique_difficulty` 非样板且困难类型可归类；machine_check——反样板检查。
- **度量**：桌面 = 困难声明非样板率；课堂 = 该困难对应的作业题得分率变化。
- **关联原则**：P-20 及手法库 17 类映射表。

### U5 负荷管理（学不懂常因过载）

- **因果依据**：认知负荷理论——内在负荷（文本难度）不可减时，外在负荷（程序切换、材料切换）必须最小化；任务切换成本使"名义时间够用"不等于"认知闭环发生"（P-35）。
- **环节落点**：S3 单页一个主要对象、超三连续动作逐项举证（P-22）；相邻页无损合并审判（P-15/26）；S5 三级时间审计（单页/页面簇/整课）。
- **强制点**：machine_check——时间盒守恒、页面动作数；review_gate——页面簇累计疲劳审计。
- **度量**：桌面 = 三级审计通过；课堂 = 实际完成耗时 vs 预算偏差。
- **关联原则**：P-15、P-22、P-26、P-35（与 K5 同源，K5 管内容量、U5 管过程量）。

### U6 解释分层（防假懂）

- **因果依据**：认识论清洁——把推断当事实、把现代解释当作者原意，学生获得的是无法迁移也无法辨析的"假知识"；文本明写/教材解释/合理推断/现代延伸四档分开，学生才能知道自己的判断站哪一层。
- **环节落点**：S2内部文本研究建立候选解释边界，G1教案定稿；S3每页 `epistemic_status` 标注；S5审查越界（现实迁移不冒充作者原意）。
- **强制点**：machine_check——`epistemic_status` 枚举合法且非空；review_gate——解释边界审查。
- **度量**：桌面 = 标注率；课堂 = 学生答题时区分"诗里写了/我认为"的比例。
- **关联原则**：P-9。

### U7 反例诚实路径（学懂是全员的）

- **因果依据**：心理安全与参与公平——想不起、无新增、不同意、沉默是课堂的正常状态，若只有"说出新内容"一条路，未达到的学生只能伪装，理解监控失真，且长期损害学习动机；差异化教学原则。
- **环节落点**：S3 每页 `normal_counterexample` 为每类反例设计同等可见、可完成、无需伪造的路径（P-17）；讨论先人人表达再限公共数量（P-36）；全员参与与公共表达质量分别设计与取证（P-27）。
- **强制点**：design_trace——`normal_counterexample` 覆盖该页声明的反例类型；machine_check——反样板；review_gate——边界学生路径可见性。
- **度量**：桌面 = 反例路径非样板率；课堂 = 沉默/想不起学生的真实完成率（观察表）。
- **关联原则**：P-17、P-27、P-36。

### U8 理解闭环（生成→回收无孤儿）

- **因果依据**：理解需要完整的"生成→比对→校准→修订→后用"循环，断在任何一环，前面的投入都不构成理解增量；产物被真实调用是其意义凭证（P-6、G5）。
- **环节落点**：S3 每页 `next_use` 声明后用消费者且后页真实取回同一载体（G5 前向边、P-41）；S7 作业提供迁移变式（第四层"迁移"）；S5 审计孤儿产物。
- **强制点**：machine_check——next_use 前向引用与字段级对齐；review_gate——回收页真实取回核对。
- **度量**：桌面 = 产物后用真实消费率；课堂 = 作业迁移题得分率。
- **关联原则**：P-6、P-15、P-26、P-41、G5。

## 四、目标三：享受学习

**操作性定义**：享受 = 学生自愿持续投入的意愿，来自自主感、胜任感、关联感三种心理营养加上文学本身的愉悦——而不是来自活动热闹。判别式（P-22）：学生课后更容易复述活动手续而不是作品内容，即为假享受。

### J1 自主感（自己的材料进入课堂）

- **因果依据**：自我决定理论（Deci & Ryan）——自主性是内在动机的第一来源；学生用自己的文学记忆、自己的初稿、自己的判断进入课堂，与执行教师预制分类的课堂有本质体验差异（P-14）。
- **环节落点**：S3 导入用学生自己的阅读经历做材料（P-30）；核心活动让学生对文本作出自己的讲述、选择、解释、判断（P-14）；S7 作业延伸层保留选题自主权。
- **强制点**：review_gate——参与是否进入意义生成的审查（完成更多空格≠参与）；design_trace——`participation_path` 声明个人生成环节。
- **度量**：桌面 = 核心活动五要素齐备率（个人生成/小组共作/公开表达/听众任务/可见修订）；课堂 = 自愿发言面、自发补充行为。
- **关联原则**：P-14、P-30。

### J2 胜任感（进步可见）

- **因果依据**：胜任感来自"我能做到"的证据；接收链中"现在比上一页多明白了什么"使微小进步可感知（P-19）；支架后撤（教师先示范一处再让学生迁移，P-32）保证任务落在最近发展区——太易无成就感，太难则挫败。
- **环节落点**：S3 每页接收链含增量表述；支架设计先示范后迁移；S7 作业分层使每个学生有"够得着"的层。
- **强制点**：design_trace——`first_person_reception` 含新增/修正表述且非样板；machine_check——作业分层配置。
- **度量**：桌面 = 增量表述非样板率、作业分层层齐备；课堂 = 学生自我报告的"学会了"与实测掌握的一致性。
- **关联原则**：P-19、P-32。

### J3 关联感（自己的作品被听见、被使用）

- **因果依据**：关联需求是内在动机三大来源之一；作品被全班听见并影响后续进程，给学生"我的东西有用"的意义感——这同时是 U8 产物后用的体验面。
- **环节落点**：S3 公开表达阶段为听众配任务、公共作品精选真实差异（P-27/36）；S4 黑板长卷/卡墙以学生真实作品为主视觉（P-18 允许学生作品为主视觉）；S5 审计公共作品是否被后续真实调用。
- **强制点**：review_gate——公开作品后用核对；machine_check——听众任务字段非空。
- **度量**：桌面 = 公共作品被调用数；课堂 = 学生作品被引用时的注意与回应（观察表）。
- **关联原则**：P-14、P-18、P-27、P-36。

### J4 文学本身的愉悦

- **因果依据**：语文学科的独特享受源——语言的质地、人物的命运、悬念的展开；若某个问题确是学生视角真想知道、需要跨文本位置存证且能统摄目标与知识，它可以成为叙事悬念，但原文顺序、叙事/论证推进或任务链也可以构成更强主线（P-2 原文主线的体验面）；教师示范朗读、叙事性复述、文学停留提供学生自己达不到的经验（P-32）。
- **环节落点**：S2先裁决最适合本课的全课主线，贯穿问题按需设置；S3 保留首读/重读的完整文学经验；S4 前台文字通过课堂朗读测试（P-13）；S5 前台禁词扫描 + 朗读测试审查。
- **强制点**：review_gate——全课主线因果审查；有贯穿问题时再审查“想知道—跨段存证—最终回收”；machine_check——问题投影允许空列表但有项不得空白，另执行前台禁词扫描。
- **度量**：桌面 = 朗读测试通过率；课堂 = 自发回读、课后仍谈论作品（观察表信号）。
- **关联原则**：P-2、P-13、P-32。

### J5 节奏多样（单调是享受的第一杀手）

- **因果依据**：注意力随重复同类刺激衰减；全课节奏拥有独立否决权（P-33）——认知动作、感官通道、社会结构、作品形态、情绪五维度连续同构产生模板疲劳；表面换标题不换底层协议仍计同构（P-20）。
- **环节落点**：S3 手法选择考虑全课节奏分布；S5 五维节奏矩阵审计（连续三页三维同构判 P2）。
- **强制点**：machine_check——节奏五维扫描；review_gate——去同质化矩阵人工复核。
- **度量**：桌面 = 同构连续段数（应为 0）；课堂 = 中后段课堂投入度维持（观察表）。
- **关联原则**：P-20、P-33。

### J6 心理安全（不怕错）

- **因果依据**：心理安全是冒险性学习（说出不成熟想法、公开修改自己观点）的前提；伦理边界（不把人物困境写成人物责任，P-9）同时保护讨论中真实经历相似处境的学生。
- **环节落点**：U7 的诚实路径同时服务本节点；S3 讨论规则先建立"可以不同意、可以保留"；S6 观察表记录课堂安全信号。
- **强制点**：machine_check——备注受害归因句式扫描（既有伦理红线）；design_trace——反例路径。
- **度量**：桌面 = 伦理扫描通过；课堂 = 不确定回答的自愿尝试率。
- **关联原则**：P-9、P-17（复用 U7）。

### J7 流畅错觉防线（享受必须来自真实胜任）

- **因果依据**：流畅错觉——加工的轻松感被误判为掌握；"看见答案后答得快"不是学习增益（P-38 的 A/B 撤图逻辑）；把课堂变顺畅、变热闹的多种手段（提前给分类、版式代学生完成任务、娱乐化活动）都以牺牲生成为代价，制造假享受。
- **环节落点**：S5 插图与活动的增益判据必须是撤答/撤图后的独立表现；S6 观察表区分"活跃"与"生成"；S9 反思警惕"这节课很顺"作为质量证据。
- **强制点**：review_gate——A/B 或撤笔回测设计存在性审查；design_trace——活动增益判据字段。
- **度量**：桌面 = 增益判据配置率；课堂 = 撤答后独立表现 vs 公开答案时的表现差。
- **关联原则**：P-12、P-22、P-38。

## 五、张力调和

三目标间存在结构性张力，裁决规则如下（理念贯彻的精髓在于处理张力，而非单目标最大化）：

| 张力 | 裁决节点 | 规则 |
|---|---|---|
| 丰富 vs 负荷 | K5 / U5 | 丰富以学生实际经历的文本经验计，不以材料量计；超预算的"多"判为缺陷而非优点 |
| 享受 vs 流畅 | J7 | 享受从学懂来，不从降低认知要求来；牺牲生成的顺畅是缺陷 |
| 挑战 vs 挫败 | J2 + U4 | 任务落在最近发展区：先诊断困难、配手法、给支架，而不是取消困难 |
| 全员 vs 深度 | U7 + P-36 | 先保障人人真实表达，再限制公共作品数量；两者分别设计、分别取证 |
| 个人生成 vs 教师讲授 | U3 + P-32 | 教师不包办也不退位：生成在前、精讲在后置、归纳引用学生原话 |
| 原文主线 vs 知识收纳 | K2 + P-4 | 知识在文本位置生长，全文后先检索后回收；收纳不得截断阅读 |

## 六、诚实边界：两本账

三目标的**最终判据在真实课堂**（P-12）。本机制文档定义的一切桌面判据，证明的是"设计条件具备"，不是"效果已发生"。两本账分开记录、不得混写：

- **桌面账**（设计条件）：本文件每个节点的桌面度量，由校验器与审查产生，写入评估报告。
- **课堂账**（效果证据）：每个节点的课堂度量，来自试教观察表、学生作品、作业与测评数据；未发生真实试教前，课堂账为空且明确标注。

系统的工作是把因果条件全部工程化，使课堂中三目标发生的概率最大化、可观察、可归因、可迭代。

## 八、修订规则

1. 在本备课框架内新增节点，需给出生效因果依据、教学落点、强制点与度量四层，缺一不收；
2. 节点变更（合并、拆分、删除）须记录原因与影响的下游条目；
3. 本文件与原则注册库（`work/principles/registry.yaml`）的映射由 `scripts/checks/validate_principle_registry.py` 机器核对；
4. 课堂账数据进入后，可以按节点提出归因假设，驱动 S9 反思与原则修订；节点只能帮助组织解释，不能凭节点标签证明因果已经成立。
