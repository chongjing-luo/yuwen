# PPT 制作操作手册（三层方法论 · 裁决版）

## 一、四源分工

| 来源 | 贡献 | 使用方式 |
|---|---|---|
| 通用版方法论 | 认知科学底线（Mayer 12 / Sweller / CRAP / 格式塔 / Alley / Tufte）与数值参数 | 底线，任何场景不得违反 |
| 语文版方法论 | 页面功能四分法（文本/任务/资源/反馈）、课型差异、批注与任务页规范 | 学科约束，覆盖通用版的美学自由度 |
| 项目实践层（视觉规范 + V6.6 构建器 + 审查判例） | 最严格可执行标准：首答态保护、以静代动、B0/B1/B2 三态、字号下限、设计系统 | **优先级最高**——教学场景判例 > 通用数值 |
| 外部 skill（pptx / nature-paper2ppt） | pptxgenjs 工程细节、渲染 QA 环、证据布局学（hero 主导 + 窄解释栏 + 非对称分栏） | 工程与质检层 |

冲突时裁决顺序：**项目实践层 > 语文版 > 通用版 > 外部 skill**。

## 二、字号与可读性（统一裁决线）

通用版 L3 正文 18-22pt 面向会议室投影；教室后排距离更远，判例反复出现的修复线更高（chapter2_visual_v8：核心释义 22pt 起步）。**语文课堂统一取项目线**：

| 元素 | 下限 | 依据 |
|---|---|---|
| 原文诗句（核心文本） | **28pt**（≤2 行 39pt / ≤4 行 32pt） | 视觉规范 + v66 poem() 实测 |
| 短语卡/随机散卡 | **26pt** | ART_RANDOM_FONT_SIZE 判例 |
| 产物槽标题/文化释义 | **22pt** | chapter2_visual_v8 修复标准 |
| 页标题 | 36pt（>20 字降 31pt），标题:正文层级差 ≥1.4× | v66 + CRAP |
| 标签/页码/模块名 | 14.5-15.5pt（非内容性） | v66 base() |

规则：**字号是内容的函数不是剩余空间的函数**——核心文本（学生必须读的原文、要生成的产物）永远拿最高档；指令、流程、注释降档。指令字号压过产物字号 = P2（判例 N022）。

## 三、色彩系统（起点 → 课文派生）

1. 先读S3 `visual_source_profile`。教材已有与本课相关的配图、人物肖像、题名字色、纸本底色或图形语言时，以它们作为课文级色板和图形系统的首选来源；只提取色彩关系、人物锚和形式气质，不复制教材水印、页码、印刷噪声或无关插图。
2. 教材缺乏有效视觉依据时，才从通用气质预设或文章类型建立补充色板；必须在S3说明为什么这一类型与作品的时代、声音、情感和页面功能相合，不能任意换皮。
3. 主色支配、辅助色托底、强调色克制。一个物理画面的同时竞争色通常不超过三种，但原文批注、真实图片和必要状态色按功能裁决，不以机械计数破坏证据。颜色不固定绑定“语言/结构/情感”，语义映射由本课一次定义后全程保持。
4. 教材印刷色不能直接保证教室投影可读。S4可以校正明度、饱和度和对比度，但须保留原色之间的关系；浅底正文保持深墨色，深底正文保持高对比暖白，任何风格一致都不能压低原文与任务可读性。
5. 深浅节奏由S3物理画面功能决定。沉静、终读或章节转折可用深色或大留白，但不为追求节奏机械交替。60-30-10只作视觉支配参考，不替代页面功能。

## 四、版式与布局

1. **标题先明确、再有味**：主标题先让学生在三秒内识别页面对象或职责；作者、背景、体裁、用典、活动和作业不以隐喻或悬念藏起来。文学意味放在副标题、引文、节奏和画面中。问句标题只在本页确有学生探究时使用。断言式标题仍服从N-04：后置完成态/讲解页可用完整判断句；首答态只直接命名文学对象或保留不泄答的真实问题。
2. 非对称分栏（nature skill）：拒绝默认 50/50；证据主导 70/30、75/25；图随内容走，几何服务证据——语文课"证据"= 原文与学生作品，原文卡与现场作品永远占主导，解释栏收窄。
3. 视觉 motif 唯一且全程重复：v66 = 左缘 0.15" 章节色条 + 左上模块名 + 右上页码；禁止标题下划线（AI 生成物标志，外部 skill 铁律）。
4. 具体版式不从封闭模板家族中选择。S3冻结内容对象、语义关系、共视/分时、主次层级、连续锚点、信息状态，并为每个物理画面冻结准确可见内容、构图关系、阅读路径、空间比例和配图裁决；S4根据真实文字长度把这些关系落实为精确坐标，运用分组、分层、对齐、并置、连接、突出、就近注释、留白与全局回归完成画面。多样性没有数量配额；连续三页底层协议同构判 P2（A-T17），应退回S3重审学习机制与信息结构。正文文字通常左对齐，仅标题、诗行或经S3说明的焦点对象可居中。
5. 版式即泄答渠道（P-42）：首答态材料等大同色随机散放，不用行群/两栏/视觉重心暗示答案；版式替学生完成任务至少 P1。
6. 留白既服务文学停留，也服务共同可读。任务页只放当下必要的问题与材料，不预放答案。原文长度、要点数和栏数没有一刀切硬门：先保证段落、句群与诗意上下文完整，再用真实投影字号、焦点数量和学生动作检验上限；无法兼得时退回S3拆分，不能用省略号破坏语义或缩字塞入。

## 五、语文课页面类型速查

页面分类有两个正交维度：**呈现角色**回答“这一页在整套课件中主要做什么”，**内容对象**回答“页内有哪些可被组织的东西”。前者每页一个主角色，后者允许主次并存。二者都不是固定模板，具体几何仍由S3冻结的语义关系、显示约束和真实文字长度生成。

| 角色组 | ID | 页面角色 | 主要职责 | 标题与视觉重点 | 禁用边界 |
|---|---|---|---|---|---|
| 定位结构 | PG01 | 标题页 | 明确课题、作者和第一视觉锚点 | 课题直接居主位，可用副标题增添气息 | 不上教学目标、方法口号和后台理念；不伪挂KID |
| 定位结构 | PG02 | 导航页 | 显示路径、当前位置或课时关系 | 路径与当前位置清楚，不预告结论 | 短课不为完整性机械加页，不泄答、不伪挂KID |
| 定位结构 | PG03 | 章节（子标题）页 | 标示真实阶段、文本范围或对象转换 | 子标题直接，允许克制原句或图像 | 不以诗意标题掩盖学习对象，不承载正文墙或伪挂KID |
| 文本与知识 | PG04 | 主干文本页 | 沿原文、篇章和核心证据推进理解 | 原文/证据主位，释义分析依附并分时 | 不把背景、典故和程序挤到原文不可读 |
| 文本与知识 | PG05 | 支撑页 | 独立讲清作者、背景、体裁、典故等必要知识 | 可用肖像、时间线、地图、古籍等差异构图 | 必须有触发页和返回页；无消费者即删除 |
| 行动与反馈 | PG06 | 活动页 | 组织一个可执行主动作及必要材料、产物落点 | 文学对象和主动作清楚，操作区真实可用 | 多个主动作、步骤墙、程序压过文本 |
| 行动与反馈 | PG07 | 作品与反馈页 | 让现场作品、回应和修订成为共同对象 | 学生作品第一，反馈与标准第二 | 不用预制答案冒充学生作品 |
| 收束与延伸 | PG08 | 总结收纳页 | 重建全文、知识、证据和方法的整体关系 | 结构关系与回指原文清楚 | 不用教师总表替代前面的形成过程 |
| 收束与延伸 | PG09 | 作业页 | 发布课后/跨课时任务及成果、条件、评价和后用 | 任务对象与成果要求第一 | 不只列题号，不缺提交与评价条件，不提前给答案 |

角色裁决只问三件事：学生第一眼面对哪一类对象；当页主动作是什么；删页后首先损失什么。三者指向同一角色时才成立。其余东西按注册表登记为内容对象：课题与路径定位、完整文本基底、当前文本焦点、知识注释、问题与任务、证据与材料、学生作品、校准与反馈、整体收纳。页面角色不规定卡片数、分栏数或固定配图；无法判定主角色时先重划语义边界，不设“综合页”兜底。

页面的常见连接关系是：`PG01? → PG02? → [PG03? → (PG04 | PG05 | PG06 | PG07)*]* → PG08? → PG09?`。问号表示可选，不是固定顺序模板。PG05必须回到后续PG04或真实消费它的页面；PG06产生的公共作品若成为新的第一注意对象，后续改用PG07；PG08不得收纳未在前页学过的结论，PG09不得把未学内容包装成巩固作业。

支撑页采用“岔出—讲清—返回”三步：S3登记触发来源、返回目标与返回用途；S4用稳定页眉、小型来源锚或回返点提示它属于支线，但不把后台术语上屏。若一个词只需一句就近注释，不另开页；若作者、背景、体裁或典故具有独立结构，塞入主干会拥挤且删除会损害理解，则开独立支撑页。支撑页可以与主干页风格不同，但必须保持同一字体系统、课文色板、人物/物象锚和页码导航。

AI生成内容必须标注工具与用途，不得作文本原貌证据。

## 六、构建工程规范（pptxgenjs）

画布 13.333×7.5"（LAYOUT_WIDE 自定义）；字体 Noto Serif CJK SC（标题/诗行）+ Noto Sans CJK SC（正文）；多行文本逐项 `breakLine: true`，不用手写 •；对齐时 `margin: 0`；圆角矩形才可用 rectRadius 且不叠矩形贴片；阴影 offset ≥0；色值 6 位无 #；渐变不支持（用背景图）；charSpacing 做字距。**每页恰好1条备注，逐字投影S3该物理状态的真实剧本**（物理画面是剧本最小单位，P-40）；S4只能补不改变教学含义的设备操作提示。构建器内置validate：页数==合同target、备注数一致、对象不越画布（±0.01）。

## 七、QA 渲染环（首渲染必有缺陷）

pptx skill 的 QA 纪律与项目双审一致并补足工程面：

1. 生成 → soffice 转 PDF → pdftoppm 逐页 PNG；
2. **新鲜眼检查**（非作者视角）：子代理按清单找问题——重叠/溢出/裁切、低对比、间距 <0.3"、边距 <0.5"、版式错配、占位残留、**字号低于 §二 下限**、首答态泄答（版式/标题/箭头/配色暗示）；
3. 一轮零发现 = 检查力度不够，重查（P-29）；
4. 修复后**复验受影响页**（一修常引一新问题）；
5. 全部缺陷入审查 JSON（页面/证据/严重度/可执行修复），进入 S5 双审。

## 八、内容分块与整体逻辑（教学 PPT 的密度治理）

教学 PPT 与其他 PPT 的根本差异：内容总量不可压缩（原文、任务、知识、作品都要呈现），因此**简洁的单位是"单屏"而不是"整套"**。四步法：

1. **内容分流**（先分流再分块）：屏幕只放"此刻必须共同面对的"（原文句、开放问题、学生作品、共同发现）；讲解串联归口头，个人留存归学习单，生成中的结构归板书。判据：删掉屏幕上这条内容，学生的认知动作是否断裂？不断裂就移走（channel_split）。
2. **按语义场景分块**：每块 = 一个组织意图所需的完整内容。多个知识点若同属一个段落、诗句组、证据链或比较场，并需要同一主要加工动作和共视关系，就应留在同屏；焦点、信息状态或学生动作改变，或者真实字号下无法共同阅读，才拆。太碎判据是上下文断裂、原文和知识被迫跨页往返或学生说不出这一页的整体对象；太大判据是出现两个互不依赖的焦点或持续切换加工动作。长文本按意义单元切，不按等长切。**块数由语义边界、理解变化和信息状态共同决定。**
3. **整体逻辑靠骨架与节奏，不靠单页容量**：①整体—局部—整体节奏（P-2），安全停点"先检索后回收"地把碎片知识重组成结构；②持续定位系统（章节色条+模块名+进度，全程不变）；③可携带结构单元（章卡在后章与综合页被真实取回）；④每页故事回接句（story_return 挂回主线）；⑤只在G1确有贯穿问题时，把已批准问题落实为“提出—存证—回收”的叙事弧；问题为空时服从原文或任务主线，不为PPT模板造问。
4. **视觉密度管理**：每个信息状态保持一个主焦点，其余对象按S3层级降档——多内容不等于多焦点；字号是内容的函数（§二）；分组靠语义邻近、层级和必要连接，警惕程序界面化。数字预算只作溢出预警，不能凌驾于完整段落或诗句关系；最终同时通过语义完整下限和共同可读上限。密度与深浅交替；需要保护首答或改变焦点时分时呈现，不以动效把同一状态无故切碎。

**检验法**：遮住页码与活动标题，请学生按实际顺序复述"读到哪、这句怎么连、故事推进到哪"——复述出连贯整体 = 分块成立；复述出碎片手续 = 重分块（连续理解审计，A-T15/T12）。

## 九、跨课文复用（主题抽取）

跨课文只复用工程参数、字号底线和经过证明的几何函数，不复用课文皮肤。每课从S3 `visual_source_profile`生成课文级主题：色板、人物/物象锚、图形语言、图片风格、字体气质和事实边界；同单元确有共同教材视觉时可复用其父主题，再为本课覆盖人物与强调色。这样减少重复设计时间，同时避免不同作品被压成同一套模板。

## 十、不做的事（空白点裁决）

- **PPTX 原生动画**：不使用。项目"以静代动"——稍后出现的信息拆成独立物理画面（B0 首答 / B1 中间 / B2 校准），可审查、可审计、防抢答（P-34/P-40）；动画至多 fade 且仅引导注意力。
- **图表可视化**：Tufte 规则备用（通用版第十章），语文判例暂无图表页；结构分析优先 drawio 流程图转图。
- **教师手工改页保底**：轻量规范未立（登记待办）——手工改动破坏同源性（P-11），短期以"改数据源重新生成"为唯一路径。
