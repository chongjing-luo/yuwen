# 语文课堂教学手法库

## 一、选法原则

先诊断学生为何读不进去，再选手法。手法的价值不在名称新颖，而在能否让学生以不同方式接触文本、形成自己的材料、听见他人并返回原文修订。每次使用都要登记：对应原句、具体困难、学生动作、可见产物、反馈边界和后用位置。

## 二、按学习困难选手法

| 学习困难 | 可选手法 | 学生真正经历 | 可见产物/检验 |
|---|---|---|---|
| 记不起相关作品 | 静默检索、篇目目录阶梯、作品接龙、主题卡墙 | 从个人记忆出发，听见全班更广的文学谱系 | 个人清单、带作者来源的卡墙；教师不预填主题 |
| 进入不了整体声音 | 教师连续听读、节拍跟读、分部和声、停顿句捕捉 | 先让作品整体发生，再保存个人停顿 | 停顿句、问号、节奏标记 |
| 字音词义阻断 | 先猜后查、注释接力、词义替换、误译诊所 | 先形成自己的自然话，再用有限释义校准 | 有修改痕迹的口译；不把完整译文提前投影 |
| 句法关系模糊 | 分句剪条、主谓宾复位、对称句对读、虚词开关 | 操作句子结构，看见词序和虚词怎样改变意义 | 复位句、两栏对读、删换对比 |
| 人物行动混乱 | 动作着色、主体追踪、事件阶梯、撤答复述 | 追问“谁做了什么”，再离开屏幕重建 | 行动链、第一人称旁白 |
| 空间距离无感 | 路线描画、站位图、视线线条、身体走位 | 把“送、涉、至、乘、望”变成可感距离 | 有原词标注的路线或站位图 |
| 时间过程被压平 | 时间绳、日历折叠、一天还原、前后状态叠片 | 体验诗歌怎样压缩等待与多年生活 | 时间轴、日常片段、前后对照 |
| 对照/反复只会报术语 | 遮词辨别、并排对读、替换实验、声纹比较 | 先感到形式造成的差别，再命名手法 | 原词对齐、替换后的意义损失、朗读差异 |
| 情绪被标签化 | 双速度朗读谱、闭眼听辨、角色语气选择、沉默长度实验 | 把解释转成声音，让听者检验是否听见 | 朗读谱、听者回执、第二遍改读 |
| 意象被讲成答案 | 多假设观察、意象生长图、前后颜色/状态对照、证据投票 | 先看物象，再提出并比较多种解释 | 假设卡、原词证据、保留分歧 |
| 容易倒灌结局 | 当下档案、证据强度三栏、暂停预测、回看修订 | 区分初读感受、文本事实和暂不能断言 | 初见札记、全文后修订痕迹 |
| 文化背景陌生 | 微型物件台、图物配对、一步文化支架、古今边界句 | 只取得当前句所需背景，不被知识讲座淹没 | 一条文化小注和“不足以证明”句 |
| 叙事仍是碎片 | 遮答行动链、三十秒旁白、六人接力、故事地图 | 把局部知识重新组织成连续人生 | 口头旁白、章意、听众补缺 |
| 现实处境难以想象 | 生活镜头、定格画面、一天账本、双人旁白 | 将诗句还原成具体生活，同时守住想象边界 | 场景卡、原诗依据、越界修订 |
| 观点讨论浅或被教师垄断 | 立场光谱、证据席、圆桌、鱼缸讨论、同伴追问、反方钢人 | 先形成个人判断，再倾听、质询、改写 | 立场句、追问记录、修订后判断 |
| 私人议题存在风险 | 只谈作品、第三人称案例、匿名投递、可跳过选项 | 不要求暴露家庭或恋爱经历，也能参与价值讨论 | 作品依据或案例判断，不采集私人自述 |
| 以为“看见答案就是会” | 遮答检索、错误诊断、同伴出题、迁移小诗句、退出条 | 从记忆重建并解释，而非抄结论 | 检索痕迹、错因、迁移证据 |

## 三、互动结构库

同一认知任务可以采用不同社会结构，但结构必须服务目的：

- 独立静默：保证每个人先拥有自己的材料；
- 同桌见证：一人表达，一人只按限定标准反馈，再交换；
- 四人编号轮说：避免自愿发言长期被少数人占据；
- 拼图接力：各组掌握不同章节，必须彼此依赖才能完成全貌；
- 走动观摩：学生携带明确观察单查看他组作品，不作漫游式参观；
- 鱼缸讨论：内圈讨论，外圈只记录证据、追问和观点变化，再交换；
- 立场光谱：用位置呈现分歧，但移动后必须说出原诗依据并允许不站队；
- 现场卡墙：类别由学生命名、合并、移动，教师不预制完整框架；
- 热座/角色访谈：只在文本能支持人物回答时使用，不能替人物虚构心理；
- 匿名投递：适合婚姻、家庭等私人议题，公开讨论作品或第三人称案例。

## 四、反馈手法库

- 原词追问：“哪一个字托住你的说法？”
- 断点提示：只指出叙事在哪一步跳跃，不报完整顺序；
- 听者回执：只写实际听见的变化，不笼统评价“有感情”；
- 强度调节：将“就是、一定、证明”改为“可能、此刻可以看见、尚不能证明”；
- 替换检验：删掉或替换一个词，比较声音、节奏或判断损失；
- 补缺不代答：听众指出缺少人物、动作、对象、原因或依据，由作者回诗补回；
- 钢人复述：反驳前先准确复述对方最有力的文本依据；
- 可见修订：保留前稿，用另一颜色改写、重排或补证，不把教师答案抄成“修订”。

## 五、去同质化审计

每个模块完成后，建立“认知动作×社会结构×产物形态”矩阵。若连续三页在三个维度中有两个完全相同，必须解释其必要性；若只是换标题，返工。多样性不要求热闹：一次安静的长听读、一次真正的停顿、一次重读也可能比多个小游戏更有体验。

严禁以下假丰富：

- 把空格改成卡片、把卡片改成便签，但仍由教师公布同一答案；
- 每页都写“独立一分钟—同桌交流—教师总结”；
- 活动前把答案放在学习单、讲者台词或图像里；
- 为了活跃而加入与原文无关的竞速、抢答或表演；
- 要求所有学生必须产生感动、愤怒、新发现或观点改变。

## 六、选法处方：先写困难，再准入手法

任何新活动在进入教案前，先填一张六句处方；无法填全，不准因为“有趣”而采用。

| 处方项 | 必须写成什么 |
|---|---|
| 原文停点 | 精确到一句、一组词或一次声音变化，不写泛泛主题 |
| 当前困难 | 学生究竟看不见动作、听不见声音、分不清证据，还是离屏后无法重建 |
| 体验变化 | 学生经过本活动后，将从哪一种经验变成哪一种经验 |
| 不可替代动作 | 为什么必须读、听、画、排、演、辩、写或走动；换成教师讲解会失去什么 |
| 留下的作品 | 具体落在教材批注、学习单、纸卡、口头录音、板书还是故事轨道 |
| 后续调用 | 哪一页会打开、引用、反驳或修订这份作品；只有“课后复习”不算 |

活动名称最后才写。若去掉名称后只剩“填空—交流—教师总结”，处方无效，回到当前困难重新选法。

## 七、体验节奏矩阵

每页至少登记以下五个维度。连续三页若有三个维度完全相同，原则上判为P2；若确因反复练习需要同构，必须说明学生能力如何逐级增加。

| 维度 | 可用类别 | 检查问题 |
|---|---|---|
| 认知动作 | 检索、定位、口译、感受、比较、假设、排序、归因、质询、重建、迁移、自评 | 学生大脑真正换了工作吗？ |
| 感官通道 | 默读、出声读、闭眼听、凝视、身体走位、书写、观看他人作品 | 是否总在“看屏幕—填空”？ |
| 社会结构 | 独立、同桌互证、角色对读、四人轮说、全班听辨、走动观摩、鱼缸、匿名投递 | 谁在生产，谁在倾听，谁有修改权？ |
| 作品形态 | 原词标记、路线、朗读谱、听者回执、假设卡、判断句、排序链、故事旁白、立场修订 | 每页是否只是不同样式的空格？ |
| 情绪节奏 | 安静进入、好奇寻找、感官停留、声音碰撞、分歧悬置、责任辨明、回望收束 | 课堂是否一直在高强度接收或机械忙碌？ |

体验丰富不等于每页换花样。好的节奏可以是“完整静读—一处凝视—两人声音碰撞—独立判断—全班听辨—合书重建—安静收纳”，关键是每次变化都由文本困难引起。

## 八、常见手法的准入边界

| 手法 | 只有满足以下条件才使用 | 常见误用 |
|---|---|---|
| 图片/视频导入 | 学生随后必须观察、比较或引用其中可核验细节 | 只制造气氛，抢走原文第一印象 |
| 角色表演 | 台词、动作和心理均能由文本托住，表演后回到原词修订 | 虚构人物内心，把热闹当理解 |
| 小组讨论 | 个人先有材料，小组必须形成共同作品，听众有明确任务，作者有二次修订 | “讨论一下”后随机叫人回答 |
| 辩论/立场光谱 | 文本确有可争议解释，双方都能获得证据，不以私人经历作站队压力 | 把事实问题伪装成观点问题 |
| 思维导图/表格 | 结构关系本身是学习对象，并由学生生成或修订 | 教师先展示完整图，学生照抄 |
| 朗读 | 声音选择能改变理解，并有听者回执或第二遍改读 | 齐读一遍即声称体验情感 |
| 创意写作 | 明确区分诗中所写与想象补写，写后用原句核验边界 | 用现代故事覆盖古诗文本 |
| 游戏/竞赛 | 速度不是唯一优势，错误能进入解释和修订 | 抢答奖励快学生，其他人旁观 |

## 九、活动注意力预算

活动写入教案前，把学生需要记住的事项逐项计数：角色、顺序、时间、分支、纸张、符号、产出、反馈和修订位置都算一项。学生前台优先保留以下三步闭环：

> 面对文学对象做一个主动作 → 接受一项有界反馈 → 亲自修订一次

超过三步并非绝对禁止，但每多一步都要说明它新增了哪一种文本理解。以下手续通常不应进入学生前台：来源编号、原提议者签认、重复内容查核、为了可追溯而设置的卡号、多个状态标签、没有后用的个人参与证明。它们若确有管理需要，放入教师后台，由教师承担。

## 十、广泛表达后的教师归纳

作品回忆和主题导入可采用“文学接龙”：每人用“《篇名》写了……”提供一条自然话；重复篇目允许补另一层意思，不执行查重淘汰。教师在黑板保留篇名与学生原话，待材料充分后再引用现场例子，归纳作品共同关心的相遇、等待、阻隔、相守、背叛、离开等命题。归纳词必须服从现场，不要求六项齐全，也允许学生指出教师归纳过满或遗漏。

这一手法的价值在于扩大文学记忆和公共发言面；不适合在导入阶段继续发展为卡片编号、学生分类评审或深度证据辩论。深入分析应留到新文本提供共同证据以后。

## 十一、手法结束的故事回接

每种局部手法都须有自然出口：

| 手法 | 回接人物故事的出口示例 |
|---|---|
| 字词口译 | “所以，这句话里是谁做了什么？” |
| 空间描画 | “这段路让我们看见她怎样投入这次相送？” |
| 对照朗读 | “见与不见，使她的等待发生了怎样的转折？” |
| 文化支架 | “这次占问把当时的婚事推进到哪里？” |
| 意象假设 | “女子为什么在迁嫁之后忽然让一片桑叶进入回望？” |
| 删句比较 | “原诗让这声劝告怎样来到人耳边？” |

出口不必再增加一张表或一次大型活动；一句自然复述即可。章末只保留一次完整旁白，用来把本章重新放回六章人生轨道。

## 十二、大班广泛表达：并行覆盖与公共精选

大班文学回忆、旧作复习和开放讨论，必须把两个目标拆开设计：一是每个人真实开口，二是全班共同听见的内容值得积累。

推荐结构：

1. 个人先写一条可说的材料；
2. 同桌互说，使每个人先完成一次低压表达；
3. 四人组每人完整说一条，保留两三条彼此不同的材料；
4. 各组只向全班贡献一条新篇目、新证据或不同主题；没有新增可以只听记；
5. 教师准确记录学生原话，发言结束后才整理共同线索；
6. 学生只做事实纠错和必要补充，不被要求承担教师的分类劳动。

这一结构不是代表制：每个人已经在并行阶段真实表达；全班阶段的目的也不是点名覆盖，而是共同扩展、比较和保存。审查时分别核验“个体开口率”和“公共材料的新异度、可记录性与后用”，不得用其中一项冒充另一项。

## 十三、教师教学手法库

学生主动学习并不要求教师从文本理解中退场。以下手法只有在对应困难真实存在时使用，且教师完成以后必须有一个学生可以检验的最小动作。

| 教师手法 | 适用困难 | 教师真正做什么 | 学生怎样检验接收 |
|---|---|---|---|
| 叙事性精讲 | 四言诗短促，逐词懂却连不成事件 | 用自然、准确、不过度解释的语言还原谁做了什么、事情怎样推进 | 学生用原词补回一个动作或复述下一步 |
| 一处思维示范 | 学生不会从事实走向有边界判断 | 示范“明写事实—前后连接—可推断—不能断言”一次 | 学生在另一句独立迁移四步，不照抄结论 |
| 朗读示范 | 学生知道情绪标签，却听不见声音转折 | 教师提供一次克制而可辨的读法，不宣称标准答案 | 学生指出实际听见的变化和托住它的原词 |
| 板书建模 | 学生材料丰富但彼此散乱 | 引用学生原话，现场生成事件轨道、前后对照或问题谱 | 学生纠正事实、补一条连接或用板书复述 |
| 必要知识微讲 | 卜筮、通假、古今义等无法可靠猜得 | 只讲当前句必需的定义、边界和叙事作用 | 学生立即把知识放回原句口译，不做背景知识抄写 |
| 文学停留 | 物象、声音或结尾需要被感受而非立即分析 | 朗读、静默、凝视或重现一幅克制画面，守住不填表的时间 | 学生留下一个原句停点、声音选择或自然短句，也允许诚实无话 |
| 后置归纳 | 学生已经有多份真实材料但缺少语言提升 | 准确引用、区分层次、命名手法、指出边界和保留分歧 | 学生决定补充、修正或保留，而不是抄一份教师总结 |
| 讲解中的设问停顿 | 连续精讲容易成为单向发送 | 在关键关系处停下，只问一个学生当下已有支架能回答的问题 | 学生用一个原词、一次预测或一句复述完成，不展开程序 |

教师手法的风险同样需要审计：精讲过长会替代学生加工，示范过多会泄露其余任务，朗读示范可能变成模仿竞赛，后置归纳也可能把学生语言全部覆盖。合格状态是教师提供学生暂时无法独立取得的支架，然后把理解权交还学生。

## 十四、底层协议指纹与全课节奏

活动去同质化不能只看名称。为每页登记一个“协议指纹”：

> 认知动作 × 感官通道 × 社会结构 × 作品形态 × 反馈方式 × 教师作用

例如“画路线”和“填对照栏”表面不同，如果都采用个人填写、同桌找错、作者换笔、教师校准，仍共享大部分底层协议。连续三页有四个维度相同时必须返工；全课同一指纹出现过密时，即使不连续也要削减。

可用的节奏转变包括：

- 教师完整带读 → 学生只捕捉一处停点；
- 个人静默口译 → 全班听教师叙事性校准；
- 两人声音互证 → 无纸面产物的完整合读；
- 小组证据比较 → 教师板书生成公共模型；
- 个人书写 → 走动观看不同作品；
- 理性辨析 → 安静凝视或完整朗读；
- 局部细读 → 合书自然复述；
- 全文讨论 → 个人安静收纳。

丰富不等于每页换玩法。能力递进的同构练习可以保留，但必须写明本次比上次新增的独立能力；若只能说“换了一章诗”，就不是递进。

## 十五、综合与收束阶段的防重复规则

全文读完后，活动的功能应从“再次生产材料”转向“选择、组织、解释、讨论与迁移”。

- 已有六章轨道时，不再让每人重写六句人生；可以口头接力、教师板书一条公共长卷，再由学生校正转折。
- 已经写过婚后生活片刻时，原因讨论直接读取其中事实，不重新抄写。
- 已经完成获批贯穿问题时，退出页不再次压缩同样问题；本课不设贯穿问题时同样不得为收束临时造问，只带走一处语言发现、一条关系理解或一个仍愿追问的问题。
- 知识检索产生的错项应当场校准，不为“后用”再誊抄一次完整知识页。
- 终课必须给完整声音、安静回味或自然表达留出时间，不能让表单填到铃声结束。

## 十六、首答态—校准态双状态手法

当学习目标本身是排序、分类、解释边界、选择代表例或统整全文时，页面必须区分两种状态：

1. **首答态：** 只呈现原词、原句、必要释义、问题和作品落点；不出现正确顺序、完成分类、标准边界或代表例。
2. **校准态：** 学生已有首稿后，教师引用真实作品，准确释义、命名术语、指出证据强弱，学生再亲自改写、重排或补证。

双状态不一定要增加一张PPT。可用现场板书、动画逐项揭示、实体卡墙或教师口头归纳完成；但逐字稿必须写出真实等待，QA也必须能够证明默认首屏没有答案。若静态文件无法可靠证明动画默认态，优先采用可审查的空白首屏和现场板书，不用“课堂上我会晚点讲”解释完成态泄答。

如果同一静态画面同时呈现了“学生正在形成的话语”和“教师稍后才给的归纳”，时序在文件层面已经失败。必须拆成两个可审查的物理状态：前态只让真实学生作品被看见、被朗读、被回应；后态才显示教师的文本校准或现代延伸。任何“课堂上先不让学生看右边”的说明都不能代替物理分屏。

适用示例：

- 四个古今义先由学生写短义并标主体，教师后置校准，再由学生自画责任递进；
- 六张原词卡先独立放入“旧日记忆／后来事实”，教师返诗校准，再写能同时容纳两者的句子；
- 末句先写“诗写到／未写到”，教师后置说明停止判断与实际行动的边界；
- 《诗经》四项身份先合书检索，教师在等待后揭示答案并只修复真实错项；
- 四区知识图先由小组返诗补例，教师再用准确术语提升学生自然发现。

## 十七、低负荷真讨论：全员轮说与一组一卡

连续的全文归纳、原因质询之后，价值讨论不宜再复制“个人长写—小组三卡—全班合并”的重型协议。可采用：

1. 个人只返诗选一处依据，不另写长稿；
2. 四人按座位依次用两句话表达“我选的原句—我提出的关系条件”；
3. 所有人说过以前不评价、不抢答；
4. 四人说过以后才追问依据、合并相近或保留分歧；
5. 每组只形成一张公共卡，写清关系条件和原诗依据；
6. 全班只聚类同义卡、质询冲突卡，教师沿真实材料后置归纳。

这一结构的作品数量少于发言人数：组内阶段保障人人有声音，公共阶段保障材料值得全班共同听。审查时分别记录开口覆盖和公共作品质量，不能互相替代。

## 十八、知识收纳拆分：一页一个检索对象

知识总结页也服从一个主要学习对象。文化身份检索适合“合书四问—标分歧—开书修复—教师准确收束—再合书串说”；核心字词适合“自选少量词首答音义和原句—持教材核对—作者修订—教师只讲真实共错—回句终读”。两者虽然都叫检索，所需记忆线索、核对材料和教师讲解不同，不应为了减少一页而挤在同一时间盒内。

拆页不是把内容做多，而是让每一个已有知识真正完成“离开材料首答—依靠材料修复—再次回到诗中”的闭环。若一个页面无法给每项至少一次真实等待、一次可靠校准和一次本人修订，就删减对象或拆页。

## 十九、可复用的语文体验手法

下列手法不是活动配额。只有在对应困难出现、且能写清原句、学生动作、作品和后用时才准入。

| 手法 | 适用困难 | 学生真正做什么 | 可见证据 | 主要风险 |
|---|---|---|---|---|
| 图像证据边界 | 学生混淆“看得见的动作”和“叙述者告诉的动机” | 先只报画面事实，再回原词寻找图像不能给出的来意 | “图可见／诗才说明”双句 | 看图猜人格、把艺术示意当史料 |
| 同物回访 | 同一意象前后变化被学成两个孤立答案 | 先看同一物象的第一状态并留假设，后文再看第二状态修订旧稿 | 保留、改写或撤回的旧假设 | 两图不是同一对象；颜色直接替代解释 |
| 后文改前文 | 学生读后文却不改变早期理解 | 打开前稿，用新原句说明哪些保留、哪些降低强度 | 带新证据的修订痕迹 | 把后果倒推成早已确定的预谋 |
| 声音退场 | 外部声音与人物内声被读成同一平面 | 听外声、真实静默、再听内声，只画声音去向 | 外声—静默—内声三格 | 夸张表演、把私人经历拉进课堂 |
| 匿名生活文展 | “不幸、辛劳、孤立”停留在抽象标签 | 读匿名短文，猜它能回到哪一句并说明依据 | 生活片段—原句连线 | 创作越过原诗；公开身份造成暴露 |
| 因果箭头质询 | 原因讨论把相关、责任和条件混为一谈 | 对一根箭头追问“这能直接导致吗；依据在哪；强度是否过满” | 经修订的因果箭头 | 把受伤者投入写成伤害原因 |
| 双真相并置 | 学生只能把婚前记忆判为全真或全假 | 把旧日事实与后来事实同时保留，再写能容纳两者的一句 | 双栏事实与综合句 | 用旧日欢乐替后来失信免责 |
| 有界多解 | 意象或结尾被强塞单一标准答案 | 先说字面边界，再提出一至两种能接前后文的解释 | “字面—依据—解释”短链 | 以现代口号覆盖诗句 |
| 关系条件卡 | 价值讨论泛泛表态或由少数人包办 | 每人用一处原诗提出一个条件，全员轮说后每组只留一卡 | 原诗依据＋共同生活条件 | 代表代劳；公共卡太多造成重复 |
| 终读提醒 | 知识总结与完整朗读断开 | 自选两个不稳词或一处写法作边注，终读时主动照看 | 个体化终读标记 | 抄满知识表，反而听不见全诗 |

## 二十、手法的强度梯度

同一文本困难优先选择能产生理解的最低强度手法，只有证据表明不足时才升级：

> 教师一句设问停顿 → 个人原词标记 → 同桌限定互证 → 四人轮说 → 全班公共讨论 → 走动、鱼缸或立场活动

强度越高，课堂物流、等待、重复和情绪暴露的成本越高。不得为了“活动性”直接跳到全班辩论；也不得因为教师精讲省事而跳过学生能够完成的观察与首答。选择哪一级，以学生当前困难和页面唯一功能决定。

## 二十一、撤架复述与核心问题个人末答

公共答案形成以后，如果目标是“每个人能独立讲清”，必须增加真正的撤架阶段：教师校准页先让学生看清准确关系，随后切换到无答案页、熄屏，并将黑板、卡墙、展台、侧屏及教室四周所有可见答案摘下、反扣、覆盖或擦除，学生离开支架复述；断点出现后只返到相应原句，再次撤架重讲。只合书、只换PPT而黑板仍保留答案，或只口头要求“不要看”，都不算撤架。

全文核心问题宜采用以下轻量闭环：

1. 个人先答自己能够处理的一部分；
2. 小组或全班形成公共材料；
3. 教师后置校准事实、术语和伦理边界；
4. 撤去公共答案；
5. 每人完成一份带原诗的末答，或离屏复述后只修自己的断点。

必要证据是公共答案前后的两份个人材料及真实修订，不是公共卡片数量。

修订必须尊重首稿的真实状态：首稿有错漏，才补缺或纠错；首稿已经准确完整，则允许原样保留，或把其中一项改写得更具体、补上原诗依据、说明适用边界。不得为了制造“前后进步”强迫学生伪造漏项、改坏正确答案，或把无变化冒充修订。

## 二十二、随机散卡：防止版式替学生分类

当目标是自拟分组、发现关系或比较多种解释时，首答材料必须等大、同色、无栏目标题、无预制箭头并随机散放。具体原词或事件可以进入卡片，“叙事推进、比兴、复现、叠词”等目标类别不得作为原始材料。学生先独立摆放并封存，随后展示真实分法，教师最后才命名。

卡片内部也属于版式信息。每张卡只能承载一条原子证据，并与其他卡保持同等颗粒度；不得用斜杠、箭头、并列句或一张卡内的前后配对，预先告诉学生哪些材料彼此相关。把已经配好的关系卡随机摆放，仍然是泄答。审查者应只看首答页：若能从卡内配对、句子长短或颗粒差异反推出教师预设类别，页面必须返工。

随机散放不等于故意制造混乱。材料数量应在工作记忆可承受范围内，卡片文字后排可读，学生可以暂时形成两种分法或保留未归类项。若页面仍以行距、左右框、颜色或视觉重心暗示目标四类，即使没有写术语，也视为泄答。

“后排可读”必须落实到操作材料本身，而不只是页标题。短语卡需要学生逐项辨认时，原则上不小于26pt；投影环境、字形复杂度或卡片密度更差时继续放大或减少材料。随机位置还要做反聚簇核验：后台同类或明显成对材料不能反复同行、同列、相邻，防止空间邻近替学生完成分类。

## 二十五、局部句义与人物判断的适用范围

从一个词、一句诗推出人物判断时，必须写明它回答的是哪一层、覆盖哪一段经历。例如“女也不爽”能够支撑的是她在婚姻操持中并无差失，不能自动扩大为“她此前所有判断都无需反思”或“她在任何方面都没有错误”。

合格的教师校准至少同时守住三条边界：原句直接确认什么；它不能证明什么；人物受伤的责任不能被转嫁给其投入、等待、劳作或判断局限。页面文字、逐字稿和学生末答标准必须使用同一适用范围，防止一句局部判断在转述中逐轮扩大。

## 二十三、旧作取回：让学生作品拥有真实消费者

前文生成的生活片段、朗读谱、意象假设、章意或问题卡，后页若声称调用，必须真的取回同一载体：教师明确点名作品，学生物理翻回、抽取、划线、补证、反驳或修订。重新写一份内容相近的材料不叫后用。

可用的取回动作包括：

- 在旧稿上用新原句保留、改写或撤回；
- 从旧生活片段抽取事实，做成正面生活话、背面原诗的卡；
- 打开初听问题，标记哪些已经解决、哪些仍愿追问；
- 把开头文学长卷带回结尾，亲自补上一条新认识。

取回必须在逐字稿、证据位置和物料管理中同时出现；只有`next_use`字段写着“后文使用”不算成立。

## 二十四、讨论后的三层收束：学生原话、文本事实与现代延伸

开放讨论结束以后，教师可以提升语言、补足边界，但不能让一页成熟的教师结论覆盖刚刚生成的学生声音。合格画面优先让一张真实学生卡、现场板书或实物展台成为主视觉；教师归纳退到次层，并明确标示来源。

收束时至少区分三层：

1. **学生原话：** 忠实呈现，允许不完整、分歧和少数意见，不用预制“优秀答案”冒充现场生成；
2. **文本能够确认的事实或判断：** 必须带原句，并守住人物、行动和结局边界；
3. **由文本走向今天的建议：** 可以提出求助、边界、离开等现代行动，但必须明确这是迁移建议，不是作品中已经发生的事实。

若技术上不能把真实学生作品放入PPT，宁可熄暗投影、回到黑板或实物卡，也不要用空白占位后立刻以固定教师答案盖满全屏。学生没有说到的内容可以由教师补充，但必须当场说明“这是教师依据文本补的一点”，不得写成全班已经形成的共识。
