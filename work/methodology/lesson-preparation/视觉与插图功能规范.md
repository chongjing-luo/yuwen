# 视觉与插图功能规范

## 一、视觉的首要责任

每页先指定一个主视觉职责：放大原文、显示关系、承载学生操作、保存现场作品、制造声音/空间/时间体验，或提供必要物象。构图、字号、颜色、留白和插图都服务这一职责。美感不是额外贴花，而是清晰、克制、节奏和作品气质共同形成的结果。

不执行“每页必须配图”。原诗足够有力量时，让原诗成为主视觉；学生生成尚未发生时，不用完成图替学生作答。

空白只有在学生即将观察、书写、投放或投影真实作品时才有功能。用重复卡片和“你的答案、生活分镜、结构梁”等占位词制造版式完整，属于无意义视觉；它既没有作品，也没有文学对象，应删去或改成一个真实可进入的画面、原句关系或现场作品位置。课堂沉默同样用留白和时间表现，不用“沉默三秒”的文字装饰。

### 教材视觉母题优先

教材不是只提供文字的容器。课文页或单元页已有可核验的配图、人物肖像、题名字色、图形轮廓、纸本色调、纹理和留白秩序时，S3先形成视觉来源档案，再决定PPT视觉系统：

1. 登记源文件、图片裁取文件、SHA-256、画面角色和使用边界；只从当前课文或单元确有关系的教材画面取样，不把同一PDF中下一课的插图误作本课资产；
2. 提炼底色、正文色、强调色、人物锚、图形语言、图片风格与字形气质；提炼的是可复用关系，不是照抄教材页码、水印、栏线和印刷噪声；
3. 配色可以教材视觉为首选，也可以在教材没有有效视觉依据时按文章类型、时代质地和课堂功能另立色板；无论来源如何，后排可读、信息时序和页面唯一功能优先；
4. 新增图形或生成图像若引用教材风格，必须登记是直接使用教材资产、从教材视觉派生，还是按文本类型补充；人物身份以教材肖像为锚时，不得重新生成一张“相似人物”冒充史实照片；
5. 同一视觉来源在全课重复使用应承担辨认、回返或节奏功能，不为制造一致感而机械贴满每页。原文足以成为主视觉的页面仍明确判为不配图。

该档案服务K2（教材与原文锚定）、U5（减少不必要的视觉切换）和J4/J5（作品气质与课堂节奏）。视觉一致只证明设计条件成立，不证明学生已经喜欢或学会。

### 页面角色允许有辨识度，不允许视觉漂移

标题、导航、章节（子标题）、主干文本、支撑、活动、作品与反馈、总结收纳、作业九类页面可以使用不同的构图语法和密度：主干页让原文或证据居主位，支撑页可使用肖像、时间线、地图、古籍和关系图，活动页保留真实操作区，作品页让现场产物成为视觉中心，导航与章节（子标题）页可以更简洁。差异用于提示学生当前认知状态发生了什么变化，不用于给同一内容任意换皮。标题、导航和章节（子标题）页的简洁来自定位职责本身，不用虚构知识卡、目标标签或装饰框填满空间。

不同角色仍共享课文级字体系统、主色关系、人物/物象锚、图形母题、页码与导航规则。支撑页可明显区别于主干页，但须以稳定的小型角色标识、触发原句或返回锚说明它属于同一学习链；不得突然切换成另一套模板、商业海报或百科页面。标题先直接说明“作者简介、写作背景、文体知识、用典、课堂活动、课后作业”等对象，艺术气息由副标题、引文、图像和留白承担。

## 二、插图准入五问

一幅图进入PPT前必须同时回答：

1. 它帮助学生辨认哪一个动作、空间、时间、物象或叙事节点？
2. 学生会对它做什么：观察、比较、定位、排序、选择还是引用？
3. 不用这幅图会损失什么；能否用原诗、关系图或学生作品更准确地替代？
4. 图中哪些是文本事实，哪些只是气氛？是否把“可能”画成“已经发生”？
5. 它在页面上是否服从原诗和任务，不抢走核心注意力？

任一问无法回答，插图不进入课堂课件。仅作章节气氛的小景也须降为低饱和、小面积、无叙事结论的装饰，并不得挤压原文字号。

## 三、《氓》人物与画风圣经的冻结顺序

全文页面功能冻结后，先生成一张角色设定板，再制作场景图。设定板至少锁定：

- 女子W01：初见、迁嫁、婚后、决绝四阶段的年龄连续性；脸型、眉眼、肤色、身高比例、发式基础保持一致，只允许衣着磨损、神态和姿态随阶段变化；
- 男子M01：同一脸型、身材、发冠与服装体系；婚前热切和婚后冷暴不能依赖换脸表达；
- 时代视觉：先秦中原人物轮廓，交领右衽、布麻质感、克制发饰，不混入汉唐宋明典型服饰；
- 固定道具：布匹、淇水、垝垣、车、嫁妆、桑叶、家务器物；同一道具跨图形制一致；
- 画风：温润手绘动画感、简洁形体、平涂与轻水彩纹理、清楚轮廓、低细节背景；不得复制任何在世艺术家的可识别笔触或具体作品构图；
- 色彩：暖纸、桑叶青、淇水青、朱砂点色、旧金；婚前后允许明度变化，但不改变整体色彩世界；
- 光源与镜头：统一柔和侧光，人物比例与镜头高度建立固定表；装饰小景优先侧视或背影，避免戏剧海报式大场面。

角色设定板须经过脸部一致性、服饰时代感、道具一致性和原文边界四项审查后冻结。每张新图都必须引用设定板和角色ID，不凭一句通用提示重新生成。

角色设定板还必须保存可复用的“身份锚”：正面、四分之三侧面、全身比例、基础发式、基础服装、主色块和三件固定道具。场景提示词只允许调用身份锚并改变已批准的年龄阶段、姿态、表情和环境；不得重新描述一张“相似的古代女子”来碰运气。生成后先以设定板做并排身份核验，脸型、眉眼间距、鼻口比例、身形或发式基础任一明显漂移，整幅退回，不靠裁切掩盖。

## 四、场景图的功能分类

| 类型 | 适用任务 | 构图要求 |
|---|---|---|
| 动作小景 | 抱布来谋、送子涉淇、乘垝垣望复关 | 单一动作，人物少，轮廓清楚，可在PPT侧栏或角落使用 |
| 空间示意 | 淇水、顿丘、垝垣与复关的关系 | 允许图解化；不虚构精确地理；箭头应由学生生成时不预画答案 |
| 物象小景 | 桑叶沃若/黄陨、淇水有岸 | 主体明确、背景简洁，供观察与前后比较 |
| 生活片段 | 靡室劳矣、夙兴夜寐、兄弟不知 | 必须有原诗依据；用于还原日常而非煽情；避免替学生完成全部解释 |
| 关系转折 | 士贰其行、至于暴矣、亦已焉哉 | 克制、避免暴力奇观；以距离、姿态、空间失衡表现，不虚构具体伤害动作 |
| 章节气氛 | 转场或整章重读 | 小面积、低饱和、无答案性，不挤压原诗 |

### 功能图与氛围图分轨

- **功能图**必须帮助学生辨认一个明确的动作、空间、时间或物象，课堂中必须发生观察、比较、定位或引用；它要接受无图/有图A/B和撤图后的原词检验。
- **氛围图**只能在原诗、学生作品和任务都已获得足够空间以后，以小面积、低细节、低饱和方式提供季节、光线或叙事呼吸；它不得承担人物动机、婚姻判断、象征义或因果解释。

“装饰性”不是免审资格。氛围图如果删除后画面更清楚、原诗更突出，或者它只是填空白，就应删除；其美感要来自画面节奏和作品气质，不来自复杂场面或细节堆积。

### 版式泄答检查

分类、排序、因果和关系发现页必须把版式本身视为信息渠道。首答态不得用不同颜色、左右分栏、空间聚团、卡片大小、箭头、顺序或标题层级预先完成学生任务。无答案材料应等大、同色、随机散放；校准态才允许用视觉结构帮助学生看清关系。视觉审查不能只查文字是否泄答，也要检查空间是否已经给出答案。

“等大同色、随机散放”还不够：每张首答卡必须是一条等颗粒的原子证据。卡内斜杠、箭头、并列配对、成组短语或明显不同的句子颗粒度，都会替学生预先建立关系；此类页面即使空间随机，也按版式泄答处理。

随机页还必须通过**空间反聚簇**：后台预设的同类、成对或前后照应材料，不得在同一行、同一列或相邻位置反复聚集；每一类材料应分散到不同视觉区域。审查时先隐藏文字只看位置，再恢复文字核对类别分布；若学生能够借空间邻近稳定猜出关系，即使卡片等大、同色，也按泄答返工。

## 五、PPT入页规则

- 投影核心原文原则上不小于28pt，标题不小于34pt；学生需要从后排逐张辨认并操作的短语卡原则上不小于26pt；插图不得迫使原文或操作材料低于后排可读线；
- 一页只有一个主焦点，插图与任务卡不争夺同等视觉重量；
- 同一场景先做“无图版”和“入图版”A/B比较，若理解速度、定位准确性或审美秩序没有明显提升，保留无图版；
- 重要人物不随意裁掉头、手或关键道具；装饰小景可以裁边，但需保留动作方向；
- 透明背景小景要检查锯齿、白边和暗色投影；
- 图片须登记角色ID、场景ID、提示词版本、生成日期、源文件、裁切文件、使用页、功能与边界；
- 图像生成后先单图审查，再入页审查；不能以单图精美替代投影情境中的可用性。
- 同一人物在任何新图中都必须引用冻结角色板的身份锚；脸型、眉眼、鼻口比例、身形、发式、服装体系、光源和固定道具至少八项逐项核验，任一明显漂移整图退回。
- 场景图优先单一动作、少人物、低细节背景和可裁切留白；一张图若需要解释其中多个事件、多个时间或多重象征，通常不适合作为PPT示意图。
- 逐字稿若规定某项信息“稍后出现”，静态课件必须拆成两个可以分别审查的物理画面，或采用能够证明默认首屏状态的可靠动画；不能在同一静态页同时放置学生首答与教师总结，再以口头时序解释遮掩。

## 六、独立视觉验收

独立审查者逐页检查：主视觉职责是否一眼成立；原文和任务是否后排可读；图像是否泄答、越界或抢焦点；人物、服饰、道具、光源和色调是否漂移；画面是否有遮挡、裁切、低对比、拥挤和无意义空白。

人物漂移、文本事实误画、核心原文不可读或图像提前给出学生应生成的关系，至少判P1；图像无功能、画面虽美但削弱任务、风格不一致或装饰喧宾夺主，至少判P2。只有真实投影、班级距离或学生辨图速度才能判断的问题可列P3。

## 七、逐页资格与A/B预注册

整课页面功能冻结以后，必须逐页登记“禁止、可研、条件A/B”之一，不能用“重要场景都要配图”代替资格审查：

- **禁止：** 原诗、声音、学生作品、现场板书或留白本身就是唯一主视觉，图片会泄答、抢焦或规定想象；
- **可研：** 图像可能帮助字面、空间、时间或物象，但尚无合格资产，先写功能与边界，不能先生成再找用途；
- **条件A/B：** 固定SHA单图已通过文本事实、人物一致性和无水印审查，只授权制作实际入页裁切和无图/有图对照。

A/B在入页前预先固定指标：无图首答是否完整、撤图后的目标原词定位率、看图前后有依据的修订质量、诗外推断数、后排可读性、学生形成时序和人物/画风一致性。学生“更喜欢”只能作为审美反馈，不能证明学习功能。

若图片本身显示的正是学生要从原词形成的站位、感官、状态或关系，图片不得在首答态出现；合格时序必须是“原诗无图首答—短暂揭示图片—只校准一个对象—撤图—学生用原词修订”。不能把B版更快答出图中已有答案当成学习增益。只有在不降低原诗字号、不增加稳定误读的前提下，撤图后原词定位或有证据纠错优于A版，才有保留资格；没有增益即保留A版。

同一角色板、场景图或裁切文件内容变化后，旧哈希审查自动失效。人物图必须与冻结角色板并排核验脸型、眉眼、鼻口、身形、发式、服装、光源和固定道具；明显漂移整幅退回，不以裁掉面部、缩小图片或教师口头说明掩盖。

## 八、课例身份锚的存放与失效边界

角色设定板属于具体课程物料，必须存入 `work/teaching/<册>/<课>/materials/assets/`，并由当前课程的 `materials_lock.json` 登记内容哈希；方法论目录只保存本规范，不保存课例图片。

《氓》历史角色板曾登记SHA-256 `6abc2d382172231f8e24d91ea8912acd7d60519a2040a0794e0ba0c9c6f615ce`，但该资产现已退出正式课程树，且当前《氓》课程没有有效G3物料锁，因此**不存在可供现行生成继续使用的冻结身份锚**。后续重制须在当前课程目录重新生成、审查并锁定，不能仅凭历史哈希恢复“已批准”状态。

即使角色板重新取得有效锁，也只证明人物与固定道具有后续场景生成的身份参考资格，不证明角色板应直接进入课堂，更不自动批准任何场景图。每幅场景仍须逐图审查、页内A/B和整套PPT重新双审。
