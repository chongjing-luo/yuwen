# S8 命题与诊断手册

## 条目

### MM-S8-01 蓝图权重有依据
- 优先级：P0
- 条件：命制任何试卷
- 动作：KP 权重给 basis（图谱定位或语料统计），不接受“感觉重要”
- 判据：validate_assessment_package 检查通过
- 出处：K1 / N-01
- 预期信号：覆盖与权重一致

### MM-S8-02 四站闭环引用
- 优先级：P0
- 条件：组卷时
- 动作：蓝图必须引用 lesson_ref 与 homework_ref（测评是闭环第三站）
- 判据：validate_assessment_package 检查通过
- 出处：K3 / N-02
- 预期信号：同一 KP 跨站可追

### MM-S8-03 M0 不进学生卷
- 优先级：P0
- 条件：选题时
- 动作：candidate_only 条目只作变式参照进教师卷，保留溯源
- 判据：validate_assessment_package 检查通过
- 出处：§3.3 / 裁决3 / K1 / J7
- 预期信号：无未核验内容进学生产物

### MM-S8-04 评分点含解释分层
- 优先级：P0
- 条件：写评分量规
- 动作：scoring_principles 写明“推断写成诗写可检出可扣分”
- 判据：validate_assessment_package 检查通过
- 出处：U6
- 预期信号：判卷一致性

### MM-S8-05 掌握数据真实录入
- 优先级：P1
- 条件：阅卷后
- 动作：消费S7 GRD或真实测验评分，按KP逐条只追加MR到`work/teaching/_classes/<班级>/mastery_ledger.jsonl`；不生成推演数据，不让S6/S7越权代写MR
- 判据：analyze_mastery 校验通过（kp 可解析）
- 出处：P-12 / K3 / J7
- 预期信号：诊断可信

### MM-S8-06 回教建议绑卡片
- 优先级：P1
- 条件：生成诊断报告
- 动作：低于阈值的 KP 给回教方案：绑回知识卡与页面，安排下次闭卷检索
- 判据：analyze_mastery 报告含回教段
- 出处：D3-⑦快环 / K3 / K4
- 预期信号：弱 KP 被回教后再测提升
