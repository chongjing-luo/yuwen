# S5 独立终审与宿主放行准备手册

## 条目

### MM-S5-01 冻结标准版本
- 优先级：P0
- 条件：任何审查开始时
- 动作：冻结完整原则注册库及本轮实际执行的`enforcement_config`，记录 STANDARD 版本、两份文件路径/哈希与带时区时间；冻结注册库须通过完整注册库校验，不能缩成空节点/伪原则；审查期间live标准变更不影响本轮
- 判据：审查回执含版本与冻结哈希；冻结注册库校验通过；递归校验与原则检查只消费冻结配置
- 出处：收敛规则 / J7
- 预期信号：无标准漂移争议

### MM-S5-02 不追溯否决
- 优先级：P0
- 条件：想用新规则翻旧候选时
- 动作：新原则进下一版本，只约束此后的新候选
- 判据：按冻结标准评审；新规则登记版本
- 出处：收敛规则§二 / J7
- 预期信号：候选不因标准前移被反复推翻

### MM-S5-03 删除审判
- 优先级：P0
- 条件：评审任何页面
- 动作：默认本页应删除；设计者举证删后哪段理解会实际断裂；“好看/讲得顺/做了很久”非理由
- 判据：相邻合并与因果链测试（A-T12）
- 出处：P-39 / U5
- 预期信号：页页有不可替代损失

### MM-S5-04 六门审计
- 优先级：P0
- 条件：逐页过审
- 动作：G1 前置缺失/G2 功能重复/G3 覆盖虚假/G4 变化不可观察/G5 产物孤儿/G6 可无损合并逐门过
- 判据：validate_meng_v6_page_audit（重型）或逐门人审
- 出处：A-05..A-10 / U8 / J7
- 预期信号：已知退化不进候选

### MM-S5-05 反退化测试组
- 优先级：P0
- 条件：逐页复核
- 动作：23 项测试重点跑：教师抢答/多渠道泄答/活动遮蔽故事/程序成本/协议指纹
- 判据：各测试结论入审查 JSON
- 出处：A-T01..T23 / U1 / U8 / J7
- 预期信号：高频病史不复发

### MM-S5-06 双审独立与缺陷否决
- 优先级：P0
- 条件：提交宿主前
- 动作：视觉+学生接收双审，审查者与S2/S3/S4全部内容作者分离；P0/P1/P2任一存在即不得形成候选，不以平均分妥协；审查者只判定和退回责任阶段，不直接代修内容
- 判据：两份双审回执的作者全集与上游三阶段作者精确一致，审查者不在其中，P0-P2清零
- 出处：P-21 / J7
- 预期信号：审查先于用户发现问题

### MM-S5-07 全课节奏五维
- 优先级：P1
- 条件：页面审计完成后
- 动作：五维矩阵审计全课；连续三页三维修相同原则上返工
- 判据：节奏矩阵成文
- 出处：P-33 / A-T17 / J5
- 预期信号：模板疲劳不出现

### MM-S5-08 模块重建触发
- 优先级：P1
- 条件：模块失败率高时
- 动作：>1/4 物理画面被判 P0-P2 或同根因贯穿≥3 页→停止局部润色，重划页面
- 判据：重建决定与范围记录
- 出处：P-43 / U5 / J7
- 预期信号：旧错误边界不遗留

### MM-S5-09 终审候选停止规则
- 优先级：P0
- 条件：判断何时停止打磨
- 动作：同一冻结候选连续两轮仅P3且登记观察方法后，生成`status: awaiting_host_release`的本地终审候选并停止桌面打磨；提交宿主作项目外放行裁决
- 判据：audit lock含不同`round_id`的两轮记录，状态精确为`awaiting_host_release`；项目内无`released`声明；未获宿主放行不得进入S6
- 出处：收敛规则§三 / J7
- 预期信号：桌面回归在宿主决策点收敛，不以本地文件冒充外部授权

### MM-S5-10 诚实声明
- 优先级：P0
- 条件：任何审查报告
- 动作：报告必须写明“真实课堂仍待试教”；课堂断言只能引 L4
- 判据：报告含边界声明；selfcheck 课堂账分列
- 出处：P-12 / J7
- 预期信号：两本账永不混写

### MM-S5-11 终审前回归完整血缘
- 优先级：P0
- 条件：任何G4终审开始前
- 动作：先验证materials lock并由G0到G3顺序回归；完成双审后将完整原则注册库快照、冻结enforcement配置、审计报告、视觉/学生接收回执和冻结物料哈希写入同课G4 audit lock；报告和回执均精确绑定materials lock、冻结物料与两份标准哈希并关闭字段集；宿主另提供项目目录外的外部事件注册表并绑定相同快照与候选；发现第一个断点即停止终审，把下游标stale并退回责任阶段
- 判据：G0/G1/G2/G3命令和对象SHA-256全部记录且退出码为0；完整冻结注册库校验通过，原则检查使用冻结配置；双审事件逐项匹配宿主注册表的候选与标准哈希；P3风险结构化覆盖Office渲染/课堂节奏/学习效果；带`--external-event-registry`的validate_lesson_audit通过，且输出仍为待宿主放行候选
- 出处：P-11 / P-21 / J7
- 预期信号：终审对象来自当前获批教案和设计，双审与冻结凭证不能脱离物料单独自报，本地校验不越权替宿主放行
