# S0 资料整理手册

## 条目

### MM-S0-01 外部资料必经 inbox 台账
- 优先级：P0
- 条件：任何外部资料（教材/试卷/教辅/课标/新闻/文献/书刊/他人 PPT）进入系统时
- 动作：原样落盘 `Tmp/inbox/`，同拍在 `inbox/LEDGER.jsonl` 记一行（file/sha256/来源/日期/裁决状态 pending）
- 判据：inbox 内每个文件都能在台账找到对应行；驻留超 3 日且 verdict 仍为 pending 的件出现在体检清单
- 出处：设计方案 §3.7 配套规则②；`Tmp/README.md` inbox 台账契约
- 预期信号：无资料绕过 inbox 直接入 L0/L1（catalog 审计可查）

### MM-S0-02 裁决四问决定原始件去留
- 优先级：P0
- 条件：inbox 台账登记后、预处理开始前
- 动作：依次回答权威等级？可再生？转换含判断？版权敏感？——按 §3.7 判据表得出 keep_raw / process_only / discard，回写台账 verdict
- 判据：S1/S2 源与不可再生件一律 keep_raw；裁决结果可追溯到四个答案
- 出处：设计方案 §3.7 原始件去留判据表
- 预期信号：无"删了原始又无存根"的策展条目（入册门禁拦截）

### MM-S0-03 不留原始必留来源存根
- 优先级：P0
- 条件：verdict = process_only（不留原始）时
- 动作：在产出的策展条目 front matter 写入 source 存根：来源描述、获取方式、原件 SHA、日期、可再生路径
- 判据：无存根的干净条目不得入册（入册门禁直接拒收）
- 出处：设计方案 §3.7 配套规则①；来源存根与血缘契约
- 预期信号：任何策展条目被质疑时可追溯到其来源描述

### MM-S0-04 入册即登记 catalog
- 优先级：P0
- 条件：任何实体（整理件/策展件）首次进入资料轴时
- 动作：在 `work/knowledge/_meta/catalog.jsonl` 增行：id/type/title/path/status/authority/tags/updated/summary/last_consumed
- 判据：catalog 行的 path 按本表 ID 解析规则可解析到实体文件；front matter 五件套齐全
- 出处：设计方案 §3.8 目录层与释义层；catalog 五件套契约
- 预期信号：零消费体检可运行；人从 INDEX.md、AI 从解析表都能找到该实体

## 已编译条目（MM-S0-05..09，编译自设计方案 §3.8）

### MM-S0-05 无损整理的确定性要求
- 优先级：P0
- 条件：原件→整理件的任何转换（解析/切分/清洗/OCR）
- 动作：转换必须是"原件+代码→整理件"的确定性纯函数：同输入同输出、无人工中间改写、可一键重建；整理件入册登记（front matter 五件套 + catalog 行）
- 判据：删除任一整理件后重跑管线可逐字节重建（抽样核对 SHA）；整理件头部五件套齐全
- 出处：设计方案 §3.8 / §3.7 临时层定义；确定性重建契约
- 预期信号：Tmp/work 可随时清空而不损失任何整理件

### MM-S0-06 语义加工的门禁
- 优先级：P0
- 条件：整理件→策展件（抽取观点/标注考点/摘要——任何含判断的转换）
- 动作：产出条目必须过入册门禁：schema 校验 + 权威等级必填（S1-S4）+ 血缘可解析（上游实体存在）+ 来源存根（若原始未保留）+ 账本状态机登记
- 判据：无权威等级或血缘悬空的条目被门禁拒收；candidate_only_M0 条目不进学生产物（validate_assessment_package 同款纪律）
- 出处：设计方案 §3.3/§3.5/§3.8；权威分级、血缘与账本状态机契约
- 预期信号：任何策展条目被质疑时可回溯核验（含"诗写/推断"分层不混写）

### MM-S0-07 视图生成约定
- 优先级：P1
- 条件：任何人读索引（INDEX.md、按考点/任务群视图）
- 动作：视图由 build_catalog.py 从 catalog 生成，永不手工编辑；改视图需求＝改生成器，不改产物
- 判据：视图头部带"生成物"标记；重跑生成器后 diff 为空（除日期）
- 出处：设计方案 §3.8 目录层；“索引是视图不是复制”契约
- 预期信号：多分类出现时无内容复制漂移

### MM-S0-08 消费登记与零消费处置
- 优先级：P1
- 条件：任何操作（skill/校验器/人）读取某实体作为输入时
- 动作：写入 catalog 行的 last_consumed（条目级，§12 裁决 5）；体检时长期（>90 天）零消费实体进入处置清单：补消费方或降级归档
- 判据：build_catalog --check 报告未消费清单；处置决定有记录
- 出处：设计方案 §5.3/§12-5；catalog 消费登记与零消费处置契约
- 预期信号：无长期无人消费的策展物堆积

### MM-S0-09 文件命名细则
- 优先级：P0
- 条件：资料轴产生任何新文件
- 动作：文件名 = ID 打头 + 可选人类可读后缀（`CARD-X3-U01-01_氓.md`）；引用只写 ID；解析一律前缀匹配（docs/architecture/ID解析表.md）
- 判据：新增 ID 族先在解析表登记规则再产生数据；catalog path 可按表解析
- 出处：设计方案 §3.8 物理层；`docs/architecture/ID解析表.md`【所有者裁决1】
- 预期信号：人和 AI 都能从 ID 落到文件（人靠浏览、AI 靠解析表）
