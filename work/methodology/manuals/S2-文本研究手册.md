# S2 教案与证据研究手册

> 文件名为兼容既有catalog保留；当前S2主产物是教案，文本研究是第一阶段内部的G0专业支持，不再单独拥有最终教学裁决权。

## 条目

### MM-S2-01 裸读先行
- 优先级：P0
- 条件：研究任何课文
- 动作：先只读正文记录第一遍真实困惑（不查注释）——学生困难的预演
- 判据：裸读笔记在档，先于任何参考阅读
- 出处：U4 / 手法库§一
- 预期信号：预判困难命中率（课堂验证）

### MM-S2-02 解释边界四层
- 优先级：P0
- 条件：做任何关键判断
- 动作：区分文本明写/教材注释/合理推断/现代延伸，逐条标注
- 判据：边界标注覆盖全部关键判断；越界即退回
- 出处：P-09 / U6
- 预期信号：学生答题区分“诗写/我推断”

### MM-S2-03 候选 KP 挂文本锚点
- 优先级：P0
- 条件：整理知识清单
- 动作：每个候选 KP 挂到具体诗句位置；挂不上的登记缺口，教/defer由教案主skill裁决
- 判据：候选锚点表成文且文本位置可回到教材PDF
- 出处：P-04 / K2
- 预期信号：知识在文本位置生长（课堂）

### MM-S2-04 困难归 17 类
- 优先级：P0
- 条件：预判学习困难
- 动作：困难必须落到手法库的具体类型，禁止“基础弱”式不可操作描述
- 判据：困难清单可归类且有文本依据
- 出处：M-02 / U4
- 预期信号：手法选择有据

### MM-S2-05 全课主线与候选贯穿问题初审
- 优先级：P0
- 条件：裁决全课怎样推进时
- 动作：先比较原文顺序、叙事/论证推进、任务链与问题链何者最能串联目标和知识；贯穿问题只作按需候选。候选须过“初读者想知道—跨文本位置存证—统摄目标与知识—全文后可回收”四项初审，不满足则降为局部问题或不设
- 判据：研究档案写明主线候选及取舍理由；贯穿问题允许为零；不得把研究候选冒充G1正式问题
- 出处：K1 / K2 / J4 / P-31
- 预期信号：学生能沿原文和学习因果复述理解增长，不被教师谜底牵引

### MM-S2-06 关系边真实
- 优先级：P1
- 条件：连接已学课文
- 动作：关系边引用真实 CARD-ID 并注明关系性质
- 判据：关系边可解析
- 出处：N-03 / K4
- 预期信号：跨课文比较可用

### MM-S2-07 PDF规范原件优先
- 优先级：P0
- 条件：研究教材、课标或真题中的任何事实
- 动作：PDF/规范原件作证据根，MinerU与Markdown只作定位；冲突先回原件并登记差异
- 判据：evidence manifest位于本课`_meta`、LES-ID格式正确且不跨课程目录；含教材与课标PDF路径、SHA-256及派生关系；PDF有真实签名且非空壳，派生源、知识源与证据档案达到最低实体门；G0验证通过
- 出处：K1 / U6 / J7
- 预期信号：关键事实均可回页核验

### MM-S2-08 教案先行与全面坐标
- 优先级：P0
- 条件：开始任何单篇课文正式备课
- 动作：第一份正式教学成果写教师可读教案；正式课按`LES-{册代码}-{课文代码}-{两位序号}`定稳定ID并绑定唯一课程目录；完成教材、课标、学段知识体系、高考、现实时代五个坐标，但坐标明细进入依据附录，不先占据正文
- 判据：一个LES-ID只解析到一个课程目录且一个目录只登记一个LES-ID；五坐标均有调查结论；E0允许存在但不得伪造关联；正文具有教材与文本分析、学情、目标、重点难点、完整教学内容、课时与整体教学逻辑、达标判断的教师教案形态；未审教案不建lesson.json
- 出处：P-44 / K1 / K4 / J7
- 预期信号：目标与内容不再由PPT反向拼凑

### MM-S2-09 目标、作品整体解释与知识全账
- 优先级：P0
- 条件：G1教案起草
- 动作：逐项审计语言、思维、审美、文化、立德树人、现实迁移六向并记录纳入/不单列及理由；语言、立德树人、现实迁移必须有目标落点，其他三向有据取舍；每项目标标维度并绑定原文/教材支持的必教或检索旧知KID、达标证据、失败信号和复现位置。另逐项裁决作品主旨/核心观点、作者/叙述者/抒情主体表达意图或作品表达指向、情感变化或态度语调组织；适用项形成有证据边界的课堂范围KID，确不适用项写文体理由，只有成为核心学习结果时才进入目标。用14类、文化五类和作品整体解释三项做后台覆盖审计；再由本篇课文裁决实际KID，语义去重后按原文推进、意义结构、叙事/论证关系或学习依赖形成自适应知识簇。同一知识事实只定义一次，每个KID恰好归入一个主簇，簇写组织依据与聚合理由；目标、背景、阶段和审计只回指KID。每条KID标来源、状态、证据和阶段；必教/检索旧知另列可解析的KP ID。需要逐词逐句疏通的古诗文，知识全账覆盖连续原文单元的词义、语序/省略、整句译意和全文连贯译述，不以若干重点注释代替全文理解。研究时按证据依赖推进，成文时把最终裁决写成教师教案正文：教材与文本分析、学情、目标、重点难点、完整教学内容、课时与整体教学逻辑、达标判断；五坐标明细、六向审计过程、覆盖过程、来源、解释边界、KID/KP映射、哈希、defer与审批信息进入依据/治理附录。机器合同保留完整字段，不把机器字段逐项翻译成人读正文
- 判据：六向审计无缺项，目标维度与审计引用一致；作品整体解释三项无缺项，适用项通过KID唯一指向准确结论并另有证据边界和阶段，不适用项有具体理由；`work_interpretation`不得另写statement形成第二事实源；后台覆盖无未说明缺项，成品目录不机械复制审计类别；知识簇非空、具有本篇组织依据，所有KID（含教师储备/defer）全部且唯一归簇；无近义重复事实；育人/迁移目标具体到本篇、有文本依据且能以失败信号拒绝空泛口号；必教/检索旧知/defer/教师储备分明；目标只绑定必教或检索旧知KID，教师储备/defer不得进入课堂阶段；必教/检索旧知的`kp_ids`与`source_ref`均解析到G0登记知识源；每个KID的`stage_refs`与`stages[].kid_refs`反向投影完全一致；每个目标声明的`目标—KID`关系在同一阶段共同承担，并能回查该阶段的原文范围、初步教法和达标证据；古诗文完整疏通目标有全文译述产物；全面调查不等于全部讲授；教师不读附录能在三分钟内回答为什么教、教什么、学生学到什么、怎样推进和凭什么达标，治理附录不另写方案、不反向淹没正文
- 出处：P-04 / P-09 / P-11 / P-44 / P-46 / K1 / K2 / U6 / J7
- 预期信号：教学设计可逐项消费而无内容缺口

### MM-S2-10 完整整体教学逻辑
- 优先级：P0
- 条件：目标、知识全账和全课主线完成初步裁决后
- 动作：先用连续文字串联导入、必要背景、文本展开、知识形成、学生体验、讨论、重新整体化、总结检索、评价与迁移；再在同一“课时安排与整体教学逻辑”部分，逐阶段写进入理由、原文/材料范围、目标与KID、初步教法、学生变化与体验、教师作用、达标证据和转段理由；高考/新闻按调查结论纳入或说明不纳入
- 判据：逻辑段与阶段落实表共同构成唯一主线，并位于人读教案核心决策正文；删除/调换反证通过；目标或必教KID无游离；只列编号或“讲解/讨论”不能算落实；覆盖审计只回指，不重复写第三份方案，也不以治理字段打断教师对整课的连续阅读
- 出处：K1 / K2 / U8 / J4 / P-31
- 预期信号：学生可复述自己怎样沿整堂课从不懂走向有证据的理解

### MM-S2-11 所有者审核绑定当前哈希
- 优先级：P0
- 条件：教案准备由G1候选转为批准
- 动作：批准前先生成不含回执、状态固定为`candidate_owner_review`的机器合同候选并预检；把人读教案、候选合同、合同canonical SHA-256和G0清单SHA-256作为一个组合交所有者。只有所有者明确批准当前组合后，才生成正式回执与G1锁；作者不得自批；贯穿问题字段允许为空，有问题时须登记统摄理由、目标与知识责任、阶段链和最终回收阶段
- 判据：`validate_lesson_plan.py --candidate`通过只表示候选可审、不得写approved；正式锁固定在同课`_meta/lesson_plan_lock.json`，仍须保留内容完全一致的已预检候选并绑定真实回执；教案、合同、证据任一改变后旧回执立即失效；审核者与作者规范化后不同
- 出处：P-21 / P-37 / P-44 / J7
- 预期信号：教学设计只能消费真实批准版本

### MM-S2-12 高考必查、按需呈现
- 优先级：P1
- 条件：完成每课高考坐标
- 动作：检索本篇/作者/知识/同类文本/同类能力并分E0—E3；只有能调用旧知、诊断、迁移或说明普遍性的可靠材料才进入课堂
- 判据：E0如实记录；进入课堂的材料有真题来源、使用目的、学生动作和回到本课的位置
- 出处：K1 / U2 / U6 / J7
- 预期信号：考试关联服务语文理解，不制造焦虑或固定凑页
