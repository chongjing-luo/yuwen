# S6 课堂观察手册

## 条目

### MM-S6-00 宿主放行事件准入
- 优先级：P0
- 条件：准备试教或写入任何OBS记录
- 动作：消费项目目录外`external-host-release-registry.v1`，逐条核对宿主事件的课程ID、当前G4 audit lock SHA-256、来源定位、记录哈希与`decision: released`；OBS写入`g4_audit_lock_sha256/host_release_event_id/host_release_source`
- 判据：`validate_evidence.py <obs.jsonl> --type obs --host-release-registry <宿主只读路径>`通过；项目内无`host_release*.json`
- 出处：J7 / P-11 / 两本账边界
- 预期信号：课堂证据只产生于宿主真实放行的当前候选，不发生候选自放行

### MM-S6-01 信号对应节点
- 优先级：P0
- 条件：配置观察表
- 动作：每个观察信号标注其机制节点（K/U/J）；无节点绑定的信号不采集
- 判据：观察表逐信号有节点编号
- 出处：设计方案§3.5血缘② / J7
- 预期信号：证据可按节点归因

### MM-S6-02 记录事实不记评价
- 优先级：P0
- 条件：课堂现场记录
- 动作：只记发生了什么（人次/原话/动作），“气氛好/很顺”不是证据
- 判据：记录为事实型字段
- 出处：J7 / P-12
- 预期信号：反思有据可归

### MM-S6-03 作品样本可追溯
- 优先级：P0
- 条件：采集学生作品
- 动作：样本标明来自哪页/哪题/哪个学生（脱敏与否按裁决，如实即可）
- 判据：样本登记来源
- 出处：设计方案§3.5 / U2 / K3
- 预期信号：回教与评语可引用

### MM-S6-04 未采集如实标注
- 优先级：P0
- 条件：整理观察数据
- 动作：没采到的信号写“未采集”，不以桌面推演代替
- 判据：观察表无空洞
- 出处：P-12 / J7
- 预期信号：两本账不混写

### MM-S6-05 观察证据当日只追加
- 优先级：P1
- 条件：课后当天
- 动作：OBS只追加到`work/teaching/_classes/<班级>/observations.jsonl`，作品保留原件并登记来源；不在S6写GRD/MR，不修改历史行或评估报告冒充课堂账
- 判据：L4出现可追溯的当日OBS新行；mastery ledger仍由S8负责
- 出处：D3-⑤慢环 / U8 / J7
- 预期信号：闭环不断链
