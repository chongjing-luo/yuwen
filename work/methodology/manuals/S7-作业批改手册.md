# S7 作业与批改手册

## 条目

### MM-S7-01 闭卷检索必含
- 优先级：P0
- 条件：设计任何作业包
- 动作：至少一道闭卷检索题（先写后核、亲手订正、痕迹计入证据）
- 判据：validate_homework_package N-02 检查通过
- 出处：N-02 / K3
- 预期信号：延迟保持率（测评）

### MM-S7-02 迁移变式必含
- 优先级：P0
- 条件：设计任何作业包
- 动作：至少一道迁移题（变式情境运用 KP，作答区分诗写/推断）
- 判据：validate_homework_package U8 检查通过
- 出处：U8 / U6
- 预期信号：迁移题得分率

### MM-S7-03 每题六件套
- 优先级：P0
- 条件：写任何作业题
- 动作：kp_ids/page_refs/prompt/expected_evidence/feedback_trigger/normal_path 齐备
- 判据：validate_homework_package 通过
- 出处：设计方案§6门禁 / K3 / J7
- 预期信号：批改可执行可回流

### MM-S7-04 时长上限
- 优先级：P0
- 条件：定作业总量
- 动作：必做（巩固+迁移其一）≤45 分钟；超限砍题不砍质量
- 判据：validate_homework_package 时长检查
- 出处：K5 / U5
- 预期信号：完成率 ≥90%（课堂）

### MM-S7-05 反馈证据引用
- 优先级：P0
- 条件：写任何反馈
- 动作：每条反馈引用学生原文一处；只给分数或等级的反馈不合格
- 判据：FR-01 抽查通过
- 出处：essay_feedback_rubric / U2
- 预期信号：学生可执行修订

### MM-S7-06 反馈触发修订
- 优先级：P0
- 条件：反馈成文时
- 动作：每篇至少一条可执行修订指令；批改后学生有修订动作
- 判据：FR-02；修订痕迹率统计
- 出处：U3 / FR-02
- 预期信号：修订痕迹率（台账）

### MM-S7-07 批改数据入台账
- 优先级：P1
- 条件：批改完成后
- 动作：每题得分+错因类型录入 GRD/MR 台账（错因可操作，不写“粗心”）
- 判据：analyze_mastery 可运行
- 出处：设计方案§6 S7/S8跳 / K3 / U8
- 预期信号：诊断有数据底座
