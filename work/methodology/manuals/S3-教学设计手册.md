# S3 教学设计手册

## 条目

### MM-S3-01 评估标准先于页面
- 优先级：P0
- 条件：开始设计任何页面前
- 动作：先写该事件/页面的具体困难、学生接收或动作、后续检验/第一次后用、删除损失和失败信号；再按`event_type.requires`逐项写真实等待、回应与诚实分支、可见或可听产物、反馈和必要修订（P-37）；无预期判据不开工
- 判据：共同合同与`event_type`闭合且非模板；`artifact/real_wait/bounded_feedback/visible_revision/normal_counterexample`只按注册表命中项齐全，讲授叙述朗读沉静事件不以“无产物”等占位串伪造条件合同；审查者能据此判断返工
- 出处：P-37 / U8
- 预期信号：课堂出现预设失败信号时能被观察表捕获

### MM-S3-02 事件类型决定页面合同
- 优先级：P0
- 条件：填写任何逻辑页
- 动作：所有事件填写前页输入、困难、唯一功能、信息状态、学生接收/动作、后用、视觉职责、第一人称接收、删除损失、连续增量、注意力预算与故事回接，并以`next_use_ref`指向真实后续检验；产物、等待、反馈、修订和正常反例逐项由注册表`requires`决定
- 判据：schema v2.6 strict通过；`activity_contract.event_type`可解析并决定条件字段；后用引用指向后续真实页面、末页收束或明确测评对象；非生成事件没有虚假任务字段
- 出处：A-01 / P-15 / U8 / J7
- 预期信号：审查者能沿字段证明接收链

### MM-S3-03 反样板
- 优先级：P0
- 条件：任何追溯字段成文
- 动作：禁止 contract() 默认模板串；每字段写该页具体情形
- 判据：check_trace_evidence --strict 0 发现
- 出处：P-28 / LRN-20260814-001 / J7
- 预期信号：双审不再出现“字段齐全但无证据”页

### MM-S3-04 KP 落点或显式 defer
- 优先级：P0
- 条件：确定教学内容时
- 动作：G1每个必教/检索旧知KID的KP投影在`kp_scope`与目标`kp_refs`中精确保持；页面以`lesson_kids`和`knowledge_payload`承接KID及其知识生命周期；每个课级KP有落点页或带理由defer
- 判据：G1 `KID→KP`与G2投影严格一致，validate_lesson_schema K1 检查通过
- 出处：N-01 / K1
- 预期信号：作业与测验可按同一 KP 闭环

### MM-S3-05 只落实G1按需批准的问题
- 优先级：P0
- 条件：G1含贯穿问题，或阶段需要局部提问
- 动作：G1贯穿问题按批准的提出、存证和回收阶段落实，不改变措辞和责任；G1问题为空时不得为了模板在S3另造贯穿问题。局部问题只服务本阶段具体困难，到文而问，不写入贯穿问题投影
- 判据：`three_questions`与G1问题文本精确一致且允许空列表；有问题时提出、存证、回收事件闭环；局部问题不冒充全课问题
- 出处：K1 / K2 / J4 / P-05 / P-11
- 预期信号：学生在拥有相应原文证据后对问题产生真实反应，不被问题模板牵引

### MM-S3-06 参与五要素
- 优先级：P0
- 条件：活动确实需要合作、公开表达或同伴反馈
- 动作：合作前保留个人生成痕迹；小组任务须有互依而非报答案；发生公开表达时必须给听众具体任务；收到反馈后由原作者作可见修订。独立检测、静读、倾听和终读不为凑参与形式强塞五环
- 判据：只对合作/公开表达事件，由`student_action/activity_contract.participation_type/script.student_process/visible_revision`共同证明实际需要的参与环节；公开表达页可定位表达者、听众动作和本人修订；讲授、叙述、静读、倾听和沉静不因本条强塞合作
- 出处：P-14 / J1
- 预期信号：主动开口率与生成证据达标（S6 度量）

### MM-S3-07 首答态四渠道保护
- 优先级：P0
- 条件：任何学生生成任务
- 动作：屏幕、教师台词、学习单、版式四渠道不得提前泄答
- 判据：多渠道泄答测试（A-T04/T13）+ 版式等权检查
- 出处：P-34 / P-42 / U1
- 预期信号：首答非空白抽样率高

### MM-S3-08 反例诚实路径
- 优先级：P0
- 条件：任何学生生成、引导回应、讨论、操练、收纳或检索任务
- 动作：想不起/不同意/沉默有同等可见可完成路径，无需伪造
- 判据：normal_counterexample 覆盖该页反例类型且非模板
- 出处：P-17 / U7
- 预期信号：沉默学生真实完成率（S6 度量）

### MM-S3-09 手法由知识性质、目标深度与困难共同选择
- 优先级：P1
- 条件：为页面选手法时
- 动作：先判断知识性质、目标深度和具体困难，再选择课堂事件类型；只有学生主要通过自主加工获得增量时才选主活动类别，其他轴按需登记；连续事件底层协议不同构
- 判据：`activity_contract.event_type`及适用类别ID可解析，事件合同与“知识—困难—体验—证据”闭环一致；讲授叙述沉静允许无主活动，去同质化审计通过
- 出处：P-20 / M-02 / U4 / J5
- 预期信号：课中后段投入度维持

### MM-S3-10 语义场景与时间盒
- 优先级：P1
- 条件：排页面时间
- 动作：单页保持一个连贯语义场景或组织意图，可容纳需要共视且加工动作一致的多组知识；先守住语义完整下限，再守住共同可读、焦点清楚和负荷可承受上限；timeboxes 秒和=分钟×60
- 判据：v2.6语义单位、共视/分时、层级、连续锚点、动态密度和边界理由通过；时间盒守恒检查 + 累计负荷审计（A-T22）；不以固定要点数、字数或一页一个KID代替判断
- 出处：P-22 / P-35 / K5 / U5
- 预期信号：实际耗时与预算偏差 ≤10%

### MM-S3-11 教师后置归纳与精讲位置
- 优先级：P1
- 条件：安排师生活动
- 动作：学生能够凭文本形成的开放解释先生成，教师归纳引用现场原话并后置；作者、出处、字词、句法、文体、可靠背景和必要解释边界在文本需要处直接准确讲清；复杂知识需要连续叙述时不拆成碎问；示范一处再迁移
- 判据：教师归纳责任测试（A-T09/T16）＋规范知识不猜测/完整讲授审查
- 出处：P-23 / P-32 / U3 / J2
- 预期信号：学生生成材料被公开使用（J3）

### MM-S3-12 全课六维协议与情绪曲线预排
- 优先级：P1
- 条件：成课后
- 动作：按认知动作、感官通道、社会结构、作品形态、反馈方式、教师作用六维指纹和情绪曲线自检；连续三页有四维同构原则上返工，能力递进须写新增能力
- 判据：`教学设计.md`形成逐页六维节奏矩阵与可能情绪曲线，数据来自`activity_contract/student_experience`而非另造 schema 字段；协议指纹测试（A-T17）
- 出处：P-33 / J5
- 预期信号：中后段课堂投入不衰减

### MM-S3-15 人读设计与课程数据同源
- 优先级：P0
- 条件：生成design lock前
- 动作：教学设计按课时写成连续可读的课堂事件链，并显式标出lesson ID、事件ID与全部page ID；人读稿采用“课堂正文＋设计索引”：正文按真实顺序呈现阶段、事件类型、学生前台、教师逐字稿、学生过程、必要回应/反馈、时间和转场，使教师可连续无声试讲；索引紧凑登记事件—页面/状态、目标/KID、活动与版式裁决、信息状态、后续检验和删除损失。另设全课视觉来源说明，并逐物理画面投影配图资格、图源/派生、教学功能、出现时机、页面位置与视觉权重、事实伦理边界。其余条件合同保存在lesson.json，不逐项翻译成正文；design lock登记S3内容作者
- 判据：教学设计达到最低有效内容，ID锚点与lesson.json对应，`author_id`非空，lineage通过；只读课堂正文即可复原整课而非拼接模板页，设计索引可回查关键裁决且不另造课堂；审批者不打开JSON也能审查每个物理画面的配图决定及其边界；技术字段不先于、不重复或淹没课堂过程；长度底线不替代语义审查
- 出处：P-11 / K2 / U8 / J7
- 预期信号：审查者可从人读事件直接定位机器页面合同

### MM-S3-16 原文绑定与字段闭合

### MM-S3-17 受控类别选择与扩展
- 优先级：P0
- 条件：为任何阶段或页面选择活动、参与结构、作品形态或教学版式时
- 动作：读取`教学设计类别注册表.json`；先按真实课堂选择事件类型，再由事件合同判断是否需要主活动、产物、反馈和修订。只有学生自主加工时登记主活动；讲授/叙述/提问/示范另登记教师动作，讨论/分组/展示另登记学生动作、参与结构或产物。具体版式不选模板家族，只从内容对象、语义关系、显示约束与排版操作四轴组合生成。对用户举例与既往课例，先写出其可能想解决的问题、期望变化与约束，再和本篇原文、获批目标/KID、学情与证据需求核对；可补正、拆并、替换或不采纳，不得成为页数、类别或活动配额。新增类别前证明现有组合不足并补边界、证据和真实课例
- 判据：v2.6 schema的事件类型与适用类别ID全部可解析；页面不含封闭`layout_type`，页面角色、内容对象、关系、约束和操作均可解析；讲授叙述沉静不因缺主活动失败，任何事件缺其`requires`规定的`task→wait`、回应分支、产物、反馈或修订即失败；统一模板理由和无适配理由失败；候选例子的取舍可回查
- 出处：P-47 / K1 / U4 / J5 / J7
- 预期信号：活动与版式能够按知识和困难稳定选择，新增方法不会变成不可检索的孤例

### MM-S3-18 知识分页、学生体验、教学版式与逐页剧本冻结
- 优先级：P0
- 条件：任何物理页面进入G2候选前
- 动作：逐页登记KID及初遇/形成/练习/校准/回取/迁移角色；先写页面语义单位与组织意图，再裁决必须共视、必须分时、主次层级、连续锚点、密度上下限和相邻边界；写学生感知、思考、可能情绪、行动和理解变化；用内容对象、语义关系、显示约束与排版操作说明页面怎样生成，把前台元素对象化并冻结逐态可见集合；完成真实课堂所需的讲授、叙述、朗读、任务、等待、校准、反馈、总结和转场片段。可能回应、分支、产物、反馈与修订分别按`event_type.requires`落实
- 判据：`knowledge_payload/activity_contract/student_experience/slide_design/script`全部通过v2.6校验；多KID同页有共同语义单位、可见关系、相同主加工和共视需要；答案性元素与反馈不早于该事件规定的学生回应或作品提交触发，非生成事件无虚假产物；S4可唯一复原各态并只需落实精确几何、资产与美学；人读设计可无声试讲；版式理由不能以美观、清晰、大气替代教学功能
- 出处：P-01 / P-08 / P-15 / P-19 / P-40 / P-47 / K2 / U1 / U8 / J4 / J5
- 预期信号：S4无需重新决定怎样教，只需忠实完成视觉、美学和多媒体实现

### MM-S3-19 状态—剧本—时间同态
- 优先级：P0
- 条件：页面含一次以上任务、状态变化、材料进入、学生作品公开或校准时
- 动作：按课堂真实顺序使用`transition/instruction/narration/reading/task/wait/calibration/feedback/summary/cut`片段；讲授、叙述、朗读和总结直接写完整真实语言。每次发布新任务后立即配置属于该任务的真实等待；每个非B0信息状态由同触发片段进入；时间盒按顺序覆盖全部真实片段，不设固定段数。剧本声称会出现的现场作品、关系图、共性断点、检查项或回取栏逐一登记为前台元素并进入对应状态；动态内容可冻结为空位或“现场填写”对象，但不得用固定答案冒充。来源辨界材料只呈现待判断陈述，不在卡面预印其所属类别
- 判据：结构化信息状态、逐字台词、触发时点和时间盒能唯一复原同一堂课；`segment_ids`按顺序恰覆盖全部片段；自由文本投影不矛盾；剧本所称学生作品与收纳载体均能定位到元素、状态、触发和操作时间；分类产物不是文字与预印标签配对
- 出处：P-34 / P-40 / P-42 / U1 / U3 / U5 / J4
- 预期信号：试讲时无“屏幕尚未变化但教师已讲答案”、无任务二缺等待、无时间盒与真实动作脱节

### MM-S3-20 上游证据守恒与逐课时恢复审计
- 优先级：P0
- 条件：G1目标证据落成页面，或一课时完成事件编排后
- 动作：先把G1每项目标的达标证据拆为可核对原子：数量、是否互不重复、是否要求同一学生、个人/小组、闭卷/开卷、必含成分、覆盖阶段、产物载体、字数约束的精确对象、掌握标准和第一次后用；建立“原子—页面—剧本—可见产物”对照，任一原子不得靠多名学生各做一部分、教师答案或含糊累计冒充。再按课时统计连续口头/书面综合输出、材料切换、公开比较与修订密度，在高强度输出之间安排与本课知识相称的朗读、倾听、动作、短校准或沉静恢复，不为多样性硬插活动
- 判据：G1证据原子逐项投影无缩水，数量与互异性可由同一规定主体的产物核验，字数范围能明确回答“计算哪几栏/哪一段”；每课时的高强度事件能够闭环，连续综合输出有必要性或恢复段；页面单独可执行但组合过载仍判失败
- 出处：P-33 / P-35 / P-37 / K1 / U5 / U8 / J5 / J7
- 预期信号：课堂输出能在预算内完成，学生作品达到上游规定形态，后半课不因连续切换而失速

### MM-S3-21 Markdown审批稿与G2所有者门
- 优先级：P0
- 条件：S3严格校验通过、准备形成design lock时
- 动作：把全部课堂事件唯一投影为同课`教学设计.md`，含lesson ID、全部事件/page ID、总逻辑、阶段时间，以及核心优先的双层投影：课堂正文按课时连续呈现学生经历、教师真实语言与必要互动，设计索引紧凑呈现事件—页面、知识分页、活动裁决、教学版式理由、证据与后用；全课视觉来源和逐物理画面的配图资格、来源/派生、功能、时机、位置权重、事实伦理边界必须作为可审内容进入人读稿，不得只保存在课程数据中。不得把其余条件合同铺成逐页模板、让审核者跨越治理信息拼接课堂。向用户提交当前Markdown、lesson.json和G1锁三项SHA-256并停止。只有用户明确批准该组合后，才生成精确绑定三项哈希的`G2_owner_approval.json`和design lock；任一项改变都须重新审批
