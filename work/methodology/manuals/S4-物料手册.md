# S4 教学物料手册

## 条目

### MM-S4-01 同源单点生成
- 优先级：P0
- 条件：制作任何物料
- 动作：先验证design lock；全部产物由获批教学设计与lesson.json同源生成，改课程源不手改成品；四种必需角色使用不同路径与不同内容哈希，生成manifest与含S4作者ID的materials lock
- 判据：G2有效，四种必需角色不复用文件或同一内容，manifest SHA链完整，`author_id`非空，materials lock通过，跨文件页码标记一致
- 出处：P-11 / J7
- 预期信号：改一处数据全部产物同步更新

### MM-S4-02 前台禁词零容忍
- 优先级：P0
- 条件：任何学生可见文字
- 动作：后台设计语言不上屏；舞台指令只入备注
- 判据：run_principle_checks frontstage_banned 0 命中
- 出处：P-07 / A-T07 / J4 / J7
- 预期信号：学生第一眼看见诗文而非控制语

### MM-S4-03 字号下限表
- 优先级：P0
- 条件：排任何文本
- 动作：原文≥28pt（按行数 39/32/27 自适应）、短语卡≥26、产物槽与释义≥22、标题 36 起、层级差≥1.4×
- 判据：构建器断言 + 视觉审查实测字号
- 出处：PPT手册§二 / 判例v8 / U5 / J2
- 预期信号：后排可读（课堂验证）

### MM-S4-04 首答态标题留开放
- 优先级：P0
- 条件：写任何首答态页标题
- 动作：标题只命名文学对象或留开放问题；断言式标题仅限后置完成态与讲解页
- 判据：标题首眼泄答测试（A-T13）
- 出处：N-04 / U1
- 预期信号：首答独立性（课堂抽样）

### MM-S4-05 版式等权与源序交错
- 优先级：P0
- 条件：排首答态材料组
- 动作：等大、同色、对齐托盘且源序交错语义族——行列均不成分组键
- 判据：视觉审查 + 数据源顺序核对
- 出处：P-42 / M-22 / U1
- 预期信号：首答分布不集中于“正确”区

### MM-S4-06 分发时点拆件
- 优先级：P0
- 条件：制作学生纸质材料
- 动作：会泄露后页信息的拆独立物件；登记首次发放事件与台词
- 判据：真实分发顺序测试（A-T11）+ 分发时点表
- 出处：P-25 / U1
- 预期信号：跨渠道泄答为零

### MM-S4-07 QA 渲染环
- 优先级：P0
- 条件：任何构建后
- 动作：soffice→PDF→逐页 PNG→非作者新鲜眼检查→修复→复验，至少一轮修复闭环
- 判据：PPTX先过OPC/PresentationML关系树结构门（含slide自身关系无External；图片须有`r:embed`、内部image关系和非空media部件，空`p:pic`不算；整份课件至少一项真实可见文本/图片），再由Office打开、soffice渲染和逐页检查形成发现-修复-复验记录；结构门不冒充可放映性
- 出处：PPT手册§七 / P-29 / J7
- 预期信号：首渲染缺陷全部被捕获

### MM-S4-08 前台朗读测试
- 优先级：P0
- 条件：任何学生可见文字成文
- 动作：教师读出声不生硬；学生第一次听就知道面对谁、想什么、做什么
- 判据：人检记录逐页通过
- 出处：P-13 / J4
- 预期信号：课堂指令零二次解释

### MM-S4-09 色彩纪律
- 优先级：P1
- 条件：配色时
- 动作：先执行S3 `visual_source_profile`：教材有可靠色调时保留其色彩关系、人物锚和图形语言；教材不足时按文章类型与课堂功能补充。用主色支配、辅助色托底、强调色克制的层级组织画面，不把固定颜色机械绑定“语言/结构/情感”；必要时为投影对比度校正明度与饱和度，但不让不同页漂成无关视觉世界
- 判据：视觉来源与色板一致性审查；正文、原文、任务和状态色满足后排对比；颜色不泄答、不抢原文
- 出处：P-18 / PPT手册§三 / K2 / U5 / J4 / J5
- 预期信号：色彩不成为泄答或干扰渠道

### MM-S4-10 密度四步治理
- 优先级：P1
- 条件：内容多、怕挤时
- 动作：①分流（屏/口/单/板书）→②按S3语义场景、共视/分时和连续锚点生成具体几何→③骨架导航→④以真实字号同时检查语义完整下限与共同可读、单焦点、负荷可承受上限；固定条数和字数只作预警；遮页复述检验
- 判据：连续理解审计（A-T15/T12）；需改变语义分组、分页或揭示时序即退回S3，不缩字、不暗拆
- 出处：PPT手册§八 / K5 / U5
- 预期信号：学生能复述连贯整体而非碎片

### MM-S4-11 逐屏真实课堂剧本
- 优先级：P0
- 条件：每个PPT物理画面及其状态变化
- 动作：从有效G2逐页剧本同源生成讲者备注和独立screenplay，逐字保留承接、教师原话、学生过程、等待、可能回应、教师分支、反馈、证据、秒数与切页句；只补设备操作提示，不在S4重写教学语言
- 判据：screenplay作为manifest必需角色入锁；逐一锚定page ID并与lesson.json剧本同态，逐屏时间守恒，分支可执行，舞台指令不上屏；任何教学性改写须退回S3
- 出处：P-08 / P-40 / U3 / J4
- 预期信号：无声试讲可还原真实课堂发生，学生有思考与体验空间

### MM-S4-12 文本物料最低有效与原文锚定
- 优先级：P0
- 条件：写manifest前
- 动作：剧本、学习单、板书分别形成独立Markdown；拒绝短占位，学习单与板书至少回到一处教材原文
- 判据：三角色通过最低内容、标题、逐页/原文锚点校验；机器底线不替代朗读和教学审查
- 出处：P-04 / P-08 / P-11 / K2 / J4
- 预期信号：任何文本物料都能追溯到真实页面或课文位置

### MM-S4-13 忠实实现视觉来源与物理画面蓝图
- 优先级：P0
- 条件：构建任何PPT物理画面、取得或生成图片资产时
- 动作：逐屏读取S3冻结的可见元素、构图关系、阅读路径、空间比例、配图裁决和剧本片段；只完成精确坐标、字号、配色、字体、资产取得/生成、裁切、动效与母版统一。直接使用教材资产时保留来源哈希；从教材视觉派生时记录父资产、用途和事实边界；历史人物肖像不得被生成的相似脸替代。真实画布若证明蓝图不可读或图片功能不成立，退回S3，不在S4暗拆、暗并、换图或缩字
- 判据：每个PPT物理画面可反查唯一`physical_screen`；视觉资产有父源和SHA-256；required/optional/forbidden裁决未漂移；讲者备注恰含该屏绑定剧本；渲染QA完成发现—修复—复验
- 出处：P-11 / P-18 / P-40 / P-47 / K2 / U1 / U5 / J4 / J5
- 预期信号：PPT制作可以直接执行，视觉一致性不以牺牲原文、史实或课堂时序为代价

### MM-S4-14 页面角色的视觉语法与标题直接性
- 优先级：P0
- 条件：把S3页面角色和物理画面蓝图落实为PPTX时
- 动作：忠实保持PG01—PG09的主要职责：标题页课题主位，导航页显示路径，章节（子标题）页标示真实转换，主干页保持原文/证据主位，支撑页使用适合知识对象的肖像/时间线/地图/古籍等构图，活动页突出文学对象与单一主动作，作品反馈页让现场作品居主位，总结页重建关系，作业页明确任务成果与评价后用。标题、导航和章节（子标题）页不用虚构知识卡、目标标签或装饰框填满空间。支撑页允许与主干页有不同构图和密度，但字体、课文色板、视觉母题、人物锚和页码导航同源；不改S3触发—返回链。主标题直接说明对象或职责，艺术气息只在不遮蔽意义的副标题、引文、节奏和图像中实现
- 判据：每个物理画面可回查唯一`presentation_role`；角色视觉重点与注册表一致且未变成固定模板；PG05视觉可辨但不漂出全课主题；标题通过三秒识别、课堂朗读与首眼泄答三项审查；若需改变页面角色、语义分组或返回目标则退回S3
- 出处：P-13 / P-18 / P-47 / K2 / U1 / U5 / J4 / J5
- 预期信号：学生无需教师补充解释即可识别页面性质，支撑页切换清楚而主干阅读不断线
