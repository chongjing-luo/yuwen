## 条目标准格式（六字段）

```
### MM-<环节>-<序号> <规则名>
- 优先级：P0|P1|P2（P0 核心=执行前必读；P1 常用；P2 备查）【所有者裁决：不设数量上限，以优先级管理】
- 条件：什么情形下适用
- 动作：做什么
- 判据：怎样算做对（含审查门/校验器名）
- 出处：S1—S9写教学原则/当前备课目标框架锚点；S0写数据治理契约或架构来源
- 预期信号：做对了应出现什么可核验证据（S1—S9可为课堂信号，S0为数据质量信号）
```

## 准入与归档

- 新增条目：S1—S9教学规则说明目标框架/原则锚点，S0资料规则说明数据治理来源；所有条目都须有触发事件和可检查判据；
- 归档：修订时旧版整体移入本目录 `archive/`，同 DEVLOG 协议；
- 防腐：条目登记被哪些 skill 步骤引用，长期零引用触发处置（§5.3）。
