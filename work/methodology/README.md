# 语文教学方法论唯一入口

本目录集中保存“如何做”的人读方法论。任何agent或教师需要查方法时，从本页进入，不再从 `work/` 根目录或多个平行目录猜路径。这是方法论的存放与寻址契约，不需借用备课目标节点证明合法性。

## 权威层级

| 层 | 路径 | 作用 | 权限边界 |
|---|---|---|---|
| 上位法条 | `lesson-preparation/备课基本原则.md` | 规定必须坚持什么 | 原则含义的人读权威；机器状态以注册库为准 |
| 唯一流程 | `lesson-preparation/语文备课操作规程.md` | 规定单篇备课按什么顺序进行 | 唯一三阶段总流程，不与手册并列另起流程 |
| 专项规则 | `manuals/README.md`及S0—S9 | 规定各环节条件、动作、判据 | 只能细化本环节，不能改变总流程 |
| 目标工作框架 | `lesson-preparation/备课三目标与实现机制.md` | 暂用K/U/J组织备课目标、教学作用与课堂观察 | 可修订；不是项目宪法，不约束资料与工程 |
| 设计工具 | `lesson-preparation/原则体系.md`、手法库、视觉规范、逐页审计协议、PPT手册 | 支持具体教学决策 | 不新增上位原则，不冒充唯一流程 |
| 理论参考 | `foundations/` | 四层八份通用/语文理论资料 | 用于解释与选法，不作为现行门禁真相源 |
| 历史归档 | `archive/` | 已被现行体系吸收的早期方法文档 | 只供溯源，不作为当前规则入口 |

机器原则注册位于 `work/principles/registry.yaml`；验收制度与检查报告位于 `work/evaluation/`。它们分别回答“教学规则怎样被机器投影”和“怎样检查与记录结果”，因此只在本页链接，不复制到本目录。

## 使用顺序

1. 先读 `lesson-preparation/语文备课操作规程.md` 确定所在阶段。
2. 查对应的 `manuals/S{阶段}-*手册.md`，执行六字段MM条目。
3. 遇到具体教学困难时，再调用手法库、视觉规范或理论参考。
4. 以原则注册库、环节门禁和评估机制核验，不以“读过方法论”代替执行证据。

## 存放纪律

- 新的人读通用方法只能进入本目录的既有分层；不得在 `work/` 根目录另建“方法论”“原则总结”“操作方案”。
- 同一内容只保留一个正文，其他地方写链接；不建立兼容副本或软链接。
- 新增备课与教学规则应说明它在当前目标框架中的预期作用，并进入注册、设计追溯或审查门之一；S0资料规则和工程规则分别依据数据契约和可验证判据准入。
