# 语文备课规范理论框架

> 本文档整理中国语文教育学界的规范理论来源，而非个人见解。所有观点均标注学者姓名、著作出处。

---

## 一、语文课程论基础

### 代表学者：王荣生（上海师范大学教授，中国大陆第一位语文课程与教学论博士）

### 核心著作
- 《语文科课程论基础》（教育科学出版社，2014重版）
- 《语文课程与教学内容》（中国人民大学出版社，2021版）
- 《阅读教学设计的要诀》（中国轻工业出版社，2021第二版）
- 《听王荣生教授评课》（华东师范大学出版社，2007）

### 核心理论

#### 1. 三个层级的区分：课程内容 / 教材内容 / 教学内容

> **"语文课程的问题主要出在课程内容上。"**（王荣生，2003）

- **课程内容**：语文课程"应该教什么"——由课程标准规定
- **教材内容**：语文教材"用什么去教"——通过选文和单元编排呈现
- **教学内容**：课堂上"实际教了什么"——由教师根据教材和学情确定

三者不一致是语文教学效率低下的根源：课程内容研制缺失、教材名存实亡、教学内容急需学理审议。

#### 2. 选文四类型鉴别：定篇 / 例文 / 样本 / 用件

| 类型 | 功能 | 课程内容 | 教学方式 |
|------|------|---------|---------|
| **定篇** | 学习经典本身 | 经典文本的丰厚内涵 | 逐字逐句研读，不替代 |
| **例文** | 学习某一语文知识/方法 | 文本中体现的某一规则或方法 | 以文为例，举一反三 |
| **样本** | 学习阅读这类文章的方法 | 在阅读过程中生成的读写方法 | 从样本中归纳方法 |
| **用件** | 作为信息/资料使用 | 文本提供的信息本身 | 提取信息，完成任务 |

> **诊断意义**：教师常将"定篇"当"例文"教（只讲手法不讲经典本身），或将"用件"当"定篇"教（把信息材料当经典精读）。

#### 3. 阅读教学设计的两个依据

> **"依据体式来阅读，是阅读的通则；依据文本体式来解读课文，来把握一篇课文的教学内容，是阅读教学的基本规则。"**（王荣生）

**依据一：文本体式（文体特征）**
- 小说——关注人物、情节、环境、叙事视角
- 散文——关注"这一篇"独特的情感体验和语言表达
- 诗歌——关注意象、节奏、情感、韵律
- 文言文——"一体四面"（文章、文学、文化、语言）
- 实用文——关注信息获取、交际目的、表达方式

**依据二：学情分析**
- 学生能独立读懂什么？（教学起点）
- 学生反复阅读仍读不懂什么？（教学重点）
- 学生的感受与文本要求之间的差距在哪里？（教学切入点）

> **"学生不喜欢的，使他喜欢；学生读不懂的，使他读懂；学生读不好的，使他读好。"**

#### 4. 从"教的活动"转向"学的活动"

> 核心问题：语文课堂长期以"教的活动"为基点（教师讲、教师问、教师总结），应转向以"学的活动"为基点。

具体标准：
- 学生的"学的活动"有较充分的展开（时间保障）
- 学习经验有较充分的表达与交流（学生动起来）
- 班级每个学生都能获得共同的学习经验（面对学习共同体）

#### 5. "教什么比怎么教更重要"

> 王荣生反复强调：**语文教学研究要从过多的关注教学方法，转移到确定合宜的教学内容。**

很多课的问题不是"教得不好"，而是"教的东西不对"——教学内容本身不合适、不准确、不需要教。

## 二、语文核心素养与学习任务群

### 代表学者：王宁（北京师范大学资深教授，高中语文课标组组长）

### 理论来源
- 《普通高中语文课程标准（2017年版2020年修订）》
- 《从语言战略角度看信息时代的语文教育》（《语言战略研究》，2024）
- 《通向语文核心素养的学习任务群》（讲座/文章）

### 核心理论

#### 1. 语文核心素养四个方面及其关系

> **"语文核心素养提炼为四个方面：语言建构与运用、思维发展与提升、审美鉴赏与创造、文化传承与理解。这四个方面的具体内容是互相关联的。"**（王宁）

四者关系：
- **语言建构与运用**——核心与基础，语文课程**独有**的素养
- **思维发展与提升**——从语言建构中生发，是"内在的"
- **审美鉴赏与创造**——以语言为媒介，同时也是审美本体
- **文化传承与理解**——以语言为载体，有丰富文化内涵

> **"思维发展与提升、审美鉴赏与创造、文化传承与理解都是从语言建构与运用中生发出来的。"**

#### 2. 学习任务群的定位

> **"所谓学习任务群就是确定与语文核心素养发展相关的主题，设计教学情境和多样的学习任务，让学生自己在体验中完成任务。"**（王宁）

与过去三种组织方式的对比：

| 过去的组织方式 | 特征 | 弊端 |
|---|---|---|
| 以文本为纲 | 把文本系统化，不管学生 | 忽视学生主体 |
| 以知识为纲 | 布知识点（曾多达133个） | 负担重，消化不了 |
| 以行为训练为纲 | 听说读写平行分解 | 机械训练 |
| **学习任务群** | 回到学生素养，综合训练 | （转型中） |

任务群中的选文和训练有了新定位：
- 文本——"只是作为言语资源，用来解决语言运用问题"
- 训练——"是一种综合的、总体的、面向问题解决的训练"

#### 3. "三思三想"教学设计逻辑

> **"从所思所想出发，以能思能想启迪，向应思应想前进。"**（王宁）

- **所思所想**：学生的实际情况、已有经验
- **能思能想**：学生通过学习过程产生的变化
- **应思应想**：经过学习完成后的应然状态

> **"学习任务群一定要超过学生现有水平，但又是学生能达到的。"**

#### 4. 对"真实情境"的界定

> **"情境存留在语境之中，情境存留在思想接受的过程中，情境是师生共同营造的。"**（王宁）

不是必须离开教室去寻觅外在环境，也不是教师事先安排的，而是在语文学习过程中师生共同营造的语境。

#### 5. 中国语文教育的传统

> **"我国语文教育本就有文以载道、以文化人的传统。语文教育与道德教育、历史教育、哲学教育融合在一起，所谓文史哲不分家。"**（陆志平引，王宁认同）

历史脉络：周代国学教育 → 汉代经学教育 → 宋代理学教育 → 清代小学通经史 → 当代语文课程

> 与西方母语教育的根本差异：西方语言和文化是分开的（语言教学是语法，文化课是文学），中国语文课语言与文化不可分割。

#### 6. 教师角色定位

> **"教师只是一个沟通者，一个组织者。"**

批评"错位"现象：教师常错位到"传意者"，自己把文本吞了以后，用自己的理解替代作者的思想，直接灌输给学生。

> **"首先要相信学生的智慧……不要过于相信自己而轻视学生。"**

## 三、文本解读学

### 代表学者：孙绍振（福建师范大学教授）

### 核心著作
- 《文学文本解读学》（长江文艺出版社）
- 《名作细读：微观分析个案研究》
- 《月迷津渡：古典诗词个案微观分析》
- 《孙绍振如是解读作品》

### 核心理论

#### 1. 以创作论为武器解读文本

> 孙绍振解读学的指导思想：**以文学创作论为武器，揭示作品的创作奥秘。**

核心理念：作品好比果实，我们拿到果实时，它从种子入土到开花结果的整个生成过程都不见了，被手里的果实遮蔽了。**解读就是还原它的生成机制，艺术形成的奥秘就揭示了。**

#### 2. 文本解读方法谱系（"十二法"）

赖瑞云在孙绍振基础上系统梳理的解读方法：

| 方法 | 核心操作 |
|------|---------|
| **还原法** | 将艺术加工后的文本"还原"为原生状态，对比发现艺术加工的奥秘 |
| **矛盾法** | 找出文本内部的矛盾/不一致处，分析其产生的机制和效果 |
| **错位美法** | 人物之间的情感、认知"错位"产生审美张力 |
| **替换法** | 将原文词句替换为其他表达，对比发现原文的不可替代性 |
| **关键词语解读法** | 聚焦文本中关键性的词语，分析其独特的表达功能 |
| **形象三维组合解读法** | 从感知、情感、智性三个维度分析文学形象 |
| **三层揭秘法** | 从表层意思→深层情感→文化意蕴三个层次逐层揭示 |
| **感觉解读法** | 从作家独特的感觉方式入手，分析艺术感知的特征 |
| **艺术形式规范知识解读法** | 运用文论/文体知识解读文本的艺术形式特征 |

#### 3. 对语文教育的核心主张

> **文本解读是语文教学最重要的基本理念。** 教师的专业素养首先体现为文本解读能力——能读出一般读者读不出的东西。

## 四、多元有界解读观

### 代表学者：赖瑞云（福建师范大学文学院研究员、博士生导师）

### 核心著作
- 《混沌阅读》
- 《孙绍振〈文学文本解读学〉简释》（人民出版社）
- 《文本解读与语文教学新论》

### 核心理论

#### 1. 多元有界

> **"一千个哈姆雷特，还是哈姆雷特，不可能是李尔王或者贾宝玉。"**

多元解读是合理的（读者经验不同，理解必然不同），但必须有边界——这个边界由文本本身的规定性设定。

#### 2. 文言文教学"四结合"

赖瑞云提出文言文教学的"四结合"策略：
1. **文野结合**——专业化解读与直觉体悟结合
2. **文白结合**——文言理解与白话疏通结合
3. **文史结合**——文本阅读与相关文献资料结合
4. **文道结合**——语言学习与文化理解结合

#### 3. 专业化解读的两个路径
- **第一类**：运用知识理论（文体知识、创作理论、解读方法）
- **第二类**：引入相关文献资料（特别是古典作品，背景/语言/内容有隔膜，文献的"助解"作用突出）

## 六、对备课的直接指导（整合各学者理论）

### 备课的程序

依据王荣生 + 王宁 + 孙绍振的理论，规范的语文备课程序：

```
Step 1：确定选文类型（王荣生：定篇/例文/样本/用件）
    → 决定这篇课文在课程中的功能

Step 2：文本体式分析（王荣生：依据体式确定教学内容）
    → 依据文体特征确定"读什么""学什么"

Step 3：文本的专业化解读（孙绍振：以创作论为武器）
    → 运用还原法/矛盾法/替换法等读出一般读者读不出的东西

Step 4：学情分析（王荣生：依据学情选择教学内容）
    → 确定学生起点、落差、困难点

Step 5：确定核心素养目标（王宁：四维度对齐）
    → 语言建构与运用为核心，其余从中生发

Step 6：设计学习任务（王宁：学习任务群 + 三思三想）
    → 从学生"所思所想"出发，设计通向"应思应想"的任务

Step 7：设计"学的活动"（王荣生：从教的活动转向学的活动）
    → 确保学生活动充分展开，经验充分表达与交流

Step 8：设计评价（潘庆玉：语文教学评价）
    → 过程性评价与结果性评价结合
```

### 备课的自检标准

| 维度 | 自检问题 | 理论依据 |
|------|---------|---------|
| 教学内容 | 教的东西对不对？是不是这篇课文应该教的？ | 王荣生：教什么比怎么教更重要 |
| 文本体式 | 教学内容是否契合这篇课文的文体特征？ | 王荣生：依据体式确定教学内容 |
| 学情 | 是否基于学生已有的阅读经验？落差找准了吗？ | 王荣生：依据学情选择教学内容 |
| 解读深度 | 教师自己读出了什么独特的东西？ | 孙绍振：专业化解读 |
| 素养目标 | 是否以语言建构与运用为核心？四维是否关联？ | 王宁：四素养不可分割 |
| 任务设计 | 是否从学生"所思所想"出发？ | 王宁：三思三想 |
| 学的活动 | 学生有没有充分的阅读、表达、交流机会？ | 王荣生：以学的活动为基点 |
| 解读边界 | 多元解读是否有文本依据？ | 赖瑞云：多元有界 |
