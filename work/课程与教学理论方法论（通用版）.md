## 第一章　杜威实用主义教育学——现代教育理论的总源头

> 来源：约翰·杜威（John Dewey, 1859–1952），《民主主义与教育》（1916）、《经验与教育》、《我们怎样思维》

杜威是整个现代教育理论的总源头。后来所有的课程理论和教学理论——无论是继承还是反对——都绕不开他。

### 1.1 五个核心命题

| 命题 | 含义 | 对教学设计的意义 |
|------|------|----------------|
| **教育即生活** | 教育不是为将来的生活做准备，教育本身就是生活 | 教学情境必须是"真实的生活情境"，不是虚假的"为了教学造的情境" |
| **教育即生长** | 教育除了生长本身没有外在目的 | 评价学生不是看"达到了什么标准"，而是看"有没有在生长" |
| **教育即经验的改造** | 学习是人与环境交互作用中经验的不断重组 | 知识不是从外部灌进去的，是在活动中建构的 |
| **做中学** | 教学不是"先学后做"，而是在"做"的过程中"学" | 任务驱动、项目学习、实践探究——这些做法的哲学根基在杜威 |
| **儿童中心** | 教育的重心要从教师和教材转移到儿童 | 但杜威不是极端儿童中心——他强调教师是"引导者"而非"放任者" |

### 1.2 思维五步

> 来源：杜威《我们怎样思维》

```
① 疑难的情境 → ② 确定疑难的所在 → ③ 提出假设 → ④ 推断 → ⑤ 验证
```

这跟后来加涅的"九大教学事件"、威金斯的"逆向设计"都有血缘关系——都是从"如何引发真正的思考"出发来设计教学。

## 第二章　泰勒原理——课程开发的母版

> 来源：拉尔夫·泰勒（Ralph W. Tyler, 1902–1994），《课程与教学的基本原理》（1949），被誉为"现代课程理论之父"

泰勒原理是所有课程开发的母版。崔允漷的"教—学—评一致性"和威金斯的 UbD，其祖宗就是泰勒。

### 2.1 四个基本问题（即课程开发四步骤）

```
① 确定教育目标
    目标从哪里来？三个来源：学生需要 + 社会生活 + 学科专家建议
    目标怎么筛？两个过滤器：教育哲学 + 学习心理学

② 选择学习经验
    五条原则：
    — 必须让学生有机会实践目标隐含的行为
    — 必须使学生获得满足感
    — 必须在学生力所能及的范围内
    — 同一目标可用多种经验达成
    — 同一经验可产生多种结果

③ 组织学习经验
    三个准则：连续性（反复出现）+ 顺序性（由浅入深）+ 整合性（横向联系）

④ 评价结果
    检查目标是否达成
```

### 2.2 贡献与局限

| 贡献 | 局限 |
|------|------|
| 提供了课程开发的清晰框架，至今仍是主流 | 过分强调预设目标，忽视课堂中生成的、非预期的学习 |
| "目标—经验—组织—评价"的闭环逻辑清晰 | 容易把教育简化为"达标"过程，忽视教育的内在价值 |
| 为后续所有课程开发模型奠定基础 | 过程模式（斯滕豪斯）和实践模式（施瓦布）就是来批判它的 |

## 第三章　过程模式与实践模式——对泰勒的批判与超越

### 3.1 斯滕豪斯——过程模式

> 来源：劳伦斯·斯滕豪斯（Lawrence Stenhouse），《课程研究与研制导论》（1975）

**核心立场：**

- **教育有内在价值**（intrinsic value），不能还原为外在目标——有些学习本身就是有意义的，不需要用"达到了什么目标"来证明
- **过程比结果重要**——教育不是制造"产品"，而是师生共同探究的过程
- **"教师即研究者"**——教师不应是课程方案的被动执行者，而应在教学过程中持续研究、反思、改进

> **对备课的意义：** 不是所有教学都需要预设精确的行为目标。有些课的价值恰恰在于"不可预测"——课堂上的生成性对话、师生共同发现，比"完成教案"更重要。这跟叶澜的"动态生成"理念一脉相通。

### 3.2 施瓦布——实践模式

> 来源：约瑟夫·施瓦布（Joseph Schwab），"实践"系列论文（1969–1983）

**核心立场：**

课程是一个**"相互作用的生态系统"**，由四个要素构成：

| 要素 | 含义 |
|------|------|
| **教师** | 教师不是课程的执行者，而是课程的创造者 |
| **学生** | 学生不是课程的接收者，而是课程的参与者 |
| **内容** | 学科内容有自身的逻辑和结构，不能任意裁剪 |
| **环境** | 教室、学校、社区、时代——课程必须嵌入具体环境 |

课程开发不是套用普遍原理，而是**针对具体情境的"审议"**（deliberation）——在四要素之间寻找平衡。

> **对备课的意义：** 同一份教案在不同班级、不同教师手里效果可能完全不同——因为四要素的组合不同。备课不能只备内容和目标，还要备"这个班的学生的状态""这间教室的环境"。

## 第四章　分析教育哲学——什么知识值得教

### 4.1 赫斯特——知识形式论

> 来源：保罗·赫斯特（Paul Hirst）与罗伯特·彼得斯（R. S. Peters），《教育的逻辑》（The Logic of Education, 1970）

**核心观点：**

- **教育的核心是"博雅教育"**（liberal education）——通过掌握不同的知识形式来发展理性心灵
- 人类知识有**七种形式**（forms of knowledge），每种有独特的概念、逻辑和验证标准：

| 知识形式 | 独特概念 | 验证标准 |
|---------|---------|---------|
| 形式逻辑/数学 | 数、矩阵、公理 | 定理的可推演性 |
| 自然科学 | 重力、光合作用 | 感官观察与实验验证 |
| 对人与心理的理解 | 相信、意图、希望 | 内省与行为观察 |
| 道德知识与经验 | 正义、善、义务 | 道德推理 |
| 美学知识与经验 | 美、风格、和谐 | 审美判断 |
| 宗教知识与经验 | 上帝、罪、信仰 | 宗教体验 |
| 哲学 | — | 对其他形式的次元性反思 |

> **对备课的意义：** 不同类型的知识需要用不同的方式教——数学靠推演验证，科学靠实验观察，文学靠审美体验，道德靠推理判断。**教师首先要判断自己教的知识属于哪种形式，才能选择合适的教学和评价方式。**

### 4.2 彼得斯——"教育即引领入门"

> 来源：罗伯特·彼得斯（R. S. Peters）

- 教育不是灌输信息，而是**"引领学生进入"**（initiation）某种知识和经验的模式
- 教育目的内建于教育概念本身——不是外在的"为了考试"或"为了就业"
- 强调**"为知而知"**——知识本身就有价值，不必屈从于功利目的

## 第五章　后现代课程理论——开放与生成

### 5.1 多尔——后现代课程观

> 来源：威廉·多尔（William Doll），《后现代课程观》（1993）

**核心立场：** 现代主义课程是封闭的、预设的、机械的；后现代课程应该是开放的、生成的、生态的。

**"4R"原则：**

| 4R | 含义 |
|------|------|
| **丰富性**（Richness） | 课程要有"深度、意义的层次、多种可能性" |
| **回归性**（Recursive） | 课程不是线性的，而是螺旋回归的——回头再看时会有新发现 |
| **关联性**（Relational） | 课程要关联教育、文化、宇宙等多重层面 |
| **严密性**（Rigorous） | 不是现代主义那种确定性，而是"有目的的寻找不确定性" |

### 5.2 派纳——概念重建

> 来源：威廉·派纳（William Pinar），《理解课程》（1995）

**核心主张：** 课程领域应从"开发"（development）转向"理解"（understanding）——不再只关注"怎么设计课程"，而要追问"课程是谁的？它服务于谁的利益？它传递了什么意识形态？"

> **对备课的意义：** 你选择教什么、怎么教，本身就隐含着价值立场。选不同内容、不同侧重，不是纯粹的技术差异，是教育价值观的差异。

## 第六章　中国课程论传统

### 6.1 核心素养导向

> 来源：《中国学生发展核心素养》（2016）；各学科课程标准（2017年版2020年修订）

**核心素养总体框架：**

```
                    文化基础
                   ↗        ↖
        人文底蕴        科学精神
                   ↘        ↙
                    自主发展
                   ↗        ↖
        学会学习        健康生活
                   ↘        ↙
                    社会参与
                   ↗        ↖
        责任担当        实践创新
```

核心素养是泰勒原理"目标来源三要素"（学生需要 + 社会生活 + 学科专家建议）在当代中国的重新表述。

### 6.2 钟启泉——课程改革理论

> 来源：钟启泉（华东师范大学教授），《单元设计：撬动课堂转型的一个支点》（教育发展研究，2015）、《基于核心素养的课程发展》

**核心观点：**

- "单元设计是'核心素养—课程标准—单元设计—学习评价'这一课堂改革链中的关键一环"
- 从"阶梯型"到"登山型"的单元设计转变

| 维度 | 阶梯型设计（旧） | 登山型设计（新） |
|------|----------------|----------------|
| 设计重心 | 为教师的"教"设计 | 为学生的"学"设计 |
| 构成要素 | 仅关注知识点掌握 | "知识""认知过程""元认知"统一 |
| 文本性能 | 预设标准答案 | 不设标准答案 |
| 学习指向 | 浅层学习 | 深度学习 |

深度学习的三个修饰词：**主体性、对话性、协同性**。

## 第七章　中国教学论三大派

### 7.1 王策三——教学认识论

> 来源：王策三，《教学论稿》（1985）、《教学认识论》

**核心观点：**

- **教学是一种特殊的认识过程**——"特殊认识说"
- 教学是教师领导学生认识人类文明成果并获得身心发展的活动
- 教学过程本质上是一个认识过程，但它有特殊性：有教师的领导、以间接经验（书本知识）为主、有明确的发展目的

> **影响：** 20世纪60–90年代几乎主导了中国教学论领域，形成了"课堂教学重在传授学科知识"的实践思想。后来的课改在某种程度上是对这一传统的反思和超越。

### 7.2 李秉德——教学要素论

> 来源：李秉德，《教学论》（1991）

以系统论为指导，提出教学的**七要素**：

| 要素 | 说明 |
|------|------|
| **学生** | 学习的主体 |
| **教师** | 教学的组织者和引导者 |
| **教学目的** | 指向核心素养/课程目标 |
| **教学内容** | 学科知识、方法、价值观 |
| **教学方法** | 教学策略和学习方式 |
| **教学环境** | 物质环境 + 心理环境 |
| **教学反馈** | 评价与调节 |

> **对备课的意义：** 备课时可以用这七个要素做检查清单——你有没有遗漏某个要素？很多课的问题出在"只备了内容和教法"，忽视了环境、反馈等要素。

### 7.3 叶澜——"生命·实践"教学论

> 来源：叶澜（华东师范大学教授），《新基础教育论》、《回归突破："生命·实践"教育学论纲》、《让课堂焕发生命活力》（1997）

**核心观点：**

- **课堂教学是师生生命共在的历程**——不能只看作认识活动，要从"生命"的高度看待课堂
- **动态生成性**——教学过程不是执行预设的教案，而是在多种可能性中做出选择、不断生成新的状态。教师对这种动态生成的把握就是"教育智慧"
- **"教天地人事，育生命自觉"**——教育是唤醒学生内在的自我意识，让生命达到自觉的状态

**"四观十二性"体系：**

| 四观 | 核心内容 |
|------|---------|
| **价值观** | 未来性、生命性、社会性 |
| **学生观** | 主动性、潜在性、差异性 |
| **教师观** | 具体性、发展性 |
| **活动观** | 双边共时性、灵活结构性、动态生成性、综合渗透性 |

> **对备课的意义：** 一份好的教案不只是技术文件，它应该预设了"可能发生的生命碰撞"。教案不是剧本，课堂执行不是"照演"——好的教案要给生成留空间。

## 第八章　教学要素论

综合李秉德的七要素说和施瓦布的四要素说，教学设计需要协调的核心要素：

| 要素 | 来源 | 备课中的具体操作 |
|------|------|----------------|
| **教师** | 李秉德/施瓦布 | 教师的专业素养、教学风格、对文本的理解程度 |
| **学生** | 李秉德/施瓦布 | 学生的已有经验、认知水平、兴趣需要、个体差异 |
| **目标** | 李秉德/泰勒 | 核心素养目标，可观测、可评价 |
| **内容** | 李秉德/施瓦布 | 学科知识的选择、组织和呈现方式 |
| **方法** | 李秉德 | 教学策略、学习方式、活动设计 |
| **环境** | 李秉德/施瓦布 | 物质环境（教室布置、资源设备）+ 心理环境（课堂氛围、师生关系）|
| **评价** | 李秉德 | 过程性评价 + 结果性评价，教—学—评一致性 |

# 第三编　教学设计理论

> 核心问题：如何把课程目标转化为可操作的课堂教学？

## 第九章　大单元教学论

### 9.1 主要理论来源

| 学者 | 单位 | 核心贡献 |
|------|------|---------|
| **崔允漷** | 华东师范大学 | 大单元教学的系统定义者，"单元=微课程=学习事件"，创建单元学历案设计模型（七步骤），获国家级教学成果一等奖 |
| **钟启泉** | 华东师范大学 | 从课程论层面奠定基础，"单元设计是撬动课堂转型的杠杆"，从"阶梯型"到"登山型" |
| **荣维东** | 西南大学 | 大单元四要素和四步实施路径，原文载于《语文建设》2021年12月 |

### 9.2 大单元的定义

> 来源：崔允漷

> **"这里所说的单元是一种学习单位，一个单元就是一个学习事件，一个完整的学习故事，因此一个单元就是一个微课程。或者说，一个单元就是一个指向素养的、相对独立的、体现完整教学过程的课程细胞。"**

判别标准：

> **"譬如语文教材中一个单元通常是一个主题下的几篇课文，如果这几篇课文没有一个完整的'大任务'驱动，没能组织成一个围绕目标、内容、实施与评价的'完整'的学习事件，那它就不是我们所讲的单元概念。"**

**核心区分：教材单元 ≠ 大单元。教材单元是编者给的材料分组，大单元是教师重构的学习事件。**

### 9.3 与传统单元教学的本质区别

> 来源：荣维东《大单元教学的基本要素和实施路径》

| 维度 | 传统单元教学 | 大单元教学 |
|------|------------|----------|
| **学习材料** | 多篇课文，仍以单篇为主 | 多文本视为整体，统整使用 |
| **课程知识** | 知识点零散、随意 | 用"大概念"统摄凝练 |
| **教学方式** | 讲授分析为主 | 真实/拟真情境任务驱动，自主合作探究 |
| **课程资源** | 单一教材文本 | 跨单元、跨书册、跨媒介整合 |

"大"的四个含义：
1. **内容更多**——根据需要整合
2. **大概念统摄**——有核心议题、主题、原理、策略
3. **结构化重组**——遵循学科逻辑、认知逻辑、心理逻辑统整
4. **大情境驱动**——基于特定议题/任务的"做中学"

### 9.4 大单元教学的关键要素

> 来源：荣维东

**四要素：**

| 要素 | 含义 |
|------|------|
| **情境目标** | 目标最好是一个任务场景，而非机械的知识技能目标 |
| **统整内容** | 真实的、有关联的、整体性的内容，需跨单元/跨书册/跨媒介整合 |
| **活动经验** | 让学生经历知识产生的过程——教学活动、教学事件的设计 |
| **动态评价** | 过程性评价 + 结果性评价，以学习任务单/评价量表/自检表呈现 |

> 崔允漷的"单元学历案"六要素（更细化）：①单元名称与课时　②学习目标　③评价任务　④学习过程（含资源与建议）　⑤作业与检测　⑥学后反思

### 9.5 单元学历案设计模型（七步骤）

> 来源：崔允漷（国家级教学成果一等奖）

```
Step 1：研读教材，对标核心素养，从大观念/大任务/大问题/大项目中选一种组织单元
Step 2：确定单元主题，规划课时安排
Step 3：依据课标+教材+学情，确定单元目标
Step 4：依据单元目标，设计真实情境下的综合性评价任务
Step 5：将单元目标细化为课时目标，分课时设计评价任务和学习过程
Step 6：整体设计单元作业与检测
Step 7：设计学后反思，搭建反思支架
```

**注意 Step 3→4→5 的顺序：先定目标，再定评价，最后定学习过程——这就是逆向设计的具体操作。**

## 第十章　逆向设计（UbD）

### 10.1 理论来源

> 来源：格兰特·威金斯（Grant Wiggins）& 杰伊·麦克泰格（Jay McTighe），《Understanding by Design》（追求理解的教学设计），1998年

这是大单元设计的国际理论源头，也是崔允漷单元学历案"评价先行"原则的学术根基。

### 10.2 什么是"理解"

> "理解"不是简单的"知道"，而是**吸收**；不是"复述"，而是**对知识与技能的有效迁移运用**。

**理解的六个侧面：**

| 侧面 | 含义 |
|------|------|
| **解释** | 能对现象、事实和数据做出合理解释 |
| **阐明** | 能讲述有意义的叙事，能说明事物的意义 |
| **应用** | 能在新的情境中有效运用知识 |
| **洞察** | 能批判性地审视观点，有批判性的视角 |
| **移情** | 能感受他人的情感和视角 |
| **自知** | 能认识到自己的偏见和理解局限 |

### 10.3 逆向设计三阶段

**传统设计顺序：** 目标 → 教学 → 评价（最后考）

**逆向设计顺序：**

```
阶段1：确定预期结果
    → 学生应该理解什么大概念？达到什么素养目标？
    → 哪些是持久的理解？哪些是重要问题和争论点？
    ↓
阶段2：设计评估证据
    → 什么证据表明学生理解了？
    → 表现性任务是什么？其他评估证据有哪些？
    ↓
阶段3：规划学习体验
    → 设计怎样的学习活动才能达成目标并通过评估？
    → 序列如何安排？怎样差异化？
```

> 钟启泉："评价任务的设计为什么要先于教学过程的设计？"——因为只有先确定"什么是学会的证据"，教学过程才有方向。

### 10.4 "大概念"（Big Ideas）

> 来源：威金斯&麦克泰格；刘徽（浙江大学）《"大概念"视角下的单元整体教学构型》（教育研究，2020）

大概念的特征：
- 是学科领域中最精华、最有价值的核心知识
- 反映学科本质和原理
- 成为学生解决问题的基本策略与方法
- 联结分散的小概念，勾连丰富的学习资源
- 具有超越具体课文的**迁移力**

大概念的两种提炼方式：
1. **基于课程标准**：分析教材，确定大单元学习中学生需要掌握的核心知识与能力
2. **基于学情**：细化学业质量标准，确定大单元学习中学生最难解决的问题

## 第十一章　教育目标分类学

### 11.1 布鲁姆/安德森——认知目标分类（修订版）

> 来源：本杰明·布鲁姆（Benjamin Bloom），1956年提出；安德森（Anderson & Krathwohl），2001年修订

**认知过程维度（六个层次，从低到高）：**

| 层次 | 行为动词 | 教学中的例子 |
|------|---------|------------|
| ①记忆 | 列举、识别、复述、定义 | 复述事实、背诵定义 |
| ②理解 | 解释、总结、比较、举例 | 用自己的话复述内容 |
| ③应用 | 运用、演示、执行、解决 | 用所学方法解决新问题 |
| ④分析 | 区分、归因、解构、组织 | 分析事物的结构和内在逻辑 |
| ⑤评价 | 判断、批判、辩护、评论 | 评价观点的合理性 |
| ⑥创造 | 设计、建构、创作、策划 | 创造新的作品或方案 |

**知识维度（四种知识类型）：**

| 类型 | 含义 |
|------|------|
| **事实性知识** | 术语、细节、事实 |
| **概念性知识** | 分类、原理、理论 |
| **程序性知识** | 方法、技能、算法 |
| **元认知知识** | 关于认知的知识、策略性知识 |

**低阶思维与高阶思维：**

```
低阶思维（LOTS）：记忆 → 理解 → 应用
高阶思维（HOTS）：分析 → 评价 → 创造
```

> 钟启泉指出，深度学习要求从浅层学习走向深度学习，**在落实高阶思维的过程中，低阶思维目标自然落地**。

### 11.2 马扎诺——新教育目标分类学

> 来源：罗伯特·马扎诺（Robert Marzano），《重塑教育目标新分类学》

马扎诺在布鲁姆基础上增加了**两个更高维度**——元认知系统和自我系统：

| 系统 | 水平 | 核心功能 | 核心问题 |
|------|------|---------|---------|
| **认知系统** | 水平1：信息提取 | 再认、再现 | 学生能不能检索出信息？ |
| | 水平2：理解 | 整合、象征 | 学生能不能识别知识的核心特征？ |
| | 水平3：分析 | 概括、认定、匹配、分类 | 学生能不能识别知识的内在逻辑？ |
| | 水平4：知识应用 | 调查、实验、决策、问题解决 | 学生能不能运用知识解决问题？ |
| **元认知系统** | 水平5：元认知 | 精确度监控、过程监控、目标设定 | 学生**会不会管理自己的学习**？ |
| **自我系统** | 水平6：自我 | 动机检查、情绪检查、效能检查、重要性检查 | 学生**愿不愿学**？学习对他有什么意义？ |

**自我系统的激活方式：**

| 激活方式 | 教学操作 |
|---------|---------|
| 新奇感 | 呈现意外信息、打破预期 |
| 情感连结 | 连接学生的情感经验 |
| 认知冲突 | 呈现与已有认知矛盾的情境 |
| 与真实生活相关联 | 让学生看到知识的现实用途和人生意义 |

> **这是最被忽视的维度。** 如果自我系统没被激活（学生觉得"这跟我有什么关系"），再好的认知设计都白搭。

## 第十二章　教学设计核心原则

### 12.1 局部与整体的四重关联

> 来源：教学讨论中提炼的设计原则

任何一个知识点的教学，都必须同时考虑四个维度的关联：

```
            ┌──→ ① 局部 → 整体知识体系（不能孤立教）
            │
  局部知识点 ┼──→ ② 局部在整体结构中的位置和作用
            │
            ├──→ ③ 知识的现实意义（为什么存在？回应什么问题？）
            │
            └──→ ④ 学生生涯纵向贯通（同一主题在不同学段如何递进深化？）
```

与大单元教学论的对应：
- 第①条 ↔ 大概念统摄
- 第②条 ↔ 结构化重组
- 第③条 ↔ 大情境驱动
- 第④条 ↔ 螺旋上升

### 12.2 加涅——九大教学事件

> 来源：罗伯特·加涅（Robert Gagné），《学习的条件》《教学设计的原理》

| 教学事件 | 对应的内部加工 | 备课中的操作 |
|---------|-------------|------------|
| ①引起注意 | 感觉登记器接收刺激 | 导入——用问题/冲突/情境引发关注 |
| ②告知目标 | 形成预期 | 明确告诉学生这节课要学什么、达到什么 |
| ③刺激回忆先备知识 | 提取到工作记忆 | 复习/联系已有知识 |
| ④呈现刺激材料 | 选择性知觉 | 呈现新内容 |
| ⑤提供学习指导 | 语义编码 | 提供支架、方法、框架 |
| ⑥引出行为表现 | 反应 | 让学生做练习/完成任务 |
| ⑦提供反馈 | 强化 | 及时反馈——不只是"对/错"，而是"为什么" |
| ⑧评价行为表现 | 提取与强化 | 检测目标达成度 |
| ⑨促进保持与迁移 | 提取并概括化 | 在新情境中运用 |

可合并为三个环节：

```
准备阶段（①②③）：引起注意 → 告知目标 → 激活旧知
操作阶段（④⑤⑥⑦）：呈现内容 → 提供指导 → 引出行为 → 提供反馈
迁移阶段（⑧⑨）：评价表现 → 促进迁移
```

**常见问题：** 有①④⑥（有导入、有讲解、有练习），但没有②③⑤⑦⑨（没明确目标、没激活旧知、没给支架、没及时反馈、没促迁移）。

### 12.3 加涅的五种学习结果

| 类型 | 含义 |
|------|------|
| 言语信息 | 能陈述事实/知识 |
| 智力技能 | 能运用概念/规则 |
| 认知策略 | 能调控自己的认知过程 |
| 动作技能 | 能执行身体动作 |
| 态度 | 形成价值取向和行为倾向 |

## 第十三章　认知发展理论

### 13.1 皮亚杰——认知发展阶段论

> 来源：让·皮亚杰（Jean Piaget），瑞士心理学家

| 阶段 | 年龄 | 思维特征 | 对教学的约束 |
|------|------|---------|------------|
| 感知运动 | 0–2 | 动作思维，通过感知和动作认识世界 | — |
| 前运算 | 2–7 | 兆具象思维，不可逆，自我中心 | 不能处理抽象概念 |
| 具体运算 | 7–11 | 守恒、可逆、分类，但依赖具体事物 | 需要具体材料支撑 |
| 形式运算 | 11+ | 假设演绎推理、抽象思维、系统思考 | 可以处理抽象概念和思辨 |

**对备课的指导：**
- 高中学生已进入形式运算阶段，可以处理抽象概念和思辨
- 但不是所有学生都稳定处于形式运算阶段——遇到困难时仍会退回具体运算，需要具体材料做"脚手架"
- 设计任务时要提供从具体到抽象的过渡路径

### 13.2 维果茨基——最近发展区（ZPD）

> 来源：列夫·维果茨基（Lev Vygotsky），苏联心理学家

> 学生现有发展水平（独立能完成的）与潜在发展水平（在成人指导或同伴合作下能达到的）之间的差距，就是**最近发展区（Zone of Proximal Development）**。

**支架（Scaffolding）：**
- 在最近发展区内提供的临时性支持
- 帮助学生跨越现有水平与潜在水平之间的差距
- 随着学生能力提升**逐步撤除**，最终实现独立

**支架设计原则：**

| 原则 | 含义 |
|------|------|
| **精准投放** | 只放在最难的环节，不要到处铺路 |
| **临时性** | 随着能力提升逐步撤除 |
| **差异化** | 不同水平的学生给不同密度的支架 |

**支架类型：** 资源支架（提供材料）、思维支架（提供框架）、方法支架（提供步骤）、评价支架（提供标准）

### 13.3 布鲁纳——螺旋式课程

> 来源：杰罗姆·布鲁纳（Jerome Bruner），《教育过程》（1960）

> **"任何学科的基础都可以用某种形式教给任何年龄的任何人。"**

核心命题：同一学科内容在不同发展阶段以不同深度反复出现，**螺旋上升**。

**三个表征系统：**

| 表征系统 | 年龄 | 特征 |
|---------|------|------|
| 动作表征 | 0–3 | 通过动作认识事物 |
| 图像表征 | 3–8 | 通过图像/模型认识事物 |
| 符号表征 | 8+ | 通过语言/符号认识事物 |

**对备课的指导：** "局部知识与学生生涯纵向贯通"的理论基础——同一核心概念在不同认知水平上的重新建构。

## 第十四章　学习如何发生

### 14.1 建构主义

> 来源：皮亚杰（个人建构）、维果茨基（社会建构）、布鲁纳（发现学习）

> 知识不是由教师传递给学生的，而是学生在真实情境中通过主动探究和意义建构获得的。

**四大要素：**

| 要素 | 含义 |
|------|------|
| **情境** | 学习必须在真实或拟真的情境中发生 |
| **协作** | 学习者与同伴、教师之间的社会性互动 |
| **会话** | 通过语言交流实现意义协商 |
| **意义建构** | 学习的终极目标——生成自己的理解 |

**对备课的指导：**
- 教师角色：从"传递者"变成"设计者"和"引导者"
- 教学要创设**认知冲突**——让学生发现已有经验无法解释的新现象
- 小组讨论、合作探究不是装饰，是建构知识的核心机制

### 14.2 奥苏贝尔——有意义学习理论

> 来源：戴维·奥苏贝尔（David Ausubel），美国教育心理学家

> **"影响学习的唯一最重要的因素，就是学习者已经知道了什么，要探明这一点，并应据此进行教学。"**

**两种学习的区分：**

| 类型 | 含义 | 效果 |
|------|------|------|
| **有意义学习** | 新知识与学生已有知识结构建立实质性、非人为的联系 | 理解深、保持久、可迁移 |
| **机械学习** | 新知识孤立存储，没有与已有知识建立联系 | 死记硬背、易遗忘、不能迁移 |

**关键工具——先行组织者：**

在呈现新内容之前，先给学生一个**比新内容更抽象、更概括的"引导性材料"**，为后续学习提供"认知锚点"。

先行组织者的两种类型：
- **说明性组织者**：提供与新知识相关的背景概念框架
- **比较性组织者**：将新知识与学生已有的类似知识进行对比

**对备课的指导：**
- 导入环节不应只是"激发兴趣"，更应该是**激活已有知识结构**
- 单元教学的第一节课，应该提供"先行组织者"——让学生先看到整个单元的认知地图

## 第十五章　动机理论

### 15.1 自我决定理论（SDT）

> 来源：德西（Edward Deci）& 瑞安（Richard Ryan）

人的三种基本心理需求——当这三种需求被满足时，内在动机被激发：

| 需求 | 含义 | 教学设计中的满足方式 |
|------|------|-------------------|
| **自主感**（Autonomy） | "我选择学，不是被迫学" | 给学生选择空间 |
| **胜任感**（Competence） | "我能做到，我有能力" | 设计难度适中的挑战——在最近发展区内 |
| **归属感**（Relatedness） | "我属于这个群体，我被接纳" | 创设合作情境——小组讨论、同伴互评 |

### 15.2 ARCS动机模型

> 来源：约翰·凯勒（John Keller）

| 要素 | 含义 | 教学设计中的操作 |
|------|------|----------------|
| **A** Attention（注意） | 引发并维持注意力 | 用认知冲突、悬念、意外信息引起注意 |
| **R** Relevance（相关） | 与学生的目标/需求相关 | 连接学生生活经验 |
| **C** Confidence（信心） | 建立成功预期 | 提供支架，设置合理难度递进 |
| **S** Satisfaction（满意） | 学习成果带来的满足 | 成果展示、获得认可、看到进步 |

### 15.3 心流理论

> 来源：米哈里·契克森米哈赖（Mihaly Csikszentmihalyi）

当任务挑战与个人技能水平**匹配**时，人会进入"心流"状态——高度专注、忘记时间、内在驱动。

```
高挑战 + 高技能 → 心流（最佳学习状态）
高挑战 + 低技能 → 焦虑（太难，放弃）
低挑战 + 高技能 → 无聊（太简单，走神）
低挑战 + 低技能 → 冷漠（既不难也不感兴趣）
```

**对备课的指导：** 支架的作用就是把"高挑战+低技能"的焦虑状态，转化为"适度挑战+有支撑"的心流状态。

## 第十六章　迁移理论

### 16.1 近迁移与远迁移

| 类型 | 含义 |
|------|------|
| **近迁移** | 相似情境中的运用 |
| **远迁移** | 不同情境/领域中的运用 |

### 16.2 高通路迁移与低通路迁移

> 来源：威金斯与麦克泰格，UbD

| 类型 | 迁移路径 | 机制 | 效果 |
|------|---------|------|------|
| **低通路迁移** | 具体→具体 | 直接类比 | 迁移范围窄 |
| **高通路迁移** | 具体→抽象→具体 | 先提取大概念/原理，再在新情境中运用 | 迁移范围广 |

**对备课的指导：** 大单元教学为什么强调"大概念"？因为**大概念是高通路迁移的中间环节**——只有把具体的知识提升到大概念层面，才能迁移到全新的情境。

**促进迁移的教学策略：**

| 策略 | 操作 |
|------|------|
| 提取大概念 | 不停留在"写了什么"，而要上升到"触及了什么基本问题" |
| 多情境练习 | 同一概念在不同情境中反复运用 |
| 对比与类比 | 引导学生发现不同情境之间的结构性相似 |
| 远迁移任务 | 设计跨文本、跨单元、跨媒介、跨学科的综合性任务 |

---

## 第十七章　元认知理论

> 来源：约翰·弗拉维尔（John Flavell），1976年提出"元认知"概念

### 17.1 元认知的三个成分

| 成分 | 含义 |
|------|------|
| **元认知知识** | 知道什么样的策略适合什么样的任务 |
| **元认知监控** | 在学习过程中觉察自己的理解状态 |
| **元认知调节** | 根据监控结果调整策略 |

### 17.2 元认知策略的教学层次

```
Level 1：教师示范元认知（"我读到这里时感到困惑，于是我又读了一遍……"）
Level 2：师生共同练习元认知（"你们读这段时有没有觉得哪里奇怪？"）
Level 3：学生独立使用元认知策略（学生自己提问、自己监控、自己调节）
```

### 17.3 元认知自检问题（可教给学生）

| 阶段 | 自检问题 |
|------|---------|
| 学习前 | 我对这个话题已经知道什么？我的学习目标是什么？ |
| 学习中 | 这段话的主要意思是什么？我理解了吗？哪里不清楚？我需要重读吗？ |
| 学习后 | 我学到了什么？它和我已有的认识有什么不同？我还有什么疑问？ |

# 第五编　教学评价理论

> 核心问题：怎么知道学生学会了？评价如何成为学习的组成部分？

---

## 第十八章　教—学—评一致性

> 来源：崔允漷；威金斯UbD

> **"教—学—评一致性是有效教学的核心技术。"**（崔允漷）

含义：学习目标、评价任务、教学活动三者必须对齐——
- 评价任务用来检测学习目标的达成程度
- 教学活动要服务于目标的达成和评价的通过
- 三者不是先后松散关系，而是**逆向设计**的紧密嵌套

---

## 第十九章　评价类型与表现性任务

### 19.1 过程性评价与结果性评价

| 类型 | 特点 | 形式 |
|------|------|------|
| **过程性评价** | 在学习过程中持续进行，即时反馈 | 提问、观察、展示、互评、学习任务单 |
| **结果性评价** | 在学习结束后进行，总结判断 | 单元测验、终结性考试 |

> 课标："评价的过程即学生学习的过程。"——评价不是学习的终点，而是学习本身的组成部分。

### 19.2 表现性任务

> 来源：威金斯UbD

表现性任务是逆向设计阶段2的核心——用真实情境下的综合任务来检测学生是否真正"理解"了。

特点：
- 在真实或拟真的情境中完成
- 要求学生综合运用知识解决问题
- 有明确的评价标准（量规）
- 产出可见的成果（报告、作品、表演等）

### 19.3 学后反思

> 来源：崔允漷（学历案第七步）

> **"教下去的是知识与技能，留下来的是素养。"**

学后反思不是简单的"总结收获"，而是需要教师搭建**支持性的反思支架**：
- 对照素养目标，检查自己的达成情况
- 梳理学习路径，形成自己的认知地图
- 发现困惑，提出后续探究的问题

# 第六编　备课操作框架

> 核心问题：以上理论如何整合为一套可操作的备课流程？

---

## 第二十章　通用备课程序

> 综合泰勒原理、逆向设计UbD、大单元教学论、加涅九大教学事件、奥苏贝尔有意义学习、马扎诺自我系统

```
Step 0：现实之问（前置思考）
    → 这个知识点/文本能回应学生什么真实的困惑？
    → 马扎诺：自我系统激活——学生觉得"这跟我有关系"才会学
    → 不是"内容有什么可以教"，而是"内容能回应什么"

Step 1：课程标准对标
    → 对标学科核心素养和课标要求
    → 确定这个知识点在整个课程体系中的定位

Step 2：单元定位
    → 崔允漷：大单元视野中的位置
    → 在单元选文/内容脉络中的独特角色
    → 与前后内容的关联（连续性+顺序性+整合性）

Step 3：确定大概念
    → 威金斯/刘徽：提炼统摄性的核心知识
    → 大概念是高通路迁移的中间环节
    → 局部知识在整体知识体系中的位置

Step 4：文本/内容的专业化解读
    → 教师先独立钻研，形成自己的理解
    → 读出一般读者读不出的东西

Step 5：学情分析
    → 奥苏贝尔：探明学生已经知道了什么
    → 维果茨基：确定最近发展区——现有水平与潜在水平的差距
    → 确定学生起点、落差、困难点

Step 6：确定素养目标
    → 对标学科核心素养
    → 布鲁姆/安德森：目标覆盖适当的认知层次
    → 目标可观测、可评价

Step 7：设计评价任务（逆向设计阶段2——先于教学过程）
    → 威金斯：什么是"学会了"的证据？
    → 设计表现性任务和过程性评价
    → 评价方式与认知层次匹配

Step 8：设计教学活动（逆向设计阶段3）
    → 加涅：九大教学事件作为完整性检查
    → 情境创设 → 任务驱动 → 活动展开 → 成果展示 → 评价反思
    → 从教的活动转向学的活动

Step 9：设计迁移与反思
    → 威金斯：促进远迁移
    → 崔允漷：学后反思支架
    → 元认知培养：教学生监控自己的学习
```

## 第二十一章　备课自检标准

| 维度 | 自检问题 | 理论依据 |
|------|---------|---------|
| **现实意义** | 这节课回应了学生什么真实的困惑？学生觉得跟他有关系吗？ | 马扎诺：自我系统；余党绪：人生关怀 |

| **学的活动** | 学生有没有充分的学习、表达、交流机会？ | 建构主义；王荣生：学的活动 |
| **评价先行** | 评价任务是否先于教学过程设计？三者是否对齐？ | 威金斯：逆向设计；崔允漷：教—学—评一致性 |

| **生成空间** | 教案有没有给课堂生成留空间？ | 叶澜：动态生成；斯滕豪斯：过程模式 |

# 第七编　教学模式与深度学习

> 核心问题：有哪些教学模式可选？怎样让学习真正"深"下去？

---

## 第二十二章　教学模式谱系

> 来源：布鲁斯·乔伊斯（Bruce Joyce）& 玛莎·韦尔（Marsha Weil），《教学模式》（Models of Teaching）

### 22.1 教学模式的定义

> **"教学模式是构成课程和作业、选择教材、提示教师活动的一种范式或计划。"**（乔伊斯&韦尔）

教学模式是在一定教学思想或理论指导下建立起来的、较为稳定的教学活动结构框架和活动程序。

### 22.2 四大类教学模式

| 类别 | 理论依据 | 核心目标 | 代表模式 | 典型教学方法 |
|------|---------|---------|---------|------------|
| **信息加工类** | 信息加工理论 | 帮助学生成为更有能力的学习者 | 归纳思维模式、概念获得模式、布鲁纳发现教学、奥苏贝尔有意义接受学习、加涅累积学习、记忆模式、讲授模式 | 探究法、问题解决法、归纳法 |
| **社会互动类** | 社会互动理论 | 发展社会性品格和合作能力 | 杜威/塞林小组探究、西伦小组研究、奥利弗/谢弗法理学模式、社会调查模式 | 合作学习法、角色扮演法、辩论法 |
| **个人发展类** | 人本主义心理学、个别化教学理论 | 发展独特人格，促进个人与社会关系的理解 | 罗杰斯"非指导性教学"、戈登"创造工学" | 启发式教学法、求同存异法、自我导向学习 |
| **行为系统类** | 行为主义心理学、社会学习理论 | 培养行为习惯和技能 | 斯金纳程序教学、布鲁姆掌握学习、直接教学、模拟训练 | 直接教学法、练习法、反馈强化 |

### 22.3 教学模式、教学策略、教学方法的关系

```
教学理论 → 教学模式 → 教学策略 → 教学方法 → 教学实践
（最高层）  （稳定框架） （灵活方案） （具体操作） （课堂行为）
```

| 概念 | 层次 | 特征 |
|------|------|------|
| **教学模式** | 最宏观 | 相对稳定，提供整体框架 |
| **教学策略** | 中间层 | 较灵活，可随情境调整 |
| **教学方法** | 最微观 | 具体操作方式 |

> **对备课的意义：** 大单元设计和逆向设计解决"宏观设计"问题，但具体到每节课"用什么方式上"，需要教学模式层面的知识。一位教师如果不掌握多种模式，就会陷入"所有课文一个上法"的困境。乔伊斯指出："没有一种教学模式在任何时候适合所有的学生，优秀的教学往往是由一系列的教学模式组合而成的。"

## 第二十三章　深度学习理论

> 来源：郭华（北京师范大学教育学部教授、博士生导师），《深度学习及其意义》；易进、郭华《对课堂教学语境下"深度学习"内涵的深度解读》

### 23.1 定义

> **"深度学习，就是指在教师引领下，学生围绕着具有挑战性的学习主题，全身心积极参与、体验成功、获得发展的有意义的学习过程。"**（郭华）

关键限定：
- **在教师引领下**——不是学生自发的、偶然的学习，而是由教师设计和引发的
- **具有挑战性的学习主题**——任务有难度，学生现有经验不足以直接完成
- **全身心参与**——不仅是"颈部以上"的认知活动，而是理智与情感共在
- **有意义的学习**——与奥苏贝尔"有意义学习"（建立新旧联系）和罗杰斯"意义学习"（促进人的整体变化）一脉相通

### 23.2 深度学习的五个基本特征

| 特征 | 含义 |
|------|------|
| **① 活动与体验** | （根本特征）学生在主动活动中体验知识的丰富内涵；学习不是被动容纳，而是通过有目的的活动感受、理解、掌握知识 |
| **② 联想与结构** | 理解事物之间的联系，形成认知网络；调动已有经验参与当下学习，将新内容与旧经验建立关联 |
| **③ 本质与变式** | 透过多样表象把握事物本质；去除非本质属性干扰，分辨本质与非本质的区别 |
| **④ 迁移与创造** | 将所学知识运用于解决实际问题；面对新情境能激活知识网络 |
| **⑤ 价值与评判** | 依据一定标准判断是非优劣；对所学内容及学习过程进行价值评判 |

> 马飞龙的"变式理论"：最关键的是教师对教学中相同点与不同点、变与不变的内容的呈现和处理。提供标准正例之外，还须设计非标准正例甚至反例。

### 23.3 深度学习与浅层学习的区别

| 维度 | 浅层学习 | 深度学习 |
|------|---------|---------|
| 知识状态 | 零散知识点 | 把握核心知识，理解学科本质 |
| 学习方式 | 记忆、复述 | 分析、综合、评价、创造 |
| 学习动机 | 外部驱动（考试、奖励） | 内在驱动（兴趣、意义感） |
| 迁移能力 | 不能迁移 | 能在新情境中创造性运用 |
| 思维层次 | 低阶思维（LOTS） | 高阶思维（HOTS）为主，低阶自然落地 |

### 23.4 与其他理论的关系

| 关联理论 | 关系 |
|---------|------|
| 钟启泉"深度学习三修饰词" | 主体性、对话性、协同性——即深度学习的社会维度 |
| 布鲁姆目标分类 | 深度学习要求从低阶走向高阶 |
| 威金斯UbD | 理解六侧面与深度学习的五个特征高度互补 |
| 奥苏贝尔有意义学习 | 深度学习是"有意义学习"在课堂教学语境下的具体化 |

## 第二十四章　项目化学习（PBL）

### 24.1 理论来源

| 来源 | 代表 |
|------|------|
| **国际** | 克拉斯克&布卢门菲尔德，《基于项目的学习》（载《剑桥学习科学手册》）；BIE/PBLWorks"黄金标准PBL" |
| **中国本土** | 夏雪梅（上海市教育科学研究院），《项目化学习设计：学习素养视角下的国际与本土实践》（教育科学出版社，2018/2021第2版） |

### 24.2 夏雪梅的项目化学习四特征

| 特征 | 含义 |
|------|------|
| **核心知识的再建构** | 不是脱离知识的"活动"，而是围绕学科核心知识展开的深度加工 |
| **创建真实的驱动性问题和成果** | 驱动性问题必须指向真实情境，成果须公开展示 |
| **用高阶学习包裹低阶学习** | 先设计高阶认知任务（分析/评价/创造），低阶任务（记忆/理解）在其中自然完成 |
| **将素养转化为持续的学习实践** | 不是一个"活动"，而是一个持续数周的学习周期 |

### 24.3 六维度项目设计框架

> 来源：夏雪梅

| 维度 | 核心问题 |
|------|---------|
| **① 核心知识** | 项目指向哪些学科核心知识和概念？ |
| **② 本质问题与驱动性问题** | 什么是这个项目要探究的本质问题？如何转化为能驱动学生探究的驱动性问题？ |
| **③ 高阶认知策略** | 项目要求学生运用哪些高阶认知策略？（如比较、分类、分析、评价、创造） |
| **④ 主要学习实践** | 学生在项目中要经历哪些学习实践？（如探究、实验、调查、创作、展示） |
| **⑤ 学习成果及公开方式** | 最终成果是什么？如何公开展示？ |
| **⑥ 覆盖全程的评价** | 如何设计贯穿项目始终的过程性评价和终结性评价？ |

### 24.4 BIE黄金标准PBL的核心要素

| 要素 | 含义 |
|------|------|
| 具有挑战性的问题/疑问 | 驱动整个项目的核心问题 |
| 持续探究 | 不是一次性活动，而是持续深入 |
| 真实性 | 真实或拟真的情境和任务 |
| 学生的声音和选择 | 学生对项目方向、方式、成果有自主权 |
| 反思 | 贯穿全程的元认知活动 |
| 批判与修正 | 接受反馈、改进成果的过程 |
| 公开展示 | 成果向真实受众展示 |

> **对备课的意义：** PBL为课标中的"综合性学习""跨学科学习""当代文化参与"等任务群提供了直接的设计方法。特别是语文的"整本书阅读与研讨"任务群，天然适合用项目化学习方式实施。

## 第二十五章　差异化教学

> 来源：卡罗尔·安·汤姆林森（Carol Ann Tomlinson），弗吉尼亚大学教授，《多元能力课堂中的差异教学》（1995）

### 25.1 核心理念

> **"差异化教学是教师积极主动地修改课程、教学方法、教学资源、学习活动和学生产出，以最大限度地满足班级里所有学生的不同需求。"**（汤姆林森）

### 25.2 四个差异化维度

| 维度 | 含义 | 教学中的操作 |
|------|------|------------|
| **内容差异化** | 不同学生接触不同层次/角度的内容 | 根据布鲁姆目标分类，为基础薄弱学生设计记忆/理解层次任务，为学有余力学生设计评价/创造层次任务 |
| **过程差异化** | 不同学生用不同方式学 | 提供视觉（文本）、听觉（音频）、动觉（表演）等多种学习通道；灵活分组——独立、两人、小组、全班 |
| **产品差异化** | 不同学生用不同方式呈现成果 | 写札记、画思维导图、做口头汇报、录制视频——多种表达方式评价同一学习目标 |
| **环境差异化** | 不同学生需要不同的学习环境 | 安静独立区 vs 合作讨论区；不同座位安排；不同的时间分配 |

### 25.3 差异化教学的关键原则

| 原则 | 含义 |
|------|------|
| **弹性分组** | 不是固定的"分层"，而是根据任务特点灵活调整分组——有时按兴趣，有时按水平，有时随机混合 |
| **不可见的差异化** | 学生看到的材料不暴露自己是"哪一层"——用组名而非层级名称标记 |
| **渐进支架撤离** | 一节课内支架逐步减少——Task 1 有支架、Task 2 更轻、Task 3 撤掉 |
| **同一目标，不同路径** | 差异化的不是"学什么"，而是"怎么学"和"怎么展示学到了" |

> 核心问题：教师的专业素养由什么构成？备完课后如何持续改进？

## 第二十六章　教师知识基础与PCK

### 26.1 舒尔曼的教师知识七分类

> 来源：李·舒尔曼（Lee S. Shulman），美国斯坦福大学教授，卡内基促进教学基金会主席，"Knowledge and Teaching: Foundations of the New Reform"，《哈佛教育评论》（1987）

舒尔曼指出，传统教师知识研究只关注"学科知识"和"一般教学法知识"，忽略了两者之间的关键领域——他称为**"迷失的范式"（missing paradigm）**。

| 知识类型 | 含义 |
|---------|------|
| ① 学科内容知识 | 所教学科的具体概念、规则、原理及其联系 |
| ② 一般教学法知识 | 各科通用的课堂组织、管理、评估的原则与策略 |
| ③ 课程知识 | 对课程、教材的演变、发展及应用的整体了解 |
| ④ **学科教学知识（PCK）** | **将学科知识转化为学生可理解的形式的专门知识——学科与教学法的"合金"** |
| ⑤ 关于学生的知识 | 学生课前懂什么、不懂什么，如何深入浅出 |
| ⑥ 教育情境知识 | 学校、学区、社区、文化背景对教学的影响 |
| ⑦ 教育目标与价值知识 | 对教育目的（品格发展 vs 升学）的认识 |

### 26.2 PCK的特殊地位

> **PCK是教师知识基础中最有价值的，体现了教师的专业特点，是区分学科专家和教师的独特专业能力。**（舒尔曼）

学科专家"懂学科"，但不一定能把学科知识转化为学生可学的形式；一般教育者"懂教学"，但不一定理解学科内容的深层逻辑。**PCK就是两者交汇处的那种特殊知识——"我知道这个学科内容该怎么教给这类学生"。**

> **对备课的意义：** PCK不是一次性获得的，而是在持续的教学实践中不断积累的。每一篇课文的备课过程，都是PCK的增长过程。教师的专业成长，本质上是PCK的持续建构。

## 第二十七章　行动教育与课例研究

> 来源：顾泠沅（华东师范大学教授、博士生导师，上海市教育科学研究院原副院长），"青浦实验"；《行动教育：教师在职学习的范式革新》

### 27.1 "青浦实验"的背景

1977年恢复高考后，顾泠沅在上海青浦全县4373名高中毕业生数学摸底考试中发现，及格率仅2.8%，零分比例达23.5%。他立下"军令状"，用十年将青浦数学成绩提升到全市平均水平以上。此后持续45年的"青浦实验"成为中国基础教育改革的里程碑。

### 27.2 "三个关注，两次反思"

顾泠沅总结出的教师在职研修"行动教育"范式：

```
关注一：个人已有经验的原行为阶段
                ↓【反思一：已有行为与新理念/新经验的差距】
关注二：新理念之下的课例新设计阶段
                ↓【反思二：教学设计与学生实际获得的差距】
关注三：学生获得的新行为阶段
```

| 阶段 | 关注什么 | 产出什么 |
|------|---------|---------|
| **原行为** | 教师自己的已有经验 | 原始教学方案 |
| **新设计** | 吸收新理念后的改进方案 | 修改后的教学设计 |
| **新行为** | 课堂实施后的学生实际获得 | 课堂观察记录、学生反馈 |

两轮反思分别完成：
- **反思一**：更新理念（从"原来我这么做"到"原来应该这么做"）
- **反思二**：理念向行为转移（从"应该这么做"到"实际做成了什么样"）

### 27.3 于漪的"三次备课"

顾泠沅引用人民教育家于漪的经验：

> **"一篇课文，三次备课，坚持三年，一定能成为好教师。"**

| 备课 | 内容 |
|------|------|
| 第一次 | 不看任何参考，凭自己的理解备（裸备——原行为） |
| 第二次 | 对照参考书和优秀教案，反思差距（新设计） |
| 第三次 | 课后根据学生实际反应，反思教与学的落差（新行为） |

> **对备课的意义：** 备课不是"写完教案就结束"的一次性行为，而是一个"设计→实施→反思→再设计"的持续循环。课例研究提供了让这个循环落到实处的操作框架。

## 第二十八章　LICC听评课范式

> 来源：崔允漷（华东师范大学教授）

课堂观察的四个维度——**L（学习）·I（教学）·C（课程）·文化（C）**：

| 维度 | 观察什么 | 核心问题 |
|------|---------|---------|
| **学习（Learning）** | 学生怎么学？是否有效？ | 学生有没有真正学进去？ |
| **教学（Instruction）** | 教师怎么教？方式是否有效？ | 教师的策略是否促进了学习？ |
| **课程（Curriculum）** | 教的是什么？内容是否合适？ | 教学内容是否准确、合适？ |
| **文化（Culture）** | 课堂氛围如何？师生关系如何？ | 这是什么样的课堂文化？ |

> **对备课的意义：** 备课后的教学实施需要被观察和评估，LICC提供了系统化的观察框架——不只看"教师讲得好不好"，而是从四个维度全面检视课堂质量。

# 第九编　评价技术进阶

> 核心问题：怎么设计具体的评价工具？怎么判断学生思维的深度？

---

## 第二十九章　SOLO分类评价法

> 来源：约翰·比格斯（John Biggs）& 科利斯（Kevin Collis），澳大利亚，1982年。SOLO = Structure of the Observed Learning Outcome（可观察的学习成果结构）

### 29.1 核心理念

与皮亚杰不同，SOLO不对"学生总体认知水平"分类，而是对**学生回答具体问题时的思维结构**分类——不给人贴标签，而是判断"这一次回答"达到了什么层次。

### 29.2 五个思维层次

| 层次 | 含义 | 思维特征 |
|------|------|---------|
| **① 前结构** | 无法理解问题，逻辑混乱或同义反复 | 无有效回答 |
| **② 单点结构** | 只涉及单一要点，找到一个线索就跳到结论 | 点状思维 |
| **③ 多点结构** | 能联系多个要点，但彼此孤立，未形成关联 | 线状思维 |
| **④ 关联结构** | 能将多个要点整合起来，建立合理联系 | 面状思维 |
| **⑤ 抽象拓展结构** | 能抽象概括，从理论高度分析，问题意义得到拓展 | 立体/系统思维 |

> 前三个层次是基础知识的积累（量变），后两个层次是理论思维的飞跃（质变）。

### 29.3 SOLO的优势

| 优势 | 说明 |
|------|------|
| **操作性强** | 无论文科理科，都能根据回答质量划分思维层次 |
| **指导目标设定** | 教师可预设学生应达到的思维层次，循序渐进提升 |
| **检测教学效果** | 清晰显示学生对具体问题的认识水平 |
| **质性评价** | 关注回答的"质"（思维结构）而非"量"（要点数量） |

---

## 第三十章　评价量规（Rubrics）设计

> 来源：威金斯（UbD）；阿特（Arter）& 麦克泰格

### 30.1 量规的两种类型

| 类型 | 特征 | 适用场景 |
|------|------|---------|
| **分析性量规** | 分维度逐项评分 | 详细诊断学生的优势和不足 |
| **整体性量规** | 对整体表现给一个综合等级 | 快速评分，如期末作文评分 |

### 30.2 量规设计的四要素

| 要素 | 含义 |
|------|------|
| **维度** | 评价的几个方面（如：内容、结构、语言、创新） |
| **等级** | 质量层次（如：优秀、良好、合格、待改进） |
| **描述性标准** | 每个维度每个等级的具体表现描述——不能只写"好/中/差"，要写出可观测的行为指标 |
| **权重** | 不同维度在总分中的比重 |

### 30.3 真实性评价

> 来源：威金斯UbD

评价任务应模拟真实世界中的任务——不是"考试题"，而是"实际问题"。

| 特征 | 说明 |
|------|------|
| **真实情境** | 任务发生在真实或拟真的情境中 |
| **综合运用** | 要求综合运用多种知识、技能 |
| **可见成果** | 产出可见的作品、报告、表演 |
| **公开受众** | 成果向真实受众展示（不只是给教师看） |

# 第十编　扩展理论视野

> 以下理论不直接影响日常备课操作，但拓展了理解教学的视野和批判性维度。

---

## 第三十一章　多模态读写

> 来源：New London Group（1996），"A Pedagogy of Multiliteracies: Designing Social Futures"

### 核心命题

在数字时代，"读写"不只是文字读写，还包括：
- **语言**（文字）
- **视觉**（图像、图表）
- **音频**（声音、音乐）
- **空间**（排版、布局）
- **手势**（肢体语言、表情）
- **多模态整合**（以上多种模式的组合）

> **意义：** 课标的"跨媒介阅读与交流"任务群，以及语文教学中的"图文转换""影视鉴赏""新媒体阅读"等内容，都需要多模态读写理论支撑。

---

## 第三十二章　批判教育学与知识社会学

### 32.1 阿普尔——课程是"谁的知识？"

> 来源：迈克尔·阿普尔（Michael Apple），《意识形态与课程》

核心追问：选什么进教材？经典的选择标准是谁定的？课程传递了谁的文化？课程服务于谁的利益？

> **对语文的意义：** 选谁的诗进教材？"经典"的标准是什么？语文教育传递了谁的文化？这些追问不是要否定经典，而是让选择变得**有意识**而非无意识。

### 32.2 弗莱雷——"银行储蓄式教育"与"提问式教育"

> 来源：保罗·弗莱雷（Paulo Freire），《被压迫者教育学》

| 教育模式 | 特征 |
|---------|------|
| **银行储蓄式教育** | 教师把知识"存入"学生头脑，学生被动接收、存储、复述 |
| **提问式教育** | 师生共同提出问题、共同探究、共同建构知识 |

> 弗莱雷的名言："教育不是银行储蓄，而是意义的命名过程。"

### 32.3 布迪厄——文化资本

> 来源：皮埃尔·布迪厄（Pierre Bourdieu）

核心概念：**文化资本**——家庭背景赋予学生的、被学校教育制度认可的知识、技能、品味、习惯。

> **对语文的意义：** 语文教育中的"阅读量""文学品味""语言素养"，在很大程度上受到学生家庭文化资本的制约。好的语文教学要意识到这种起点差异，为文化资本薄弱的学生提供补偿性支持——这就是差异化教学的社会学基础。

---

## 第三十三章　课堂社会学与学习共同体

### 33.1 佐藤学——学习共同体

> 来源：佐藤学（Manabu Sato），东京大学教授，《课程与教师》《教师的挑战》

核心主张：课堂是师生**共同学习的场域**（learning community），不是教师单向传递知识的场所。

三个原则：
1. **公共性**——课堂是向世界开放的公共空间
2. **民主主义**——所有学生平等参与
3. **卓越性**——追求每个学生都能达到的最高水平

### 33.2 课堂话语分析

> 来源：卡兹登（Cazden）、梅汉（Mehan）

经典分析框架——IRF结构：
```
I（Initiation）：教师发起——提问/指令
R（Response）：学生回应——回答
F（Follow-up）：教师跟进——评价/追问
```

研究问题：
- 谁在说话？说话机会如何分配？
- 教师的提问是开放性的还是封闭性的？
- 教师的"跟进"（F）是在真正回应学生，还是在把学生的回答拉回预设答案？

> **对备课的意义：** 课堂互动设计不只是"安排小组讨论"，还要思考：谁有发言权？讨论的结构是开放的还是被教师控制的？
