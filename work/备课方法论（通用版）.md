## 第一编　备课的本质

### 第一章　备课是什么

备课不是"写教案"，也不只是"准备要讲的内容"。不同理论传统对备课的本质有不同界定：

| 理论来源 | 对备课的本质界定 |
|---------|----------------|
| **泰勒原理**（1949） | 备课就是课程开发在微观层面的实施——回答"目标→经验→组织→评价"四个基本问题 |
| **加涅/迪克-凯里** | 备课是系统化教学设计（Instructional Design）——用工程学思维把教学当作可设计的系统 |
| **威金斯UbD** | 备课是"逆向设计"——先想清楚"什么是学会的证据"，再倒推教学活动 |
| **奥苏贝尔** | 备课的核心是"探明学生已经知道了什么，并据此进行教学" |
| **叶澜** | 备课不是写"剧本"，而是预设"可能发生的生命碰撞"——给生成留空间 |
| **崔允漷** | 备课是"学历案"设计——不是备"教什么"，而是备"学生怎样学" |

这些界定不矛盾，而是不同侧重。系统设计派（泰勒/加涅/迪克-凯里）强调备课的**技术规范性**；生成性派（叶澜/施瓦布）强调备课的**艺术性和情境性**；逆向设计派（威金斯/崔允漷）强调备课的**逻辑优先级**。

**好的备课应该三者兼备：既规范又有弹性，且逻辑正确。**

### 第二章　备课不是什么——常见误区

| 误区 | 表现 | 问题所在 |
|------|------|---------|
| **备课=抄教案** | 从教参或网上复制现成教案 | 没有经过自己的思考，教学变成"照本宣科" |
| **备课=写PPT** | 把精力花在做课件上 | 媒体替代了设计，形式掩盖了内容 |
| **备课=备讲稿** | 只准备自己要讲什么 | 忽视了学生要做什么、学什么 |
| **备课一次成型** | 写完教案不再修改 | 缺少迭代改进，无法适应实际学情 |
| **备课脱离学情** | 凭经验或想象设计 | 不了解学生实际水平，目标定得太高或太低 |

## 第二编　备课的理论基础

### 第三章　教学设计过程模型

备课的理论根基是教学设计理论。以下三个模型从不同角度为备课提供了流程框架。

#### 3.1 ADDIE模型

教学设计领域最通用的流程框架，由五个阶段构成：

```
A (Analysis  分析)
  ├── 学习者特征分析：学生是谁？认知水平如何？已有知识是什么？
  ├── 任务分析：教学内容的核心要素是什么？知识结构如何？
  └── 需求分析：为什么要教这个？学生缺什么？

D (Design  设计)
  ├── 目标设计：学生学完后能做什么？（可观测的行为目标）
  ├── 评估设计：用什么证据证明学生学会了？
  ├── 策略设计：用什么方法/模式来教？
  └── 媒体设计：用什么资源/工具来支持？

D (Development  开发)
  └── 制作教案、PPT、学案、素材、评价工具

I (Implementation  实施)
  └── 上课——将设计付诸实践

E (Evaluation  评估)
  ├── 形成性评价：过程中随时收集反馈，修正设计
  └── 总结性评价：课后评估目标达成度
```

ADDIE的"A→D→D"三步对应备课，"I→E"对应上课和反思。ADDIE是**迭代循环**的——评估的结果反馈回分析阶段，开始下一轮改进。

#### 3.2 迪克-凯里（Dick & Carey）系统方法模型

比ADDIE更细化，九个步骤构成闭环：

```
① 确定教学目标
      └→ 这节课/单元要达到什么目标？目标从课标、教材、学情三方综合确定
② 进行教学分析
      └→ 目标中包含的知识和技能是什么？画出目标的知识结构图
③ 分析学习者与情境
      └→ 学生已有基础、认知特点、学习偏好；教学环境条件
④ 编写绩效目标
      └→ 将①的目标细化为可观测、可测量的具体行为目标
⑤ 开发评估工具
      └→ 为每个目标设计对应的检测方式——注意：评估在策略设计之前！
⑥ 制定教学策略
      └→ 选择教学模式、教学方法、媒体和资源
⑦ 开发选择教学材料
      └── 制作教案、学案、PPT等
⑧ 设计和实施形成性评价
      └→ 一对一试教→小组试教→全班试教，收集反馈
⑨ 修改教学
      └── 根据形成性评价的结果修订教学设计和材料
```

**关键特征：** 第④步写目标→第⑤步立刻开发评估工具→第⑥步才设计教学策略——这是逆向设计在系统方法中的体现。迪克-凯里模型比ADDIE更适合用于**精确到课时的备课**。

#### 3.3 加涅的九大教学事件与备课的关系

加涅的九大教学事件（详见《教学环节技术与技巧（通用版）》）为备课提供了**完整性检查清单**。备完课后，对照九大事件检查：

| 教学事件 | 备课中是否设计了对应环节？ |
|---------|----------------------|
| ①引起注意 | 有没有导入设计？ |
| ②告知目标 | 有没有明确告诉学生学什么？ |
| ③刺激回忆先备知识 | 有没有激活旧知的环节？ |
| ④呈现刺激材料 | 有没有呈现新内容的方式设计？ |
| ⑤提供学习指导 | 有没有支架/方法/框架的提供？ |
| ⑥引出行为表现 | 有没有让学生练习/完成任务？ |
| ⑦提供反馈 | 有没有设计反馈机制？ |
| ⑧评价行为表现 | 有没有检测目标达成的方式？ |
| ⑨促进保持与迁移 | 有没有迁移到新情境的设计？ |

> 很备课的问题出在：有①④⑥，但缺少②③⑤⑦⑨——即有导入、有讲解、有练习，但没明确目标、没激活旧知、没给支架、没反馈、没促迁移。

### 第四章　"三备""六备"传统

中国教学论中流传最广的备课经验概括。

#### 4.1 "三备"

| 维度 | 含义 | 关键问题 |
|------|------|---------|
| **备教材** | 深入研读教学内容 | 教学内容的本质是什么？重点难点在哪里？ |
| **备学生** | 分析学情 | 学生已经知道了什么？可能遇到什么困难？ |
| **备教法** | 选择教学方法与策略 | 用什么方式让学生学会？ |

"三备"对应泰勒"目标来源三要素"中的"学科知识"和"学生需要"两个维度。

#### 4.2 "六备"（扩展版）

在"三备"基础上增加三个维度：

| 新增维度 | 含义 |
|---------|------|
| **备学法** | 学生用什么方式学最有效？提供怎样的学法指导？ |
| **备教学媒体** | 用什么媒体/资源来支持教学？ |
| **备作业** | 设计什么样的作业来检测和巩固？ |

## 第三编　备课的基本原则

### 第五章　八条基本原则

综合各理论来源，备课遵循以下基本原则：

| 原则 | 来源 | 具体含义 |
|------|------|---------|
| **① 目标先导原则** | 泰勒/ADDIE | 先定目标，再选内容和方法。目标是一切教学设计的起点。 |
| **② 逆向设计原则** | 威金斯/崔允漷 | 目标→评价→教学活动，评价设计先于教学活动设计。只有先确定"什么是学会的证据"，教学活动才有方向。 |
| **③ 教-学-评一致性原则** | 崔允漷 | 教的（目标）、学的（活动）、评的（检测）必须指向同一个目标。三者脱节是课堂效率低下的根本原因。 |
| **④ 学情优先原则** | 奥苏贝尔/王荣生 | "影响学习的唯一最重要的因素，就是学习者已经知道了什么。"备课必须先了解学情，据此设计。 |
| **⑤ 系统设计原则** | 迪克-凯里 | 备课是一个系统过程，各要素（目标、内容、方法、评价、媒体）相互关联，不能孤立处理。 |
| **⑥ 预设与生成统一原则** | 叶澜 | 既要充分预设，又要给课堂生成留空间。教案不是剧本，课堂不是演出。 |
| **⑦ 现实联结原则** | 杜威"教育即生活" | 任何知识都应该与现实结合起来，才有素材基础和生命力。备课的第一步不是"文本有什么可以教"，而是"这节课能回应学生什么真实的困惑"。 |
| **⑧ 迭代改进原则** | ADDIE形成性评价/顾泠沅行动教育 | 备课不是一次性的，而是"设计→实施→评价→修改"的循环。好的教案是改出来的。 |

### 第六章　各原则之间的关系

这八条原则不是平行的，而是有层级关系：

```
现实联结（⑦）           ← 最高统领：为什么备课？一切为了让学生与现实发生真实的碰撞
    ↓
目标先导（①）+ 逆向设计（②） ← 逻辑骨架：目标→评价→活动
    ↓
学情优先（④）           ← 输入条件：一切设计基于学情
    ↓
系统设计（⑤）+ 教-学-评一致性（③） ← 内部约束：各要素协调统一
    ↓
预设与生成统一（⑥）      ← 弹性空间：给课堂留出生命碰撞的可能
    ↓
迭代改进（⑧）           ← 持续优化：课后反思→修改→再设计
```

**现实联结原则（⑦）是最高统领**——它回答的不是"怎么备课"，而是"为什么要备课"。如果不与现实联结，备课就退化为技术操作，失去了教育的根本意义。

## 第四编　备课的层次结构

### 第七章　三个层次

备课不是一个粒度，而是从宏观到微观的三个层次：

| 层次 | 时间跨度 | 核心任务 | 产出 |
|------|---------|---------|------|
| **学期备课** | 一学期（约18周） | 研读课程标准；通读整册教材；了解全年级/全班学情；制定学期教学计划 | 学期教学进度表 |
| **单元备课** | 一个单元（2-4周） | 研读单元整体；确定单元大目标和核心任务；设计任务序列；统筹课时分配 | 单元教学方案/大单元设计 |
| **课时备课** | 一节课（40-45分钟） | 具体到每节课的目标、活动、评价、板书、作业 | 课时教案/学历案 |

### 第八章　三者之间的关系

三者是**从宏观到微观的递进关系**：

```
学期备课 → 定方向（整个学期往哪走）
    ↓
单元备课 → 定结构（这个单元怎么组织）
    ↓
课时备课 → 定细节（这节课怎么上）
```

**常见问题：** 只做课时备课，不做学期和单元备课——结果是"只见树木不见森林"，每节课之间缺少联系，学生学完一个单元后形不成整体认知。

**大单元教学的要求：** 在崔允漷的大单元设计理念下，单元备课变得尤为重要——单元是"指向素养的、相对独立的、体现完整教学过程的课程细胞"。课时备课必须服从单元整体设计。

## 第五编　课时备课完整流程

### 第九章　九步备课流程

综合迪克-凯里、ADDIE、崔允漷学历案、"三备"传统，课时备课的完整流程如下：

```
Step 0：现实之问
    └→ 这节课的知识能回应学生什么真实的困惑？
        怎样让知识与现实发生真实的联结？

Step 1：课标与教材研读
    └→ 这节课对标什么课标要求？
        在教材单元中处于什么位置？
        和前后内容有什么联系？

Step 2：学情分析
    └→ 学生已经知道了什么？
        可能遇到什么困难？
        最近发展区在哪里？

Step 3：确定教学目标
    └→ 用可观测的行为动词描述目标
        区分基础/提高/拓展层次
        对标核心素养

Step 4：设计评价任务（逆向设计的核心）
    └→ 什么证据表明学生达成了目标？
        设计怎样的检测/任务？

Step 5：设计教学过程
    └→ 导入→任务序列→结课
        每个环节标注：教师活动、学生活动、设计意图、时间

Step 6：准备教学资源
    └→ PPT、学案、板书设计、素材材料

Step 7：设计作业
    └→ 分层设计；检测目标达成；促进迁移

Step 8：预设反思点
    └→ 可能出问题的地方？应对方案？
        课后反思要点
```

### 第十章　为什么Step 0是"现实之问"

传统备课流程从"课标与教材研读"开始，走的是**"文本→学生"的单向传递**路线。这条路线的结构性缺陷是：**"现实意义"永远只能排在最后，变成锦上添花的附属品**。

如果备课从**"学生的现实困惑"**开始，一切都会翻转：

| 如果从"教材"开始 | 如果从"现实之问"开始 |
|----------------|-------------------|
| 教材定位 → 文本解读 → 目标设定 → 活动 → （最后补上现实意义） | 现实困惑 → 文本能回应什么 → 设计怎样的相遇 → 课标目标自然达成 |
| 文本到学生的单向传递 | 学生到文本的双向对话 |

**现实之问的理论依据：**
- **杜威**："教育即生活"——教学情境必须是真实的生活情境，不是虚假的"为了教学而造的情境"。
- **马扎诺自我系统**：如果学生觉得"这跟我没关系"，认知设计再好都白搭。自我系统的激活方式就是"与真实生活相关联"。
- **余党绪"母题"**：母题就是文本核心价值与学生人生关怀的交叉点——"确立母题"就是在回答"这篇课文为什么和今天的生命有关"。

**操作方法：** 在备任何一节课时，先问自己三个问题：
1. **这节课的知识在现实中对应什么真问题？** （不是"这个知识点有什么用"，而是"它回应了什么人类经验中的困惑"）
2. **学生此刻的生命处境和这个知识有什么交叉？** （16岁的学生会关心这个问题吗？怎样让他们感到"这跟我有关"？）
3. **怎样在课堂中创造知识与现实的碰撞？** （设计什么情境/任务/活动能让这种联结真正发生？）

## 第六编　备课各环节的具体操作方法

### 第十一章　Step 1 课标与教材研读

#### 11.1 要研读什么

| 研读内容 | 要读出什么 |
|---------|---------|
| **课程标准** | 这节课对应什么学段目标？什么素养要求？什么内容领域？ |
| **教材单元导语** | 单元主题是什么？单元目标是什么？ |
| **课文/教学内容** | 核心内容是什么？体式特点是什么？重点难点在哪里？ |
| **教学参考/教师用书** | 编者意图是什么？有哪些教学建议？哪些内容需要"留白"给教师发挥？ |
| **前后课文** | 这课和前面已学的有什么联系？和后面将学的有什么衔接？ |

#### 11.2 教材研读的三个层次

```
第一层：通读——整体感知
    └→ 这课在讲什么？结构是什么？

第二层：细读——发现精彩处和疑难处
    └→ 哪里最精彩？哪里最难？哪里容易引起争议？

第三层：研读——找到"那一个"
    └→ 这课不可替代的独特价值是什么？什么是别的课文教不了而它才能教的？
```

### 第十二章　Step 2 学情分析

#### 12.1 分析什么

| 分析维度 | 具体方法 |
|---------|---------|
| **已有知识基础** | 前测、课前问卷、回顾上次作业、课堂提问抽样 |
| **认知发展水平** | 按皮亚杰阶段论判断学生能处理什么层次的内容；大多数学生处于什么水平 |
| **可能的困难点** | 根据教学经验和教学内容预判学生会卡在哪里 |
| **兴趣与动机** | 这个年龄段的学生关心什么？怎样引发关联？（对接Step 0现实之问） |
| **个体差异** | 班级里有哪些不同层次的学生？需要怎样差异化？（对接汤姆林森差异化教学） |

#### 12.2 学情分析的工具

| 工具 | 适用场景 |
|------|---------|
| 前测题 | 检测已有知识基础，3-5题即可 |
| KWL表 | K（已知什么）→ W（想知道什么）→ L（学到了什么），课前填K和W |
| 观察记录 | 回顾前几节课学生的表现，找出薄弱环节 |
| 个别访谈 | 对代表性学生（好/中/差各一名）做简短交流 |

> **奥苏贝尔原话：** "影响学习的唯一最重要的因素，就是学习者已经知道了什么，要探明这一点，并应据此进行教学。"

### 第十三章　Step 3 确定教学目标

#### 13.1 目标编写法——ABCD法

| 要素 | 含义 | 示例 |
|------|------|------|
| **A** Audience（对象） | 谁来学？ | "全班学生" / "基础组学生" |
| **B** Behavior（行为） | 能做什么？ | "能分析X与Y的关系" |
| **C** Condition（条件） | 在什么条件下？ | "在阅读文本后，借助注释" |
| **D** Degree（程度） | 达到什么水平？ | "准确识别至少两处，并说明原因" |

**完整示例：** "在通读全文后（C），全班学生（A）能分析X与Y的关系（B），准确指出至少两处关联并说明理由（D）。"

#### 13.2 动词选择要匹配认知层次

布鲁姆认知层次（修订版）对应的行为动词：

| 认知层次 | 可用动词 | 不可用动词 |
|---------|---------|----------|
| ①记忆 | 列举、识别、复述、默写 | "了解"（不可观测） |
| ②理解 | 解释、总结、比较、转述 | "掌握"（不可观测） |
| ③应用 | 运用、演示、解决、操作 | — |
| ④分析 | 区分、归因、解构、对比 | — |
| ⑤评价 | 判断、批判、辩护、评估 | — |
| ⑥创造 | 设计、建构、创作、编排 | — |

> **关键：** 避免使用"了解""掌握""体会""感受"等不可观测的词。用可观测的行为动词替代——能看出学生有没有做到。

#### 13.3 目标分层

| 层次 | 面向 | 目标特点 |
|------|------|---------|
| **基础目标** | 全体学生必须达成 | 对应布鲁姆①②③层次 |
| **提高目标** | 多数学生应达成 | 对应布鲁姆④层次 |
| **拓展目标** | 学有余力学生挑战 | 对应布鲁姆⑤⑥层次 |

### 第十四章　Step 4 设计评价任务

#### 14.1 逆向设计的核心操作

> **先设计评价，再设计教学活动。** 这不是"最后出考题"，而是"先确定什么算学会了"。

| 评价类型 | 时间点 | 设计方式 |
|---------|-------|---------|
| **诊断性评价** | 课前 | 前测题、知识检索——检测已有基础 |
| **形成性评价** | 课中 | 提问、讨论观察、课堂任务完成情况、 exit ticket |
| **总结性评价** | 课后 | 作业、小测、项目成果——检测目标达成度 |

#### 14.2 评价与目标的对应关系

**每个教学目标至少有一个评价任务来检测。** 如果目标写了三个，但作业只检测了一个，就违反了教-学-评一致性。

| 目标 | 对应的评价任务 |
|------|-------------|
| 目标1：能复述…… | 课堂提问 / 填空 |
| 目标2：能分析…… | 讨论任务 / 短文分析 |
| 目标3：能评价…… | 议论写作 / 辩论 |

#### 14.3 评价工具

| 工具 | 来源 | 适用 |
|------|------|------|
| SOLO分类法 | 比格斯 | 评估回答质量的结构层次 |
| 评价量规（Rubrics） | 威金斯/阿特 | 表现性任务的评分标准 |
| 选择性反应评价 | 传统 | 客观题检测记忆和理解 |
| 交流性评价 | — | 口头问答、讨论观察 |
| 表现性评价 | 威金斯UbD | 真实或拟真情境中的综合任务 |

### 第十五章　Step 5 设计教学过程

这是教案的核心部分。每个教学环节应包含四个要素：

```
环节名称（如"任务一：探究XX"）
├── 教师活动：教师做什么？（讲解/提问/展示/巡视/点拨）
├── 学生活动：学生做什么？（阅读/讨论/练习/展示/思考）
├── 设计意图：为什么这样设计？（对应哪个目标？理论依据是什么？）
└── 时间分配：多少分钟？
```

#### 15.1 教学过程的基本结构

```
导入（3-5分钟）
    └→ 情境创设 / 问题引发 / 旧知激活

主体活动（30-35分钟）
    ├── 任务/活动1（8-12分钟）
    ├── 任务/活动2（8-12分钟）
    └── 任务/活动3（8-12分钟）

结课（3-5分钟）
    └→ 归纳总结 / 检测反馈 / 拓展延伸
```

> 具体的导入技术、提问技术、讲解技术、结课技术、板书技术等，详见《教学环节技术与技巧（通用版）》。

#### 15.2 教学模式的选择

不同教学内容适合不同的教学模式。根据乔伊斯《教学模式》四大类：

| 教学内容特点 | 推荐模式 | 典型操作 |
|------------|---------|---------|
| 需要归纳概念 | 信息加工类（概念获得模式） | 给正例和反例→学生归纳→验证 |
| 需要合作探究 | 社会互动类（合作学习模式） | 分组任务→小组讨论→全班分享 |
| 需要个性化表达 | 个人发展类（非指导性教学） | 自由写作/个性化阅读 |
| 需要技能训练 | 行为系统类（直接教学） | 讲解→示范→练习→反馈 |

### 第十六章　Step 6 准备教学资源

| 资源类型 | 内容 | 注意事项 |
|---------|------|---------|
| PPT/课件 | 核心观点、任务说明、图片素材 | 每页一个核心观点，避免满屏文字 |
| 学案/导学案 | 学生课堂使用的学习支架 | 与教学过程同步，不是额外负担 |
| 板书设计 | 提前设计好板书结构 | 与讲解同步，不要先写完再讲 |
| 补充材料 | 拓展阅读、视频片段、实物 | 紧密服务教学目标，不堆砌 |
| **AI生成图片** | 场景示意图、概念可视化图、背景图 | 见§16.1–16.4 |

#### 16.1 什么时候需要AI生成图片

不是每节课都需要配图。配图服务于两个目的：**入境**（帮助学生建立情境感）和**解惑**（将抽象概念具象化）。满足以下任一条件才考虑生成图片：

| 适用场景 | 举例 |
|---------|------|
| **需要建立空间/环境情境** | 地理地貌、历史场景、实验装置 |
| **抽象概念需要可视化** | 细胞结构、物理力场、数学几何关系 |
| **学生缺乏直接经验的远距离事物** | 异国风俗、古代器物、微观/宏观现象 |
| **需要一个统一的视觉背景来串联课堂** | 单元主题PPT的统一风格背景 |

> **反面清单——以下情况不需要配图：** ①学生已有充分生活经验的内容（强行配图多余）；②文字本身已经是最佳呈现方式的内容；③纯粹为了"PPT好看"而与教学目标无关的装饰图。

#### 16.2 AI图像生成的基本原则

| 原则 | 含义 | 违反后果 |
|------|------|---------|
| **风格统一** | 整份课件使用同一种视觉语言（同一画种、同一色调体系） | 视觉混乱，增加 extraneous cognitive load（Mayer一致性原则） |
| **服务于教学目标** | 每张图都应能回答"这张图帮助学生理解什么？" | 图片变成装饰，分散注意力 |
| **信息适度** | 一张图只传达一个核心信息，背景简洁 | 信息过载，学生不知道看哪里 |
| **准确性** | 涉及科学/历史的内容必须事实正确 | 传播错误信息 |
| **版权意识** | AI生成图片仅限教学内部使用，不公开发表牟利 | — |

#### 16.3 AI图像生成的操作流程

```
① 确定需求
    └→ 这张图解决什么认知障碍？
       是场景图（建立情境）、示意图（解释概念）、还是背景图（烘托氛围）？

② 选择视觉风格
    └→ 整份课件已确定什么风格？（写实/插画/水墨/扁平化/3D…）
       新图必须与已有图片保持同一风格

③ 编写Prompt
    └→ 基本结构：主体 + 风格 + 构图 + 色调 + 细节约束 + 禁止元素
       示例："一座宋代风格的拱桥，工笔水墨画风格，鸟瞰视角，
              色调以青绿为主，桥下有流水和远山，留白，
              不要现代建筑，不要文字"

④ 生成与筛选
    └→ 一次生成4张，选最佳；必要时迭代修改prompt再生成

⑤ 校验
    └→ 准确性：内容有没有事实错误？
       风格：和课件整体统一吗？
       构图：有没有干扰元素？需不需要裁切？
```

#### 16.4 Prompt工程速查

| 参数维度 | 常用选项 | 说明 |
|---------|---------|------|
| **画种/风格** | 水墨、工笔、油画、水彩、版画、摄影、3D渲染、扁平插画、线稿 | 决定整份课件的视觉基调 |
| **构图** | 特写、全景、鸟瞰、侧视、俯视、散点透视 | 决定画面信息密度 |
| **色调** | 暖色调、冷色调、单色、低饱和、高对比 | 决定情绪基调——与文本气质匹配 |
| **氛围词** | 宁静、苍凉、热烈、肃穆、梦幻 | 让AI理解你想要的情感基调 |
| **禁止元素** | "no text, no watermark, no modern objects" | 防止AI加入干扰元素 |
| **留白** | "generous negative space" / "minimalist composition" | 避免画面太满，留出PPT文字位置 |

### 第十七章　Step 7 设计作业

已在《教学环节技术与技巧（通用版）》第七编详述，核心要点：

| 原则 | 操作 |
|------|------|
| 素养导向 | 作业不是巩固知识，而是发展素养 |
| 分层设计 | 基础层 + 提高层 + 拓展层 |
| 针对性 | 针对本课重难点和学情 |
| 教-学-评一致 | 作业必须检测教学目标 |
| 适量性 | 严格控制总量和时间 |

### 第十八章　Step 8 预设反思点

叶澜说好的备课要"预设可能发生的生命碰撞"。预设反思不是课后的事，而是**备课时就要做的前瞻**。

#### 18.1 三种预设

| 预设类型 | 问自己的问题 |
|---------|-----------|
| **预判难点** | 学生在哪里会卡住？如果卡住了，我怎么搭支架？ |
| **预判生成** | 学生可能说出什么意想不到的回答？怎么接？接住后怎么推进？ |
| **预判时间** | 哪个环节可能超时？超时了怎么压缩？哪个环节可能提前结束？余下的时间做什么？ |

#### 18.2 课后反思的维度

| 维度 | 反思问题 |
|------|---------|
| 目标达成 | 预设的目标达成了吗？哪些没达成？为什么？ |
| 学情判断 | 课前对学情的判断准确吗？实际和预想有什么差异？ |
| 活动效果 | 哪个活动效果最好？哪个最差？为什么？ |
| 生成事件 | 课堂上发生了什么意料之外的事？处理得好不好？ |
| 改进方向 | 下次再上这课，会怎么调整？ |

## 第七编　教案规范格式

### 第十九章　教案应包含的内容

| 部分 | 内容 | 必需/可选 |
|------|------|----------|
| **课题信息** | 课题、学科、年级、课时、执教者、日期 | 必需 |
| **教材分析** | 本课在单元中的地位；教学内容的特点分析 | 必需 |
| **学情分析** | 学生已有基础；可能的困难点；个体差异 | 必需 |
| **教学目标** | 对标核心素养，分层描述，用可观测动词 | 必需 |
| **教学重难点** | 重点是什么、难点是什么 | 必需 |
| **教学方法与策略** | 用什么方法、什么模式、什么媒体 | 必需 |
| **教学过程** | 导入→任务→结课，每环节含教师活动/学生活动/设计意图/时间 | 必需（核心） |
| **板书设计** | 提前设计好结构 | 必需 |
| **作业布置** | 分层设计 | 必需 |
| **教学反思** | 课后补写 | 课后 |
| **教学资源清单** | PPT、学案、素材列表 | 可选 |

### 第二十章　教案 vs 学历案

崔允漷提出"学历案"概念，与传统教案有本质区别：

| 维度 | 传统教案 | 学历案 |
|------|---------|--------|
| **核心问题** | 教师教什么？怎么教？ | 学生学什么？怎么学？ |
| **主体** | 教师的活动 | 学生的活动 |
| **目标表述** | "使学生理解……" | "我能……" / "我会……" |
| **过程设计** | 教师讲解步骤 | 学生学习步骤 |
| **评价方式** | 教师检测学生 | 学生自我检测 |
| **使用者** | 教师 | 教师+学生 |

> 学历案不是替代教案，而是**视角的转换**——从"教的设计"转向"学的设计"。在崔允漷的框架下，学历案包含六个要素：单元名称与课时、学习目标、评价任务、学习过程（含资源与建议）、作业与检测、学后反思。

## 第八编　集体备课与迭代改进

### 第二十一章　集体备课的规范

集体备课不是"分工写教案然后拼在一起"，而是**专业对话的过程**。

#### 21.1 集体备课的基本流程

```
个人初备 → 集体研讨 → 修改完善 → 课后反思
```

| 阶段 | 操作 |
|------|------|
| **个人初备** | 每人独立研读教材和课标，形成自己的教学思路 |
| **集体研讨** | 围绕"教什么""怎么教""为什么这样教"展开讨论，碰撞不同观点 |
| **修改完善** | 主备人根据讨论结果修改教案，形成共享教案 |
| **个性化调整** | 各教师根据自己班学情做个性化调整 |
| **课后反思** | 实施后交流效果，记录改进点 |

#### 21.2 集体备课的讨论焦点

好的集体备课不应只讨论"怎么教"，而应聚焦三个更深层的问题：

1. **教学内容的确定**：这课到底该教什么？（不是"怎么讲"，而是"教什么值得教"）
2. **学情的差异**：不同班级的学生可能有什么不同的反应？
3. **目标与评价的一致性**：目标合理吗？评价能检测目标吗？

### 第二十二章　迭代改进——行动教育

顾泠沅（华东师范大学）提出的"行动教育"模式，是备课迭代改进的规范方法。

#### 22.1 "三个关注、两个反思"

```
原行为阶段              新设计阶段              新行为阶段
（教师原有教学）    →    （课例研究后的新设计） →    （改进后的教学）
     ↕                      ↕                      ↕
  关注已有经验           关注新理念新设计         关注学生获得
     ↕                      ↕                      ↕
  反思1：寻找差距        反思2：寻找改进策略      （回到反思1，新一轮循环）
```

#### 22.2 课例研究的操作

| 步骤 | 操作 |
|------|------|
| ①选定课题 | 选一节有代表性的课作为研究对象 |
| ②原行为观察 | 教师按原有设计上课，团队听课观察 |
| ③反思讨论 | 课后围绕"学生学到了什么""哪里出了问题"展开讨论 |
| ④新设计 | 根据讨论结果重新设计教学 |
| ⑤新行为观察 | 教师按新设计上课，团队再次听课 |
| ⑥对比反思 | 对比两次教学的效果差异，提炼经验 |

> 这一模式的关键不在于"改教案"，而在于**通过实践检验备课设计的有效性**——教案写得好不好，最终要由课堂效果来回答。
