# S4 教学物料手册

## 条目

### MM-S4-01 同源单点生成
- 优先级：P0
- 条件：制作任何物料
- 动作：全部产物由 lesson.json 单一数据源生成；改数据不改产物、绝手工分叉
- 判据：manifest SHA 链完整；跨文件页码标记一致
- 出处：P-11
- 预期信号：改一处数据全部产物同步更新

### MM-S4-02 前台禁词零容忍
- 优先级：P0
- 条件：任何学生可见文字
- 动作：后台设计语言不上屏；舞台指令只入备注
- 判据：run_principle_checks frontstage_banned 0 命中
- 出处：P-07 / A-T07
- 预期信号：学生第一眼看见诗文而非控制语

### MM-S4-03 字号下限表
- 优先级：P0
- 条件：排任何文本
- 动作：原文≥28pt（按行数 39/32/27 自适应）、短语卡≥26、产物槽与释义≥22、标题 36 起、层级差≥1.4×
- 判据：构建器断言 + 视觉审查实测字号
- 出处：PPT手册§二 / 判例 v8
- 预期信号：后排可读（课堂验证）

### MM-S4-04 首答态标题留开放
- 优先级：P0
- 条件：写任何首答态页标题
- 动作：标题只命名文学对象或留开放问题；断言式标题仅限后置完成态与讲解页
- 判据：标题首眼泄答测试（A-T13）
- 出处：N-04 / U1
- 预期信号：首答独立性（课堂抽样）

### MM-S4-05 版式等权与源序交错
- 优先级：P0
- 条件：排首答态材料组
- 动作：等大、同色、对齐托盘且源序交错语义族——行列均不成分组键
- 判据：视觉审查 + 数据源顺序核对
- 出处：P-42 / M-22
- 预期信号：首答分布不集中于“正确”区

### MM-S4-06 分发时点拆件
- 优先级：P0
- 条件：制作学生纸质材料
- 动作：会泄露后页信息的拆独立物件；登记首次发放事件与台词
- 判据：真实分发顺序测试（A-T11）+ 分发时点表
- 出处：P-25 / U1
- 预期信号：跨渠道泄答为零

### MM-S4-07 QA 渲染环
- 优先级：P0
- 条件：任何构建后
- 动作：soffice→PDF→逐页 PNG→非作者新鲜眼检查→修复→复验，至少一轮修复闭环
- 判据：渲染检查记录在案（含发现-修复-复验）
- 出处：PPT手册§七 / P-29
- 预期信号：首渲染缺陷全部被捕获

### MM-S4-08 前台朗读测试
- 优先级：P0
- 条件：任何学生可见文字成文
- 动作：教师读出声不生硬；学生第一次听就知道面对谁、想什么、做什么
- 判据：人检记录逐页通过
- 出处：P-13 / J4
- 预期信号：课堂指令零二次解释

### MM-S4-09 色彩纪律
- 优先级：P1
- 条件：配色时
- 动作：一页≤3色、语义全程恒定（蓝语言/绿结构/红情感）、60-30-10 支配、深浅页交替
- 判据：视觉审查 + 色板一致性检查
- 出处：PPT手册§三 / J5
- 预期信号：色彩不成为泄答或干扰渠道

### MM-S4-10 密度四步治理
- 优先级：P1
- 条件：内容多、怕挤时
- 动作：①分流（屏/口/单/板书）→②认知单元分块→③骨架导航→④密度预算（≤7要点/原文≤200字）；遮页复述检验
- 判据：连续理解审计（A-T15/T12）
- 出处：PPT手册§八
- 预期信号：学生能复述连贯整体而非碎片
