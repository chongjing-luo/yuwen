# S2 文本研究手册

## 条目

### MM-S2-01 裸读先行
- 优先级：P0
- 条件：研究任何课文
- 动作：先只读正文记录第一遍真实困惑（不查注释）——学生困难的预演
- 判据：裸读笔记在档，先于任何参考阅读
- 出处：U4 / 手法库§一
- 预期信号：预判困难命中率（课堂验证）

### MM-S2-02 解释边界四层
- 优先级：P0
- 条件：做任何关键判断
- 动作：区分文本明写/教材注释/合理推断/现代延伸，逐条标注
- 判据：边界标注覆盖全部关键判断；越界即退回
- 出处：P-09 / U6
- 预期信号：学生答题区分“诗写/我推断”

### MM-S2-03 KP 挂诗句锚点
- 优先级：P0
- 条件：整理知识清单
- 动作：每个教级 KP 挂到具体诗句位置；挂不上的决定教或 defer
- 判据：锚点表成文且诗句在文本契约内
- 出处：P-04 / K2
- 预期信号：知识在文本位置生长（课堂）

### MM-S2-04 困难归 17 类
- 优先级：P0
- 条件：预判学习困难
- 动作：困难必须落到手法库的具体类型，禁止“基础弱”式不可操作描述
- 判据：困难清单可归类且有文本依据
- 出处：M-02 / U4
- 预期信号：手法选择有据

### MM-S2-05 三问起草与想知道审查
- 优先级：P0
- 条件：设计全课问题前
- 动作：以初读者身份起草三问并过“想知道”审查（读第一遍是否真想问）
- 判据：审查记录在档；问不出悬念的组重写
- 出处：J4
- 预期信号：课堂对问题有真实反应

### MM-S2-06 关系边真实
- 优先级：P1
- 条件：连接已学课文
- 动作：关系边引用真实 CARD-ID 并注明关系性质
- 判据：关系边可解析
- 出处：N-03 / K4
- 预期信号：跨课文比较可用
