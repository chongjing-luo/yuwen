# S1 规划手册

## 条目

### MM-S1-01 KP 落点或 defer
- 优先级：P0
- 条件：制定单元/学期规划
- 动作：图谱全部教级 KP 落到课时或写明显 defer 与理由
- 判据：规划表逐 KP 可查；无悬空 KP
- 出处：N-01 / K1
- 预期信号：规划即教学内容清单

### MM-S1-02 复现排程
- 优先级：P0
- 条件：排课时
- 动作：每个核心 KP ≥2 次提取式激活（课堂首答/作业闭卷/单元卷/跨课回投），间隔 ≥1 周
- 判据：排程表成文且可执行
- 出处：N-02 / K3
- 预期信号：延迟测验收率提升（课堂）

### MM-S1-03 跨课回投清单
- 优先级：P1
- 条件：涉及已学内容时
- 动作：回投边引用真实卡片 ID，注明回投方式
- 判据：关系边全部可解析（validate_lesson_schema relations）
- 出处：N-03 / K4
- 预期信号：学生主动调用旧知识（观察表）

### MM-S1-04 负荷分布预排
- 优先级：P1
- 条件：排连续课时时
- 动作：避免连续两课时都是高强度综合课；高峰分散
- 判据：负荷分布图成文
- 出处：K5 / P-35
- 预期信号：累计疲劳判 P0 为零

### MM-S1-05 消费学情输入
- 优先级：P1
- 条件：规划某单元前
- 动作：读取上次 mastery 热图，弱 KP 进入回教排程
- 判据：规划文档引用了诊断报告
- 出处：D3-⑦ 快环
- 预期信号：弱 KP 在下一单元被回教
