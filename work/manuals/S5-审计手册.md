# S5 审计放行手册

## 条目

### MM-S5-01 冻结标准版本
- 优先级：P0
- 条件：任何审查开始时
- 动作：记录 STANDARD 版本与注册库哈希；审查期间标准变更不影响本轮
- 判据：审查回执含版本与哈希
- 出处：收敛规则 / J7
- 预期信号：无标准漂移争议

### MM-S5-02 不追溯否决
- 优先级：P0
- 条件：想用新规则翻旧候选时
- 动作：新原则进下一版本，只约束此后的新候选
- 判据：按冻结标准评审；新规则登记版本
- 出处：收敛规则§二
- 预期信号：候选不因标准前移被反复推翻

### MM-S5-03 删除审判
- 优先级：P0
- 条件：评审任何页面
- 动作：默认本页应删除；设计者举证删后哪段理解会实际断裂；“好看/讲得顺/做了很久”非理由
- 判据：相邻合并与因果链测试（A-T12）
- 出处：P-39 / U5
- 预期信号：页页有不可替代损失

### MM-S5-04 六门审计
- 优先级：P0
- 条件：逐页过审
- 动作：G1 前置缺失/G2 功能重复/G3 覆盖虚假/G4 变化不可观察/G5 产物孤儿/G6 可无损合并逐门过
- 判据：validate_meng_v6_page_audit（重型）或逐门人审
- 出处：A-05..A-10
- 预期信号：已知退化不进候选

### MM-S5-05 反退化测试组
- 优先级：P0
- 条件：逐页复核
- 动作：23 项测试重点跑：教师抢答/多渠道泄答/活动遮蔽故事/程序成本/协议指纹
- 判据：各测试结论入审查 JSON
- 出处：A-T01..T23
- 预期信号：高频病史不复发

### MM-S5-06 双审独立与缺陷否决
- 优先级：P0
- 条件：放行前
- 动作：视觉+学生接收双审，审查者与作者分离；P0/P1/P2 任一存在即不放行，不以平均分妥协
- 判据：双审回执 P0-P2 清零（或按收敛放行）
- 出处：P-21 / J7
- 预期信号：审查先于用户发现问题

### MM-S5-07 全课节奏五维
- 优先级：P1
- 条件：页面审计完成后
- 动作：五维矩阵审计全课；连续三页三维修相同原则上返工
- 判据：节奏矩阵成文
- 出处：P-33 / A-T17
- 预期信号：模板疲劳不出现

### MM-S5-08 模块重建触发
- 优先级：P1
- 条件：模块失败率高时
- 动作：>1/4 物理画面被判 P0-P2 或同根因贯穿≥3 页→停止局部润色，重划页面
- 判据：重建决定与范围记录
- 出处：P-43
- 预期信号：旧错误边界不遗留

### MM-S5-09 放行停止规则
- 优先级：P0
- 条件：判断何时停止打磨
- 动作：连续两轮仅 P3（且登记观察方法）→ 以“桌面已验·待试教”放行进 S6
- 判据：放行凭证含两轮记录
- 出处：收敛规则§三
- 预期信号：桌面回归终止于试教而非更严桌面

### MM-S5-10 诚实声明
- 优先级：P0
- 条件：任何审查报告
- 动作：报告必须写明“真实课堂仍待试教”；课堂断言只能引 L4
- 判据：报告含边界声明；selfcheck 课堂账分列
- 出处：P-12
- 预期信号：两本账永不混写
