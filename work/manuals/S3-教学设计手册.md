# S3 教学设计手册

## 条目

### MM-S3-01 评估标准先于页面
- 优先级：P0
- 条件：开始设计任何页面前
- 动作：先写该页失败信号与学生动作、产物、第一次后用（P-37）；无预期判据不开工
- 判据：页面数据含 failure_signals 且非模板；审查可依此判返工
- 出处：P-37 / U8
- 预期信号：课堂出现预设失败信号时能被观察表捕获

### MM-S3-02 页面合同十八字段
- 优先级：P0
- 条件：填写任何逻辑页
- 动作：前页输入/困难/唯一功能/信息状态/动作/产物/等待/反馈/修订/后用/反例/视觉职责/接收/删除损失/连续增量等全填且具体
- 判据：validate_lesson_schema 通过；字段针对本页内容而非通用话术
- 出处：A-01 / P-15
- 预期信号：审查者能沿字段证明接收链

### MM-S3-03 反样板
- 优先级：P0
- 条件：任何追溯字段成文
- 动作：禁止 contract() 默认模板串；每字段写该页具体情形
- 判据：check_trace_evidence --strict 0 发现
- 出处：P-28 / LRN-20260814-001
- 预期信号：双审不再出现“字段齐全但无证据”页

### MM-S3-04 KP 落点或显式 defer
- 优先级：P0
- 条件：确定教学内容时
- 动作：knowledge_refs 解析到知识卡；每个教级 KP 有落点页或带理由 defer
- 判据：validate_lesson_schema K1 检查通过
- 出处：N-01 / K1
- 预期信号：作业与测验可按同一 KP 闭环

### MM-S3-05 三问以“学生想知道”为准
- 优先级：P0
- 条件：起草全课问题
- 动作：三问须是初读者真实会问的问题，开头设问、逐章存证、文末回收
- 判据：模拟初读审查通过；三问措辞与回收页一致
- 出处：J4 / P-05
- 预期信号：课堂首答阶段学生对问题有真实反应

### MM-S3-06 参与五要素
- 优先级：P0
- 条件：设计核心活动
- 动作：个人生成→小组共作→公开表达→听众任务→可见修订五环齐备
- 判据：participation_path 声明五环；审查核对
- 出处：P-14 / J1
- 预期信号：主动开口率与生成证据达标（S6 度量）

### MM-S3-07 首答态四渠道保护
- 优先级：P0
- 条件：任何学生生成任务
- 动作：屏幕、教师台词、学习单、版式四渠道不得提前泄答
- 判据：多渠道泄答测试（A-T04/T13）+ 版式等权检查
- 出处：P-34 / P-42 / U1
- 预期信号：首答非空白抽样率高

### MM-S3-08 反例诚实路径
- 优先级：P0
- 条件：任何任务设计
- 动作：想不起/不同意/沉默有同等可见可完成路径，无需伪造
- 判据：normal_counterexample 覆盖该页反例类型且非模板
- 出处：P-17 / U7
- 预期信号：沉默学生真实完成率（S6 度量）

### MM-S3-09 手法由困难选择
- 优先级：P1
- 条件：为页面选手法时
- 动作：先归类困难（手法库 17 类）再选法；连续页底层协议不同构
- 判据：unique_difficulty 可归类；去同质化审计通过
- 出处：P-20 / M-02
- 预期信号：课中后段投入度维持

### MM-S3-10 时间盒单对象
- 优先级：P1
- 条件：排页面时间
- 动作：单页一个主要认知对象；timeboxes 秒和=分钟×60
- 判据：时间盒守恒检查 + 累计负荷审计（A-T22）
- 出处：P-22 / P-35
- 预期信号：实际耗时与预算偏差 ≤10%

### MM-S3-11 教师后置归纳与精讲位置
- 优先级：P1
- 条件：安排师生活动
- 动作：生成在前、精讲置后；归纳引用学生原话；示范一处再迁移
- 判据：教师归纳责任测试（A-T09/T16）
- 出处：P-23 / P-32
- 预期信号：学生生成材料被公开使用（J3）

### MM-S3-12 全课节奏五维预排
- 优先级：P1
- 条件：成课后
- 动作：认知/感官/社会/作品/情绪五维自检，连续三页三维同构即返工
- 判据：rhythm_matrix 成文；协议指纹测试（A-T17）
- 出处：P-33 / J5
- 预期信号：中后段课堂投入不衰减
