## 条目标准格式（六字段）

```
### MM-<环节>-<序号> <规则名>
- 优先级：P0|P1|P2（P0 核心=执行前必读；P1 常用；P2 备查）【所有者裁决：不设数量上限，以优先级管理】
- 条件：什么情形下适用
- 动作：做什么
- 判据：怎样算做对（含审查门/校验器名）
- 出处：注册库锚点（原则 ID / 机制节点）
- 预期信号：做对了课堂应出现什么证据（节点课堂度量）
```

## 准入与归档

- 新增条目：节点绑定 + 触发事件（准入法庭不变）；
- 归档：修订时旧版整体移入本目录 `archive/`，同 DEVLOG 协议；
- 防腐：条目登记被哪些 skill 步骤引用，长期零引用触发处置（§5.3）。
