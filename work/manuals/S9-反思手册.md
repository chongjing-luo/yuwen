# S9 反思沉淀手册

## 条目

### MM-S9-01 先证据后判断
- 优先级：P0
- 条件：写任何反思
- 动作：每个结论必须引用观察记录/作品/台账；“很顺”不是证据
- 判据：反思逐条有证据引用
- 出处：J7 / P-12
- 预期信号：反思不流于感想

### MM-S9-02 归因到节点
- 优先级：P0
- 条件：分析问题
- 动作：现象→设计侧原因（具体页面/字段）→机制节点编号
- 判据：反思含节点列
- 出处：设计方案§3.5
- 预期信号：修订有明确落点

### MM-S9-03 原则修订走收敛准入
- 优先级：P0
- 条件：提案新规则时
- 动作：触发证据+服务节点+强制方式+进入下一版本；不追溯否决本轮
- 判据：提案过注册库准入检查
- 出处：收敛规则§四 / D3-⑧
- 预期信号：方法论不膨胀

### MM-S9-04 learnings 回流 promote
- 优先级：P1
- 条件：沉淀经验时
- 动作：重大发现记 LRN 条目；Recurrence ≥2 自动升格为原则提案
- 判据：LEARNINGS.md 条目含复发计数
- 出处：§5.3
- 预期信号：教训不重付

### MM-S9-05 下一轮决定落到字段
- 优先级：P0
- 条件：结束反思
- 动作：课程数据修改清单/回教 KP/新增观察信号都落到具体字段与位置
- 判据：决定清单可直接执行
- 出处：设计方案§6 S9 跳
- 预期信号：迭代可执行非口号
